# 临床微生物实验诊断：知识梳理

> 资料依据：`04实验诊断.pdf`，共 186 页。该文件的实际主题为临床微生物实验诊断，涵盖采样、细菌、病毒、真菌及医院感染。页码指原PDF顺序。
> 原课件中的保存时间、标本量、计数阈值等，在下文均作为教学示例保留；实际解释必须联系标本、病原体、试剂及实验室流程。

## 一、核心脉络：从标本到有临床意义的结果

```text
临床怀疑感染
    ↓
根据受累部位与病程选择标本和项目
    ↓
正确采集、标识、保存、运送
    ↓
镜检 / 培养 / 抗原抗体 / 核酸与测序
    ↓
病原鉴定，必要时药敏及耐药机制检测
    ↓
判断：真正致病、定植、污染，还是结果仍不确定
    ↓
联系临床表现，沟通、报告、随访和院感监测
```

**本章的中心：检出微生物后，还要建立它与患者疾病之间合理的因果联系。** 标本质量、解剖部位、宿主免疫状态与检测方法共同决定结果的含义。

## 二、先分清五个概念

对应第 9～14 页。

| 概念 | 核心含义 | 典型思考 |
| --- | --- | --- |
| 正常菌群/微生物群 | 特定部位存在的微生物群落 | 在原部位检出，不一定致病 |
| 条件致病 | 宿主防御下降、菌群失衡或微生物异位后致病 | 大肠埃希菌在肠道与在尿路中的意义不同 |
| 定植 | 微生物存在并可繁殖，未造成相应感染性疾病证据 | 呼吸道、皮肤、生殖道常需考虑 |
| 感染 | 病原与宿主相互作用并建立感染过程 | 可以尚无明显临床疾病表现 |
| 感染性疾病 | 感染引起临床病理损伤及相应疾病表现 | 不能与“任一检测阳性”画等号 |

另需区分：**污染**发生于采集、运送或检测等环节，检出的微生物未必来自真正感染灶。

内源性感染来自自身菌群等，外源性感染来自外界。医院感染是医疗场景下获得的感染，不能把它仅限于医务人员直接传给患者。

## 三、分析前质量：为什么采样决定检验价值

对应第 7、21～26 页。

### 3.1 采样原则

1. **位置正确**：标本应代表感染灶，避免仅获得表面背景菌。
2. **时机合适**：尽早采集，尽可能在抗微生物治疗前获得有价值的标本。
3. **量足够**：标本量不足可造成假阴性，血培养尤其受采血量影响。
4. **减少污染**：无菌部位与有菌部位标本的解释逻辑不同。
5. **项目匹配**：容器、保存液、温度和运送方式须适合拟检测的病原及方法。
6. **信息完整**：身份、部位、采样时间、采样者及相关临床信息应可追溯。

### 3.2 运送及拒收

- 课件以尽快、通常2小时内送检为一般原则，但不同标本有特殊要求。
- 容器须密闭防漏，使用合适的生物安全转运包装。
- 无标识、泄漏、错误容器、严重延迟或保存不当，均可能使标本失去解释价值。
- 难以重新取得的侵入性标本应与临床沟通，由实验室评估处理和报告限制。
- 课件“同日重复标本不处理”是特定流程的教学表述，不能推广为所有项目的统一规则。

**关键记忆：不是所有标本都放冰箱，也不是所有标本都用同一种培养/运送体系。**

## 四、常见标本：采什么、怎么解释

对应第 27～59 页。

### 4.1 血培养

| 要点 | 目的 |
| --- | --- |
| 皮肤及瓶塞消毒，给予消毒剂足够作用时间 | 降低皮肤菌污染 |
| 静脉血，标本量与培养瓶匹配 | 提高阳性检出率 |
| 通常使用多套培养，并按需要配置需氧/厌氧瓶 | 增加检出机会，也帮助判断污染 |
| 尽早采样，尽可能在抗菌药物前 | 降低治疗后的假阴性 |
| 接种后尽快送检，避免冷藏 | 保护病原体及检测流程有效性 |

课件采血量示例：婴儿0.5～2 mL、儿童2～5 mL、成人10～20 mL。实际需按体重、培养瓶和采样方案确定，不能理解为所有年龄段、每一瓶均固定使用该量。

**不必为了等待体温高峰而延迟血培养。** 课件强调采血量与采集质量比“恰好在发热峰采血”更重要。课件所引“两套敏感性98%”是特定研究数据，不作为所有情境的固定性能。

### 4.2 脑脊液CSF：同一标本，不同项目保存要求不同

| 检查方向 | 课件原则 |
| --- | --- |
| 细菌培养 | 尽快送检，避免冷藏导致某些脆弱病原体受损 |
| 病毒相关检测/培养 | 按所检病毒和方法使用相应低温保存及运送条件 |

由专业人员无菌采集，明确检测项目并及时分装。不要把细菌培养的要求直接套用到全部CSF检测。

### 4.3 呼吸道标本

上呼吸道包括咽、鼻咽等拭子；下呼吸道包括深咳痰、支气管肺泡灌洗液BALF、保护性毛刷及组织等。

- 咽/鼻咽取材需到达目标部位，避免仅擦过口腔或鼻前部。
- 痰应尽量为深部咳出的呼吸道分泌物，唾液不能代替合格痰标本。
- 上呼吸道存在大量正常菌群，因此非无菌部位培养的结果不能只按“有菌/无菌”解释。
- 百日咳等特殊病原需提前告知实验室，选用相应标本和培养/检测体系。

**痰的低倍镜质量评估，按第47页教学表：**

| 类别 | 白细胞/低倍视野 | 鳞状上皮细胞/低倍视野 | 课件评价 |
| --- | --- | --- | --- |
| A | >25 | <10 | 合格 |
| B | 10～25 | 10～25 | 合格 |
| C | <10 | >25 | 不合格 |

理解核心：**白细胞体现炎症背景，较多鳞状上皮细胞提示口咽污染。** 该表不作为所有人群、所有病原检测的统一拒收标准。

### 4.4 尿培养

常用清洁中段尿，目标是减少外生殖器和尿道口菌群污染。尽快送检；延迟时按实验室要求低温保存或使用合适保存体系，避免细菌在体外增殖影响计数。

第56页的教学判读：

| 标本 | 课件计数示例 | 原课件思路 |
| --- | --- | --- |
| 清洁中段尿 | <5×10⁴ CFU/mL | 课件按较低意义处理，仍报告计数及菌群特点 |
| 清洁中段尿 | 5×10⁴～10⁵ CFU/mL | 纯培养更有意义，混合菌生长需考虑污染 |
| 清洁中段尿 | >10⁵ CFU/mL | 需结合主要菌数量及混合程度进一步鉴定/药敏 |
| 导尿标本 | >10³ CFU/mL | 需结合菌种数、主要生长菌和临床解释 |
| 耻骨上膀胱穿刺 | 任意细菌生长 | 应重视其意义，同时评估采样污染可能 |

**不能把中段尿10⁵ CFU/mL当成全部尿路感染的绝对诊断线。** 症状、性别、采样方式、既往治疗及单一/混合菌生长都会影响解释。

### 4.5 粪便及直肠拭子

- 采集含脓、血、黏液等有病变代表性的部分。
- 避免尿液、清洁剂或消毒液污染。
- 不易取得粪便时，可按项目考虑直肠拭子。
- 课件列Cary-Blair用于沙门菌、志贺菌、耶尔森菌、弯曲菌等运送，碱性蛋白胨水APW用于疑似霍乱弧菌的相应流程。
- 病原体存活能力不同，应尽快运送，不把某一种运送液的可保存时间推广给全部肠道病原。

### 4.6 厌氧标本

重点是**代表感染灶并尽量隔绝空气**。组织或抽吸物往往比表面拭子更有价值，应使用专用厌氧运送条件。

## 五、细菌感染诊断：镜检、培养、鉴定、药敏

对应第 60～96 页。

### 5.1 血流感染与阳性血培养处理

血流感染可来自心内膜、导管等血管内病灶，也可由尿路、呼吸道、腹腔等血管外病灶播散而来。菌血症可为短暂、间歇或持续。

**菌血症与脓毒症并非同一个概念。** 血培养结果与机体临床反应、器官功能应分别评估。

```text
血培养仪报警阳性
    ↓
尽快涂片和革兰染色，描述可确认的形态
    ↓
结合形态选择分离培养基
    ↓
纯培养、鉴定、药敏及必要复核
    ↓
及时沟通，报告并联系临床解释
```

课件列血平板、巧克力平板作为基本培养体系，并按需增加麦康凯、厌氧或真菌培养基。自动血培养系统可通过微生物代谢产生CO₂等信号监测生长。

### 5.2 镜检的作用与边界

| 方法 | 主要提供的信息 | 不能直接推出的结论 |
| --- | --- | --- |
| 革兰染色 | 革兰反应、形态、排列、炎症细胞等 | 通常不能仅凭涂片确定所有菌种及药敏 |
| 抗酸染色 | 提供抗酸性微生物线索 | 阴性不能排除低菌量感染，阳性也需进一步鉴定 |
| 其他荧光等方法 | 帮助发现着色较弱或数量少的微生物 | 仍需结合相应确认检查 |

课件称涂片为“指南针”：**快、能指方向，但要避免超出证据报告。**

### 5.3 传统鉴定中的常见对应

| 试验 | 课件关联/学习抓手 |
| --- | --- |
| 触酶 catalase | 帮助区分葡萄球菌与链球菌等 |
| 凝固酶 coagulase | 金黄色葡萄球菌鉴定的重要线索 |
| 胆汁七叶苷、6.5% NaCl | 联系肠球菌等鉴别 |
| 奥普托欣敏感 | 肺炎链球菌相关线索 |
| 杆菌肽敏感 | A群链球菌的传统筛查线索 |
| CAMP阳性 | B群链球菌的传统鉴定线索 |

上述试验通常需要组合使用，不将单项反应当作全部鉴定流程。

### 5.4 自动化生化鉴定及药敏

| 平台 | 核心逻辑 | 主要限制 |
| --- | --- | --- |
| ATB/API相关系统 | 读取生化反应模式，与数据库比对；药敏模块观察特定药物条件下生长 | 依赖合适菌种范围、培养物及数据库 |
| VITEK 2 | 自动孵育并动态读取生长/生化信号，输出鉴定及药敏 | 罕见菌、复杂耐药机制等可能需要复核 |

**仪器输出不等于最终无需审核。** 需要确认纯培养、菌种合理性、药敏模式及临床部位，必要时补充表型或分子检查。

### 5.5 MALDI-TOF MS：蛋白指纹鉴定

```text
菌落或经验证的前处理标本
    ↓
样本与基质形成共结晶，经激光解吸/电离
    ↓
飞行时间分析，形成质谱峰
    ↓
与数据库蛋白指纹比对，给出鉴定
```

优点：鉴定快速、通量较高，常用于细菌和酵母等。限制：数据库覆盖、近缘菌区分、前处理及菌量等影响结果；通常仍以培养获得的菌落为常规检测对象。

**两点辨析：**

- 常规质谱鉴定主要回答“是什么菌”，不能自动等同完整药敏。
- 第89页“飞行时间与质荷比成正比”为简化表述；在固定加速条件下，飞行时间与质荷比的平方根相关。

第51页肺炎病例中，痰培养出现多种菌，血培养获得肺炎链球菌。学习重点是结合无菌部位证据、痰中混合菌群和肺炎表现评估病原意义；具体治疗需另结合药敏与临床。

## 六、病毒感染诊断：直接证据与间接证据

对应第 97～140 页。

### 6.1 检测方法总表

| 方法 | 检测对象 | 主要价值 | 主要限制 |
| --- | --- | --- | --- |
| 光镜、包涵体检查 | 感染细胞形态及部分病毒相关结构 | 快速形态线索 | 适用范围有限，通常不足以完整分型 |
| 电镜/免疫电镜 | 病毒颗粒、形态及抗体结合 | 直观观察与研究 | 对设备、菌/病毒量和专业判断有要求 |
| 病毒分离培养 | 能在合适活细胞体系增殖的病毒 | 活病毒证据，研究、分型及药敏等用途 | 较慢，不适用于所有病毒的日常诊断 |
| 病毒抗原 | 病毒蛋白等 | 较快、可用于早期检测 | 阴性受取样和检出限影响 |
| 病毒抗体 | 宿主免疫应答 | 暴露、免疫应答及部分近期感染判断 | 窗口期、既往感染及持续阳性 |
| PCR/RT-PCR、核酸杂交 | 病毒核酸 | 直接检测、定量、分型及部分耐药分析 | 阳性不必然代表活病毒或当前致病性 |
| mNGS等测序 | 标本中的核酸序列 | 疑难病例、广泛病原筛查及新发病原研究 | 背景污染、宿主核酸、数据库和解释难度 |

**“金标准”依具体病毒及临床问题而定。** 课件中“病毒培养是金标准”和“核酸是金标准”不能脱离检测目标理解为相互替代的一条绝对规则。

### 6.2 课件中的抗原与标本对应

- 呼吸道标本：RSV、流感、副流感、腺病毒等。
- 粪便：轮状病毒、腺病毒、星状病毒等。
- 皮损：HSV、VZV等。
- 血液：如CMV pp65抗原检测等。

同样的检测对象，在不同部位标本中的临床意义和敏感性可不同。

### 6.3 核酸检测的基本逻辑

- PCR通过变性、退火、延伸扩增目标序列；RNA目标通常先逆转录。
- 实时荧光检测在扩增过程中记录信号，TaqMan利用特异性探针水解产生信号变化。
- 定量检测可辅助监测病毒载量变化、治疗反应和部分耐药相关问题。
- **病毒载量不等于组织损伤程度。** 第118～119页将核酸高低与病情、预后直接对应的表述过于简化，应结合病毒类型、病程和其他证据。

### 6.4 POCT与一体化核酸平台

POCT强调在现场或接近患者处获得结果。课件展示“样本进、结果出”的提取扩增一体化平台，减少手工步骤、缩短周转时间，但检测通量、靶标范围和成本各有约束。

**POCT描述检测场景和流程，PCR描述检测方法，二者不是同一层级概念。**

### 6.5 mNGS与三代测序

| 技术 | 主要特点 | 解读重点 |
| --- | --- | --- |
| 靶向PCR | 对已知目标进行检测 | 快，但范围受所选靶标限制 |
| 多重/芯片检测 | 同时检测一组预设目标 | 仍依赖面板覆盖 |
| mNGS | 对标本核酸广泛测序并比对 | 适合病原不明等问题，但不能保证检出所有微生物 |
| 三代测序TGS | 长读长，部分平台可实时读取、便携或直接RNA测序 | 不同平台、版本性能不同 |

mNGS报告的序列数、覆盖度和病原名称需要与标本部位、背景信号、宿主状态及其他证据共同解释。**检出序列不等同已证明该病原造成疾病。**

第133页猪疱疹病毒相关病例用于说明疑难病原发现价值；第137页的三代测序准确率数字反映课件所引时期，不当作所有现代平台的固定性能。

## 七、真菌感染诊断

对应第 141～165 页。

### 7.1 方法之间的分工

- **镜检**：快速发现酵母、芽生孢子、菌丝等形态。
- **培养和鉴定**：明确病原种类，提供进一步药敏的基础。
- **组织病理**：观察组织内真菌及侵袭证据，对区分侵袭性感染很重要。
- **抗原/细胞壁成分**：G、GM等辅助早期诊断。
- **分子方法**：补充难培养、低菌量等情况下的证据。

### 7.2 曲霉与白色念珠菌

| 病原 | 课件形态/鉴定重点 | 判读限制 |
| --- | --- | --- |
| 曲霉 | 组织中常见有隔、透明、较均匀菌丝，常呈锐角约45°分枝，可侵犯血管 | 形态可提供方向，但仍需鉴别其他丝状真菌 |
| 白色念珠菌 | 芽生孢子、假菌丝，芽管及厚壁孢子试验；糖同化/发酵、显色培养或质谱 | 非无菌部位检出时需考虑定植 |

显色培养基中，课件以白念绿色、热带蓝色等作为示例。**颜色是初步识别线索，依培养基和培养条件而定，不替代完整鉴定。**

### 7.3 G试验与GM试验

| 比较 | G试验 | GM试验 |
| --- | --- | --- |
| 对象 | （1,3）-β-D-葡聚糖 | 半乳甘露聚糖 |
| 主要覆盖思路 | 较广泛真菌相关成分 | 主要联系曲霉感染 |
| 能否鉴定菌种 | 不能 | 不能鉴定具体曲霉菌种 |
| 临床用途 | 侵袭性真菌感染辅助证据 | 特定高危人群中曲霉感染辅助诊断及监测 |
| 限制 | 非真菌种属特异，存在假阳性及覆盖不足 | 灵敏度受患者群体、标本及治疗等影响，也可交叉反应 |

联合结果的正确读法：

| G/GM组合 | 可提出的方向 | 不能直接得出的结论 |
| --- | --- | --- |
| G＋、GM＋ | 曲霉或其他情境，需结合证据 | 不能凭两阳性直接确诊曲霉病 |
| G＋、GM− | 念珠菌、肺孢子菌等方向，也仍需考虑曲霉 | **不能据GM阴性排除曲霉** |
| G−、GM＋ | 可能为曲霉，也需排查假阳性等 | 不能只因G阴性否认感染 |
| G−、GM− | 证据不足；部分真菌如毛霉相关感染仍需考虑 | 不能排除全部真菌感染 |

**对原课件第164～165页的辨析：** GM表现并非完全不受免疫状态影响；“G阳性、GM阴性排除曲霉”过于绝对。应结合危险因素、影像、培养和组织证据。[IDSA：曲霉病诊断建议](https://www.idsociety.org/practice-guideline/aspergillosis/)

课件所列G试验pg/mL阈值、采血管及保存时限与具体检测体系有关，不作为所有试剂的统一标准。

## 八、非培养炎症指标：辅助判断，不替代病原学

对应第 166～174 页。

### 8.1 PCT降钙素原

课件强调细菌性感染时PCT可升高，其动态变化可辅助评价感染严重程度和治疗反应。

第172页分段数值可作为课件记忆材料：

| PCT，ng/mL | 课件分段含义的概括 |
| --- | --- |
| <0.05、0.05～0.1 | 原课件描述为正常/非细菌感染倾向 |
| 0.1～0.25、0.25～0.5 | 原课件联系局部感染及抗菌药管理 |
| 0.5～2、2～10 | 原课件联系更严重的细菌感染/脓毒症 |
| >10 | 原课件联系重度全身感染及休克等 |

**不能按这个表单独诊断脓毒症、排除细菌感染或决定是否开始抗菌药。** 低PCT不能确保没有局部/早期感染，高PCT也不能替代临床诊断；动态趋势和具体场景比孤立阈值更有价值。[SCCM：Surviving Sepsis Campaign成人指南](https://www.sccm.org/survivingsepsiscampaign/guidelines-and-resources/surviving-sepsis-campaign-adult-guidelines)

### 8.2 SAA、CRP

- SAA是急性时相蛋白，细菌、病毒及其他炎症情况下均可升高。
- CRP也反映炎症，缺乏病原特异性。
- 联合检测可辅助观察模式和动态，不能由“SAA升、CRP不升”就唯一确定病毒感染。

## 九、医院感染：定义、危险因素与微生物学工作

对应第 175～186 页。

### 9.1 定义与边界

课件定义包括在医院内获得、住院期间或出院后发生的感染，通常不包括入院前已发生或已处于潜伏期的感染；工作人员在医院内获得的感染也在讨论范围。

| 情况 | 课件判断思路 |
| --- | --- |
| 无明确潜伏期，入院48小时后发生感染 | 作为医院感染识别的常见时间线索 |
| 与上次住院直接相关的感染 | 可能纳入 |
| 新部位感染或新病原相关感染 | 需排除污染、原混合感染等后评估 |
| 只有定植、没有相应感染证据 | 不等同医院感染性疾病 |
| 创伤或非生物因素引起炎症 | 不是微生物感染的同义词 |

**48小时是课件中的常用判定线索，具体感染类别仍有各自定义。**

### 9.2 危险因素与常见病原

- 易感宿主：原发病重、免疫抑制、老年、婴幼儿等。
- 医疗相关因素：手术、人工气道、呼吸机、导尿、中心静脉导管、长期住院和抗菌药物暴露等。
- 常见病原：MRSA、耐药凝固酶阴性葡萄球菌、VRE，产ESBL/AmpC相关肠杆菌目细菌，铜绿假单胞菌、不动杆菌、嗜麦芽窄食单胞菌等，以及真菌和病毒。

### 9.3 流行环节与检验科任务

传播可来自外源性接触，也可由自身菌群造成内源性感染。**医务人员的手和被污染设备是重要传播媒介。** 课件将内源性感染称为“不可预防”过于绝对，应理解为预防路径与外源性传播不同。

微生物实验室的任务包括：正确收集标本、病原鉴定、药敏、耐药表型检测、及时报告、资料及菌株保存，并支持暴发识别和耐药监测。

## 十、把所有检测放在同一张表中

| 临床要回答的问题 | 优先考虑的证据 | 核心限制 |
| --- | --- | --- |
| 有无微生物形态线索 | 镜检 | 快，但通常鉴定层级有限 |
| 是否存在可生长病原 | 培养 | 受取样、既往治疗、培养条件影响 |
| 是什么菌 | 生化、质谱、分子鉴定 | 数据库及检测范围有限 |
| 对哪些药物敏感 | 标准化AST | 体外结果需结合体内暴露和感染部位 |
| 当前是否有病原核酸 | PCR/测序 | 核酸阳性不自动等同活病原致病 |
| 是否发生过免疫应答 | 抗体 | 有时间延迟，可能持续阳性 |
| 有没有明显宿主炎症反应 | PCT、CRP、SAA等 | 非病原特异 |
| 是侵袭感染还是定植/污染 | 综合临床、标本、病原及组织证据 | 单一阳性通常不足 |
