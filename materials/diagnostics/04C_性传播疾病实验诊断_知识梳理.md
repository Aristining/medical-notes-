# 性传播疾病的实验诊断：知识梳理

> 资料依据：`04CSTD实验诊断2026(1).pdf`，共 44 页。页码指原PDF顺序。
> 本章按“临床表现、病原、标本、检测方法、结果解释”整理。课件中部分培养和HIV流程属于旧教学表述，相关位置另列更新说明。

## 一、核心脉络：先定位综合征，再选择病原检测

```text
生殖道相关症状或暴露线索
    ↓
辨认临床表现
    ├─ 尿道炎 / 宫颈炎：考虑淋球菌、沙眼衣原体等
    ├─ 生殖器溃疡：考虑梅毒、HSV、软下疳等
    ├─ 疣状增生：考虑尖锐湿疣等
    └─ 全身免疫受损或特定暴露：考虑HIV等
    ↓
按病灶、部位和检测目标选标本
    ↓
镜检 / 培养 / 抗原抗体 / 核酸 / 病理
    ↓
结合窗口期、定植、既往治疗及临床表现解释
```

**生殖道感染不都属于性传播疾病。** 固有菌群失衡或条件致病菌也可导致生殖道感染；从生殖道检出微生物，不自动证明它是致病菌或能确定传播方式。

## 二、主要疾病与病原对照

对应第 3～4 页及各病原章节。

| 疾病/综合征 | 主要病原或方向 | 课件表现 | 检验主线 |
| --- | --- | --- | --- |
| 淋病 | 淋病奈瑟菌 | 男性尿痛、尿道脓性分泌物，女性可少症状 | 合适标本，核酸和/或培养；培养可进一步做药敏 |
| 非淋菌性尿道炎、宫颈炎 | 沙眼衣原体等，必要时考虑其他病原 | 尿痛、非典型分泌物、宫颈炎表现 | 直接病原检测，不能仅凭症状认定某一种病原 |
| 梅毒 | 梅毒螺旋体 | 一期硬下疳、二期皮肤黏膜等表现，晚期可多器官受累 | 病灶直接检测＋两类血清学试验 |
| 软下疳 | 杜克雷嗜血杆菌 | 多发、疼痛性溃疡，可伴腹股沟淋巴结炎 | 特殊病原检测/培养，普通涂片价值有限 |
| 性病性淋巴肉芽肿 | 特定沙眼衣原体感染 | 淋巴结炎、腹股沟肿大等 | 围绕衣原体及相应病型评估 |
| 生殖器疱疹 | HSV-1/HSV-2 | 簇集疱疹、水疱、溃疡，潜伏与复发 | 病灶核酸或培养，必要时其他检测 |
| 尖锐湿疣 | HPV | 乳头状、菜花状增生 | 典型皮损临床识别，必要时活检 |
| HIV感染/艾滋病 | HIV | CD4⁺T细胞及免疫功能受损，机会性感染等 | 感染筛查/补充检测，另行评估CD4和病毒载量 |
| 巨细胞病毒病 | CMV | 课件强调孕期及先天感染相关影响 | 结合感染时相、标本和临床目的检测 |

**无症状不能排除感染。** 尤其不能因女性缺少明显尿道症状，就否认淋球菌或衣原体感染。

## 三、标本选择：取对部位比单纯增加项目更重要

对应第 6～11、30 页。

### 3.1 共同原则

- 根据病变部位和病原选择尿液、尿道/宫颈/阴道拭子、病灶渗液、血液或组织。
- 标本量足够，减少外生殖器常住菌污染。
- 拭子、容器和保存液与培养/核酸等项目匹配。
- 及时送检，避免病原失活或核酸质量下降。
- 分开理解病原检测和血清学检测：两者取材对象与解释时间窗不同。

### 3.2 常用标本与目标

| 标本 | 适用思路 | 注意点 |
| --- | --- | --- |
| 男性尿道分泌物 | 淋球菌等镜检、培养或其他直接检测 | 减少尿道口背景菌污染，确保标本代表病灶 |
| 女性宫颈/阴道相关拭子 | 根据病原和方法选择 | 宫颈和阴道不是可随意互换的部位 |
| 尿液 | 某些核酸检测的合适标本 | 依试剂要求留取，不能一律使用中段尿规则 |
| 硬下疳底部组织液 | 梅毒螺旋体直接检测 | 清除表面脓痂，获取代表性渗液；阴性不排除 |
| 疱疹/溃疡病灶标本 | HSV等直接检测 | 病损阶段和取样质量影响检出 |
| 血清 | 梅毒、HIV及特定病毒血清学 | 注意窗口期、既往感染/治疗 |
| 组织活检 | 不典型增生或需要病理鉴别的病损 | 提供组织结构和细胞病变证据 |

### 3.3 两个容易混淆的采样规则

**淋球菌培养：** 对保存运送条件敏感。课件强调尽可能床边接种、合适选择培养基、CO₂和潮湿环境，目的是保持病原活性。

**衣原体/淋球菌核酸检测：** 常用标本依检测体系而定；男性首段尿、女性阴道拭子是常见选择。不能把普通细菌尿培养的“清洁中段尿”要求机械套用到所有STI核酸检测。[CDC：衣原体检测标本](https://www.cdc.gov/std/treatment-guidelines/chlamydia.htm)

## 四、淋病奈瑟菌

对应第 12、15、39～40 页。

### 4.1 直接镜检

**有症状男性尿道分泌物中，多形核白细胞内革兰阴性双球菌是重要线索。**

但女性宫颈标本及咽、直肠等部位，类似微生物和背景菌影响较大，不能将男性有症状尿道标本的镜检价值原样推广。

### 4.2 培养

课件列巧克力及改良Thayer-Martin等培养体系，约35℃、5% CO₂、潮湿环境，观察后进一步鉴定。

培养价值：

- 获取活菌并鉴定。
- **为药物敏感性试验提供菌株。**
- 治疗失败及耐药监测时尤其重要。

### 4.3 更新：培养并非唯一筛查方法

第15、39～40页“培养是唯一筛查方法”“核酸检测不常用”的表述需要更新。NAAT已是淋球菌检测的重要方法，培养在获得菌株和药敏方面仍不可替代。[CDC：淋球菌诊断](https://www.cdc.gov/std/treatment-guidelines/gonorrhea-adults.htm)

| 方法 | 最重要的分工 |
| --- | --- |
| 镜检 | 特定标本中快速提供线索 |
| NAAT | 直接检测病原核酸，适合相应部位和筛查/诊断场景 |
| 培养 | 获得活菌，进一步鉴定与药敏 |

## 五、沙眼衣原体及非淋菌性生殖道感染

对应第 14、21～23、39～40 页。

### 5.1 课件中的抗原与荧光检测

- 宫颈拭子/刮片可通过荧光标记观察细胞内抗原。
- 胶体金免疫层析可检测衣原体相关LPS抗原。
- 夹心检测由捕获抗体与标记抗体识别抗原，形成检测线。

**胶体金判读：**

| 质控线C | 检测线T | 一般理解 |
| --- | --- | --- |
| 有 | 有 | 在规定读数时间内，按试剂规则判阳性 |
| 有 | 无 | 阴性，但可能低于检出限 |
| 无 | 任意 | 无效 |

阴性含义是“本次未检出达到该方法检出水平的目标”，不能直接变成“绝无感染”。

### 5.2 现代检测框架

生殖道沙眼衣原体检测通常以适用的NAAT为重要方法。血清学不能替代无并发症生殖道局部感染的直接病原检测。[CDC：衣原体诊断](https://www.cdc.gov/std/treatment-guidelines/chlamydia.htm)

课件中抗原快检与传统染色仍可用于理解技术原理，但不应据此认定它们在所有场景优于核酸检测。

## 六、支原体与脲原体：先分清具体病原

对应第 17～20、39～40 页。

### 6.1 课件培养的代谢原理

| 病原 | 课件代谢特点 | 指示剂变化逻辑 |
| --- | --- | --- |
| 解脲脲原体Uu | 分解尿素产氨 | pH升高，酚红由偏黄色变红 |
| 人型支原体Mh | 利用精氨酸产氨的相关代谢 | pH升高，指示剂变红 |

课件列CFU和CCU等定量概念，以培养或代谢引起的颜色变化估算数量。

### 6.2 不能把“培养阳性”直接等同“致病”

- Uu、Mh等可在生殖道检出而没有相应疾病，需考虑定植与临床意义。
- **生殖支原体M. genitalium与Uu、Mh不是同一种病原。** 其常规诊断强调NAAT，不能套用Uu/Mh的显色培养原理。[CDC：生殖支原体诊断](https://www.cdc.gov/std/treatment-guidelines/mycoplasmagenitalium.htm)
- 第18～19页“培养是所有生殖道支原体感染金标准”“≥10⁴即可诊断”的表述不能普遍适用于所有支原体、所有标本和患者。

学习重点是：**具体菌种＋炎症证据＋合适标本＋检测范围**，再解释阳性结果。

## 七、梅毒：两类血清学试验的分工是本章重点

对应第 11、13、24～28、41 页。

### 7.1 直接检测

硬下疳等病灶渗液可在暗视野下观察细长螺旋体及运动特征，或用其他适用方法检测。

阳性可提供直接病原学证据；阴性可能与取材、病原数量、治疗或病损消退有关，不能直接排除梅毒。

### 7.2 两类血清试验对照

| 比较 | 非梅毒螺旋体试验 | 梅毒螺旋体特异性试验 |
| --- | --- | --- |
| 常见方法 | **RPR、TRUST、VDRL** | **TPPA、TPHA、FTA-ABS**，以及相关免疫分析 |
| 检测对象 | 针对类脂抗原的反应素等 | 针对梅毒螺旋体相关抗原的抗体 |
| 主要用途 | 与特异性检测配合诊断，定量滴度用于随访 | 提供特异性抗体证据，协助确认 |
| 假阳性考虑 | 自身免疫病、其他感染、妊娠等 | 仍需联系检测性能和临床背景 |
| 治疗后 | 滴度可下降，也可能持续低滴度 | 常可长期阳性 |
| 能否单项判断当前活动与治愈 | 不能 | **不能把持续阳性当作治疗失败** |

**记忆：RPR/TRUST/VDRL重在“反应素及滴度”，TPPA等重在“特异性抗体证据”。**

### 7.3 传统流程与反向流程

```text
传统思路：先非梅毒螺旋体试验，再以特异性试验确认
反向思路：先自动化特异性免疫分析，再做定量非梅毒螺旋体试验
```

不一致时需结合病史、其他特异性方法及必要复查。不能将“非特异性永远只筛查、特异性永远只确证”理解为唯一检测顺序。[CDC：梅毒血清学与检测流程](https://www.cdc.gov/std/treatment-guidelines/syphilis.htm)

### 7.4 两类结果组合的思考方向

依据两类试验性质，可归纳以下解释方向；这张表不是自动诊断表：

| 非梅毒螺旋体 | 特异性试验 | 应考虑 |
| --- | --- | --- |
| ＋ | ＋ | 当前或既往感染，结合滴度、症状和治疗史 |
| − | ＋ | 既往治疗、部分晚期感染、很早期感染或假阳性等 |
| ＋ | − | 生物学假阳性等，也需结合风险与复查 |
| − | − | 未见血清学证据，但窗口期等仍可能存在 |

### 7.5 前带现象与滴度随访

**前带现象：抗体过多使抗原抗体反应不能形成预期可见结构，出现假阴性，稀释后可能转阳。**

定量随访应尽量采用同一种方法、同一实验室。滴度四倍变化相当于两级倍比稀释，例如1∶32降至1∶8，而1∶32降至1∶16仅为两倍变化。[CDC：滴度变化的解释](https://www.cdc.gov/std/treatment-guidelines/syphilis.htm)

### 7.6 神经梅毒与先天梅毒：不能只看IgM

- 课件强调脑脊液VDRL、细胞数和蛋白等证据与神经梅毒的联系。
- 神经梅毒需结合神经系统表现、血清学与CSF结果综合分析。
- IgM通常不经胎盘，因此具有特定感染时相和母婴解释价值，但**单项IgM不能独立确诊或排除神经梅毒/先天梅毒**。
- 第41页脑脊液数值为课件教学线索，不是全部人群统一且充分的诊断条件。

## 八、生殖器疱疹HSV

对应第 30～34、42 页。

### 8.1 课件技术

| 方法 | 观察/检测对象 | 意义 |
| --- | --- | --- |
| 病灶刮片染色 | 多核巨细胞、核内包涵体 | 疱疹病毒相关细胞病变线索 |
| 免疫荧光/酶免疫 | 病变细胞中的病毒抗原 | 提供直接抗原证据 |
| 培养 | 可增殖病毒 | 活病毒证据，敏感性受病损阶段等影响 |
| PCR/NAAT | 病灶病毒核酸 | 直接检测病原的重要方法 |
| 型特异性抗体 | 针对HSV类型的免疫反应 | 特定情况下辅助评估，不能简单定位到当前病灶 |

### 8.2 结果解释

- 有病灶时，可用病灶NAAT或培养等适用方法确认，不要求每个病例都必须“培养加PCR”同时阳性。
- 刮片细胞改变不能单独可靠区分HSV类型。
- 病损愈合、病原间歇排出或取样不足时，直接检测阴性不能完全排除。
- 不能用一般化的“所有病毒IgM阳性即近期感染”规则判读HSV；HSV IgM并非推荐的常规诊断依据。[CDC：生殖器疱疹诊断](https://www.cdc.gov/std/treatment-guidelines/herpes.htm)

## 九、HPV感染与尖锐湿疣

对应第 32、36～37、43 页。

### 9.1 课件病理特征

- 乳头瘤样/疣状增生，棘层肥厚、角化改变。
- **挖空/空泡化细胞**：核周空晕、核改变等，是课件重点形态线索。
- 无典型挖空细胞不能直接排除相应病变，需要完整病理和临床评估。

### 9.2 必须分开三个问题

| 问题 | 检查关注点 |
| --- | --- |
| 是否有典型尖锐湿疣 | 皮损临床表现，必要时活检 |
| 是否检出HPV核酸 | 适用标本的核酸检测及分型 |
| 是否存在宫颈癌前病变风险 | 按相应宫颈筛查/诊断流程评估 |

**HPV核酸阳性不等同已经患癌，也不直接等同尖锐湿疣。** 对典型尖锐湿疣，HPV检测不能替代临床诊断；不典型病损可需活检。[CDC：尖锐湿疣的诊断](https://www.cdc.gov/std/treatment-guidelines/anogenital-warts.htm)

## 十、HIV：感染检测、免疫状态与病毒载量分工

对应第 33～36、44 页。

### 10.1 三条检测线

| 检查线 | 主要检查 | 回答的问题 |
| --- | --- | --- |
| 感染状态 | HIV抗体或抗原抗体联合筛查，依规范补充检测 | 是否感染HIV |
| 免疫状态 | CD4⁺T细胞计数 | 免疫系统受损程度如何 |
| 病毒复制及治疗反应 | HIV RNA病毒载量 | 病毒复制及治疗控制情况如何 |

**HIV感染与已经进入艾滋病期不是同一个判断。** 筛查有反应也不等同已经完成感染确诊。

### 10.2 窗口期

HIV RNA、p24抗原和抗体出现的时间不同，不同类型试剂的窗口期也不同。第44页“抗体4～8周甚至更久”的数字不能当作全部检测方法统一的排除时点。

核酸检测可在特定早期或补充检测场景提供重要信息，病毒载量则另用于治疗相关监测。

### 10.3 原课件WB规则需要更新

第35、44页主要叙述传统抗体筛查后WB确认，且列出固定条带组合及较长随访方案。这些内容用于理解WB原理，不能作为不分试剂和场景的现行诊断规则。

我国《全国艾滋病检测技术规范（2025年修订版）》明确要求抗体确证不确定时进行核酸检测，尽快明确感染状态。应采用规范的筛查、复检及补充检测流程。[中国疾控中心：2025版规范发布说明](https://ncaids.chinacdc.cn/sjb/gzdt_10321/202510/t20251024_313118.htm)

## 十一、检测方法的总对照

| 方法 | 最主要优势 | 最主要限制 | 本章例子 |
| --- | --- | --- | --- |
| 直接镜检 | 快速，看到形态/细胞病变 | 敏感性及特异性依标本和病原差异大 | 男性淋球菌尿道炎、梅毒暗视野 |
| 培养 | 活病原、菌株和药敏 | 慢、病原存活与条件要求高，部分病原难培养 | 淋球菌等 |
| 抗原 | 直接检测病原成分、速度快 | 低于检出限可阴性 | 衣原体快检、HSV抗原 |
| 抗体 | 梅毒/HIV等感染评估的重要证据 | 窗口期、既往感染/治疗、持续阳性 | 两类梅毒血清学试验 |
| 核酸 | 直接检测、敏感，可分型/部分耐药检测 | 目标范围及标本合适性，阳性需临床解释 | 淋球菌、衣原体、HSV、HIV等 |
| 病理 | 显示组织结构及细胞改变 | 取材和病变代表性影响结果 | 不典型疣状病损等 |

## 十二、复习提纲

### 12.1 建议优先记住

1. 生殖道感染、性传播感染、定植是不同概念。
2. 同样是尿标本，中段尿培养与STI首段尿核酸检测不能混用规则。
3. 有症状男性尿道涂片中的白细胞内革兰阴性双球菌具有重要价值，女性不能直接套用。
4. 淋球菌培养的独特价值是获取菌株及药敏，NAAT亦十分重要。
5. Uu、Mh与M. genitalium要分清，不将“支原体阳性”一概当病因。
6. **梅毒两类血清学配合，反应素滴度用于随访，特异性抗体可长期阳性。**
7. 前带现象是抗体过多所致的反应异常，稀释可能揭示阳性。
8. HSV重视病灶直接检测，HPV须区分疣诊断与宫颈筛查。
9. HIV重视规范补充检测，CD4和病毒载量各有分工。
10. 阴性先问窗口期、部位、标本质量和检出限；阳性先问是否足以解释疾病。
