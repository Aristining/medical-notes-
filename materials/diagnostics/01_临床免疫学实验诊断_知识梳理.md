# 临床免疫学实验诊断：知识梳理

> 资料依据：`01临床免疫学实验诊断.pptx`，共 119 张幻灯片。下文“幻灯片”均指原课件顺序。
> 整理方式：先建立诊断框架，再按疾病归纳指标。**加粗内容为建议优先掌握的主干，不代表教师划定的考试范围。**“辨析/更新”用于说明课件中的简化表述或旧流程。

## 一、核心脉络：免疫学检验究竟在回答什么

临床免疫学检验利用抗原抗体反应、免疫细胞表型及功能，回答两类问题：**是否存在某种疾病线索，以及机体的免疫状态如何。**

```text
临床问题
├─ 感染：检测病原抗原、机体抗体，结合核酸与炎症指标
├─ 肿瘤：检测肿瘤相关标志物，辅助诊断和动态监测
├─ 免疫增殖：寻找单克隆免疫球蛋白/M蛋白
├─ 免疫缺陷：检查B细胞、T细胞、吞噬细胞与补体
├─ 超敏反应：按Ⅰ～Ⅳ型机制选择检验
├─ 自身免疫：用自身抗体谱联系受累器官
└─ 移植：术前配型和抗体评估，术后监测排斥与器官功能
```

读任何一个免疫学指标，都要问：

1. **测的是什么？** 抗原、抗体、细胞数量，还是细胞功能？
2. **它反映哪个阶段？** 当前感染、既往暴露、免疫应答，还是治疗后变化？
3. **特异性有多强？** 阳性能否由其他疾病、生理状态或检测干扰解释？
4. **如何组合证据？** 与病史、影像、病理、培养、核酸及动态趋势相互印证。

## 二、免疫学检验的技术基础

对应幻灯片 3～16、108～118。

### 2.1 抗原抗体反应与标记技术

**特异性结合提供识别能力，荧光、酶、同位素或发光标记提供可检测的信号。** 标记技术提高检测灵敏度，但不能消除交叉反应和各种干扰。

| 技术 | 核心原理 | 主要用途/读图要点 |
| --- | --- | --- |
| 凝集、沉淀 | 抗原抗体结合形成可见复合物 | 传统血清学、免疫球蛋白等检测 |
| 免疫比浊/散射比浊 | 复合物改变透射光或散射光 | 血清蛋白定量，注意抗原过量 |
| 酶免疫分析/ELISA | 酶标记后由底物显色 | 病原抗原、抗体和其他蛋白检测 |
| 化学发光 CLIA | 化学反应产生光信号 | 激素、肿瘤标志物、传染病等自动化检测 |
| 电化学发光 ECLIA | 电极表面的电化学反应触发发光 | 结合免疫反应、磁珠分离等实现定量/定性 |
| 免疫荧光 IFA | 荧光标记抗体显示抗原或抗体结合 | 自身抗体核型、组织定位等 |
| 时间分辨荧光 TRFIA | 利用长寿命荧光并延迟读取 | 减少短寿命背景荧光干扰 |
| 免疫印迹 WB | 电泳分离、转膜，再用抗体识别条带 | 识别针对不同蛋白的抗体反应 |
| 胶体金免疫层析 | 毛细管作用推动免疫反应，检测线显色 | 快速、现场检测；先判断质控线是否有效 |
| 流式细胞术 FCM | 激光检测单个细胞的散射及荧光信号 | 免疫分型、细胞亚群、功能和DNA含量分析 |

**信号与浓度的关系由具体反应模式决定。** 夹心法与竞争法不能套用同一判读逻辑。

### 2.2 两种重要的结果陷阱

- **抗原过量**：免疫沉淀类检测可能出现反应不足，造成假低。课件强调预反应、阈值识别和保证适当抗体量。
- **快速检测无质控线**：结果无效，不能把它当阴性；弱检测线也应按该试剂规定的时间与规则判读。

### 2.3 免疫状态评估

| 评估层面 | 主要检查 | 要回答的问题 |
| --- | --- | --- |
| 体液免疫 | Ig、补体、特异性抗体 | 数量是否足够，是否能产生有效抗体 |
| 细胞免疫 | T细胞及CD4⁺、CD8⁺亚群 | 细胞数量和组成是否异常 |
| 细胞功能 | 淋巴细胞增殖、NK及吞噬细胞功能 | 细胞是否具备正常效应能力 |
| 免疫调节 | 细胞因子 | 炎症及免疫调节处于何种状态 |

Th1、Th2、Th17、Treg代表不同免疫应答方向。复习时先建立对应：Th1与细胞免疫相关，Th2与体液/过敏应答相关，Th17与炎症及黏膜防御相关，Treg与免疫抑制和耐受相关。**细胞数量正常不等于功能正常。**

## 三、感染性疾病的免疫学诊断

对应幻灯片 17～36。

### 3.1 把“病原证据”和“宿主反应”分开

| 检查 | 检测对象 | 主要含义 | 解释限制 |
| --- | --- | --- | --- |
| 病原抗原 | 病原体结构成分 | 提供病原存在的线索 | 受标本部位、时机、检出限影响 |
| 病原抗体 | 机体针对病原体的反应 | 提示暴露及免疫应答 | 有窗口期，阳性可能持续较久 |
| IgM | 一类抗体 | 对部分病原体可提示近期感染 | 不能通用于所有病原体，可能持续或假阳性 |
| IgG | 一类抗体 | 常用于既往暴露、免疫状态或动态比较 | 单次阳性通常不能直接确定近期感染 |
| 双份血清 | 急性期和恢复期抗体滴度 | 某些感染滴度升高≥4倍支持近期感染 | 需同类检测及合适的间隔，不能任意比较数值 |
| PCT、CRP、IL-6 | 炎症/宿主反应 | 辅助评估感染和炎症程度 | 不能单独鉴定病原或确诊感染 |

**术语辨析：PCT是 procalcitonin（降钙素原），不是 calcitonin（降钙素）。** 原课件幻灯片19英文存在混用。

### 3.2 细菌及相关病原体

| 病原/疾病 | 课件中的重点检查 | 核心理解 |
| --- | --- | --- |
| 梅毒 | RPR、TRUST、VDRL；TPPA、FTA-ABS、TP-ELISA、CMIA等 | 非梅毒螺旋体试验与梅毒螺旋体特异性试验配合，前者可用于滴度随访 |
| 伤寒、副伤寒 | 肥达试验 Widal等 | 抗体反应需要联系病程及其他病原学证据 |
| 链球菌感染 | ASO，抗链球菌溶血素O | 提供近期链球菌感染线索，帮助分析风湿热、感染后肾炎等 |
| 结核分枝杆菌 | PPD、ELISPOT等 | 关注细胞免疫反应，不可用免疫试验单独判断活动性结核 |
| 幽门螺杆菌 | 抗原、抗体、尿素酶相关检测 | 抗体与当前病原活动并非同义 |
| 肺炎支原体 | 抗原、抗MP抗体及分子检测 | 需注意病程及抗体出现时间 |
| 立克次体、衣原体 | 课件列外斐反应、抗原抗体及分子方法 | 传统血清学与直接病原证据各有适用范围 |

**结核易错点：** PPD阴性不能排除结核，重症感染或免疫功能低下者可出现假阴性；阳性也不能直接等同活动性结核。[CDC：结核菌素皮试解释](https://www.cdc.gov/tb/hcp/testing-diagnosis/tuberculin-skin-test.html)

### 3.3 病毒性肝炎

| 病毒 | 本课件的识别重点 | 学习时的界限 |
| --- | --- | --- |
| HAV | 抗HAV-IgM、IgG，抗原检测 | IgM用于近期感染判断，结合具体检测结果 |
| HBV | 免疫标志物，HBV RNA、HBcrAg等拓展指标 | 本课件没有完整展开“乙肝五项组合”，不能将简略列表当作全部诊断流程 |
| HCV | 抗HCV及核酸检测 | **抗体筛查后，HCV RNA用于判断当前感染** |
| HDV | HDAg、抗HDV-IgM、抗HDV | 区分与HBV同时感染及在HBV感染基础上的重叠感染 |
| HEV | 抗HEV-IgM、IgG及抗原 | 按病程及检测对象解释 |

**更新：** 幻灯片28列出“HCV IgM早期诊断、免疫印迹确证”的旧式表述。现在应建立“抗HCV提供暴露线索，HCV RNA确认当前感染”的框架，不宜照搬旧流程。[CDC：丙肝检测解释](https://www.cdc.gov/hepatitis-c/hcp/diagnosis-testing/index.html)

### 3.4 其他病毒与TORCH

- **乙脑等血清学诊断**：课件强调恢复期较急性期抗体滴度升高≥4倍。
- **EB病毒**：嗜异性凝集试验是课件列举的传统线索，需结合感染性单核细胞增多症的临床表现。
- **TORCH**：课件重点为弓形虫、风疹病毒、巨细胞病毒、HSV-1/2。IgM、IgG结果应结合孕周、既往结果、复核及其他证据解释，不能凭一次IgM阳性推断胎儿已经感染。
- SARS、COVID-19、手足口病用于说明不同病毒的抗原抗体检测和流行病学应用。课件中的年份与地区流行资料作为背景理解。

### 3.5 真菌：G试验与GM试验

| 项目 | 检测对象 | 主要提示 |
| --- | --- | --- |
| G试验 | （1,3）-β-D-葡聚糖 | 较广谱的真菌感染辅助证据，不能鉴定菌种 |
| GM试验 | 半乳甘露聚糖 | 主要用于曲霉感染的辅助诊断 |

二者均需结合宿主危险因素、影像、镜检、培养及病理。阴性不能一概排除侵袭性真菌感染，GM的检测表现也受患者群体和抗真菌治疗等影响。[IDSA：曲霉病诊断](https://www.idsociety.org/practice-guideline/aspergillosis/)

## 四、肿瘤免疫学诊断

对应幻灯片 37～50。

### 4.1 先记住标志物的三种性质

1. **多样性**：同一肿瘤可有多个标志物，因此可能需要联合检测。
2. **相对特异性**：同一标志物可见于不同肿瘤，也可在良性疾病中升高。
3. **动态性**：治疗、复发、转移及疾病进展可以改变标志物水平。

因此，肿瘤标志物适合辅助判断来源、评估病情、监测疗效和复发。**单次升高不能直接确诊癌症，正常也不能排除癌症。**

### 4.2 常用肿瘤标志物对照

| 标志物 | 主要联系 | 必须同时记住的限制 |
| --- | --- | --- |
| AFP | 肝细胞癌、卵黄囊等生殖细胞肿瘤 | 妊娠、活动性肝病也可升高；课件提及AFP-L3% |
| CEA | 消化道肿瘤，也见于肺癌、乳腺癌等 | 广谱，良性疾病也可升高 |
| PSA | 前列腺疾病 | **器官特异性较强，肿瘤特异性不足**；增生等也可升高 |
| PAP | 前列腺疾病的辅助评估 | 按课件了解，不能替代完整评估 |
| NSE | 小细胞肺癌、神经母细胞瘤、神经内分泌肿瘤 | **溶血会影响结果**；脑损伤也可升高 |
| HCG | 滋养细胞肿瘤、部分生殖细胞肿瘤 | 还必须考虑妊娠等生理背景 |
| CA19-9 | 胰腺、胆道等消化系统肿瘤 | 非单一肿瘤专属指标 |
| CA125 | 卵巢癌等 | 需要结合影像和其他临床资料 |
| CA15-3 | 乳腺癌 | 主要理解其辅助与动态监测价值 |
| CA50、CA242 | 胰腺及其他消化道肿瘤 | 作为联合指标理解 |
| PD-L1 | 组织/细胞层面的标志物 | 与部分肿瘤免疫治疗决策相关，不等同血清肿瘤标志物 |

课件的联合检测示例：

- 肺癌：CYFRA21-1、NSE、ProGRP、CEA、SCCA，分别联系不同组织学类型。
- 乳腺癌：CA15-3、CEA。
- 肝癌：AFP等；胰腺癌：CA19-9、CA242、CA50；卵巢癌：CA125等。

联合检测可能提高检出灵敏度，但检测项目增加也可能增加假阳性，需围绕临床问题选择。

### 4.3 诊断效能与临界值

- 敏感度：有病者中被检出的比例。
- 特异度：无病者中被正确判为阴性的比例。
- ROC曲线：纵轴敏感度，横轴1−特异度；AUC评价总体区分能力。
- Youden指数：敏感度＋特异度−1，可辅助选择截断值。

**辨析：** 幻灯片39列“下降50%、90%”评价疗效的示例，不能作为所有肿瘤、所有标志物的统一疗效标准。应联系具体疾病、治疗时点及其他疗效评价。

## 五、免疫增殖病与免疫缺陷病

对应幻灯片 51～68。

### 5.1 单克隆免疫球蛋白病：先发现，再分型

```text
怀疑单克隆免疫球蛋白异常
    ↓
血清蛋白电泳：寻找局限、狭窄的异常峰/条带
    ↓
免疫固定电泳：确定免疫球蛋白重链和轻链类型
    ↓
结合轻链、骨髓及器官损害等资料判断疾病性质
```

| 检查/现象 | 核心意义 |
| --- | --- |
| M蛋白 | 单克隆免疫球蛋白或其组分，不等同“已经确诊多发性骨髓瘤” |
| 血清蛋白电泳 | 发现异常峰；M蛋白不只出现在γ区，也可在其他区带 |
| 免疫固定电泳 IFE | 更敏感地识别单克隆条带并分型 |
| 多克隆增殖 | γ区呈宽而弥散的增高，常联系慢性炎症等 |
| κ、λ轻链 | 单一型异常增多和比值失衡提示克隆性线索 |

**易错：** 课件“κ∶λ约2∶1”是概略组成关系，不能直接当作血清游离轻链κ/λ检测的通用参考区间。

### 5.2 免疫缺陷：按受损环节选检验

| 受损环节 | 课件重点检测 | 记忆关键词 |
| --- | --- | --- |
| B细胞/体液免疫 | 血清Ig、同种血型凝集素、特异性抗体产生能力、表面Ig及CD抗原 | 数量＋抗体功能 |
| T细胞/细胞免疫 | T细胞亚群、DTH皮试、PHA刺激增殖 | 表型＋增殖功能 |
| 吞噬细胞 | 白细胞计数、趋化、吞噬杀伤、DHR123、黏附分子 | 数量＋吞噬/氧化爆发 |
| 补体 | 补体成分和功能，课件举C1抑制物 | 定位具体补体环节 |
| 遗传性缺陷 | 基因检测 | 明确分子缺陷 |

原发性免疫缺陷多联系遗传/发育因素；继发性可见于感染、肿瘤、药物等。**反复感染是线索，检验需要定位受损环节。**

### 5.3 HIV：诊断、免疫状态和治疗监测要分开

| 任务 | 主要检查 |
| --- | --- |
| 筛查感染 | HIV抗体或抗原抗体联合检测 |
| 明确感染状态 | 规范的补充检测流程，必要时核酸检测 |
| 评估免疫受损 | CD4⁺T细胞计数 |
| 评价病毒复制及治疗反应 | HIV病毒载量 |

**更新：** 幻灯片64～66的固定WB条带组合及长时间等待随访属于需要核对的旧流程，不宜作为通用判读规则。我国《全国艾滋病检测技术规范（2025年修订版）》明确：抗体确证结果不确定时应进行核酸检测，以尽快明确感染状态。[中国疾控中心发布说明](https://ncaids.chinacdc.cn/sjb/gzdt_10321/202510/t20251024_313118.htm)

## 六、四型超敏反应与检验的对应

对应幻灯片 69～75。

| 类型 | 核心机制 | 课件重点检查 | 判读提醒 |
| --- | --- | --- | --- |
| Ⅰ型 | IgE、肥大细胞等介导速发反应 | 皮肤试验、总IgE、特异性IgE | 总IgE正常不能排除过敏；特异性IgE阳性需与症状对应 |
| Ⅱ型 | 针对细胞表面/组织抗原的抗体介导损伤 | Coombs试验、免疫组化 | 联系免疫性溶血等场景 |
| Ⅲ型 | 免疫复合物沉积及补体活化 | CIC检测、组织IgG/C3检测 | PEG法简便但特异性有限 |
| Ⅳ型 | T细胞介导迟发反应 | PPD等迟发型皮肤反应 | 需考虑免疫抑制导致的假阴性 |

补充理解Coombs：直接抗人球蛋白试验检测红细胞表面已结合的Ig/补体；间接试验检测血清中可与红细胞结合的抗体。

课件列出的皮试注射方式、观察时间及风团大小用于理解示例，不能替代不同过敏原、不同皮试方法的具体判读规则。

## 七、自身免疫性疾病：由“抗体谱”联系“器官谱”

对应幻灯片 76～90。

### 7.1 基本特征与诊断思路

课件强调自身抗体和/或自身反应性T细胞、组织器官损伤、病程反复迁延、遗传倾向等。

**自身抗体阳性只是证据之一。** 先判断临床表现是否符合相应疾病，再评价抗体类型、滴度、检测方法及其他实验室结果。

### 7.2 自身抗体对照表

| 抗体 | 主要疾病联系 | 复习抓手 |
| --- | --- | --- |
| ANA | SLE及多种系统性自身免疫病 | 筛查线索，关注核型和进一步分型 |
| 抗dsDNA | SLE，尤其疾病活动相关评估 | 比抗ssDNA更具特异性 |
| 抗Sm | SLE | 重要特异性线索 |
| 抗U1-RNP | 混合性结缔组织病 MCTD | “RNP—混合” |
| 抗SSA、抗SSB | 干燥综合征等 | 不限于一种疾病 |
| 抗Scl-70 | 系统性硬化症 | 与弥漫性病变/器官受累联系理解 |
| 抗着丝点 | 局限型系统性硬化症 | 与Scl-70对照 |
| 抗Jo-1 | 肌炎相关疾病 | 联系肌炎及相关综合征 |
| 抗组蛋白 | 药物性狼疮，也可见于SLE | 不是药物性狼疮绝对专属 |
| RF | 类风湿关节炎及其他情况 | 针对IgG Fc的自身抗体，特异性有限 |
| 抗CCP | 类风湿关节炎 | 特异性较高，可在临床关节炎之前出现 |
| 抗肌动蛋白 | 自身免疫性肝炎 | 联系肝损伤背景 |
| 抗甲状腺球蛋白、甲状腺微粒体相关抗体 | 自身免疫性甲状腺病 | 联系甲状腺功能及其他检查 |
| 抗乙酰胆碱受体 | 重症肌无力 | 标志性抗体线索 |
| 抗胰岛细胞 | 自身免疫性糖尿病分型 | 反映胰岛自身免疫 |
| 抗GBM | 抗肾小球基底膜病 | 联系急进性肾炎及肺出血表现 |
| 抗胃壁细胞 | 自身免疫性胃病/恶性贫血 | 联系维生素B12缺乏背景 |
| 抗精子抗体 | 免疫性生殖障碍的辅助线索 | 不能据此认定所有不孕不育的病因 |

**两组最值得对照：** ANA与抗dsDNA/抗Sm；RF与抗CCP。前者帮助理解筛查和进一步特异性检查，后者帮助理解同一疾病中不同指标的特异性差异。

## 八、移植免疫学：术前风险与术后监测

对应幻灯片 91～107。

### 8.1 术前的三件事

| 检查 | 要回答的问题 |
| --- | --- |
| ABO血型 | 供受者是否相容，是否存在血型相关风险 |
| HLA配型 | 供受者组织相容程度如何 |
| 交叉配合试验 | 受者是否已有针对供者的抗体 |

HLA具有多基因性和高度多态性，位于第6号染色体短臂。课件强调HLA-A、B、DR等位点，不同器官移植对配型要求不同。存在特定方案下的跨血型移植，因此课件“ABO必须相同或相容”应作为常规原则理解。

### 8.2 交叉配合试验与PRA

- **淋巴细胞毒交叉配合试验**：受者血清与供者淋巴细胞反应，检测针对供者细胞的细胞毒性抗体。
- **PRA，群体反应抗体**：评价受者对一组不同个体HLA抗原的反应范围，反映致敏程度。
- 区别：交叉配合聚焦“这个供者”，PRA聚焦“对多大范围的供者可能反应”。

### 8.3 预防及监测排斥

课件措施包括组织配型、移植物预处理、交叉配合、免疫抑制和诱导免疫耐受。药物、照射等历史示例以理解免疫抑制机制为主。

术后监测包括抗供者HLA抗体、T细胞及相关免疫指标，并结合**移植器官功能和必要的病理证据**。免疫学单项检测难以独立准确判断排斥。
