# 肾功能不全 (Renal Insufficiency) 病理生理学速成笔记

> 课程日期：2026-11-03。根据 Gemini 对话《11.3泌尿系统》的课程总结导出，整理标题层级、公式与表格，正文保留原总结内容。


## 一、 概述与核心概念辨析（必考名解）

### 1. 肾脏的两大生理功能

- **泌尿功能**：排泄代谢废物（尿素、肌酐、尿酸）、药物和毒物；调节水、电解质和酸碱平衡。

- **内分泌功能**：

  - **分泌激素**：促红细胞生成素 (EPO)、$1,25-(OH)_2D_3$（活性维生素 $D_3$）、肾素、前列腺素 (PG)。

  - **灭活激素**：甲状旁腺素 (PTH)、胃泌素。

- **核心指标**：肾小球滤过率 ($\text{GFR}$，正常值约 $125\text{ ml/min}$ 或 $180\text{ L/d}$)。

  $$\text{有效滤过压} = \text{肾小球毛细血管血压} - (\text{囊内压} + \text{血浆胶体渗透压})$$

### 2. 核心概念进阶关系

    肾功能不全 (广义：肾功能严重障碍) 
      ├── 急性肾衰竭 (ARF) / 急性肾损伤 (AKI) ──> 大部分可逆
      └── 慢性肾衰竭 (CRF) / 慢性肾脏病 (CKD) ──> 终末期肾病 (ESRD) / 尿毒症 (Uremia) [不可逆]

- **肾功能不全 (Renal Insufficiency)**：各种原因引起肾功能严重障碍，出现代谢产物蓄积，水、电解质和酸碱平衡紊乱，以及肾脏内分泌功能障碍的临床综合征。

- **急性肾损伤 (AKI) / 急性肾衰竭 (ARF)**：双肾泌尿功能在短时间内（数小时至数天）急剧下降，导致含氮和非含氮代谢产物迅速积聚，出现氮质血症、高钾血症、代谢性酸中毒和水中毒。*(AKI于2005年提出，更强调早期诊断与可逆性)*。

- **慢性肾脏病 (CKD)**：肾脏损害（结构或功能异常）和/或 $\text{GFR} < 60\text{ ml/(min}\cdot1.73\text{m}^2)$ 持续 $\ge 3$ **个月**。

- **氮质血症 (Azotemia)**：由于 $\text{GFR}$ 下降，含氮代谢产物（**尿素、肌酐、尿酸**等非蛋白氮 NPN）在体内蓄积，导致各系统出现功能障碍和中毒症状的综合征。

- **尿毒症 (Uremia)**：急、慢性肾衰竭发展的**最严重阶段**，除水、电解质、酸碱平衡紊乱和内分泌失调外，还有大量代谢终末产物和尿毒症毒素滞留，引起一系列**自体中毒症状**。

## 二、 急性肾衰竭 (ARF) / 急性肾损伤 (AKI)

### 1. KDIGO 诊断标准（符合以下任一即可诊断 AKI）

1.  **$48\text{ 小时}$内**血肌酐 ($\text{Scr}$) 升高 $\ge 26.5\ \mu\text{mol/L}$ ($0.3\text{ mg/dl}$)；

2.  **$7\text{ 天}$内** $\text{Scr}$ 升高至基线值的 $\ge 1.5\text{ 倍}$；

3.  **尿量** $< 0.5\text{ ml/(kg}\cdot\text{h)}$，持续 $> 6\text{ 小时}$。

### 2. 病因与分类（三大类）

|  |  |  |  |
|----|----|----|----|
| 分类 | 占比 | 核心病因 | 性质与特点 |
| **肾前性** | $55\%$ | 有效循环血量减少 $\rightarrow$ 肾血流灌注急剧减少（休克、大出血、心衰） | **功能性肾衰**（肾小管无坏死，及时补液可迅速逆转） |
| **肾性** | $40\%$ | **急性肾小管坏死 (ATN，最常见最重要)**：持续肾缺血/再灌注损伤、肾中毒（氨基糖苷类抗生素、造影剂、重金属、蛇毒、肌红蛋白/血红蛋白管型）。此外还有肾小球、间质、血管病变。 | **器质性肾衰**（肾实质受损，补液无效甚至恶化） |
| **肾后性** | $5\%$ | 肾以下尿路急性梗阻（结石、肿瘤、前列腺肥大） | 早期解除梗阻可恢复，晚期转变为器质性损伤 |

### 3. 发病机制（核心：为什么会 GFR↓ 和少尿？）

> **记忆口诀：“一血、二管、三小球”**

1.  **肾血流动力学异常（肾血流量减少）**：

    - 肾灌注压下降；

    - **肾血管收缩**：交感-肾上腺髓质兴奋（儿茶酚胺 $\uparrow$）、$\text{RAAS}$ 激活（$\text{Ang II}\uparrow$）、缩血管物质（内皮素）$\uparrow$ 而扩血管物质（$\text{PG}$、$\text{NO}$）$\downarrow$；

    - **肾毛细血管内皮细胞肿胀**（缺血/中毒致 $\text{ATP}\downarrow \rightarrow \text{Na}^+\text{-K}^+$ 泵失灵 $\rightarrow$ 细胞水肿管腔狭窄）；

    - 肾血管内微血栓形成。

2.  **肾小管损伤（三大经典学说）**：

    - *基底膜特点*：缺血性（破裂性）损伤累及各段且**基底膜受损**；肾毒性损伤主要累及近曲小管但**基底膜完整**（易再生修复）。

    - **① 肾小管阻塞学说**：坏死脱落的上皮细胞碎片、肌红蛋白等形成管型堵塞管腔 $\rightarrow$ 阻塞上方囊内压 $\uparrow \rightarrow \text{有效滤过压}\downarrow \rightarrow \text{GFR}\downarrow$。

    - **② 原尿回漏学说**：小管上皮受损、基底膜剥脱 $\rightarrow$ 原尿经裂缝漏入肾间质 $\rightarrow$ 尿量直接减少 + 肾间质水肿压迫小管和毛细血管 $\rightarrow \text{GFR}$ 进一步 $\downarrow$。

    - **③ 管-球反馈 (TGF) 机制失调**：近曲小管和髓袢受损 $\rightarrow$ 重吸收 $\text{NaCl}\downarrow \rightarrow$ 远曲小管致密斑处 $\text{NaCl}$ 负荷 $\uparrow \rightarrow$ 反馈性引起入球小动脉收缩（腺苷介导）$\rightarrow \text{GFR}\downarrow$。

3.  **肾小球超滤系数 (**$K_f$**) 降低**：

    - 内皮细胞肿胀使通透性下降；**系膜细胞收缩**使有效滤过面积下降。

### 4. 临床病程与功能代谢变化

#### （1）少尿型 ARF（最常见，分三期）

- **① 少尿期（**$7\sim14\text{ 天}$**，最危重阶段）**：

  - **尿改变**：少尿（$<400\text{ ml/d}$ 或 $<17\text{ ml/h}$）或无尿（$<100\text{ ml/d}$）。

  - **氮质血症**：血尿素氮、肌酐升高，引起恶心呕吐等中毒症状。

  - **“死亡三角”（三大致命并发症）**：

    1.  **水中毒**：肾排水 $\downarrow$ + 分解代谢内生水 $\uparrow$ + 盲目输液 $\rightarrow$ 稀释性低钠血症、脑水肿、肺水肿、心衰。

    2.  **高钾血症（最危险的死因，可致室颤/心搏骤停）**：尿少排钾 $\downarrow$ + 组织损伤/分解代谢释放 $\text{K}^+$ + 酸中毒（$\text{H}^+\text{-K}^+$ 交换使 $\text{K}^+$ 移出细胞）+ 输入库存血/高钾食物。

    3.  **代谢性酸中毒**：$\text{GFR}\downarrow$ 致固定酸排泄障碍 + 肾小管排酸保碱功能受损 + 分解代谢产酸增多。

- **② 多尿期（**$7\sim14\text{ 天}$**，尿量** $>400\text{ ml/d}$ **标志进入此期，可达** $3000\text{ ml/d}$ **以上）**：

  - **多尿机制**：① $\text{GFR}$ 开始恢复，阻塞解除；② **新生肾小管上皮细胞功能尚不成熟**，重吸收钠水能力低下（浓缩功能障碍）；③ 少尿期蓄积的大量尿素排出引起**渗透性利尿**。

  - **临床注意**：多尿期**早期**仍存在氮质血症和高血钾；**中晚期**则极易发生**脱水、低钾血症、低钠血症**。

- **③ 恢复期（**$3\sim12\text{ 个月}$**）**：尿量及非蛋白氮恢复正常，肾小管浓缩功能需较长时间恢复。

#### （2）非少尿型 ARF

- 尿量保持在 $400\sim2000\text{ ml/d}$；主要机制为 $\text{GFR}$ 下降程度不重，以**肾小管浓缩功能障碍**为主。多见于药物肾毒性或造影剂肾病，病情较轻，高钾和水中毒少见。

### 5. 【黄金考点】功能性（肾前性）与器质性（ATN）ARF 的尿液鉴别

*(注：必须在输液和使用利尿剂前留取尿液；*$\text{钠排泄分数 } \text{FENa} = \frac{\text{尿钠}\times\text{血肌酐}}{\text{血钠}\times\text{尿肌酐}}\times 100\%$*)*

|  |  |  |  |
|----|----|----|----|
| 鉴别指标 | 功能性肾衰（肾前性） | 器质性肾衰（急性肾小管坏死 ATN） | 核心病理生理机制解释 |
| **尿比重** | $> 1.020$ (高) | $< 1.015$ (低，固定) | 肾前性小管重吸收与浓缩功能完好；ATN小管坏死丧失浓缩能力 |
| **尿渗透压** | $> 500\text{ mmol/L}$ | $< 350\text{ mmol/L}$ | 同上 |
| **尿钠 (**$\text{mmol/L}$**)** | $< 20$ (极低) | $> 40$ (高) | 肾前性激活醛固酮拼命保钠；ATN小管坏死无法重吸收钠 |
| **尿肌酐 / 血肌酐** | $> 40$ | $< 20$ | 肾前性水被大量重吸收，尿肌酐被高度浓缩 |
| **钠排泄分数 (**$\text{FENa}$**)** | $< 1\%$ | $> 2\%$ | 最敏感指标，反映肾小管对钠的重吸收能力 |
| **尿沉渣镜检** | 基本正常（或少量透明管型） | **蛋白尿、红/白细胞、上皮细胞管型/棕色颗粒管型** | ATN 存在小管上皮坏死脱落及出血炎症 |
| **补液试验反应** | 尿量迅速增多，病情好转 | **尿量持续不增，甚至诱发急性肺水肿而恶化** | 器质性肾衰必须“量出为入”，严格控水！ |

## 三、 慢性肾衰竭 (CRF) / 慢性肾脏病 (CKD) 与尿毒症

### 1. 病因与分期

- **常见病因**：原发性（慢性肾小球肾炎、慢性肾盂肾炎、多囊肾）；继发性（糖尿病肾病、高血压肾损害、狼疮性肾炎）。

- **CKD 分期（按** $\text{eGFR}$**，单位** $\text{ml/(min}\cdot1.73\text{m}^2)$**）**：

  - **G1 (**$\ge 90$**)**：代偿期，无症状。

  - **G2 (**$60\sim89$**)**：轻度下降，内环境尚稳定，不能耐受额外负荷。

  - **G3 (**$30\sim59$**)**：中度下降（肾功能不全期），出现轻度贫血、**夜尿/多尿**、轻度氮质血症和代酸。

  - **G4 (**$15\sim29$**)**：重度下降（肾衰竭期），严重贫血、高磷低钙、明显代酸与氮质血症。

  - **G5 (**$< 15$ **或透析)**：**终末期肾病 (ESRD) / 尿毒症期**，全身多系统严重中毒症状。

- **白蛋白尿分期（按尿白蛋白/肌酐比值** $\text{UACR}$**，**$\text{mg/g}$**）**：A1 ($<30$ 正常/轻度)、A2 ($30\sim300$ 微量白蛋白尿)、A3 ($>300$ 大量白蛋白尿)。

### 2. 发病机制（五大经典学说）

> 无论原发病是什么，核心病理结局都是**进行性肾小球硬化**（系膜细胞增殖 + 细胞外基质 ECM 积聚）和**肾小管-间质纤维化**。

1.  **健存肾单位学说**：病损肾单位丧失功能，残存的“健存肾单位”代偿性肥大、功能增强；随病情进展，健存肾单位越来越少，最终失代偿出现肾衰。

2.  **肾小球高滤过学说（“三高”学说）**：残存肾单位代偿性处于**高灌注、高压力、高滤过**状态 $\rightarrow$ 毛细血管扩张、内皮及足细胞受损（足突融合、剥脱）$\rightarrow$ 大分子蛋白滤出 + 系膜细胞增生与基质沉积 $\rightarrow$ **加速肾小球硬化**（代偿变损伤）。

3.  **矫枉失衡学说 (Trade-off hypothesis)**：机体为了纠正某一种内环境紊乱（**矫枉**）而产生的代偿反应（如分泌某种激素），却引发了新的组织器官损害（**失衡**）。

    - *最经典例子（钙磷代谢与 PTH）*：$\text{GFR}\downarrow \rightarrow \text{排磷}\downarrow \rightarrow \text{血磷}\uparrow\text{、血钙}\downarrow \rightarrow \text{刺激甲状旁腺分泌 }\mathbf{PTH\uparrow} \rightarrow$ 抑制残存肾小管重吸收磷，使尿磷排出增加、血磷暂时恢复正常（**矫枉**）；但持续极高水平的 $\text{PTH}$ 却导致溶骨作用增强，引发**肾性骨营养不良**、皮肤瘙痒、神经毒性等（**失衡**）。

4.  **肾小管-间质损伤学说**：慢性炎症、缺氧及残存肾小管高代谢状态，导致小管萎缩和间质纤维化（直接决定肾功能恶化速度）。

5.  **蛋白尿学说**：大量滤过的蛋白质形成管型阻塞小管，且重吸收超载激活小管上皮炎症与补体反应，加速间质纤维化。

### 3. 功能代谢变化（七大核心表现）

#### （1）尿的变化（规律：从早期的“多尿、低渗”到晚期的“少尿、等渗”）

- **尿量**：

  - **早中期** $\rightarrow$ **夜尿、多尿（**$>2000\text{ ml/d}$**）**。*机制*：① 残存肾单位血流量增加，原尿流速快，重吸收来不及；② 原尿中尿素等溶质浓度高，引起**渗透性利尿**；③ 肾髓质高渗环境破坏（髓袢受损），尿浓缩功能障碍。*(注意：CRF的多尿并不能排尽毒素，依然存在氮质血症！)*

  - **晚期** $\rightarrow$ **少尿**（健存肾单位极度减少）。

- **尿渗透压/比重**：早期浓缩功能受损呈**低渗尿/低比重尿**；晚期浓缩和稀释功能均完全丧失，尿比重固定在 $1.010\sim1.012$（与血浆渗透压相近），称为**等渗尿 (Isosthenuria)**。

- **尿成分**：蛋白尿、血尿、管型尿（晚期可见宽大肾衰管型）。

#### （2）氮质血症

- 血浆肌酐 ($\text{Pcr}$)、血尿素氮 ($\text{BUN}$)、尿酸升高。临床常用 $\text{eGFR}$**（基于 CKD-EPI 公式）** 评估肾功能。

#### （3）水、电解质和酸碱平衡紊乱

- **水钠代谢（调节适应能力丧失，“怕多又怕少”）**：水摄入多即水中毒/水肿/心衰，摄入少即脱水；限钠或利尿过度易致低钠血症，钠摄入过多则水钠潴留、高血压。

- **钾代谢**：只要尿量不少，早期靠醛固酮分泌增加促进远曲小管和肠道排钾，血钾可维持正常；晚期少尿、使用保钾利尿剂、酸中毒或感染时极易发生致命性**高钾血症**（厌食腹泻或排钾利尿剂使用不当时也可出现低血钾）。

- **钙磷与镁代谢**：**高血磷、低血钙**、高镁血症（晚期慎用硫酸镁导泻或降压，防呼吸麻痹与心搏骤停）。

  - *低钙机制*：① 血磷升高与钙结合成磷酸钙沉积；② 肾实质破坏致 $1,25-(OH)_2D_3$ **生成减少**，肠钙吸收减少；③ 毒物损伤肠道直接妨碍钙吸收。

- **代谢性酸中毒**：① $\text{GFR}\downarrow$ 致固定酸排泄减少；② 肾小管产氨 ($\text{NH}_3$) 能力下降，排 $\text{H}^+$ 减少；③ 继发性 $\text{PTH}\uparrow$ 抑制近曲小管碳酸酐酶活性，使 $\text{HCO}_3^-$ 重吸收减少。

#### （4）肾性高血压（恶性循环！）

- **钠依赖性高血压（容量依赖型，最主要）**：$\text{GFR}\downarrow \rightarrow$ 水钠排泄减少、水钠潴留 $\rightarrow$ 血容量 $\uparrow$、心输出量 $\uparrow$。

- **肾素依赖性高血压（血管阻力型）**：肾缺血激活 $\text{RAAS} \rightarrow \text{Ang II}\uparrow \rightarrow$ 外周血管收缩 + 醛固酮 $\uparrow$ 保钠保水。

- **肾减压物质减少**：肾实质破坏，分泌前列腺素 ($\text{PGE}_2, \text{PGI}_2$)、激肽等扩血管物质减少。

#### （5）肾性贫血与出血倾向

- **肾性贫血机制（必考简答）**：

  1.  **促红细胞生成素 (EPO) 生成减少（最主要原因）**；

  2.  体内蓄积的尿毒症毒素**抑制骨髓造血功能**；

  3.  毒素损伤红细胞膜（抑制钠泵），使红细胞寿命缩短、破坏增加（溶血）；

  4.  毒素引起胃肠道厌食、呕吐及吸收障碍，导致铁、叶酸、蛋白质等**造血原料缺乏**；

  5.  血小板功能障碍引起慢性失血。

- **出血倾向机制**：尿毒症毒素（胍类、酚类、尿素）抑制**血小板第3因子 (**$\text{PF}_3$**) 释放**，使血小板黏附和聚集功能明显下降（注：血小板数量通常正常，是功能障碍！）。

#### （6）肾性骨营养不良（肾性骨病，必考名解与简答）

- **定义**：CRF 时由于钙磷代谢障碍、继发性甲状旁腺功能亢进、维生素 $D_3$ 活化障碍和酸中毒等引起的骨骼病变（包括儿童肾性佝偻病、成人骨软化症、纤维性骨炎、骨质疏松等）。

- **四大发生机制**：

  1.  **高磷低钙血症与继发性甲旁亢 (**$\text{PTH}\uparrow$**)**：低钙高磷刺激 $\text{PTH}$ 大量分泌 + 肾灭活 $\text{PTH}$ 减少 $\rightarrow$ 破骨细胞活性增强，持续**溶骨**导致纤维性骨炎。

  2.  **维生素** $D_3$ **活化障碍**：肾实质破坏使 $1\alpha$-羟化酶减少，$1,25-(OH)_2D_3$ **生成不足** $\rightarrow$ 肠钙吸收不良 + **骨盐沉着（骨质钙化）障碍** $\rightarrow$ 骨软化症/佝偻病。

  3.  **慢性代谢性酸中毒**：机体动员骨盐缓冲体内酸负荷，导致**骨质脱钙**。

  4.  **铝积聚**：长期透析或口服含铝磷结合剂导致铝在骨中沉积，抑制骨盐沉着。

### 4. ARF 与 CRF 的终极对比表

|  |  |  |
|----|----|----|
| 比较维度 | 急性肾衰竭 (ARF) | 慢性肾衰竭 (CRF) |
| **病程进展** | 短、急促（数小时至数天） | 长、缓慢进行性（数月至数年） |
| **尿量演变** | **少尿** $\rightarrow$ **多尿** | **夜尿/多尿** $\rightarrow$ **少尿** |
| **血钾演变** | **高血钾（少尿期）**$\rightarrow$ **低血钾（多尿期）** | 早期正常或偏低 $\rightarrow$ **晚期高血钾** |
| **突出表现** | 以急性**泌尿功能丧失**（水、钾、酸紊乱）为主 | **毒素滞留 + 内分泌失调**（贫血、骨病、高血压）突出 |
| **双肾体积** | 正常或偏大（水肿） | **双肾缩小、皮质变薄**（纤维化硬化） |
| **预后** | 大多数可逆，预后较好 | 不可逆，最终进展为尿毒症（需透析或肾移植） |

## 四、 课堂小案例与课后思考题标准解析

### 【临床小案例解析】（对应课件第 1 页 & 第 65 页）

> **题干摘要**：女，58岁，慢性肾炎10年。近2周头晕头痛、恶心呕吐、水肿。BP $170/100\text{ mmHg}$，$\text{Hb } 74\text{ g/L}$，$\text{Scr } 786\ \mu\text{mol/L}$，血 $\text{K}^+ 5.6\text{ mmol/L}$，血浆 $\text{HCO}_3^- 11.5\text{ mmol/L}$，尿量 $450\text{ ml/24h}$，尿比重 $1.010\sim1.012$，尿蛋白 $(++)$。

1.  **为何突然出现头晕头痛、恶心呕吐、水肿？**

    - **诊断定性**：患者有10年慢性肾炎史，现 $\text{Scr}$ 高达 $786\ \mu\text{mol/L}$，已进入**慢性肾衰竭晚期（尿毒症期 / CKD G5期）**。

    - **头晕头痛**：由严重的**肾性高血压**（$170/100\text{ mmHg}$）、**重度肾性贫血**（$\text{Hb } 74\text{ g/L}$ 致脑缺氧）以及尿毒症毒素引起的脑功能障碍（尿毒症脑病早期）共同导致。

    - **恶心呕吐**：严重**氮质血症/尿毒症毒素蓄积**（尿素在肠道细菌尿素酶作用下分解产生氨，刺激胃肠道黏膜），同时合并**代谢性酸中毒**（$\text{HCO}_3^- 11.5\text{ mmol/L}$）和胃肠道水肿。

    - **水肿**：晚期健存肾单位极度减少，尿量明显减少（$450\text{ ml/d}$ 接近少尿），导致**水钠潴留**；加上长期蛋白尿 $(++)$ 导致低蛋白血症，血浆胶体渗透压下降。

2.  **发生贫血（**$\text{Hb } 74\text{ g/L}$**）的主要原因是什么？**

    - ① **最主要原因**：肾实质严重破坏，分泌**促红细胞生成素 (EPO) 明显减少**；

    - ② 体内蓄积的尿毒症毒素抑制骨髓造血，并破坏红细胞使其寿命缩短；

    - ③ 恶心呕吐等胃肠道症状导致铁、叶酸、蛋白质等造血原料摄入和吸收减少；

    - ④ 毒素抑制血小板功能导致慢性隐性失血。

3.  **该患者出现高血压（**$170/100\text{ mmHg}$**）的主要机制有哪些？**

    - ① **水钠潴留（容量依赖性）**：晚期 $\text{GFR}$ 极度下降、尿量减少，钠水排出受阻，血容量和心输出量增加；

    - ② $\text{RAAS}$ **系统激活（肾素依赖性）**：肾病变缺血刺激球旁器分泌肾素，血管紧张素 $\text{II}$ 生成增多，强烈收缩外周血管并刺激醛固酮分泌加重水钠潴留；

    - ③ **肾减压物质生成减少**：肾髓质破坏，分泌前列腺素（$\text{PGE}_2, \text{PGI}_2$）等扩血管物质减少。

4.  **血肌酐升高（**$786\ \mu\text{mol/L}$**，正常** $44\sim133\ \mu\text{mol/L}$**）提示什么？**

    - 肌酐由肌肉代谢产生，几乎全部经肾小球滤过且不被肾小管重吸收。血肌酐显著升高提示**功能性肾单位大量不可逆丧失，肾小球滤过率 (**$\text{GFR}$**) 极度下降**，患者存在严重的**氮质血症**，病情已处于终末期肾衰（尿毒症期）。

5.  **出现高血钾（**$5.6\text{ mmol/L}$**）的主要原因？**

    - ① 晚期肾单位大量破坏，$\text{GFR}$ 极度降低且肾小管泌钾功能受损，尿量减少（$450\text{ ml/d}$）导致**肾排钾显著减少**；

    - ② 患者合并严重**代谢性酸中毒**（$\text{HCO}_3^- 11.5\text{ mmol/L}$），细胞外液 $\text{H}^+$ 进入细胞内，细胞内 $\text{K}^+$ 转移至细胞外；

    - ③ 尿毒症期机体分解代谢增强，细胞释放 $\text{K}^+$ 增多。

6.  **尿检指标的变化提示肾脏的哪些功能或结构的改变？**

    - **尿量减少（**$450\text{ ml/24h}$**）**：提示残存肾单位极度减少，**肾小球滤过功能严重衰竭**（已从早中期的多尿转为晚期的少尿倾向）。

    - **尿比重固定在** $1.010\sim1.012$**（等渗尿）**：提示**肾小管的浓缩功能和稀释功能均已完全丧失**。

    - **尿蛋白** $(++)$：提示**肾小球滤过膜（电荷屏障和机械屏障）结构严重受损**，通透性增加，同时伴肾小管重吸收蛋白功能障碍。
