## 学习顺序

建议按以下顺序学习，先建立框架，再记技术名称。

1. **先区分四种成像方式：**X线、CT、MRI和超声各用什么信号？分别把什么差异显示为黑白？
2. **再理解超声：**回声强弱、回声到达时间、频率与穿透力，以及常见伪像。
3. **接着理解CT：**断层重建、CT值、窗宽窗位、平扫与增强、专门检查方案。
4. **最后理解MRI：**氢质子、磁场、射频、弛豫与序列，再联系血管、扩散、灌注和代谢成像。
5. **每轮都做比较：**同一器官为什么有时选超声，有时需要CT或MRI？图像中“亮”分别意味着什么？

| 优先级 | 学习内容 | 达标方式 |
| --- | --- | --- |
| 核心 | 四种检查的原理、优缺点；超声频率与伪像；CT平扫/增强；MRI基本概念 | 不看笔记能解释“为什么” |
| 核心 | 回声、密度、信号；CT值、窗宽窗位；CTA/MRA/MRCP | 能准确使用术语并辨析相近名称 |
| 进阶 | 谐波、复合、编码、弹性、灌注、DTI、MRS、光子计数CT | 能说出每项技术主要解决什么问题 |
| 了解 | 影像发展史、具体设备迭代年份 | 记住关键里程碑，具体细节需要时回查 |

## 一页总览

### 四种检查的基本区别

| 比较项 | 普通X线摄影 | CT | MRI | 超声 |
| --- | --- | --- | --- | --- |
| 主要物理基础 | X线穿过人体后的衰减差异 | 多角度X线衰减数据与计算机重建 | 磁场、射频激发和磁共振信号 | 声波传播、反射、散射及多普勒效应 |
| 是否使用电离辐射 | 是 | 是 | 否 | 否 |
| 常规图像形式 | 二维投影，前后结构叠加 | 断层及多种重建图像 | 多平面、多参数、多序列 | 实时二维切面，可扩展三维 |
| 图像描述词 | 密度 | 密度、CT值 | 信号强度 | 回声强度 |
| 主要优势 | 快、方便；胸部、骨骼等应用广 | 快、断层定位清楚，可定量评价衰减 | 软组织对比突出，功能信息丰富 | 实时、便携，可观察血流并引导操作 |
| 主要局限 | 结构重叠，软组织对比有限 | 电离辐射；部分检查涉及对比剂 | 时间相对较长，对运动敏感，需磁共振安全筛查 | 受气体、骨骼、体型、声窗和操作者影响 |
| 常见对比剂 | 消化道检查常用钡剂等 | 静脉增强常用碘对比剂 | 增强常用钆对比剂 | 超声造影常用微泡 |

**理解“亮”的含义：**超声亮，表示该处回到探头的回声较强；常规X线/CT亮，通常表示衰减较强；MRI亮，表示在该序列和参数下获得较高信号。同样的亮度不能跨检查方式直接类比。

### 三组贯穿全篇的概念

| 概念 | 主要回答的问题 | 例子 |
| --- | --- | --- |
| 形态与结构 | 在哪里、多大、什么形状、与周围有什么关系？ | 肿块大小、骨折移位、胆管扩张 |
| 功能与血流 | 血流、运动、灌注或组织力学性质怎样？ | 多普勒、灌注、心脏运动、弹性成像 |
| 代谢 | 组织中某些代谢物有什么变化？ | MR波谱成像MRS |

“分辨率高”也要说明是哪一种：空间分辨率侧重分开细小结构；对比/密度分辨率侧重分开性质相近的组织；时间分辨率侧重捕捉快速变化。不同检查各有优势。

## 超声医学总论

### 1. 核心：超声是什么？

**课件定位：超声PDF第4–16页。**

- 声波是机械波，传播需要介质。频率大于20,000 Hz，即20 kHz，称为超声。
- 课件列出的诊断超声常用频率约为**2–20 MHz**，远高于人耳听觉范围。
- 在常规人体软组织成像中，主要考虑纵波传播，即质点振动方向与波传播方向平行。
- 超声图像以回声为基础。一次发射后，仪器根据回声返回的时间定位深度，根据回声强弱形成灰阶。

**最重要的两个公式：**

```text
波长 λ = 声速 c / 频率 f
深度 d = 声速 c × 回声往返时间 t / 2
```

软组织成像通常按平均声速约**1540 m/s**计算。实际不同组织的声速有差异，这也是定位误差的来源之一。

**为什么除以2？**记录的是“探头到界面，再从界面回探头”的往返时间，而目标深度只是一程距离。

**计算示例：**回声往返时间为100 μs，则深度约为1540 × 100 × 10⁻⁶ / 2 = 0.077 m，即**7.7 cm**。

### 2. 核心：发射与接收的压电效应

**课件定位：超声PDF第8–9、20页。**

| 过程 | 效应 | 能量转换 | 怎样理解 |
| --- | --- | --- | --- |
| 发射超声 | 逆压电效应 | 电能变为机械振动 | 给晶体施加交变电压，使其振动发声 |
| 接收回声 | 正压电效应 | 机械振动变为电信号 | 返回声波使晶体形变，产生可处理的电信号 |

超声仪器由主机和探头等组成。探头是发射与接收的换能器，主机完成信号发射、接收、处理、显示及测量记录。

### 3. 核心：声波在人体内会发生什么？

**课件定位：超声PDF第10–13页。**

| 现象 | 基本含义 | 对图像的影响 |
| --- | --- | --- |
| 反射 | 声波遇到界面后，一部分返回 | 提供边界回声；反射太强也会限制深部显示 |
| 折射 | 斜入射且两侧声速不同时，传播方向改变 | 可导致位置失真或边缘声影 |
| 散射 | 小或不规则结构使能量向多方向分散 | 参与形成实质组织内部的回声纹理 |
| 衰减 | 传播中声能因吸收、散射等逐渐减少 | 越深越难显示；频率选择和TGC补偿与此有关 |

**为什么需要耦合剂？**探头与皮肤之间的空气会造成很强的反射。耦合剂填充微小空隙、减少空气，使声能更有效地进入人体。关键作用是改善声学接触。

**补充理解：**组织间声阻抗差异影响反射。声阻抗可表示为Z = 组织密度ρ × 声速c。常规B型超声不能简单按组织的质量密度排列明暗。

### 4. 核心：频率、分辨率和穿透深度

**课件定位：超声PDF第16–17页。**

| 选择 | 通常的效果 | 常见用途 |
| --- | --- | --- |
| 较高频率 | 波长较短，细节显示通常更好，但衰减更大、穿透受限 | 甲状腺、乳腺、浅表血管等 |
| 较低频率 | 穿透较好，但细节分辨能力相对降低 | 深部腹部结构、部分心脏检查 |

**选择原则：在能够清楚显示目标深部边界的前提下，选择合适的较高频率。**

| 探头 | 课件示例频率 | 常见观察对象 | 记忆要点 |
| --- | --- | --- | --- |
| 线阵 | 5.0–10.0 MHz | 浅表组织、甲状腺、血管 | 浅表、细节 |
| 凸阵 | 2.5–5.0 MHz | 常规腹部 | 较深、视野较宽 |
| 相控阵 | 2.0–3.0 MHz | 经肋间观察心脏 | 接触面较小，适合有限声窗 |

上述频率是教材示例，实际探头频段更丰富，要结合目标深度、体型与设备选择。

**补充：**频率并不是决定图像质量的唯一因素。脉冲长度、声束宽度、焦点、噪声和后处理也会影响分辨能力。

### 5. 核心：A、B、M、D分别看什么？

**课件定位：超声PDF第21–30页。**

| 类型 | 主要显示方式 | 主要信息 | 典型用途 |
| --- | --- | --- | --- |
| A型 | 振幅曲线 | 回声幅度与时间/距离 | 眼科等精确测距 |
| B型 | 二维灰阶切面 | 大小、形态、边界与内部结构 | 最常见的解剖结构检查 |
| M型 | 一条取样线上，深度随时间的变化 | 结构运动轨迹 | 心脏瓣膜、室壁运动等 |
| D型 | 多普勒血流显示或频谱 | 流动速度、方向及随时间变化 | 血流动力学评价 |

**记忆：A看幅度，B看切面，M看运动，D看流动。**

M型不是普通二维切面的连续照片：它连续记录的是一条选定取样线上的结构运动。

### 6. 核心：多普勒效应与彩色血流

**课件定位：超声PDF第18–19、26、30页。**

红细胞等散射体相对探头运动，会使接收到的回波频率与发射频率不同。

- 朝向探头运动：接收频率升高。
- 远离探头运动：接收频率降低。
- 彩色多普勒把血流信息叠加到二维灰阶图像上，显示血流分布及方向等。
- 频谱多普勒显示血流速度随时间的变化，可观察收缩期、舒张期等变化。

**最容易错的地方：**课件采用“红色朝向探头、蓝色背离探头”的常见色图。色图可以反转，读图必须查看色标。红、蓝表示相对探头的运动方向，不能据此直接判断动脉、静脉或血液含氧量。

**补充：多普勒频移的角度依赖。**

```text
fD = 2 × f0 × v × cosθ / c
```

其中fD为频移，f0为发射频率，v为流速，θ为声束与血流方向夹角。接近90°时，沿声束方向的速度分量很小，信号或测速可能不可靠。因此，“没看到彩色血流”还需检查角度、量程、增益等条件，不能直接等同于没有血流。

**进阶补充：**常规能量多普勒更侧重显示血流信号强弱，对少量或慢速血流较敏感，通常不提供流动方向；它与彩色速度多普勒的显示含义不同。[^S1]

### 7. 核心：黑、白、灰怎样描述？

**课件定位：超声PDF第14–16页。**

| 术语 | 图像表现 | 理解重点 |
| --- | --- | --- |
| 高回声 | 较亮 | 返回回声较强，要说明与什么组织比较 |
| 等回声 | 与参照组织接近 | 相对概念，病灶仍可能靠形态、边界或血流识别 |
| 低回声 | 较暗 | 回声较弱，不直接对应某一种疾病 |
| 无回声 | 近于黑色 | 均质、清亮液体常见，需结合后方表现及其他特征 |

均质液体内部缺少明显的声学不均匀结构，因此内部回声常少；但液体与周围组织的界面仍可有明显回声。含血液、脓液、蛋白或碎屑的液体也可能出现内部回声。

**补充：典型单纯囊肿的观察组合**是内部无回声、壁薄而光滑、后方回声增强，内部通常无可检出的血流。实际判断需要多个切面与合适参数共同支持。

### 8. 核心：图像优化的顺序

**课件定位：超声PDF第31–36页。**

| 顺序 | 检查或调节什么 | 目的 |
| --- | --- | --- |
| 1 | 探头、耦合、体位、压力和声窗 | 先让声波有效到达目标 |
| 2 | 深度与视野 | 目标完整，保留必要周围组织 |
| 3 | 总增益Gain | 调整整体回声显示，保留灰阶层次 |
| 4 | 分段增益TGC | 补偿不同深度的回声显示差异 |
| 5 | 焦点与频率 | 改善目标区域的边界与细节 |
| 6 | 局部放大、冻结与回放 | 选择有代表性的切面进行测量、保存 |

**总增益与TGC区别：**总增益影响整体显示，TGC可分别调节不同深度。二者都不能让被骨或气体阻挡的深部结构自动恢复。

**补充：增益与发射功率区别。**增益主要调节接收信号的放大和显示；发射功率改变进入人体的声能。图像太暗时，应先分析声窗、频率和接收设置。

**建立方向：**先确认探头标记与屏幕标记，再判断横切/纵切及患者左右、头足关系。屏幕近场对应靠近探头的组织，不能脱离探头位置死记“屏幕上方就是身体前方”。

**改善声窗：**可在患者耐受范围内逐渐加压、改变角度、经肋间扫查、调整体位，或配合呼吸。其作用包括移开部分肠气、改变器官位置及减少遮挡。

### 9. 核心：常见超声伪像

**课件定位：超声PDF第44–49页。**

| 伪像 | 为什么形成 | 典型表现 | 怎样验证或利用 |
| --- | --- | --- | --- |
| 混响 | 声波在界面间多次往返，延迟返回 | 多条重复、近于平行的回声线 | 寻找强反射界面，改变入射角观察 |
| 断层厚度伪像 | 声束有厚度，切面外的回声混入 | 液体腔边缘出现模糊回声 | 换切面、换角度，观察回声是否变化 |
| 旁瓣伪像 | 主声束以外的信号被错误定位 | 液体内出现虚假线状或弧形回声 | 寻找邻近强反射体，调整角度和设置 |
| 后方回声增强 | 液体衰减较少，后方获得较多声能 | 液体后方比同深度周围组织更亮 | 可支持囊性特征，须结合形态与内部回声 |
| 声影 | 骨、结石等使声能明显减少 | 强回声结构后方出现暗区 | 对照强回声体与暗区位置关系 |
| 侧方/边缘声影 | 曲面边缘折射等效应 | 囊性结构等边缘后方出现窄暗区 | 沿边缘分布，注意与实性病灶区分 |
| 镜面伪像 | 强反射界面改变声程，产生错误定位 | 界面另一侧出现重复结构 | 寻找真实结构与强反射“镜面” |

**辨析重点：**后方增强、声影都属于成像物理造成的表现，但也能提供诊断线索。不能只因称为伪像，就认为它们没有价值。

**液体腔内发现回声时的思路：**先检查增益和切面，再换角度、体位或轻压，观察回声的位置与动态变化，同时寻找强反射体。持续存在的回声也可能来自血液、沉积物或组织成分，需要进一步判断。

### 10. 进阶：新技术各解决什么问题？

**课件定位：超声PDF第28–29、37–43页。**

| 技术 | 核心思路 | 主要价值或理解边界 |
| --- | --- | --- |
| 组织谐波成像 | 利用组织非线性传播产生的谐波成分 | 可减轻部分杂波，改善边界与内部结构显示 |
| 相位反转 | 连续发射相位相反的脉冲并组合接收信号 | 抑制线性成分，提取非线性成分 |
| 空间复合成像 | 融合多个角度的图像信息 | 减少部分伪像，改善组织边界显示 |
| 全景成像 | 沿扫查路径扩展成像范围 | 展示较长结构或超出单幅视野的病变 |
| 三维超声 | 重建三维结构 | 显示表面形态及空间关系，仍需结合二维切面 |
| 超声造影CEUS | 微泡在声场中产生较强非线性回声 | 观察血流与组织灌注 |
| 弹性成像 | 评价组织受力形变或剪切波传播等 | 提供组织硬度信息，辅助纤维化或病灶评价 |
| 编码脉冲/脉冲压缩 | 发射编码信号，接收后解码 | 改善信号利用，兼顾信噪比与距离分辨能力 |
| 精细采样与重建 | 优化采样及处理 | 改善细小结构显示；课件此处不指微泡定位超分辨成像 |
| 腔内/血管内超声导管 | 微型探头靠近目标 | 观察局部结构，辅助介入监测 |

**补充边界：**组织较硬可见于多种情况，弹性结果不能单独代表恶性程度。超声造影的微泡、CT的碘剂、MRI的钆剂属于不同类型的对比剂。

### 11. 临床应用怎么归纳？

**课件定位：超声PDF第50页。**

可按“结构、动态、血流、介入引导、随访”归纳：观察脏器大小形态、内部结构与占位；观察囊性器官充盈排空、心脏运动；评价血流和灌注；发现积液；引导穿刺活检、置管引流、注药及消融；随访治疗效果。

**补充：**超声没有电离辐射，但仍应按临床需要合理使用声能与检查时间。[^S2]

## X线总论

### 1. 核心：为什么能看见人体内部？

**课件定位：放射学PPT第17–23、27页。**

X线穿过人体时，不同组织的衰减程度不同。探测系统记录剩余X线的分布，形成投影图像。常规显示下，衰减较强的骨骼等偏白，气体较黑，软组织介于其间。

**补充：常见由黑到白的基本顺序**可记为气体、脂肪、软组织/水、骨骼或钙化、金属。亮度还受组织厚度、射线能量与显示处理影响。

普通X线最大的结构性局限是**重叠**：同一射线路径上的多个结构投影到一个位置。因此，有时需要不同体位、不同方向或断层检查进一步定位。

### 2. 核心：摄影、透视、造影的区别

| 方法 | 主要目的 | 典型例子 |
| --- | --- | --- |
| 摄影 | 获得静态投影图像 | 胸片、骨关节片 |
| 透视〔补充〕 | 连续观察运动或操作过程 | 吞咽过程观察、部分介入引导 |
| 对比检查/造影 | 用对比剂增加原本不足的对比 | 食管吞钡、上消化道钡餐、气钡双重对比、静脉尿路造影 |

**课件例子应抓住的重点：**消化道对比检查可显示轮廓、充盈及运动等；静脉尿路造影展示排泄系统。课件列出的是教学实例，不意味着这些方法在所有场景下都优先于CT、MRI或内镜。

### 3. 核心：辐射防护要区分照射对象

**课件定位：放射学PPT第25页。补充校正依据：IAEA。**

| 原则 | 学习要点 |
| --- | --- |
| 正当性 | 检查预期能带来足够临床获益，避免无必要的照射 |
| 最优化 | 在达到诊断目的的前提下，合理控制照射范围、参数与次数 |
| 剂量限值 | 主要用于职业照射和公众照射；不能直接作为患者必要医疗检查的硬性上限 |

**关键辨析：**对患者为诊断或治疗而接受的医疗照射，重点是正当性和最优化，通常不适用职业/公众照射式的剂量限值。诊断参考水平用于优化实践，也不能理解为单个患者绝对不能超过的界限。[^S3]

## CT总论

### 1. 核心：CT比普通X线多做了什么？

**课件定位：放射学PPT第27–35、40页。**

CT即计算机体层成像。它从多个角度采集X线经过人体后的衰减数据，再用计算机重建断层内的衰减分布，得到切面图像。[^S4]

普通X线记录的是路径上结构的综合投影；CT利用多角度信息，把不同位置的结构分开重建，所以能显著减少投影重叠，并获得较好的密度分辨能力。

### 2. 核心：体素、像素和CT值

**课件定位：放射学PPT第33–35页。**

| 概念 | 含义 | 记忆方法 |
| --- | --- | --- |
| 体素Voxel | 人体内被采样/重建的三维体积单元 | 有体积 |
| 像素Pixel | 二维图像中的显示单元 | 有面积 |
| 矩阵 | 像素按行列组成的数字阵列 | 图像的数字格子 |
| CT值 | 将体素的X线衰减相对水进行标准化后的数值 | 用HU表示 |

**补充：CT值的基本表达式。**

```text
CT值（HU）= 1000 ×（μ组织 - μ水）/ μ水
```

μ为线性衰减系数。水约为**0 HU**，空气约为**−1000 HU**；脂肪通常为负值，许多软组织为正值，骨及钙化较高。实际值会受扫描能量、组织成分、噪声和部分容积效应等影响。[^S5]

**补充：部分容积效应。**一个体素内若混合不同组织，测得的是混合后的衰减表现。小病灶或细小钙化可能被平均化，因此层厚会影响显示。

### 3. 补充核心：窗宽与窗位

课件展示肺窗、骨窗及软组织图像。理解窗设置，可以解释“同一次CT为什么能显示出不同样子”。

| 参数 | 定义 | 改变后的主要效果 |
| --- | --- | --- |
| 窗位WL | 灰阶显示范围的中心CT值 | 决定围绕哪一类衰减范围观察 |
| 窗宽WW | 映射到灰阶的CT值跨度 | 宽窗容纳范围较大；窄窗突出较小CT值差异 |

近似显示范围为**WL − WW/2 至 WL + WW/2**。肺窗关注含气肺组织，骨窗关注骨皮质及骨小梁，软组织窗关注实质器官等。[^S5]

**重要：**调整窗宽窗位改变的是显示映射，原始扫描的CT数据并没有因此改变。

### 4. 核心：平扫与增强

**课件定位：放射学PPT第41–43页。**

| 方法 | 做法与主要信息 | 复习要点 |
| --- | --- | --- |
| 平扫 | 不进行静脉对比增强，观察原有衰减差异 | 可观察脂肪、钙化、出血等特征，具体效果依部位和病程 |
| 增强 | 注射碘对比剂，按时间采集 | 观察血管、组织灌注与病灶强化差异 |
| 多期动态增强 | 动脉期、门静脉期、延迟期等 | 观察随时间变化的强化方式 |
| CT灌注 | 对选定区域重复动态采集并分析 | 估计血流、血容量、通过时间等灌注参数 |

**平扫与增强分别提供不同信息。**增强通常增加有关血供和血管的信息，但是否需要平扫、几期增强，应由具体临床问题决定，不能理解为期数越多越好。

**补充辨析：强化不等于原本高密度。**钙化等在平扫即可较白；强化指使用对比剂后相应部位的衰减增加或显示发生变化。

### 5. 核心：肝脏动态增强怎么理解？

**课件定位：放射学PPT第43页。**

课件用肝细胞癌HCC和局灶性结节增生FNH，示范不同强化过程的比较。

| 病变 | 课件教学概括 | 应掌握的解释 |
| --- | --- | --- |
| HCC | “速升速降” | 部分典型病灶动脉期明显强化，后续相对肝实质出现洗脱表现 |
| FNH | “速升缓降” | 用于与HCC示例比较，强调动脉期强化后的变化不同 |

**补充校正：**这些口诀适合记住课件示例，不能作为所有病灶的固定规则。HCC影像判定还要结合高危背景、病灶大小、强化形态及其他征象，LI-RADS也有适用人群与具体条件。[^S6]

“洗脱”需看病灶与背景肝实质之间的相对变化，不能只盯着病灶自己是否变暗。FNH常可表现为明显动脉期强化，后期接近肝实质；还需结合瘢痕和其他影像信息。[^S7]

### 6. 核心：区分检查方案与重建方法

**课件定位：放射学PPT第41、44–47、51–55页。**

| 名称 | 属于什么 | 主要观察内容 |
| --- | --- | --- |
| CTA | CT血管成像方案 | 按血管目标进行对比剂和时相设计，观察血管腔、走行及相关病变 |
| CTU | CT尿路成像方案 | 观察肾脏、集合系统、输尿管等，常包含排泄期信息 |
| CTE | CT小肠成像方案 | 结合肠腔充盈及增强，评价肠壁和肠外改变 |
| MPR | 多平面重建 | 将容积数据重建为冠状、矢状、斜面等 |
| MIP | 最大密度投影 | 在一定厚度内突出高衰减结构，常用于血管显示 |
| VR | 容积再现 | 用容积数据展示立体结构和空间关系 |
| CPR | 曲面重建 | 沿弯曲血管或管道显示连续走行 |

**重要校正：**CTA、CTU、CTE有各自的检查准备和数据采集要求；MPR、MIP、VR、CPR是数据重建或显示方法。获得三维图像并不意味着已经完成某一种专门检查。

**课件例子：**胫骨平台骨折展示多平面重建对骨折形态的价值；肝门胆管癌例子展示胆道、血管及手术空间关系；Crohn病例子展示CTE中的肠壁及肠系膜改变。

**补充：**Crohn病“木梳征”描述肠系膜直小血管充血增多的形态，可支持炎症活动评价，但单一征象不应替代综合诊断。

### 7. 进阶：CT技术发展的方向

**课件定位：放射学PPT第38、48–53页。**

| 技术方向 | 主要进步 | 复习时抓住什么 |
| --- | --- | --- |
| 螺旋CT | 连续旋转配合检查床移动 | 更高效地获得连续容积数据 |
| 多排/多层CT | 同时获得更多层面信息 | 扩大覆盖、提高采集效率 |
| 双源CT | 两套X线源与探测系统 | 有助于快速运动结构等成像，具体依系统与方案 |
| 能谱/能量CT | 利用不同能量下的衰减信息 | 材料区分、能量相关重建与定量分析 |
| 光子计数CT | 对到达探测器的光子进行计数并利用能量信息 | 细节、能谱及剂量效率方面的潜力 |
| CT衍生功能评估 | 结合模型或特定采集分析功能 | 冠脉斑块、血流储备、心肌灌注等 |

这些是技术价值和课件示例，不意味着每项技术在所有患者、所有协议下都同样优越。光子计数CT仍使用X线，仍涉及电离辐射。[^S4]

## MRI总论

### 1. 核心：MRI的基本链条

**课件定位：放射学PPT第58–64页。**

常规临床MRI主要利用氢原子核，即质子的磁共振性质。可以按以下过程理解：

1. **进入静磁场：**质子群体形成可被利用的净磁化。
2. **射频激发：**施加特定频率的射频脉冲，使磁化状态改变。
3. **弛豫与信号采集：**激发后磁化发生演变，接收线圈采集信号。
4. **空间编码：**利用梯度磁场定位信号来源。
5. **重建图像：**依据序列和参数显示组织间信号差异。[^S8]

**补充校正：**自旋是量子性质，课件中“像地球自转”的说法可作为帮助理解的类比。能否发生核磁共振取决于原子核是否具有非零自旋等性质，不能只机械记为“核子数为奇数”。常规MRI也不涉及给患者注射放射性核素。

### 2. 补充核心：T1、T2与加权图像

这是理解后续MRI技术的基础，原课件主要以技术名称和实例展示为主。

| 概念 | 含义 | 常见学习关联 |
| --- | --- | --- |
| T1弛豫 | 纵向磁化恢复的过程 | 与T1加权对比相关 |
| T2弛豫 | 横向磁化因失相位而衰减的过程 | 与T2加权对比相关 |
| TR | 重复时间 | 两次相应激发之间的时间 |
| TE | 回波时间 | 激发后到回波采集的时间 |

以常规自旋回波教学模型理解：T1加权常用较短TR、较短TE；T2加权常用较长TR、较长TE。现代序列更复杂，不能只靠这一组规则识别所有图像。[^S9]

| 常见图像/序列 | 入门识别线索 | 用途与边界 |
| --- | --- | --- |
| T1WI | 单纯液体常低信号；未抑脂时脂肪可较亮 | 解剖结构、增强前后比较等 |
| T2WI | 单纯液体常高信号 | 显示含水较多组织、部分病变改变等 |
| 脂肪抑制 | 脂肪信号受到抑制 | 有助于显示被脂肪高信号遮掩的改变 |
| FLAIR | 抑制脑脊液等自由液体信号，保留部分T2对比 | 有助于观察邻近脑脊液的脑实质病变 |
| DWI | 对水分子扩散运动敏感 | 评价扩散受限，急性缺血等常用 |
| ADC图 | 提供表观扩散系数信息 | 与DWI结合，减少单看高信号带来的误判 |

**口诀的正确用法：**“水T1暗、T2亮”主要指常规条件下的单纯自由液体。脂肪、出血、富蛋白液体和特殊序列可能不同，始终先确认序列。

**补充：DWI高信号不自动等于扩散受限。**需要结合ADC，典型扩散受限常表现为DWI高信号、ADC降低；T2透射效应也能造成DWI变亮。病变时相及其他序列仍然重要。[^S10]

### 3. 核心：多参数、多序列有什么价值？

**课件定位：放射学PPT第63–64页。**

MRI可从不同角度观察同一病变：形态、水分含量相关对比、脂肪、扩散、灌注、强化和代谢等。各序列提供的信息可以相互验证。

| 课件列出的序列家族 | 全称或主要含义 | 现阶段应掌握的程度 |
| --- | --- | --- |
| SE | 自旋回波 | 经典基础序列 |
| FSE | 快速自旋回波 | 提高采集效率 |
| GRE | 梯度回波 | 另一类回波形成方式，具体对比依参数 |
| EPI | 平面回波成像 | 快速采集读出技术，常与扩散等结合 |

**补充辨析：**SE、FSE、GRE、EPI说明序列或采集技术；T1WI、T2WI说明主要图像加权。二者不在同一个分类层级。

### 4. 核心：增强、MRA与MR水成像

**课件定位：放射学PPT第64–68页。**

| 技术 | 原理或主要信息 | 易错点 |
| --- | --- | --- |
| MRI增强 | 常用钆对比剂改变局部弛豫相关信号 | 不是CT式的X线衰减增加 |
| 增强MRA | 结合对比剂和相应采集显示血管 | 关注注射与采集时相 |
| 非增强MRA | 利用血流相关磁共振特性成像 | MRA可以不注射对比剂 |
| MRCP | 磁共振胰胆管成像 | 常规重T2水成像突出静止或缓慢流动的胆汁、胰液 |
| MRU | 磁共振尿路成像 | 有静态水成像方法，也有增强排泄成像方法〔补充〕 |

**理解MR水成像：**在适当序列中让液体信号突出，借此展示含液管道。常规MRCP不同于ERCP，不需要内镜插管进入胆道。

### 5. 进阶：功能与定量成像

**课件定位：放射学PPT第66、69–71页。**

| 技术 | 主要研究什么 | 学习要点 |
| --- | --- | --- |
| DTI扩散张量成像 | 水分子扩散的方向依赖性 | 用于分析白质微结构并估计纤维束走行 |
| MRP灌注成像 | 组织血液供应相关信息 | 关注血流、血容量、通过时间等，参数依方法而异 |
| MRS波谱成像 | 不同化学环境中原子核的共振频率差异 | 提供代谢物相关信息，常以谱峰呈现 |
| MR弹性成像 | 组织内机械波传播与硬度 | 用于肝硬度等评价，需结合方法与病因 |

**课件术语校正：**DTI所依赖的是扩散的**各向异性**。纤维束示踪是基于扩散信息的模型估计，不能把彩色纤维束图理解为直接拍到了每根轴突。

**不要死记单个硬度值：**课件2.1、4.8、8 kPa等为示例，不宜当作适用于所有设备、序列和疾病的统一分级界值。

### 6. 核心：MRI的优势与安全边界

**课件定位：放射学PPT第63页；安全内容为补充。**

优势是软组织对比突出，可多平面、多参数、多序列成像，并具有丰富的功能和代谢成像能力。常用于脑、脊髓、关节、盆腔及部分腹部病变等评价。[^S8]

MRI不使用电离辐射，但需关注强磁场、射频发热、噪声、运动与植入物条件。植入物应核对具体型号及MR安全标签；**MR Conditional表示满足指定条件时可用**，不能笼统理解为“有金属都不能做”或“某一类器械都能做”。[^S11]

## AI与医学影像

### 1. 课件中的主要应用

**课件定位：放射学PPT第74–85页。**

| 任务 | 课件示例 | 核心作用 |
| --- | --- | --- |
| 检测 | 肺结节、动脉瘤标注 | 帮助寻找可疑区域 |
| 分割 | 病灶、血管、脑区分割 | 为测量、比较和分析提供边界 |
| 定量 | 肺炎范围、钙化斑块、狭窄程度 | 减少重复测量工作，提供一致指标 |
| 随访 | 肺结节随访 | 对比大小、体积等变化 |
| 评分 | 脑梗死ASPECTS区域分析与评分 | 辅助标准化评价 |
| 功能推算 | 血流储备分数相关分析 | 将图像与模型结合，提供功能线索 |

**补充辨析：**ASPECTS评价的是特定区域早期缺血改变的范围，不等同于直接给出精确梗死体积。

### 2. 补充：评价AI不能只看一个“准确率”

课件用“从数据学习、由专家标注带教”说明模型训练，并以“黑盒困境”提醒解释性问题。进一步复习时，关注训练/测试人群是否匹配实际使用场景，是否经过独立验证，以及漏检、误报和人工复核的影响。

FDA透明性原则强调应说明预期用途、训练和测试数据、性能与限制，并关注人和AI共同工作的表现。解释图或热图本身也不能证明模型结论正确。[^S12]

## 检查选择与读片思路

### 用临床问题组织检查选择

下表是帮助理解技术特点的常见场景，并非完整的临床检查路径。

| 需要回答的问题 | 常见有价值的检查 | 理由 |
| --- | --- | --- |
| 浅表甲状腺结节是什么结构？有无血流？ | 高频超声 | 浅表细节、实时观察、多普勒 |
| 胆囊内有无结石或积液？ | 超声 | 观察强回声、声影、液体及动态变化 |

| 复杂骨折的形态与关节面怎样？ | CT及MPR | 多方向评价骨折及空间关系 |

### 面对一张图，按固定顺序问自己

1. **这是什么检查？**普通X线、CT、MRI还是超声？是否增强？MRI是什么序列？
2. **图像方向是什么？**部位、切面、左右标记、近远场是否明确？
3. **图像质量够不够？**有没有运动、遮挡、窗设置不合适或伪像？
4. **异常在哪里？**器官内外、具体分区、与管道和周围结构的关系？
5. **异常是什么表现？**大小、形态、边界、内部均匀性、回声/密度/信号、血流或强化方式？
6. **能得出什么程度的结论？**先描述征象，再结合临床背景提出判断，必要时比较其他序列、时相或既往检查。

## 易混易错对照表

| 容易混淆的说法 | 应掌握的表述 |
| --- | --- |
| 超声频率越高，穿透越深 | 在常见软组织条件下，高频细节通常更好，但衰减更大、穿透相对差 |
| 无回声就一定是单纯囊肿 | 要结合壁、后方回声、血流、多个切面和参数 |
| 低回声就是低密度 | 超声用回声，CT用密度/衰减，MRI用信号 |
| 红色是动脉，蓝色是静脉 | 常见色图编码相对探头的运动方向，先看色标 |
| 没有彩色就没有血流 | 还需排查角度、量程、增益、低速血流等条件 |
| 调高增益就提高了发射功率 | 接收显示增益与发射声能是不同参数 |
| 所有伪像都没有意义 | 声影、后方增强等可提供有用线索 |
| CT已经是断层，所以没有任何平均化误差 | CT仍可能存在部分容积效应等 |
| 改窗宽窗位能改变病灶本身CT值 | 改变的是显示映射 |
| 增强就是图像整体更白 | 重点是组织/病灶随对比剂和时间的变化 |
| 高密度就等于强化 | 需结合平扫与增强判断，原有钙化等也可高密度 |
| CTA、CTU、CTE就是三种重建图 | 它们是专门检查方案，可再进行不同重建 |
| 肝癌一定“快进快出” | 是典型模式的教学概括，需结合背景和完整影像条件 |
| MRI任何亮区都表示同一成分 | 信号取决于序列、参数和组织性质 |
| DWI亮就一定是急性脑梗死 | 结合ADC、其他序列、部位和临床时相 |
| MRA都要打对比剂 | 有增强和非增强方法 |
| MRCP等同于ERCP | MRCP是磁共振成像，ERCP涉及内镜和插管操作 |
| DTI直接显示真实的每根神经纤维 | 示踪结果是基于扩散信息的模型估计 |
| 弹性硬度高就一定恶性 | 硬度变化有多种原因，需综合判断 |
| 患者医疗照射受职业剂量限值直接限制 | 患者诊疗照射以正当性、最优化为重点 |
| MRI无电离辐射，所以不用做安全筛查 | 仍需筛查磁场、射频和植入物相关风险 |
| AI准确率高，就可以单独诊断 | 还需明确用途、验证条件、漏检误报及人工复核 |

## 考前速记与掌握清单

### 最少要能说出的十五句话

1. 普通X线是投影图像，前后结构会重叠。
2. CT用多角度X线衰减数据重建断层。
3. 超声发射依靠逆压电效应，接收依靠正压电效应。
4. 超声用往返时间定位深度，用回声强弱显示灰阶。
5. 高频超声细节通常更好，但穿透受限。
6. 耦合剂的关键作用是减少探头与皮肤间空气。
7. A看幅度、B看切面、M看运动、D看流动。
8. 彩色多普勒颜色须结合色标，不能直接区分动静脉。
9. 液体后方可增强，结石和骨后方可有声影。
10. 水约0 HU，空气约−1000 HU。
11. 窗宽窗位改变显示，原始CT值不因此改变。
12. CTA/CTU/CTE是检查方案，MPR/MIP/VR是重建或显示方法。
13. MRI常规主要利用氢质子信号，信号高低必须结合序列。
14. MRA可以不增强，MRCP常利用重T2水成像。
15. 选择检查要围绕临床问题，同时考虑质量、局限与安全条件。

### 参考答案与解析

| 题号 | 要点 |
| --- | --- |
| 1 | 深度主要依回声往返时间计算；亮度与返回回声强弱及增益等显示设置有关。 |
| 2 | 1540 × 80 × 10⁻⁶ / 2 = 0.0616 m，即约6.16 cm。 |
| 3 | 浅表目标适合较高频率以观察细节；深部目标更依赖穿透能力，常需降低频率。 |
| 4 | 肠气使入射声能难以到达目标，增益只是放大接收到的信号，不能补回被遮挡的信息。 |
| 5 | B型显示二维切面；M型记录一条取样线上结构随时间的运动。 |
| 6 | 不能。颜色主要表示相对探头方向，并受色标设置影响。 |
| 7 | 可描述为强回声伴后方声影，为结石等提供线索，仍须结合部位、形态、动态及其他信息。 |
| 8 | 深度本身影响衰减。同深度比较更有助于判断液体低衰减造成的相对后方增强。 |
| 9 | 调整增益、切面、角度与体位，观察持续性和动态变化，寻找邻近强反射界面，并结合其他检查信息。 |
| 10 | X线形成路径上结构的综合投影；CT从多角度数据计算断层衰减分布。 |
| 11 | 体素是三维体积单元，像素是二维显示单元；水约0 HU，空气约−1000 HU。 |
| 12 | 没有。改变的是CT值到灰阶的映射范围。 |
| 13 | 不能。原有钙化、出血等也可高密度，要结合对比剂使用情况及平扫/增强变化判断。 |
| 14 | 强化随时间变化，不同时相反映的血供信息不同；单一时相可能遗漏或误解特征。 |
| 15 | CTU是围绕泌尿道设计的检查方案；MPR是对已经获取的容积数据进行多平面重建。 |
| 16 | 同一组织在不同序列下可明暗不同，必须知道加权与抑制设置，才能解释信号。 |
| 17 | DWI也受T2等因素影响。结合ADC降低可支持扩散受限，仍需综合判断。 |
| 18 | MRA有增强和非增强方法；常规MRCP用重T2成像突出胆汁、胰液等液体信号。 |
| 19 | DTI评价扩散方向性与微结构；灌注评价血供；MRS评价代谢物；弹性评价组织力学性质。 |
| 20 | MRI仍有强磁场、射频发热、噪声及植入物相关问题，必须核对安全条件。 |
| 21 | 患者医疗照射具有直接诊疗获益，应重点进行正当性与最优化；职业限值针对不同照射情境。 |
| 22 | 预期用途、人群和设备适配、独立验证、漏检误报、工作流程及人工复核要求。 |
