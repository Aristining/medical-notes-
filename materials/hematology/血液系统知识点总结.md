## 一页速览：血液系统的主线

血液系统可以按“**发生 → 分化 → 功能 → 疾病**”一条线理解：

1. **造血干细胞（HSC）** 位于骨髓龛（niche）中，具有自我更新和多向分化两大特征。
2. HSC 在细胞因子、骨髓微环境和基因网络的共同调控下，分化为红系、粒-单系、巨核系和淋巴系。
3. 各系终末细胞执行不同功能：红细胞运氧、粒细胞抗感染、淋巴细胞免疫、血小板止血。
4. 任一环节出现**生成减少、破坏增多、分布异常、功能缺陷或恶性克隆增殖**，就会形成血液病。
5. 血液病的诊断遵循“**血常规入口 → 骨髓确诊 → MICM 分型 → 分子靶向/危险分层**”的思路。

| 谱系 | 终末细胞 | 核心功能 | 关键调控因子 | 代表疾病 | 关键标志 |
|---|---|---|---|---|---|
| 红系 | 红细胞 | 运输 O₂ 和 CO₂ | EPO、铁、叶酸、B₁₂ | 缺铁性贫血、巨幼细胞贫血、地中海贫血、镰状细胞贫血 | 血红蛋白、CD71、GPA |
| 粒系 | 中性粒/嗜酸/嗜碱 | 抗感染、过敏反应 | G-CSF、GM-CSF、IL-5 | 粒细胞缺乏、白血病、类白血病反应 | MPO、CD13、CD33 |
| 单核系 | 单核/巨噬细胞 | 吞噬、抗原提呈、免疫调节 | M-CSF、GM-CSF、IL-4 | 单核细胞白血病、组织细胞病 | CD14、CD68 |
| 淋巴系 | T/B/NK | 特异性免疫、体液免疫、固有免疫 | IL-7、IL-2、IL-15 | ALL、CLL、淋巴瘤、骨髓瘤 | CD3、CD19、CD16/56 |
| 巨核系 | 血小板 | 初级止血、凝血、血管稳态 | TPO、IL-11 | ITP、血栓性血小板减少、血小板功能缺陷 | CD41/CD61、CD42b |

## 一、血液系统总论

### 1.1 核心概念

- **血液学（hematology）**：以血液和造血器官为研究对象，用形态学、生物化学、分子生物学等方法研究血液组成、功能、疾病机制及防治规律的医学科学。
- **血液病（hematological disease）**：原发于或主要发生于造血系统、以血液学异常为主要表现的疾病，包括各类贫血、良恶性白细胞疾病、血小板异常、出凝血疾病等。
- **血液系统疾病的学习逻辑**：正常造血 → 造血异常 → 血液成分异常 → 临床症状 → 实验室诊断 → 治疗。

### 1.2 血液的组成

血液由**血浆（55%）**和**有形成分（45%）**组成；有形成分中白细胞和血小板仅占不到 1%（白膜层）。

| 成分 | 组成 | 主要功能 |
|---|---|---|
| 血浆 | 水约 90%；溶质约 10% | 运输、维持胶体渗透压、免疫、凝血 |
| 血浆蛋白 | 白蛋白、球蛋白、纤维蛋白原 | 白蛋白维持胶体渗透压；球蛋白参与免疫；纤维蛋白原是凝血底物 |
| 红细胞 | 无核、双凹圆盘状 | 运输 O₂ 和 CO₂ |
| 白细胞 | 粒细胞、淋巴细胞、单核细胞 | 机体防御、免疫 |
| 血小板 | 无核细胞碎片 | 止血、凝血、血管稳态 |

### 1.3 血细胞功能与疾病谱

| 细胞/系统 | 正常功能 | 功能异常或疾病 |
|---|---|---|
| 红细胞 | 运输氧和二氧化碳 | 贫血、红细胞增多症 |
| 粒细胞 | 抗感染 | 粒细胞缺乏、功能缺陷、白血病 |
| 单核/巨噬细胞 | 吞噬、抗原提呈、免疫调节 | 单核细胞白血病、组织细胞病 |
| 淋巴细胞/浆细胞 | 特异性免疫、抗体产生 | 淋巴瘤、急慢性淋巴细胞白血病、多发性骨髓瘤 |
| 造血干细胞 | 自我更新、多向分化 | 再生障碍性贫血、MDS、PNH、白血病 |
| 血小板 | 初级止血、凝血 | 血小板减少、增多、功能缺陷 |
| 凝血/抗凝/纤溶系统 | 维持血液流动性与止血平衡 | 血友病、DIC、血栓性疾病 |

**血液系统疾病分类（课件框架）**

- 红细胞疾病：贫血、红细胞增多症。
- 粒细胞疾病：粒细胞缺乏、中性粒细胞分叶功能不全、Pelger-Huët 畸形、惰性白细胞综合征、类白血病反应。
- 单核/巨噬细胞疾病：炎症性组织细胞增多症、恶性组织细胞病等。
- 淋巴细胞和浆细胞疾病：各类淋巴瘤、急慢性淋巴细胞白血病、多发性骨髓瘤。
- 造血干细胞疾病：阵发性睡眠性血红蛋白尿（PNH）、骨髓增生异常综合征（MDS）、再生障碍性贫血（AA）、急性髓系白血病等。
- 出血性疾病：血管性紫癜、血小板减少性紫癜、凝血障碍性疾病、弥散性血管内凝血（DIC）。
- 血栓性疾病及输血相关疾病。

### 1.4 血液病常见症状与体征

| 表现 | 发生机制 | 临床提示 |
|---|---|---|
| **发热** | 致热原使体温调定点上移，体温升高 >0.5℃；血液病常见感染、肿瘤热、药物热 | 粒缺患者感染风险高；发热伴骨痛、出血需警惕白血病 |
| **贫血** | 红细胞生成减少、破坏增加、失血；或血浆容量增加造成相对性贫血 | 苍白、乏力、头晕、心悸、气短；老年人可诱发心衰 |
| **出血** | 血管壁破裂/渗漏；血小板生成减少、破坏增加、消耗增加或功能障碍；凝血因子减少/消耗；抗凝物质增多或纤溶亢进 | 皮肤黏膜瘀点、瘀斑、鼻衄、牙龈出血；深部血肿/关节出血更提示凝血因子问题 |
| **血栓** | 活体心脏或血管腔内，血液成分黏集形成固体质块 | 动脉血栓：卒中、急性冠脉综合征、外周动脉病；静脉血栓：DVT、肺栓塞 |
| **黄疸** | 溶血产生大量间接胆红素；肝细胞处理障碍；胆道梗阻 | 溶血时伴贫血、网织红细胞升高、脾大 |
| **肝脾淋巴结肿大** | 白血病/淋巴瘤浸润；髓外造血；感染或免疫反应 | 淋巴瘤常见无痛性进行性淋巴结肿大；CML 常见巨脾 |
| **骨痛/胸骨压痛** | 白血病细胞在骨髓内增殖、骨膜受牵拉 | 急性白血病的重要体征 |

> **发热与贫血的定义**
>
> - 发热：在致热原作用下，体温调定点上移，体温超过正常 0.5℃。临床上习惯把体温升高称为发热，需与过热（hyperthermia）区分。
> - 贫血：外周血单位容积血红蛋白量、红细胞计数和/或红细胞压积低于正常最低值。

### 1.5 血液病的诊断思路

**基本路径：病史 → 体检 → 血常规/外周血涂片 → 骨髓检查 → 影像/分子检查 → 综合诊断。**

| 步骤 | 内容 | 目的 |
|---|---|---|
| 病史 | 贫血、出血、发热、骨痛、体重下降、药物/毒物/放射线接触、家族史 | 判断急慢性、获得性或遗传性 |
| 体检 | 皮肤黏膜苍白/黄染/出血点、肝脾淋巴结、胸骨压痛、口腔溃疡/舌炎 | 定位受累系统和疾病线索 |
| 血常规 | WBC、Hb、PLT、MCV、MCH、MCHC、RDW、网织红细胞 | 判断哪一系异常、贫血形态学分类 |
| 外周血涂片 | 细胞形态、原始细胞、破碎红细胞、球形红细胞、靶形红细胞、Auer 小体 | 提供形态学诊断线索 |
| 骨髓穿刺/活检 | 增生程度、细胞比例、原始细胞比例、巨核细胞、铁染色 | 确诊白血病、AA、MDS、骨髓瘤等 |
| 免疫表型 | 流式细胞术检测 CD 系列抗原 | 确定细胞来源和分化阶段 |
| 细胞遗传学 | 染色体核型、FISH | 发现易位、缺失、倒位 |
| 分子生物学 | PCR、测序、融合基因 | 诊断、分型、靶向治疗、危险分层 |
| 影像学 | CT、PET-CT、MRI、超声 | 评估淋巴结、肝脾、髓外浸润 |

**骨髓增生程度（课件标准）**

| 增生程度 | 有核细胞/高倍视野 | 常见疾病 |
|---|---|---|
| 极度活跃 | >100 | 白血病 |
| 明显活跃 | 50–100 | 白血病、贫血 |
| 活跃 | 20–50 | 正常骨髓 |
| 低下 | 5–10 | 慢性再生障碍性贫血 |
| 极度低下 | 1–2 | 急性再生障碍性贫血 |

> **【补充】** 部分教材在“活跃”和“低下”之间还有“减低（10–20 个/HP）”；不同教材的界值略有差异，考试以授课标准为准。

**MICM 分型**

| 字母 | 英文 | 中文 | 主要方法 |
|---|---|---|---|
| M | Morphology | 形态学 | 骨髓涂片、细胞化学染色 |
| I | Immunology | 免疫学 | 流式细胞术 |
| C | Cytogenetics | 细胞遗传学 | 染色体核型、FISH |
| M | Molecular biology | 分子生物学 | PCR、基因测序、融合基因 |

### 1.6 血液学发展史与转化医学

| 时间 | 事件 | 意义 |
|---|---|---|
| 1590 | Jansen 父子发明/改良显微镜 | 从肉眼进入微观 |
| 1880 | Ehrlich 发明血细胞染色法 | 血细胞形态学基础 |
| 1900 | Landsteiner 发现 ABO 血型 | 安全输血 |
| 1937 | Schretenmeyer 用骨髓移植治疗再障 | 造血干细胞治疗的开端 |
| 1961 | Till 建立小鼠脾结节测定技术 | 造血干细胞研究的里程碑 |
| 1966 | Metcalf 建立 CFU-E、CFU-Meg 培养方法 | 造血祖细胞体外研究 |
| 1988 | 王振义等应用全反式维甲酸（ATRA）治疗 APL | 诱导分化治疗的典范 |
| 1992 | 张亭栋等应用三氧化二砷（As₂O₃）治疗 APL | 靶向降解致病融合蛋白 |
| 2001 | 伊马替尼（imatinib）上市 | CML 靶向治疗 |
| 2006 | Yamanaka 建立诱导多能干细胞（iPSC） | 再生医学 |
| 2017 | CAR-T 获 FDA 批准 | 细胞免疫治疗 |
| 2021–2023 | CRISPR-Cas9 治疗镰状细胞病/β 地中海贫血进入临床并获批 | 基因编辑治疗遗传性血液病 |

**转化医学的三个经典范例**

1. **APL**：t(15;17) → PML-RARα 融合基因 → ATRA 诱导分化、As₂O₃ 降解融合蛋白 → 从高致死率变为可能治愈。
2. **CML**：t(9;22) → BCR-ABL 组成性酪氨酸激酶 → 伊马替尼抑制 ATP 结合位点 → 生存期显著延长。
3. **CAR-T**：CD19 特异性 CAR 修饰 T 细胞 → 杀伤 B 细胞肿瘤。

### 1.7 病例启示

- **病例 1**：65 岁男性，长期饮酒，乏力、面色苍白、牙龈出血；WBC 3.0×10⁹/L、Hb 67 g/L、PLT 45×10⁹/L、MCV 138.7 fL。**全血细胞减少 + 大细胞性贫血**，首先考虑巨幼细胞贫血（叶酸/B₁₂ 缺乏），酒精是重要诱因；需查叶酸、维生素 B₁₂、网织红细胞和骨髓。
- **病例 2**：26 岁女性，发热、胸痛、面色苍白、肝脾大、胸骨压痛；WBC 11.2×10⁹/L、Hb 82 g/L、PLT 68×10⁹/L、原幼细胞 62%。**原始细胞 ≥20%**，考虑急性白血病，需 MICM 分型。

## 二、造血发生与调控

### 2.1 基本概念

- **造血（hematopoiesis）**：各种谱系造血细胞形成的过程。
- **造血细胞**：能产生红细胞系、粒细胞系、巨核细胞系、淋巴细胞系及单核细胞系的细胞。
- **造血干细胞（HSC）**：能自我更新并分化为所有造血细胞的一群原始造血细胞。
- **造血祖细胞（progenitor）**：由 HSC 分化而来，**丧失自我更新能力**，但仍具有分化为某一或某些谱系细胞能力的过渡性、增殖性细胞群。
- **增殖（proliferation）**：通过有丝分裂进行复制的过程。
- **分化（differentiation）**：基因调控下由一般向特殊演变、获得新功能的过程。
- **成熟（maturation）**：由原始幼稚细胞向终末细胞分化，形态特征逐渐明确的过程。
- **释放（release）**：终末细胞通过骨髓-血屏障进入血液循环的过程。

### 2.2 造血干细胞的特征

| 特征 | 内容 |
|---|---|
| 数量 | 占骨髓有核细胞的约 0.1%–0.5%（不同教材/方法可低至 0.05%） |
| 细胞周期 | 大部分处于 G₀ 期（静息状态） |
| 两大特性 | **自我更新（self-renewal）** + **多向分化（differentiation）** |
| 分裂方式 | 对称分裂（扩增干细胞池）与不对称分裂（一个干细胞 + 一个分化细胞） |
| 形态 | 类似小淋巴细胞，**无法从形态上区分** |
| 免疫表型 | **Lin⁻ CD34⁺ CD38⁻ CD90⁺ CD45RA⁻** |
| 异质性 | 不同发育时期、不同部位的 HSC 分化潜能不同 |
| 功能检测 | 体内连续移植实验、脾结节形成实验等衡量“干性” |

> **记忆锚点**：HSC 的“身份证”是 **Lin⁻、CD34⁺、CD38⁻、CD90⁺、CD45RA⁻**；既不能看形态，也不能只看 CD34（祖细胞也表达 CD34）。

### 2.3 HSC、造血祖细胞与成熟细胞的比较

| 项目 | 造血干细胞 | 造血祖细胞 | 成熟细胞 |
|---|---|---|---|
| 占骨髓细胞比例 | 约 0.05%–0.5% | 约 3% | 95% 以上 |
| 自我更新 | 有 | 无 | 无 |
| 分化潜能 | 全部谱系 | 多能或定向 | 终末分化 |
| 细胞周期 | 多数静息 | 过渡性、增殖期 | 终末分化 |
| 形态辨认 | 不能 | 不能 | 可以 |
| 功能检测 | 体内移植/脾结节 | 体外集落形成实验（CFU） | 形态、免疫表型 |

### 2.4 造血细胞的增殖、分化与成熟规律

**增殖**：除巨核细胞外，血细胞主要通过**有丝分裂（对称性增殖）**扩增；具有分裂能力的阶段从长期 HSC、短期 HSC、多能祖细胞、定向祖细胞到前体细胞逐渐减弱。

**成熟的一般规律**

| 项目 | 规律 | 例外 |
|---|---|---|
| 细胞大小 | 逐渐变小 | **巨核细胞逐渐变大** |
| 核质比 | 逐渐降低 | — |
| 细胞核 | 逐渐变小、浓缩 | 红细胞最终脱核；巨核细胞核分叶、多倍体 |
| 核形状 | 圆形 → 凹陷 → 分叶/杆状 | — |
| 染色质 | 细致疏松 → 粗糙致密 | — |
| 核仁 | 数量减少、体积变小 → 消失 | — |
| 核染色 | 淡紫色 → 深紫色 | — |
| 胞浆 | 逐渐增多 | — |
| 胞质染色 | 蓝色 → 红/粉/其他颜色 | — |
| 颗粒 | 粒细胞中逐渐增多 | — |
| 血红蛋白 | 红系逐渐增多 | — |
| 有丝分裂能力 | 逐渐降低 | **淋巴细胞可再次活化增殖** |

**红系成熟**

原红细胞 → 早幼红细胞 → 中幼红细胞 → 晚幼红细胞 → 网织红细胞 → 成熟红细胞。

对应三个核心事件：

1. **核糖体合成**（原红/早幼红）；
2. **血红蛋白蓄积**（中幼红/晚幼红）；
3. **脱核**（晚幼红 → 网织红）。

**粒系成熟**

原粒细胞 → 早幼粒细胞 → 中幼粒细胞 → 晚幼粒细胞 → 杆状核粒细胞 → 分叶核粒细胞。

- 原粒细胞：核细致疏松，2–5 个核仁，胞浆少、无颗粒。
- 早幼粒细胞：体积略大，核偏位，开始出现嗜天青颗粒。
- 中幼粒细胞：核致密、核仁消失，开始出现特异性颗粒。
- 晚幼粒细胞：核呈肾形。
- 杆状核：核呈带状，直径均一。
- 分叶核：核分 2–5 叶，含特异性颗粒。

### 2.5 造血发生的场所与变迁

**胚胎期造血**

| 阶段 | 时间 | 主要造血内容 |
|---|---|---|
| 卵黄囊造血（胚外造血） | 胚胎第 2–6 周 | 以红细胞为主，产生第一代巨幼红细胞 |
| 肝脏造血 | 第 6 周–第 7 个月 | 主要造血场所；以红细胞为主，产生第二代巨幼红细胞；第 4 个月后产生粒细胞和少量巨核细胞，第 5 个月后逐渐减少 |
| 脾脏造血 | 第 3 个月开始 | 红细胞；第 5 个月后产生粒细胞、淋巴细胞、单核细胞 |
| 骨髓造血 | 第 4 个月开始 | 第 7 个月至出生成为主要造血场所 |
| 淋巴结造血 | 胚胎后期 | 淋巴细胞造血 |

> **记忆口诀**：**卵黄囊 2–6 周，肝 6 周–7 月，脾 3 月起，骨髓 4 月起、7 月后为主。**

**出生后造血**

| 场所 | 功能 |
|---|---|
| 骨髓 | 主要造血场所；5 岁以前所有骨骼骨髓均造血；18 岁以后主要在椎骨、胸骨、肋骨、骨盆及长骨骨干骺端 |
| 胸腺 | T 细胞发育成熟的场所（一级淋巴器官） |
| 脾脏 | 大量 T、B 细胞；B 细胞成熟和免疫应答；清除衰老红细胞 |
| 淋巴结 | T、B 记忆细胞与抗原提呈细胞接触，产生免疫应答 |

- **一级淋巴器官**：骨髓（B 细胞）、胸腺（T 细胞）。
- **二级淋巴器官**：脾脏、淋巴结、黏膜相关淋巴组织。
- **髓外造血（extramedullary hematopoiesis）**：骨髓纤维化等疾病状态下，肝、脾、淋巴结重新恢复胎儿期造血功能。

**骨髓结构**

- 红骨髓：造血活跃，含造血细胞岛，按区域造血。
- 黄骨髓：脂肪组织替代，潜在性造血组织，必要时可转化为红骨髓。
- 骨髓由结缔组织、神经、血管、基质细胞、细胞外基质和造血细胞组成，约占体重的 3.4%–5.9%。
- **血窦壁**构成骨髓-血屏障，调控成熟血细胞释放入血。

**胸腺结构**

- 皮质：胸腺细胞密集，T 细胞发育、TCR 重排、阳性/阴性选择主要发生于此。
- 髓质：含胸腺小体（Hassall 小体）、树突状细胞、上皮细胞。
- 胸腺是 T 细胞获得 MHC 限制性和自身耐受的场所。

**脾脏结构**

- 白髓：动脉周围淋巴鞘、淋巴滤泡，主要含 T、B 细胞。
- 边缘带：白髓与红髓交界，是血源性抗原应答的重要区域。
- 红髓：脾索、脾血窦，负责清除衰老红细胞、调节血容量。
- 脾脏功能：红细胞清除、血容量调节、免疫功能。

**淋巴结结构**

- 浅层皮质：初级滤泡、次级滤泡、生发中心（B 细胞）。
- 深层皮质/副皮质：T 细胞区。
- 髓质：髓索、髓窦，含浆细胞和巨噬细胞。
- 淋巴结是对**组织抗原**产生免疫应答的主要场所；脾脏主要对**血源性抗原**产生应答。

### 2.6 造血微环境（niche）

**定义**：造血微环境又称造血干细胞龛（niche），由除 HSC 以外的所有参与调控造血的间质成分组成，包括微血管系统、神经成分、网状细胞、基质细胞、细胞外基质及其他结缔组织。它是 HSC 赖以生存的场所，调控造血细胞的增殖、分化、发育和成熟。

| 组成细胞/成分 | 关键分子 | 主要作用 |
|---|---|---|
| 成骨细胞 | CXCL12、骨桥蛋白（OPN） | 维持 HSC 干性和存活；骨内膜附近定位部分 HSC |
| 内皮细胞 | Notch 配体、TGF-β、E-选择素 | 维持干祖细胞干性/分化；调节增殖和黏附；血窦壁构成骨髓-血屏障 |
| 神经细胞 | 去甲肾上腺素等 | 有髓神经调节血管舒缩和血流；无髓神经末梢释放神经体液因子影响造血 |
| 网状细胞/间充质干细胞 | CXCL12、SCF | CXCL12 调控 HSC 定植；SCF 促进干性维持 |
| 细胞外基质 | 层粘连蛋白、纤连蛋白、蛋白多糖、胶原、整合素 β1 | 黏附、细胞间信息传递、调控增殖和分化 |

> **一句话总结 niche**：通过分泌细胞因子和细胞外基质，调控 HSC 的**维持、增殖状态、分化、迁移**。

### 2.7 造血发生的调控

#### （1）内在因素：基因调控网络

| 层面 | 关键分子/机制 | 作用 |
|---|---|---|
| 信号通路 | Wnt、Notch | 调控 HSC 自我更新和分化 |
| 表观遗传 | DNA 甲基化、组蛋白乙酰化、羟基化等 | 调控基因表达 |
| 自我更新相关转录因子 | HoxB4、Bmi1、Meis1 等 | 维持干细胞特性 |
| 谱系分化转录因子 | GATA1（红系）、C/EBPα（粒系）、Pax5（B 细胞）、GATA3（T 细胞） | 决定谱系方向 |
| 造血发生关键基因 | Scl、Runx1、Bmi1、Meis1 | 早期造血发育 |

#### （2）外在因素：细胞因子、微环境和细胞外基质

**细胞因子的定义与特性**

- 定义：由基因编码的细胞外信号分子，由多种骨髓细胞和内分泌器官产生，调控细胞增殖和分化。
- 特性：
  1. 低浓度即可发挥作用，功能多样；
  2. 不同细胞因子作用于不同发育阶段的细胞；
  3. 通常可在不同谱系细胞中发挥作用；
  4. 不同因子之间具有协同效应。

**细胞因子的分类**

| 分类方式 | 类别 | 代表因子 |
|---|---|---|
| 按来源 | 近程因子（骨髓基质细胞分泌） | CSF、IL-3 |
| 按来源 | 远程因子（内分泌器官分泌） | EPO（肾）、TPO（肝） |
| 按作用时间 | 早期作用因子 | SCF、Flt3-L、IL-3、IL-6 |
| 按作用时间 | 晚期作用因子 | G-CSF、M-CSF、EPO、TPO |
| 按作用方向 | 正向调控因子 | SCF、EPO、TPO、G-CSF 等 |
| 按作用方向 | 负向调控因子 | TGF-β、TNF、IFN、LIF、PF4、MIP-1α 等 |

**正向调控因子与作用细胞**

| 细胞因子 | 主要作用细胞/阶段 |
|---|---|
| SCF、Flt3-L | HSC |
| GM-CSF | CFU-GM |
| G-CSF | CFU-G |
| M-CSF | CFU-M |
| Meg-CSF | CFU-Meg |
| IL-3 | CFU-GEMM（多能祖细胞） |
| IL-6 | B 系祖细胞 |
| IL-1 | T 系祖细胞 |
| IL-5 | CFU-Eos（嗜酸性粒细胞集落） |
| EPO | CFU-E（红系集落） |
| TPO、IL-11 | CFU-Meg 和血小板 |

**负向调控因子**

| 因子 | 作用 |
|---|---|
| TGF-β | 抑制干祖细胞增殖 |
| TNF-α、TNF-β | 抑制各种祖细胞增殖 |
| IFN-α、β、γ | 调节免疫、抗病毒、抗肿瘤、抗增殖 |
| LIF | 抑制胚胎干细胞和 HSC 分化 |
| PF4 | 抑制巨核细胞增殖 |
| MIP-1α | 抑制祖细胞集落形成 |

**细胞因子的临床应用**

- 促进肾性贫血患者红细胞生成（EPO）。
- 促进化疗/放疗后骨髓抑制的恢复（G-CSF、GM-CSF）。
- 增强杀伤肿瘤细胞（IFN、IL-2）。
- 促进恶性细胞分化（ATRA）。
- 增强免疫系统功能。
- 治疗骨髓衰竭。

### 2.8 骨髓移植与造血干细胞动员

**骨髓移植（bone marrow transplantation，BMT）**：又称造血干细胞移植。经大剂量放化疗或其他免疫抑制剂预处理，清除受体体内的肿瘤细胞或异常克隆，再将自体或异体 HSC 移植给受体，使受体重建供体来源的正常造血和免疫功能。

| 分类 | 干细胞来源 | 特点 |
|---|---|---|
| 自体移植 | 患者本人 | 无排异风险；肿瘤复发率较高 |
| 同基因移植 | 同卵双生双胞胎 | 无排异风险、疗效高；机会极少 |
| 异基因移植 | HLA 配型相合的供者、亲缘单倍相合供者 | 可产生移植物抗肿瘤效应；有 GVHD 风险 |
| 骨髓移植 | 骨髓 | 经典来源 |
| 外周血干细胞移植 | 动员后的外周血 | 采集方便，临床常用 |
| 脐血干细胞移植 | 脐带血 | 免疫耐受性好，细胞数量有限 |

- **归巢（homing）**：HSC 从外周血定位到骨髓 niche 的过程，有助于干性维持和血液系统稳态。
- **动员（mobilization）**：HSC 从骨髓 niche 迁徙到外周血的过程，有助于急性状态下造血细胞的补充。
- **临床应用**：白血病、骨髓瘤、淋巴瘤、乳腺癌、再生障碍性贫血、骨髓纤维化等。
- **并发症【补充】**：感染、GVHD、肝静脉闭塞病、复发等。
- **未来方向**：体外扩增 HSC、HSC 基因治疗、基因编辑（镰状细胞病、地中海贫血）。

### 2.9 细胞治疗

**细胞治疗**：利用具有特定功能的细胞，经生物工程方法获取和/或体外扩增、特殊培养后，使其具有增强免疫、杀伤病原体和肿瘤细胞、促进组织器官再生和机体康复等治疗功效。

| 细胞类型 | 原理/作用 |
|---|---|
| CAR-T | 将识别肿瘤抗原的单链抗体与 T 细胞活化信号胞内域融合，导入 T 细胞，使其特异性杀伤肿瘤 |
| CAR-NK | 类似 CAR-T，但利用 NK 细胞，异体应用潜力较大 |
| 树突状细胞（DC） | 提呈抗原，促进抗肿瘤免疫 |
| NK 细胞 | 直接杀伤肿瘤细胞，无需预先致敏 |
| 间充质干细胞（MSC） | 免疫调节、组织修复 |
| 血小板等血液成分 | 成分输血、止血支持 |

**CAR-T 的关键环节**：采集患者 T 细胞 → 导入 CAR 基因 → 体外扩增 → 回输 → 识别 CD19 等抗原 → 杀伤肿瘤。常见不良反应为**细胞因子释放综合征（CRS）**和神经毒性。

### 2.10 病例：急性再生障碍性贫血

**病例要点**：29 岁男性，口腔溃疡、头晕乏力、贫血貌、全身出血点；WBC 0.20×10⁹/L、Hb 24 g/L、PLT 6×10⁹/L；骨髓增生严重低下，造血组织 6%、脂肪 94%，巨核细胞未见。

**诊断**：急性再生障碍性贫血（SAA）。

**发病机制**：骨髓造血功能衰竭，包括：

1. 造血干细胞缺陷；
2. 造血微环境异常；
3. 免疫异常（细胞毒性 T 细胞攻击 CD34⁺ 干祖细胞）；
4. 遗传倾向。

**治疗原则**：

1. 病因治疗：去除导致骨髓损害的药物、毒物、射线等。
2. 支持治疗：预防感染、成分输血。
3. 免疫抑制治疗：抗胸腺细胞球蛋白（ATG）、抗淋巴细胞球蛋白（ALG）、环孢素 A。
4. 造血生长因子：GM-CSF、G-CSF、EPO、IL-3。
5. 异基因造血干细胞移植。

## 三、红细胞与贫血

### 3.1 红细胞的基本特征

- 直径约 **7.5 μm**，**双凹圆盘状**，无核，无细胞器（无线粒体）。
- 主要成分是血红蛋白（Hb），占红细胞干重的 96%。
- 正常成人 Hb：男性 120–160 g/L，女性 110–150 g/L。
- 功能：运输 O₂ 和 CO₂；维持血液 pH、黏度和渗透压。

### 3.2 红细胞生成（erythropoiesis）

**发育阶段与形态变化**

| 阶段 | 形态特点 | 关键事件 |
|---|---|---|
| 原红细胞 | 体积大、核圆、核仁明显、胞浆深蓝、无 Hb | 核糖体合成 |
| 早幼红细胞 | 体积变小、染色质开始聚集、胞浆嗜碱 | 核糖体合成 |
| 中幼红细胞 | 胞浆灰蓝/多染性，Hb 开始出现 | Hb 蓄积 |
| 晚幼红细胞 | 核固缩、胞浆红染、Hb 丰富 | Hb 蓄积、准备脱核 |
| 网织红细胞 | 无核，残留核糖体/多聚核糖体，体积略大于成熟 RBC，非双凹 | 脱核后早期 |
| 成熟红细胞 | 双凹圆盘、无核、无细胞器 | 进入循环 |

**网织红细胞（reticulocyte）**

- 正常约占循环红细胞的 **0.5%–1.5%**（课件以 1% 表示）。
- 用**亚甲蓝染色**可显示残留的 RNA/核糖体。
- 是反映骨髓红系造血活性的重要指标：溶血或急性失血时升高；再生障碍性贫血时降低。
- 严重贫血时，骨髓可提前释放较多网织红细胞（>3%）。

**红系生成的三阶段**

1. 核糖体合成；
2. 血红蛋白蓄积；
3. 细胞核排出。

### 3.3 红细胞生成的调控

#### （1）EPO：最重要的红系生长因子

- **促红细胞生成素（erythropoietin，EPO）**：约 34 kDa 的糖蛋白。
- 主要由**肾皮质/肾间质细胞**在缺氧时产生，肝脏产生少量。
- 刺激因素：出血、溶血、缺铁、高原缺氧等。
- 作用：直接刺激红系造血，使定向红系祖细胞加速成熟，1–2 天内网织红细胞升高。
- 信号通路：EPO 受体（EPOR）→ JAK2 → STAT5、PI3K/Akt 等；负性调控包括 SHP-1 等磷酸酶。
- **JAK2 V617F 突变**导致 JAK2 持续活化，见于真性红细胞增多症（PV）等骨髓增殖性肿瘤。

**EPO 的反馈环**

缺氧 → 肾脏感知 → 释放 EPO → 刺激红骨髓 → 红细胞增多 → 携氧能力提高 → 缺氧改善（负反馈）。

**HIF 与氧感知**

- 缺氧诱导因子（HIF）是细胞感知低氧的关键转录因子；常氧下 HIF-α 被脯氨酸羟化酶修饰、泛素化降解，低氧下稳定，促进 EPO 等基因转录。
- 相关研究获 **2016 年拉斯克基础医学奖**、**2019 年诺贝尔生理学或医学奖**。

**高原红细胞增多症（HAPC）**

- 高原缺氧导致红细胞和血细胞比容升高；表现为发绀、头晕、头痛、气短、胸闷、乏力、关节痛、食欲下降、失眠等。
- 治疗：改善缺氧、放血疗法、抗凝/溶栓（需评估血栓风险）。
- 藏族等高原人群可通过 EPAS1、EGLN1（PHD2）等适应位点维持相对正常的血细胞比容，是**遗传适应**的典型例子。

#### （2）造血原料

| 原料 | 作用 | 缺乏后果 |
|---|---|---|
| 铁 | 血红素合成 | 缺铁性贫血（小细胞低色素） |
| 叶酸 | 一碳单位载体，参与 DNA 合成 | 巨幼细胞贫血 |
| 维生素 B₁₂ | 参与甲硫氨酸合成和叶酸代谢，维持 DNA 合成 | 巨幼细胞贫血 + 神经系统症状 |
| 氨基酸 | 珠蛋白合成 | 蛋白质营养不良性贫血 |
| 维生素 B₆ | ALA 合酶辅酶 | 血红素合成障碍 |
| 维生素 C | 促进铁吸收、抗氧化 | 加重缺铁 |

### 3.4 红细胞膜的结构与功能

**膜组成**

| 成分 | 占比 |
|---|---|
| 蛋白质 | 49% |
| 脂质 | 42% |
| 碳水化合物 | 8% |
| 无机离子 | 1% |

**膜脂质**

- 磷脂约 60%、中性脂质（主要为胆固醇）约 30%、糖脂约 10%。
- 磷脂组成：鞘磷脂（SM）27%、磷脂酰胆碱（PC）28%、磷脂酰乙醇胺（PE）27%、磷脂酰丝氨酸（PS）14%、磷脂酰肌醇（PI）2%–3%。
- **膜磷脂非对称分布**：
  - 外层：PC、SM、糖脂；
  - 内层：PE、PS、PI。
- **PS 外翻**的后果：
  1. 启动凝血活化途径，促进血栓形成；
  2. 被巨噬细胞识别并吞噬，是衰老/凋亡红细胞的清除信号。

**膜蛋白**

| 类型 | 代表蛋白 | 功能 |
|---|---|---|
| 内在蛋白（整合蛋白） | 区带 3 蛋白（Band 3，AE1，阴离子交换蛋白） | 转运 Cl⁻/HCO₃⁻，参与气体运输 |
| 内在蛋白 | 血型糖蛋白（glycophorin） | 血型抗原、膜稳定性 |
| 周围蛋白（膜骨架） | 血影蛋白（spectrin） | 维持双凹形状、对抗剪切力 |
| 周围蛋白 | 肌动蛋白（actin） | 膜骨架收缩、变形 |
| 周围蛋白 | 锚蛋白（ankyrin） | 连接 spectrin 与 Band 3 |
| 周围蛋白 | 区带 4 蛋白（Band 4.1） | 连接 spectrin-actin，稳定膜骨架 |

> **记忆锚点**：**Band 3 管阴离子交换，血影蛋白管形状，锚蛋白管连接。** SDS-PAGE 可按分子量分离膜蛋白。

**膜功能**

1. **维持细胞稳定性和变形性**：双凹形状提供较大表面积/体积比，缩短气体扩散距离，便于通过毛细血管。
2. **膜通透性**：AE1（Cl⁻/HCO₃⁻ 交换）、AQP1（水通道）、KCC1、NKCC2、SK 钾通道等。
3. **抗原性和免疫功能**：ABO、Rh 等 20 余种血型系统；衰老细胞抗原（SCA）。
4. **受体功能**：甲状腺激素受体、GABA 受体、乙酰胆碱受体、流感病毒受体、CR1、转铁蛋白受体（TfR）、EPO 受体等。

**膜相关疾病**

| 疾病 | 机制 | 特点 |
|---|---|---|
| 遗传性球形红细胞增多症（HS） | 血影蛋白基因异常 → 血影蛋白减少/功能障碍 → 膜面积丢失、球形变、变形性下降 | 溶血性贫血、网织红细胞增多、脾大；外周血球形红细胞 |
| 遗传性椭圆形红细胞增多症 | 膜骨架蛋白异常 | 椭圆形红细胞、溶血 |
| 先天性红细胞生成异常性贫血（CDA） | 红系无效造血、多核红细胞、铁蓄积 | Ⅰ、Ⅱ、Ⅲ 型；Ⅱ 型 Band 3 的 N-乙酰乳糖聚糖链不足，鞘磷脂过度糖基化 |
| 膜脂质异常 | 脂质组成改变 | 靶形红细胞、棘形红细胞 |

> **【补充】** HS 多数为常染色体显性遗传，也可涉及锚蛋白、Band 3、Band 4.2 等；诊断可用渗透脆性试验、EMA 结合试验、流式细胞术。

### 3.5 红细胞的代谢

成熟红细胞**没有线粒体**，不能进行三羧酸循环和氧化磷酸化，只能依靠葡萄糖无氧代谢供能。

| 代谢途径 | 占比/产物 | 主要功能 | 相关疾病 |
|---|---|---|---|
| **糖酵解（EMP，Embden-Meyerhof 途径）** | 代谢 90%–95% 的葡萄糖；每分子葡萄糖净生成 2 分子 ATP | 维持红细胞形状、变形性和阳离子泵 | 丙酮酸激酶（PK）缺乏 → 非球形红细胞溶血性贫血 |
| **2,3-DPG 支路（Rapoport-Luebering 支路）** | 由 1,3-二磷酸甘油酸生成 2,3-二磷酸甘油酸（2,3-DPG） | 调节血红蛋白氧亲和力；缺氧/酸碱失衡时促进 O₂ 释放 | — |
| **磷酸戊糖途径（HMP 途径）** | 代谢 5%–10% 的葡萄糖；生成 NADPH | 维持谷胱甘肽还原系统，抗氧化，保护 Hb 和膜蛋白 | G6PD 缺乏 → 氧化性溶血、Heinz 小体 |

**2,3-DPG 的意义**

- 与脱氧血红蛋白结合，降低 Hb 对 O₂ 的亲和力，使氧解离曲线右移，促进组织释氧。
- 缺氧、贫血、酸中毒时 2,3-DPG 升高，是机体的代偿机制。

**G6PD 缺乏症**

- 最常见的红细胞酶缺陷，**X 连锁遗传**。
- 平时可无症状；在感染、氧化性药物（伯氨喹、磺胺、呋喃妥因、达普松等）或进食蚕豆后发生溶血。
- 机制：NADPH 不足 → 谷胱甘肽还原障碍 → Hb 氧化变性、沉淀形成 **Heinz 小体** → 膜损伤、血管内溶血。
- 临床表现：急性溶血、血红蛋白尿、黄疸；新生儿黄疸可很严重。
- 实验室：G6PD 活性测定、Heinz 小体染色、Coombs 试验阴性。

**PK 缺乏症**

- 常染色体隐性遗传；ATP 生成不足 → 红细胞能量代谢障碍 → 非球形红细胞溶血性贫血。
- 与 G6PD 缺乏不同，PK 缺乏通常为慢性溶血，氧化性药物不是主要诱因。

### 3.6 血红蛋白的结构、功能与合成

**结构**

- 血红蛋白分子量约 **68,000 Da**，占红细胞干重的 96%。
- 由 **2 条 α 链 + 2 条 β 链**（珠蛋白）和 **4 个血红素**组成。
- 每个血红素 = 原卟啉环 + 二价铁（Fe²⁺）。
- 每个血红素可结合 1 分子 O₂，因此 1 个 Hb 可运输 4 分子 O₂。

**功能**

- 肺部氧合：Hb + O₂ → 氧合血红蛋白（鲜红色）。
- 组织释氧：氧合血红蛋白 → 脱氧血红蛋白（暗红色）。
- 运输 CO₂：约 7% 的 CO₂ 以氨甲酰血红蛋白形式运输。

**珠蛋白基因与 Hb 类型**

| Hb 类型 | 组成 | 出现时期/比例 |
|---|---|---|
| Hb Gower 1 | ζ₂ε₂ | 胚胎早期 |
| Hb Gower 2 | α₂ε₂ | 胚胎早期 |
| Hb Portland | ζ₂γ₂ | 胚胎早期 |
| **HbF** | α₂γ₂ | 胎儿期主要 Hb（65%–95%）；成人 <1% |
| **HbA** | α₂β₂ | 成人主要 Hb（>95%） |
| **HbA₂** | α₂δ₂ | 成人少量（2.5%–3.5%） |

- α 珠蛋白基因簇位于 16 号染色体（ζ、α）。
- β 珠蛋白基因簇位于 11 号染色体（ε、Gγ、Aγ、δ、β）。
- 珠蛋白合成受血红素调节：血红素可促进珠蛋白合成，HRI（血红素调节的 eIF2α 激酶）参与调控。

**血红素合成**

- 部位：有核红细胞和肝细胞。
- 限速酶：**ALA 合酶（δ-氨基-γ-酮戊酸合酶）**，辅酶为**磷酸吡哆醛（维生素 B₆）**。
- 调节：
  - 血红素/高铁血红素升高 → 抑制 ALA 合酶合成和活性（负反馈）；
  - 巴比妥类、类固醇、睾酮、口服避孕药等可诱导 ALA 合酶。
- **卟啉症**：血红素合成途径中某种酶缺陷，导致中间代谢产物蓄积，引起神经症状和/或光敏性皮肤症状。

**血红蛋白病**

| 疾病 | 分子机制 | 主要表现 |
|---|---|---|
| **地中海贫血（thalassemia）** | 一条或多条珠蛋白链合成缺陷 → 链合成不平衡 | 无效红细胞生成、溶血、小细胞低色素性贫血 |
| α 地中海贫血 | α 链减少 → 过多 β 链形成 β₄（HbH，可溶）；严重时 γ₄（Hb Bart's） | HbH 病、Hb Bart's 胎儿水肿 |
| β 地中海贫血 | β 链减少 → 过多 α 链（不可溶）沉积，红细胞损伤 | 重度贫血、无效造血、铁过载 |
| **镰状细胞贫血（sickle cell anemia）** | β 链第 6 位谷氨酸 → 缬氨酸（HbS） | 脱氧时 HbS 聚合、红细胞镰变、溶血、血管阻塞 |

- 1949 年 Pauling 提出镰状细胞贫血是“**分子病**”，是分子医学的开端。
- 镰状细胞病可因感染、脱水、缺氧、寒冷诱发**镰形细胞危象**（疼痛、脾梗死、急性胸综合征等）。
- **【补充】** 治疗：补液、镇痛、氧疗、输血、羟基脲（提高 HbF）；根治性治疗为异基因造血干细胞移植或基因治疗。
- 2023 年 12 月 8 日 FDA 同时批准两款细胞/基因疗法：
  - **Lyfgenia（lovo-cel）**：慢病毒载体基因添加，使患者干细胞产生抗镰状化的 HbAT87Q；
  - **Casgevy（exa-cel）**：CRISPR/Cas9 基因编辑，增加胎儿血红蛋白（HbF）生成。

### 3.7 铁代谢与缺铁性贫血

**铁的分布**

- 成人体内铁约 3–5 g。
- 血红蛋白铁约占 65%；储存铁（铁蛋白、含铁血黄素）约 25%–30%；肌红蛋白、酶类等约 10%；血浆转铁蛋白结合铁很少。
- 铁在体内几乎完全封闭循环，排出量极少（约 1 mg/d，主要通过肠黏膜脱落、皮肤、汗液、月经等）。

**铁的吸收**

- 主要吸收部位：十二指肠和空肠上段。
- 肠绒毛细胞摄入铁 → **DMT-1**（二价金属离子转运蛋白）→ 细胞内铁蛋白储存或经 **ferroportin（膜铁转运蛋白）** 转出 → **hephaestin（膜铁转运辅助蛋白）** 氧化为 Fe³⁺ → 与转铁蛋白结合 → 运至骨髓等组织。
- 影响吸收的因素：
  - 铁储存降低或造血加快时，铁吸收增加；
  - 酸性条件有利于铁吸收（维生素 C 可促进）；
  - 血红素可直接被吸收；
  - 草酸等可使铁沉淀，抑制吸收。
- **【补充】** 肝脏分泌的**铁调素（hepcidin）**是铁代谢的核心负调控激素：与 ferroportin 结合使其降解，减少铁吸收和释放；炎症时 hepcidin 升高，导致慢性病贫血。

**缺铁的原因**

1. 慢性失血（成人最常见，如月经过多、消化道出血、痔疮）。
2. 饮食中铁摄入不足（婴幼儿、素食者）。
3. 妊娠和哺乳（铁向胎儿和婴儿转移）。
4. 铁吸收不良（胃切除、慢性腹泻、乳糜泻）。
5. 血管内溶血伴血红蛋白尿（铁丢失）。
6. 铁向非造血组织转移（炎症、肿瘤）。
7. 遗传因素（罕见）。

**缺铁的发展阶段**

1. **铁减少期（iron depletion）**：储存铁减少，血清铁蛋白降低，血红蛋白正常。
2. **缺铁性红细胞生成期（iron-deficient erythropoiesis）**：血清铁降低、转铁蛋白饱和度降低、总铁结合力升高，血红蛋白仍可正常。
3. **缺铁性贫血期（IDA）**：血红蛋白下降，出现小细胞低色素性贫血。

**缺铁性贫血的实验室特点**

| 指标 | 变化 |
|---|---|
| 血清铁蛋白 | 降低（最敏感的储存铁指标；<15–30 μg/L 提示缺铁） |
| 血清铁 | 降低 |
| 总铁结合力（TIBC） | 升高 |
| 转铁蛋白饱和度 | 降低（<20%） |
| 血红蛋白 | 降低 |
| MCV、MCH | 降低（小细胞低色素） |
| RDW | 升高（红细胞大小不均） |
| 骨髓铁染色 | 细胞外铁减少/消失，铁粒幼细胞减少 |

- 血涂片：轻度缺铁时中心淡染区扩大；重度缺铁时小细胞低色素明显，可见靶形红细胞、卵圆形红细胞。
- **MCV 比 MCHC 更敏感**：MCV 与血红蛋白浓度的相关性约 70%，MCHC 约 50%。
- 体征：**凹甲（koilonychia，匙状甲）**、口角炎、舌炎；严重者可有**吞咽困难（Plummer-Vinson 综合征，食管蹼）**。

**治疗要点**

- 病因治疗（查清失血原因最重要）。
- 口服铁剂：硫酸亚铁、富马酸亚铁、右旋糖酐铁等；与维生素 C 同服促进吸收。
- 网织红细胞在治疗后 5–10 天上升，Hb 逐渐恢复；Hb 正常后仍需继续补铁 3–6 个月以补足储存铁。
- 口服不耐受或吸收不良者可静脉补铁。
- 输血仅用于严重贫血或急需纠正缺氧。

### 3.8 叶酸、维生素 B₁₂ 与巨幼细胞贫血

**DNA 合成与一碳单位**

- 叶酸的活性形式是**四氢叶酸（THF）**，作为一碳单位载体参与 DNA 合成。
- 胸腺嘧啶核苷酸合成：dUMP → dTMP，需要**胸腺嘧啶核苷酸合酶**和**亚甲基四氢叶酸**。
- 二氢叶酸还原酶（DHFR）将叶酸还原为 THF。
- 维生素 B₁₂ 参与：同型半胱氨酸 → 甲硫氨酸，同时使甲基四氢叶酸转为 THF，维持叶酸代谢。

**吸收**

| 物质 | 来源 | 吸收部位/机制 |
|---|---|---|
| 叶酸 | 绿色蔬菜、香蕉等水果；人体不能合成 | 空肠，主动转运 |
| 维生素 B₁₂ | 只存在于动物性食物 | 胃壁细胞分泌**内因子** → B₁₂-内因子复合物 → 回肠末端受体介导吸收；转运蛋白为转钴胺素 |

**缺乏的后果**

- 叶酸或 B₁₂ 缺乏 → DNA 合成障碍 → 细胞核发育落后于胞浆（核质发育不平衡）→ **巨幼细胞贫血**。
- 累及所有骨髓细胞，可表现为全血细胞减少。
- 外周血：**卵圆形大红细胞**、红细胞大小不一、**中性粒细胞分叶过多**（>5 叶）。
- 骨髓：红系增生、巨幼红细胞、核染色质疏松、核仁明显；粒系和巨核系也可受累。
- B₁₂ 缺乏还可引起**神经系统症状**（亚急性联合变性：感觉异常、深感觉障碍、共济失调、痉挛性截瘫），叶酸缺乏通常无神经系统症状。
- **注意**：单纯补充叶酸可掩盖 B₁₂ 缺乏的血液学表现，但神经损害仍可进展。

**治疗**

- 叶酸缺乏：口服叶酸。
- B₁₂ 缺乏：肌注或口服 B₁₂；恶性贫血需终身补充。
- 同时纠正铁缺乏（治疗后期铁需求增加，可能出现相对性缺铁）。

### 3.9 红细胞的衰老与破坏

- 红细胞寿命约 **100–120 天**。
- 衰老红细胞变形能力下降、膜结构改变、Hb 变性，最终在**脾脏**被巨噬细胞吞噬清除（脾脏是红细胞清除的主要场所）。
- 血红蛋白分解：
  - 血红素 → 胆红素（间接胆红素，脂溶性，与白蛋白结合运至肝脏）→ 肝内结合为直接胆红素（水溶性）→ 胆汁排泄；
  - 铁 → 回收利用；
  - 珠蛋白 → 氨基酸 → 再利用。
- 溶血时间接胆红素升高、尿胆原增加、网织红细胞升高；血管内溶血可有血红蛋白尿、含铁血黄素尿。

### 3.10 贫血总论

**定义**

贫血是指外周血单位容积内血红蛋白浓度、红细胞计数和/或血细胞比容低于正常最低值，导致血液携氧能力下降、组织缺氧的临床综合征。贫血是**症状/综合征**，不是单一疾病。

**实验室诊断标准（课件）**

| 人群 | RBC（×10¹²/L） | Hb（g/L） | Hct |
|---|---|---|---|
| 成年男性 | <4.0–4.5 | <120 | <0.40 |
| 成年女性 | <3.5–4.0 | <110 | <0.35 |
| 孕妇 | — | <100 | — |

**WHO 血红蛋白阈值**

| 人群 | Hb 阈值（g/dL） |
|---|---|
| 儿童 0.5–5 岁 | 11.0 |
| 儿童 5–12 岁 | 11.5 |
| 青少年 12–15 岁 | 12.0 |
| 非妊娠女性 >15 岁 | 12.0 |
| 妊娠女性 | 11.0 |
| 男性 >15 岁 | 13.0 |

> **注意**：课件同时给出“中国成人标准”和“WHO 标准”，两者数值不同；考试时先看题目采用哪套标准。

**贫血严重程度（课件）**

| 分级 | Hb 水平 |
|---|---|
| 轻度 | 91 g/L 至正常下限 |
| 中度 | 61–90 g/L |
| 重度 | 31–60 g/L |
| 极重度/危及生命 | <30 g/L |

**病因分类**

1. **红细胞生成减少**：造血干细胞缺陷（AA）、造血微环境异常、造血原料缺乏（铁、叶酸、B₁₂）、无效造血（MDS）、骨髓浸润、EPO 不足（CKD）。
2. **红细胞破坏增加（溶血）**：红细胞膜缺陷（HS）、酶缺陷（G6PD、PK）、血红蛋白病（地中海贫血、镰状细胞病）、自身免疫性溶血、微血管病性溶血（TTP/HUS/DIC）、感染、药物。
3. **失血**：急性失血、慢性失血。

**形态学分类**

| 类型 | MCV | 常见疾病 |
|---|---|---|
| 小细胞低色素性贫血 | <80 fL | 缺铁性贫血、地中海贫血、铁粒幼细胞贫血、慢性病贫血（部分） |
| 正细胞正色素性贫血 | 80–100 fL | 急性失血、AA、溶血性贫血、CKD、骨髓浸润 |
| 大细胞性贫血 | >100 fL | 巨幼细胞贫血、酒精性肝病、MDS、甲状腺功能减退、某些药物 |

**骨髓分类**

- 增生性贫血：骨髓红系增生（溶血、失血、缺铁治疗后）。
- 增生低下性贫血：AA、纯红细胞再生障碍。
- 无效造血：MDS、巨幼细胞贫血。

**临床表现**

| 系统 | 表现 | 机制 |
|---|---|---|
| 一般 | 乏力、倦怠、头晕、注意力下降 | 组织缺氧 |
| 呼吸循环 | 活动后气短、心悸、心动过速、高动力循环、收缩期杂音 | 代偿性心输出量增加 |
| 皮肤黏膜 | **睑结膜/口唇苍白（最常见体征）** | 皮肤黏膜血管收缩、Hb 减少 |
| 消化 | 食欲减退、舌炎、口角炎、吞咽困难 | 黏膜缺氧、营养缺乏 |
| 神经 | 头痛、耳鸣、眩晕；B₁₂ 缺乏可有感觉异常、共济失调 | 脑缺氧/神经损害 |
| 严重 | 心绞痛、心力衰竭、意识障碍 | 失代偿 |

**体征鉴别线索**

- **凹甲（匙状甲）**：特异于缺铁性贫血。
- **萎缩性舌炎、口角炎**：见于维生素 B₁₂ 和叶酸缺乏。
- **吞咽困难 + 食管蹼**：Plummer-Vinson 综合征，见于缺铁性贫血。
- **黄疸 + 脾大 + 网织红细胞升高**：溶血性贫血。
- **舌乳头萎缩、牛肉舌**：B₁₂ 缺乏。

**贫血的诊断思路**

1. 确认贫血：Hb、RBC、Hct。
2. 判断形态：MCV、MCH、MCHC、RDW。
3. 判断骨髓反应：网织红细胞计数。
4. 寻找病因：
   - 小细胞低色素 → 铁代谢、血红蛋白电泳；
   - 大细胞 → 叶酸、B₁₂、甲状腺功能、骨髓；
   - 正细胞 → 溶血指标、骨髓、肾功能；
   - 溶血 → 间接胆红素、LDH、结合珠蛋白、Coombs 试验、红细胞膜/酶检查。
5. 必要时骨髓穿刺/活检。

**常见贫血的鉴别**

| 疾病 | 主要机制 | MCV | 网织红细胞 | 关键实验室/体征 |
|---|---|---|---|---|
| 缺铁性贫血 | 铁缺乏 → Hb 合成不足 | 低 | 正常或轻度升高 | 铁蛋白↓、血清铁↓、TIBC↑、凹甲 |
| 巨幼细胞贫血 | 叶酸/B₁₂ 缺乏 → DNA 合成障碍 | 高 | 低/正常 | 大细胞、中性粒细胞分叶过多、B₁₂ 神经症状 |
| 再生障碍性贫血 | HSC 损伤、免疫攻击 | 正常 | 低 | 全血细胞减少、骨髓脂肪化、巨核细胞缺如 |
| 慢性病贫血 | 炎症 → hepcidin↑、铁利用障碍 | 正常/低 | 正常 | 血清铁↓、TIBC↓、铁蛋白↑ |
| 溶血性贫血 | 红细胞破坏增加 | 正常/高 | 高 | 间接胆红素↑、LDH↑、结合珠蛋白↓、脾大 |
| 地中海贫血 | 珠蛋白链合成障碍 | 低 | 高 | 血红蛋白电泳异常、家族史、靶形红细胞 |
| 镰状细胞贫血 | HbS 聚合、镰变 | 正常 | 高 | 镰变试验、Hb 电泳、疼痛危象 |
| 骨髓增生异常综合征 | 无效造血、病态造血 | 高/正常/低 | 低/正常 | 骨髓病态造血、原始细胞、细胞遗传学异常 |

## 四、白细胞：髓系及其疾病

### 4.1 髓系细胞的发育

所有血细胞和免疫细胞都起源于骨髓造血干细胞（HSC），HSC 具有**自我更新**和**多向分化**两大特征。

**粒细胞发育**

原粒细胞 → 早幼粒细胞 → 中幼粒细胞 → 晚幼粒细胞 → 杆状核粒细胞 → 分叶核粒细胞。

- 中性粒细胞、嗜酸性粒细胞、嗜碱性粒细胞各自沿相似阶段发育，但颗粒染色和功能不同。
- 单核细胞：原单核细胞 → 幼单核细胞 → 单核细胞 → 进入组织分化为巨噬细胞、朗格汉斯细胞、树突状细胞。

**髓系发育的主要细胞因子**

| 细胞 | 主要细胞因子 |
|---|---|
| 中性粒细胞 | IL-3、GM-CSF、G-CSF |
| 嗜酸性粒细胞 | GM-CSF、IL-3、**IL-5（较专一）** |
| 嗜碱性粒细胞 | GM-CSF、IL-3、IL-4 |
| 单核细胞 | **M-CSF（主要）**、GM-CSF、IL-4 |

### 4.2 白细胞的分类与形态

**分类**

- 粒细胞（granulocyte）：中性粒细胞、嗜酸性粒细胞、嗜碱性粒细胞。
- 淋巴细胞（lymphocyte）：T 细胞、B 细胞、NK 细胞。
- 单核细胞（monocyte）。

**正常白细胞计数与分类【补充】**

| 细胞 | 百分比 | 绝对数（×10⁹/L） |
|---|---|---|
| 中性粒细胞 | 50%–70% | 1.8–6.3 |
| 淋巴细胞 | 20%–40% | 1.1–3.2 |
| 单核细胞 | 3%–8% | 0.1–0.6 |
| 嗜酸性粒细胞 | 0.5%–5% | 0.02–0.5 |
| 嗜碱性粒细胞 | 0%–1% | <0.1 |

**形态特点**

| 细胞 | 大小 | 胞浆 | 颗粒 | 胞核 |
|---|---|---|---|---|
| 中性粒细胞 | 12–15 μm | 无色/淡红色 | 细小、均匀的特异性颗粒 | 深紫色，杆状或分叶状，核质比小 |
| 嗜酸性粒细胞 | 10–15 μm | 红色 | 粗大、均匀的橘红色颗粒 | 常呈哑铃形/双叶 |
| 嗜碱性粒细胞 | 10–15 μm | 深蓝色 | 紫黑色粗大颗粒，可覆盖核 | 分叶状，常被颗粒遮盖 |
| 单核细胞 | 12–20 μm | 灰蓝色，毛玻璃样 | 细尘埃样嗜天青颗粒 | 大，肾形/马蹄形，位于中央或偏位 |
| 淋巴细胞 | 6–15 μm（小 6–9，大 9–15） | 蓝色/淡蓝色 | 小淋巴细胞少，大颗粒淋巴细胞有嗜天青颗粒 | 圆形/卵圆形，染色质致密，占细胞大部分 |

> **小淋巴细胞 vs 大淋巴细胞**：小淋巴细胞多为静息/初始或记忆细胞；大淋巴细胞多为抗原激活后的活化状态。大颗粒淋巴细胞（LGL）形态上属大淋巴细胞，主要由 NK 细胞和部分 CD8⁺ T 细胞组成。

### 4.3 中性粒细胞的动力学与颗粒

**分布**

| 池 | 细胞阶段 | 停留时间/特点 |
|---|---|---|
| 骨髓分裂池 | 原粒、早幼粒、中幼粒 | 约 10 天 |
| 骨髓成熟/贮存池 | 晚幼粒、杆状核、分叶核 | 贮存备用 |
| 血液循环池 + 边缘池 | 成熟中性粒细胞 | 约 10 小时；两池可互换 |
| 组织 | 中性粒细胞 | 约 1–2 天 |

- 中幼粒细胞从骨髓进入血液约需 8–14 天，感染时可缩短至 48 小时。
- 中性粒细胞从血液进入组织的清除半衰期约 6–8 小时，感染时可延长至数天。
- 血液中中性粒细胞稳态由三方面维持：骨髓生成、边缘池/循环池分布、进入组织的速率。

**颗粒**

| 颗粒 | 形成阶段 | 标志物 | 主要功能 |
|---|---|---|---|
| 初级颗粒（嗜天青颗粒） | 早幼粒细胞 | **髓过氧化物酶（MPO）**、酸性水解酶、防御素 | 杀菌；与吞噬体融合后消化病原体 |
| 次级颗粒（特异性颗粒） | 中幼粒细胞 | **乳铁蛋白** | 螯合铁、抑菌、黏附 |
| 三级颗粒（白明胶酶颗粒） | 晚幼粒/杆状核阶段 | 白明胶酶 | 降解细胞外基质，促进迁移 |
| 分泌囊泡 | 成熟阶段 | 受体、酶等 | 黏附、迁移、吞噬、杀伤 |

> **记忆锚点**：**早幼粒产初级颗粒（MPO），中幼粒产次级颗粒（乳铁蛋白），晚幼粒产三级颗粒（白明胶酶）。**

### 4.4 白细胞的功能

#### （1）中性粒细胞

**炎症反应的基本步骤**

1. **滚动（rolling）**：内皮细胞活化后表达 E-选择素、P-选择素，与中性粒细胞表面配体结合。
2. **紧密黏附（adhesion）**：内皮细胞表达 ICAM-1/ICAM-2，与中性粒细胞 β₂ 整合素结合。
3. **跨内皮迁移（transmigration）**：释放蛋白酶和活性氧，局部降解基底膜，穿过内皮间隙。
4. **趋化（chemotaxis）**：沿 IL-8、C5a、LTB₄、细菌肽等趋化因子浓度梯度移动。
5. **吞噬（phagocytosis）**：通过 FcγR、补体受体识别调理后的病原体，形成吞噬体。
6. **杀伤（killing）**：脱颗粒 + 呼吸爆发。

**杀菌机制**

| 机制 | 核心 | 关键分子/过程 |
|---|---|---|
| **氧化杀菌** | 呼吸爆发，大量产生活性氧（ROS） | NADPH 氧化酶（NOX2）→ 超氧阴离子 O₂⁻ → H₂O₂ → MPO 催化 H₂O₂ + Cl⁻ → 次氯酸 HOCl |
| **非氧化杀菌** | 脱颗粒，释放预先合成的抗菌物质 | 防御素（穿孔）、弹性蛋白酶/溶菌酶（降解）、乳铁蛋白（螯合铁） |
| **NETosis** | 释放中性粒细胞胞外诱捕网（NETs） | DNA 网状结构物理捕获并杀灭病原体 |

> **【补充】** 慢性肉芽肿病（CGD）为 NADPH 氧化酶缺陷，表现为反复严重细菌/真菌感染；MPO 缺乏者多数无症状或感染风险轻度增加。

#### （2）嗜酸性粒细胞

- 功能：黏附、趋化、吞噬、杀伤细菌和寄生虫；参与 I 型超敏反应的负反馈调节。
- 颗粒成分：**主要碱性蛋白（MBP）**、嗜酸性粒细胞过氧化物酶（EPO）、嗜酸性粒细胞神经毒素（EDN）、组胺酶。
- 对体积较大的寄生虫不能吞噬，采用**脱颗粒**方式杀伤。
- 表面有 IgE 受体；通过**组胺酶**降解组胺，限制 I 型超敏反应。

#### （3）嗜碱性粒细胞

- 颗粒含**组胺、肝素、慢反应物质、嗜酸性粒细胞趋化因子**等。
- 抗原-抗体反应时释放颗粒，激发急性过敏反应：支气管哮喘、荨麻疹、过敏性鼻炎。
- 也参与迟发变态反应和慢性过敏性疾病（如过敏性哮喘）。
- 是过敏性疾病的重要效应细胞，并参与炎症损伤、修复与重塑。

#### （4）单核/巨噬细胞

- 趋化、吞噬、合成和分泌细胞因子、诱导和调节免疫反应、肿瘤免疫、清除凋亡细胞。
- 进入组织后分化为巨噬细胞、朗格汉斯细胞、树突状细胞。
- 是连接固有免疫和适应性免疫的重要桥梁（抗原提呈）。

### 4.5 中性粒细胞减少

**定义**

- 成人外周血白细胞总数正常范围：**4.0–10.0×10⁹/L**。
- 白细胞减少（leukopenia）：WBC <4.0×10⁹/L。
- 中性粒细胞减少（neutropenia）：成人中性粒细胞 <1.8×10⁹/L；1 个月–10 岁 <1.5×10⁹/L；10–14 岁 <1.8×10⁹/L。
- 中性粒细胞缺乏（agranulocytosis）：中性粒细胞 <0.5×10⁹/L。

**病理生理机制**

| 机制 | 说明 | 常见原因 |
|---|---|---|
| 生成减少 | 骨髓造血受抑、原料缺乏、无效造血 | 细胞毒药物、苯、辐射；免疫介导；感染；骨髓浸润（白血病、骨髓瘤、转移瘤）；先天性/周期性粒细胞减少；AA、PNH；B₁₂/叶酸缺乏；MDS |
| 破坏增多 | 抗体或免疫复合物介导破坏；脾功能亢进 | 自身免疫病、自身免疫性粒细胞减少、慢性乙肝；严重细菌感染/败血症；脾亢 |
| 分布异常 | 边缘池增多、循环池减少，但总池不减少 | 假性粒细胞减少；血液透析后肺血管滞留；脾功能亢进 |
| 清除/利用加速 | 感染时中性粒细胞大量进入组织 | 严重感染、炎症 |

**临床表现**

| 程度 | 中性粒细胞绝对值 | 感染风险 |
|---|---|---|
| 轻度 | 1.0–2.0×10⁹/L | 很少感染 |
| 中度 | 0.5–1.0×10⁹/L | 易感染 |
| 重度 | <0.5×10⁹/L | 持续 5–7 天以上几乎必然感染 |

- 感染未发生时：疲乏、无力、头晕、食欲减退。
- 感染发生时：畏寒、寒战、高热。
- 常见感染部位：口腔、舌、咽部（坏死性溃疡）；肺、尿路、肝胆、面部/肛周皮肤脓肿。
- 严重感染和败血症是粒缺患者的主要死因。

**治疗**

1. 去除病因，治疗原发病。
2. 防治感染：环境隔离、口腔护理、发热时经验性广谱抗生素。
3. 升高白细胞：G-CSF、GM-CSF、造血原料。
4. 严重粒缺可考虑粒缺期输血支持（粒细胞输注少用）。

### 4.6 中性粒细胞增多

**定义**

- 白细胞增多：WBC >10.0×10⁹/L。
- 中性粒细胞增多：中性粒细胞绝对值 >7.5×10⁹/L。
- 临床上以中性粒细胞增多最常见，其次为嗜酸性粒细胞增多。

**机制**：骨髓贮存池释放增加、生成增多、破坏/凋亡减少、分布改变（边缘池 → 循环池）。

**原因**

| 类别 | 常见情况 |
|---|---|
| 感染 | 各种细菌感染，尤其是化脓性感染 |
| 物理/情绪刺激 | 冷、热、运动、剧痛、创伤、妊娠、缺氧 → 假性中性粒细胞增多 |
| 炎症/组织坏死 | 风湿病、肾炎、胰腺炎、结肠炎、心肌梗死、肺梗死 |
| 肿瘤 | 类白血病反应 |
| 代谢/内分泌 | 甲亢危象、糖尿病酮症酸中毒、尿毒症、急性痛风 |
| 中毒/过敏 | 铅、汞、砷、肾上腺素、糖皮质激素、CO 中毒 |
| 其他 | 手术后、脾切除后、输血反应 |
| 造血系统疾病 | 骨髓增殖性肿瘤：CML、PV、MF、ET、CNL；粒缺恢复期 |

**临床表现与治疗**：主要与原发病相关；治疗以去除病因、治疗原发病为主。

**类白血病反应 vs CML**

| 项目 | 类白血病反应 | CML |
|---|---|---|
| 病因 | 感染、炎症、肿瘤、应激等 | BCR-ABL 融合基因 |
| 白细胞 | 可显著升高，但常 <50×10⁹/L，少数更高 | 常 >50×10⁹/L，可达 100×10⁹/L 以上 |
| 中性粒细胞碱性磷酸酶（NAP/AKP） | **升高** | **降低** |
| 嗜酸/嗜碱细胞 | 不明显 | 常增多（尤其嗜碱） |
| 脾大 | 一般无或轻度 | 常见明显巨脾 |
| 细胞遗传学 | 无 Ph 染色体 | Ph 染色体 t(9;22)，BCR-ABL 阳性 |
| 转归 | 去除病因后可恢复 | 需 TKI 长期治疗 |

### 4.7 白血病总论

**定义**

白血病（leukemia）是骨髓中原始与幼稚血细胞急剧增生的恶性克隆性疾病，白血病细胞可出现于骨髓及其他器官和组织，产生**感染、贫血、出血和浸润**等临床表现。

**病因**

| 因素 | 例子 |
|---|---|
| 化学因素 | 苯、甲苯、杀虫剂；烷化剂（马利兰、马法兰、苯丁酸氮芥、塞替派、环磷酰胺）；丙卡巴肼、亚硝基脲、乙双吗啉、氯霉素 |
| 物理因素 | γ 射线、核辐射、放射治疗、同位素照射 |
| 生物因素 | HTLV-I、EB 病毒等 |
| 遗传因素 | 家族易感性、遗传性疾病（如 Down 综合征、Fanconi 贫血） |

**发病机制**

化学/物理/生物/遗传因素 → 癌基因激活、抑癌基因失活、染色体/DNA/RNA/蛋白质异常 → **增殖失控、凋亡受阻、分化障碍** → 白血病。

**临床表现**

1. **发热、感染**：正常粒细胞减少、免疫功能低下。
2. **贫血**：红系受抑、失血、溶血。
3. **出血**：血小板减少/功能异常、凝血异常、DIC（尤其 APL）。
4. **器官和组织浸润**：肝脾淋巴结肿大、骨痛/胸骨压痛、牙龈增生、皮肤浸润、中枢神经系统白血病、睾丸肿大。

**分类**

| 分类 | 类型 |
|---|---|
| 急性白血病 | AML（急性髓系白血病/急性非淋巴细胞白血病）、ALL（急性淋巴细胞白血病，T/B 型） |
| 慢性白血病 | CML（慢性髓性白血病）、CLL（慢性淋巴细胞白血病） |

**分型历史**

- 1976 年：FAB 分型（形态学）。
- 1986 年：MICM 分型（形态、免疫、细胞遗传学、分子）。
- 2001 年：WHO 分型（结合临床、形态、免疫、遗传、分子）。

### 4.8 急性髓系白血病（AML）

**FAB 分型**

| 型别 | 名称 |
|---|---|
| M0 | 急性未分化型白血病 |
| M1 | 急性粒细胞白血病微分化型 |
| M2 | 急性粒细胞白血病部分分化型 |
| M3 | 急性早幼粒细胞白血病（APL） |
| M4 | 急性粒-单细胞白血病 |
| M4Eo | 急性粒-单细胞白血病伴嗜酸性粒细胞增多 |
| M5 | 急性单核细胞白血病 |
| M6 | 红白血病 |
| M7 | 急性巨核细胞白血病 |

> 骨髓原始细胞 **>20%** 是急性白血病诊断的重要界值（WHO 标准）。

**急性早幼粒细胞白血病（APL，AML-M3）**

- 占 AML 的 10%–15%。
- 临床以**出血**为突出表现，易并发 DIC。
- 髓细胞分化阻滞在早幼粒细胞阶段。
- 经典染色体易位：**t(15;17)(q22;q12)**，形成 **PML-RARα** 融合基因。
- 免疫表型：HLA-DR（−）、CD33⁺、CD13⁺、CD14⁺、CD15⁺（课件病例）。
- 细胞化学：POX 强阳性；可见 Auer 小体。

**APL 的靶向治疗机制**

| 药物 | 机制 |
|---|---|
| **ATRA（全反式维甲酸）** | 在 10⁻⁹–10⁻⁸ M 浓度下诱导早幼粒细胞分化；作用于 PML-RARα，恢复 RARα 的转录调控；PML 定位于核体（NB），与抑制细胞生长、诱导凋亡有关 |
| **As₂O₃（三氧化二砷）** | 降解 PML-RARα 融合蛋白，诱导分化与凋亡 |
| **ATRA + As₂O₃** | 协同作用，使 APL 成为可能治愈的疾病；完全缓解率 >80%–90%，5 年生存率 >70%–80% |

> **临床要点**
>
> - APL 疑诊时应**尽早使用 ATRA**，不必等待遗传学结果，以降低早期出血死亡。
> - **ATRA 分化综合征**：发热、体重增加、呼吸困难、低血压、肾功能不全等；一旦发生应使用地塞米松并暂停 ATRA。
> - APL 的促分化治疗是中国对世界血液学的重大贡献（王振义、张亭栋）。

### 4.9 慢性髓性白血病（CML）

**分子基础**

- 1960 年 Nowell 和 Hungerford 发现**费城染色体（Ph）**。
- 1973 年 Rowley 发现 Ph 染色体是 9 号和 22 号染色体长臂之间的交互易位：**t(9;22)(q34;q11)**。
- 9q34 上的 **ABL** 原癌基因与 22q11 上的 **BCR** 基因融合，形成 **BCR-ABL** 融合基因。
- BCR-ABL 编码具有**组成性酪氨酸激酶活性**的融合蛋白。

**BCR-ABL 类型**

| 类型 | 特点/常见疾病 |
|---|---|
| p190 | 多见于 Ph⁺ ALL |
| **p210** | CML 慢性期最常见 |
| p230 | 多见于慢性中性粒细胞白血病 |

**临床表现与分期**

- 起病缓慢，早期约 50% 无症状。
- 常见症状：疲乏、体重下降/食欲减退、多汗/盗汗、腹胀/腹块。
- 常见体征：**脾脏肿大**（可巨脾）。
- 分期：**慢性期 → 加速期 → 急变期**。
- 实验室：白细胞显著升高，粒细胞各阶段均见，**嗜酸/嗜碱细胞增多**，NAP 积分降低；血小板可正常或增多。

**伊马替尼（imatinib）**

- 第一代酪氨酸激酶抑制剂（TKI）。
- 靶向作用于 Abl 激酶结构域中的 **ATP 结合位点**，抑制 BCR-ABL 激酶活性。
- 阻止底物磷酸化和下游信号转导，抑制肿瘤细胞增殖和存活。
- 使 CML 患者生存期从 4–5 年延长到 10–20 年，是靶向治疗的里程碑。
- 二代 TKI：达沙替尼、尼洛替尼等。

### 4.10 病例串联

- **APL 病例**：31 岁油漆工，发热、牙龈出血、皮肤瘀点瘀斑、口腔血泡；WBC 1.78×10⁹/L、Hb 65 g/L、PLT 11×10⁹/L；骨髓异常早幼粒细胞 48%，POX 强阳性，t(15;17)，PML-RARα 阳性。诊断 APL，尽早 ATRA + As₂O₃。
- **CML 病例**：36 岁男性，腹胀、脾肋下 12 cm；WBC 162×10⁹/L、Hb 82 g/L、PLT 330×10⁹/L；外周血各阶段粒细胞，嗜酸/嗜碱增多，NAP 低；Ph 染色体阳性，BCR-ABL p210 阳性。诊断 CML 慢性期，TKI 治疗。

## 五、淋巴细胞与淋巴系统疾病

### 5.1 淋巴细胞的概述

**形态**

- 球形/卵圆形，直径 6–15 μm（小淋巴细胞 6–9 μm，大淋巴细胞 9–15 μm）。
- 小淋巴细胞核染色质致密，占细胞面积约 90%，胞浆少。
- 大颗粒淋巴细胞（LGL）形态上属大淋巴细胞，由 NK 细胞和部分 CD8⁺ T 细胞组成。

**分类**

| 类型 | 来源/成熟场所 | 主要功能 | 外周血比例 |
|---|---|---|---|
| **T 细胞** | 骨髓来源，胸腺成熟 | 细胞免疫、免疫调节 | 65%–75% |
| **B 细胞** | 骨髓成熟（鸟类法氏囊同源） | 体液免疫、产生抗体 | 10%–20% |
| **NK 细胞** | 骨髓来源 | 固有免疫、直接杀伤 | 课件：约占免疫细胞的 15% |

> **历史**：Bruce Glick 通过鸡法氏囊实验发现 B 细胞；Max Cooper 和 Jacques Miller 提出 T/B 双谱系，获 2019 年拉斯克基础医学奖。

### 5.2 B 淋巴细胞

#### （1）B 细胞的发育与分化

- 在骨髓内发育成熟，移行至外周淋巴组织。
- 接受抗原刺激后，成熟为**浆细胞**。
- 浆细胞形成并分泌免疫球蛋白，执行特异性体液免疫应答。

**B 细胞发育阶段与相关肿瘤**

| 发育阶段 | 关键事件 | 相关恶性肿瘤 |
|---|---|---|
| 祖 B 细胞（pro-B） | Ig 重链 VDJ 重排 | B-ALL（阻滞在前 B 阶段） |
| 前 B 细胞（pre-B） | 胞浆 μ 链、轻链重排 | B-ALL |
| 未成熟 B 细胞 | 表达 mIgM | B-ALL |
| 成熟初始 B 细胞 | 表达 mIgM + mIgD | 套细胞淋巴瘤（MCL）、U-CLL |
| 生发中心 B 细胞 | 体细胞高频突变、类别转换 | DLBCL、滤泡淋巴瘤（FL）、Burkitt 淋巴瘤 |
| 记忆 B 细胞 | 生发中心后 | M-CLL |
| 边缘区 B 细胞 | 边缘区 | 边缘区淋巴瘤（MZL）、脾边缘区淋巴瘤（SMZL）、华氏巨球蛋白血症（WM） |
| 浆细胞 | 分泌抗体 | 多发性骨髓瘤（MM） |

> **记忆锚点**：**B-ALL 停在“前 B”，CLL 来自“初始/记忆 B”，MCL 来自“初始/边缘区前”，DLBCL/FL/Burkitt 来自“生发中心”，MM 来自“长寿命浆细胞”。**

**B 细胞发育的调控**

- 外在因素：骨髓微环境中的 SCF、IL-7、VLA-4/VCAM-1、c-KIT 等。
- 内在因素：转录因子网络（如 E2A、EBF1、PAX5 等）【补充】。

#### （2）B 细胞受体（BCR）与表面分子

- **BCR**：膜表面免疫球蛋白（mIg），是 B 细胞特异性识别和结合抗原决定簇的结构。
  - **mIgM**：最先出现，早期免疫反应重要。
  - **mIgD**：与 mIgM 共同表达在初始 B 细胞表面，调节活化/增殖。
  - **mIgA**：黏膜免疫。
  - **mIgG**：高效中和毒素、调理吞噬。
  - **mIgE**：过敏反应。
- **BCR 复合物**：mIg（识别抗原）+ **Igα/Igβ（CD79a/CD79b）异二聚体**（传递信号）。
- **共受体复合物**：CD19/CD21/CD81；CD19 传递协同信号，显著放大 BCR 信号；CD21 结合补体 C3d。
- 其他标志：CD20、CD22、PAX5；浆细胞标志 CD138、CD38。

#### （3）B 细胞的活化

B 细胞完全活化需要两个关键信号：

1. **第一信号（抗原特异性信号）**：BCR 特异性结合抗原，CD79a/CD79b 传递信号。
2. **第二信号（共刺激信号）**：活化的辅助 T 细胞（Tfh）通过 **CD40L** 与 B 细胞表面 **CD40** 结合。

- BCR 结合抗原后可内化抗原，加工成肽段，以 **pMHC II** 形式提呈给辅助 T 细胞，从而获得 T 细胞帮助。
- 生发中心内发生体细胞高频突变、亲和力成熟和类别转换。

### 5.3 T 淋巴细胞

#### （1）T 细胞的发育

- 来源于骨髓，在**胸腺**中发育成熟，在外周淋巴组织执行功能。
- 发育过程：**双阴性（DN，CD4⁻CD8⁻）→ 双阳性（DP，CD4⁺CD8⁺）→ 单阳性（SP，CD4⁺ 或 CD8⁺）→ 成熟单阳性 T 细胞**。
- **阳性选择**：在胸腺皮质上皮细胞上，TCR 识别自身 MHC 分子，获得 **MHC 限制性**；不能识别的凋亡。
- **阴性选择**：在胸腺髓质上皮细胞/树突状细胞上，对自身抗原高亲和力反应的 T 细胞被清除，获得**自身耐受**；AIRE 基因参与组织特异性抗原的表达【补充】。
- 主流路径：**αβ T 细胞**；替代路径：**γδ T 细胞**（皮肤、肠道等黏膜屏障）。

**胸腺微环境**

- 皮质、髓质、被膜、小梁；胸腺细胞、胸腺上皮细胞、树突状细胞、胸腺小体（Hassall 小体）。
- 胸腺是 T 细胞 TCR 重排、阳性/阴性选择、获得功能的场所。

#### （2）T 细胞表面分子

**TCR-CD3 复合体**

- **TCR（T-cell antigen receptor）**：T 细胞表面特异性识别抗原的结构。
  - αβ 型：主要分布于外周血（90%–95%）。
  - γδ 型：主要分布于皮肤和黏膜（5%–10%）。
- **CD3**：成熟 T 细胞的表面标志；由 γ、δ、ε、ζ、η 五种肽链组成，均为跨膜蛋白；胞内段含 **ITAM**，负责将 TCR 接收的抗原信号转导至胞内。

**CD4**

- CD4⁺ T 细胞约占 αβ T 细胞的 **65%**。
- 结构：单体肽链，胞外含四个 Ig 样功能区。
- 功能：辅助受体，与 **MHC II 类分子**的 β2 功能区结合，增强 TCR 与 pMHC II 的相互作用，并招募 Lck 等激酶强化信号。
- **CD4 是 HIV 的主要受体**；CCR5/CXCR4 为辅助受体。CCR5Δ32 纯合供者骨髓移植可使部分 HIV 患者长期缓解（“柏林病人”“伦敦病人”“杜塞尔多夫病人”）。
- 2018 年“基因编辑婴儿”事件涉及 CCR5 编辑，存在严重伦理问题，不应重复。

**CD8**

- CD8⁺ T 细胞约占 αβ T 细胞的 **35%**。
- 结构：αβ 异二聚体或 αα 同二聚体。
- 功能：辅助受体，与 **MHC I 类分子**的 α3 功能区结合，增强 TCR 与 pMHC I 的相互作用，促进信号转导。
- CD8⁺ T 细胞分化为细胞毒性 T 细胞（CTL）。

**CD28 与 CTLA-4**

| 分子 | 表达 | 配体 | 功能 |
|---|---|---|---|
| CD28 | 外周 T 细胞（组成性） | B7（CD80/CD86） | 提供共刺激信号，促进 T 细胞活化、增殖、IL-2 分泌 |
| CTLA-4 | 活化 T 细胞 | B7（CD80/CD86） | 抑制信号，阻止 T 细胞增殖，抑制 IL-2 分泌 |

> CTLA-4 与 B7 的亲和力高于 CD28，可竞争性抑制共刺激；这是 CTLA-4 抗体（ipilimumab）抗肿瘤的原理。

#### （3）T 细胞的活化

| 信号 | 内容 | 关键分子 |
|---|---|---|
| **第一信号** | 抗原特异性识别 | TCR 识别 pMHC；CD3 ITAM 磷酸化 → ZAP-70 → PLCγ、MAPK → NFAT、NF-κB、AP-1 入核 |
| **第二信号** | 共刺激 | APC 的 B7（CD80/CD86）与 T 细胞 CD28 结合；仅有第一信号会导致 T 细胞**无能（anergy）** |
| **第三信号** | 细胞因子辅助 | IL-2 等促进 T 细胞增殖和分化 |

- **负向调控**：CTLA-4、PD-1 等抑制性受体与配体结合后，招募磷酸酶（SHP-1/SHP-2 等），终止信号传导，维持免疫耐受。
- **免疫检查点治疗**：ipilimumab（抗 CTLA-4）、nivolumab（抗 PD-1）等；用于黑色素瘤、非小细胞肺癌等。
- **双特异性抗体**：KN046（PD-L1/CTLA-4）、依沃西单抗（PD-1/VEGF）、卡度尼利单抗（PD-1/CTLA-4）等，通过同时阻断两条通路增强抗肿瘤免疫。

**肿瘤免疫逃逸的四个环节**：识别、预警、杀伤、微环境。

#### （4）T 细胞亚群

**按 TCR 构成**：αβ T 细胞、γδ T 细胞。
**按 CD4/CD8**：CD4⁺ T 细胞、CD8⁺ T 细胞。
**按功能**：辅助性 T 细胞（Th）、细胞毒性 T 细胞（CTL）、调节性 T 细胞（Treg）。

**CD4⁺ 辅助性 T 细胞亚群**

| 亚群 | 诱导因子 | 核心转录因子 | 标志性细胞因子 | 核心功能 | 相关疾病 |
|---|---|---|---|---|---|
| **Th1** | IL-12、IFN-γ | T-bet | IFN-γ、TNF-α | 抗胞内菌/病毒；活化 CD8⁺ T、巨噬细胞 | 多发性硬化、克罗恩病、迟发型超敏反应 |
| **Th2** | IL-4 | GATA3 | IL-4、IL-5、IL-13 | 抗寄生虫；活化 B 细胞（IgE）、嗜酸性粒细胞 | 过敏、哮喘、体液免疫亢进 |
| **Th17** | IL-6、TGF-β、IL-23 | RORγt | IL-17A/F、IL-22 | 黏膜防御（胞外菌/真菌）、促炎 | 类风湿关节炎、银屑病、炎症性肠病 |
| **Tfh** | IL-6、IL-21 | Bcl-6 | IL-21、CXCL13 | 辅助 B 细胞在生发中心分化、产生高亲和力抗体 | 自身抗体相关疾病、体液免疫缺陷 |
| **Th9** | TGF-β、IL-4 | PU.1 | IL-9 | 抗寄生虫、促炎、参与过敏 | 哮喘、肠道炎症、肿瘤微环境调节 |
| **Th22** | TNF-α、IL-6 | AHR | IL-22、TNF-α | 皮肤/黏膜屏障修复、抗感染 | 银屑病、特应性皮炎、肠道炎症 |

**调节性 T 细胞（Treg）**

- 表型：**CD3⁺ CD4⁺ CD25⁺ Foxp3⁺**。
- 来源：
  - 自然 Treg（nTreg）：胸腺发育；
  - 诱导 Treg（iTreg）：外周初始 T 细胞在 TGF-β 等诱导下产生。
- 功能：主动抑制免疫应答，维持自身耐受，防止过度免疫损伤；在肿瘤中帮助免疫逃逸。
- 机制：分泌 IL-10、TGF-β；细胞接触抑制。

**细胞毒性 T 细胞（CTL）**

- 表型：**CD3⁺ CD8⁺**，颗粒酶 B⁺、穿孔素⁺。
- 识别 MHC I 类分子提呈的抗原（病毒/肿瘤抗原），直接杀伤靶细胞。
- 杀伤机制：穿孔素/颗粒酶、Fas/FasL、TNF。
- 是清除感染细胞和癌细胞的主力。

**特殊功能 T 细胞亚群**

| 亚群 | 表型 | 抗原识别 | 核心功能 | 分布/特点 |
|---|---|---|---|---|
| **NKT 细胞** | CD3⁺ NK1.1⁺、半恒定 TCR | CD1d 提呈的脂质抗原 | 快速分泌 IFN-γ/IL-4；抗感染、抗肿瘤、免疫调节 | 肝、骨髓、胸腺；连接固有/适应性免疫 |
| **MAIT 细胞** | CD3⁺、半恒定 TCR、CD161⁺ | MR1 提呈的微生物维生素 B 代谢物 | 黏膜抗感染（细菌/真菌）、促炎、组织修复 | 肠道、肺、肝；占黏膜 T 细胞的 30%–50% |
| **耗竭 T 细胞** | CD3⁺ CD8⁺ PD-1⁺ TIM-3⁺ LAG-3⁺ | 长期慢性抗原刺激 | 效应功能丧失（低细胞因子、低杀伤） | 慢性感染（HIV/HBV）、肿瘤微环境；免疫检查点靶点 |
| **衰老 T 细胞** | CD3⁺ CD28⁻、KLRG1⁺、端粒短 | 抗原应答降低 | 增殖能力下降，促炎因子分泌增加 | 老年、慢性炎症；与感染/肿瘤易感性相关 |

**γδ T 细胞 vs αβ T 细胞**

- γδ T 细胞：更古老，是先天免疫的延伸，负责快速、广泛的早期防御和组织维护；主要位于皮肤、肠道等黏膜屏障。
- αβ T 细胞：适应性免疫的精密产物，负责高度特异、持久的靶向清除和免疫记忆。

### 5.4 NK 细胞

**基本特征**

- **不受 MHC 限制**、对多种靶细胞具有自发细胞毒性的效应细胞，无需预先致敏即可杀伤。
- 大多数 NK 细胞具有 LGL 形态；课件称约占免疫细胞的 15%。
- 表型：**CD3⁻ CD16⁺ CD56⁺**；不表达 TCR、CD3、CD4。
- 功能：细胞毒性（直接杀伤靶细胞）、免疫调节（分泌细胞因子）。

**CD16 与 ADCC**

- CD16（FcγRIII）是 IgG 的低亲和力 Fc 受体。
- 靶细胞被特异性抗体包裹后，NK 细胞通过 CD16 识别抗体 Fc 段，触发胞内信号，释放穿孔素和颗粒酶，高效杀伤靶细胞——**抗体依赖性细胞介导的细胞毒作用（ADCC）**。
- NK 细胞活化后，CD16 可被 ADAM17 等金属蛋白酶剪切而脱落，表达下调。

**CD56 亚群**

| 亚群 | 比例 | CD16 | 特点/功能 |
|---|---|---|---|
| **CD56dim** | 约 90% | 高表达 | 成熟 NK；杀伤功能为主；ADCC 主力 |
| **CD56bright** | 约 10% | 低表达 | 未成熟 NK；擅长分泌大量细胞因子；免疫调节和组织归巢 |

**NK 细胞受体**

NK 细胞不表达 TCR/CD3，功能不受 MHC 限制，但受三大类受体精确调控：

1. **抑制性受体（KIR）**：识别靶细胞上正常的自身 MHC I 类分子，防止攻击正常自体细胞。
2. **活化性受体（KAR）**：识别应激、感染或癌变时异常表达的分子，传递激活信号。
3. **共刺激受体**：增强活化性受体信号，类似 T 细胞的“第二信号”。

> **“缺失自我”（missing-self）**：靶细胞 MHC I 类分子下调或缺失时，KIR 抑制信号减弱，NK 细胞被激活。这是 NK 细胞识别肿瘤和病毒感染细胞的重要机制。

**NK 细胞的功能**

1. 固有免疫：直接杀伤肿瘤/病毒感染细胞。
2. 调节获得性免疫：分泌 IFN-γ 等细胞因子，调节 DC、T 细胞。
3. 调节造血：参与造血微环境和造血调控。

**NK 细胞相关治疗**：CAR-NK、NK 细胞输注、双特异性/三特异性 NK 衔接器（在发展中）。

### 5.5 淋巴细胞减少症

**定义**：外周血总淋巴细胞计数 **<1.0×10⁹/L（1000/μL）**。

- 正常成人外周血淋巴细胞中约 80% 为 T 细胞，近 2/3 为 CD4⁺ T 细胞；因此淋巴细胞减少多表现为 **T 细胞（尤其 CD4⁺ T）绝对计数降低**。

**病因（按机制）**

| 机制 | 常见原因 |
|---|---|
| 生成缺陷 | 先天性免疫缺陷（SCID）；获得性骨髓衰竭（AA、MDS）；营养不良/锌缺乏；肿瘤浸润骨髓 |
| 破坏增加 | 感染（HIV 直接破坏 CD4⁺ T）；自身免疫病（SLE）；医源性（化疗、放疗、阿仑单抗等） |
| 异常滞留/重新分布 | 急性病毒感染（流感）、脓毒症/感染性休克、糖皮质激素、脾肿大 |
| 其他/未知 | 晚期恶性肿瘤、终末期肾病、特发性 CD4⁺ T 细胞减少症、种族因素 |

**病因（按来源）**

- **遗传性**：SCID、ADA 腺苷脱氨酶缺陷（可基因治疗）、Wiskott-Aldrich 综合征、免疫缺陷伴肢体短小型侏儒症、伴胸腺瘤的免疫缺陷等。
- **获得性**：骨髓衰竭（AA、MDS）；感染（HIV/AIDS 最常见、肝炎、流感、结核、疟疾）；医源性（免疫抑制剂、化疗、放疗、大手术）；全身性疾病/营养（自身免疫病、淋巴瘤、恶性肿瘤、锌缺乏、酗酒）。
- **特发性 CD4⁺ T 细胞减少症**：罕见，持续性 CD4⁺ T 减少，排除 HIV 及其他已知病因。

### 5.6 淋巴细胞增多症

**定义**：外周血总淋巴细胞计数 **>4.0×10⁹/L（4000/μL）**。

**核心分类**

| 类型 | 性质 | 机制/特点 |
|---|---|---|
| **克隆性（原发性）** | 恶性、单克隆增殖 | 单个淋巴细胞恶性转化，形成无限制增殖的同一克隆 |
| **反应性（继发性）** | 良性、多克隆、可逆 | 病毒/细菌毒素、再分布、胸腺激素等导致 |

**克隆性淋巴细胞增多**

1. **淋巴细胞白血病**
   - **CLL**：最常见的成人白血病；外周血成熟 B 细胞克隆性增多；流式 **CD5⁺、CD19⁺、CD23⁺** 单克隆 B 细胞。
   - **ALL**：外周血大量原始/幼稚淋巴细胞；高度侵袭性；B 细胞型常见，T 细胞型次之。
   - **毛细胞白血病（HCL）**：罕见 B 细胞肿瘤，细胞表面有“毛发样”胞质突起；【补充】BRAF V600E 突变，CD11c/CD25/CD103 阳性。
2. **淋巴瘤白血病期**：淋巴瘤细胞播散至骨髓和外周血；可见于套细胞淋巴瘤、滤泡性淋巴瘤、脾边缘区淋巴瘤、成人 T 细胞白血病/淋巴瘤（ATLL，HTLV-I 相关）。
3. **前驱病变**：单克隆 B 细胞增多症（MBL），外周血小克隆 B 细胞，未达 CLL 诊断标准，需长期随访。

**反应性淋巴细胞增多**

| 类别 | 例子 |
|---|---|
| 感染 | 病毒：EBV、CMV、HIV、HSV、VZV、风疹、腺病毒、肝炎病毒；细菌：百日咳、结核、布鲁菌；寄生虫：弓形虫 |
| 肿瘤 | 癌症、胸腺瘤 |
| 免疫系统疾病 | 类风湿关节炎、自身免疫性纯红再障 |
| 慢性炎症 | 结节病、韦格纳肉芽肿 |
| 应激 | 哮喘、外科手术、急性心衰、感染性休克、心肌梗死、癫痫状态 |
| 其他 | 长期吸烟、超敏反应、脾切除后、药物（达沙替尼） |

**急性感染性淋巴细胞增多症**

- 病因：肠道病毒、柯萨奇病毒、腺病毒等；儿童（2–10 岁）多见。
- 临床：外周血淋巴细胞显著、一过性增高（20,000–30,000/μL）；细胞形态接近正常；无淋巴结肿大/脾大；骨髓原始细胞比例不高。
- 易与急性白血病混淆，但为良性、自限性。

### 5.7 急性淋巴细胞白血病（ALL）

**定义**

起源于 B 系或 T 系淋巴祖细胞的恶性克隆性疾病，以骨髓和外周血中原始、幼稚淋巴细胞异常增殖和积聚为特征。

**流行病学**

- 双峰年龄分布：第一个高峰 2–5 岁（儿童），第二个高峰 50 岁以后（成人）。
- **ALL 是儿童最常见的恶性肿瘤**，约占儿童白血病的 75%。
- 儿童在专科中心治愈率可达 80%–90%；成人预后显著较差，5 年总生存率从年轻成人的约 60% 降至 60 岁以上患者的 <20%–30%。

**病因与发病机制**

| 因素 | 内容 |
|---|---|
| 遗传易感性 | Down 综合征（ALL 风险增加约 20 倍）、Li-Fraumeni 综合征（TP53 胚系突变）、共济失调毛细血管扩张症；ARID5B、IKZF1 等多态性位点 |
| 环境因素 | 产前 X 射线暴露、大剂量放射治疗史 |
| 核心机制 | “多步骤打击”：获得性体细胞遗传异常在 HSC/祖细胞中累积 → 增殖失控、分化阻滞、凋亡受阻；染色体数目/结构异常、拷贝数变异、序列突变 |

**临床表现**

| 类别 | 表现 |
|---|---|
| 骨髓造血受抑 | 发热（感染）、出血（血小板减少）、贫血 |
| 白血病细胞浸润 | 淋巴结和肝脾肿大、骨/关节疼痛、口腔和皮肤肿胀、胸腺肿块、睾丸肿大、中枢神经系统白血病 |

**实验室检查**

1. **血象**：白细胞可增高、正常或减少；低者可 <1.0×10⁹/L，称为**白细胞不增多性白血病**；血片可见原始/幼稚细胞；伴贫血、血小板减少。
2. **骨髓象**：诊断主要依据；增生明显/极度活跃，原始和幼稚淋巴细胞大量增生，正常红系/巨核系受抑；可见“**裂孔现象**”（仅原始细胞和成熟细胞，中间阶段缺如）；核质发育不平衡。
3. **细胞化学染色**：
   - 过氧化物酶（POX）阴性；
   - 苏丹黑（SBB）阴性；
   - 糖原（PAS）可阳性（呈块状/颗粒状）；
   - 醋酸-萘酚酯酶（ANAE）可阳性。
4. **免疫学**：B 系（CD19、CD20、CD22、CD79a、PAX5）、T 系（CD3、CD7、CD5）、祖细胞标志（CD34、TdT）。
5. **细胞遗传学/分子生物学**：见下表。

**ALL 常见染色体异常和受累基因**

| 类型 | 染色体异常 | 融合基因/基因 |
|---|---|---|
| 前体 B-ALL | t(9;22)(q34;q11.2) | BCR-ABL |
| 前体 B-ALL | t(4;11)(q21;q23) | MLL-AF4 |
| 前体 B-ALL | t(12;21)(p13;q22) | TEL-AML1（RUNX1） |
| 前体 B-ALL | t(1;19)(q23;p13.3) | E2A-PBX1 |
| 前体 B-ALL | t(5;14)(q31;q32) | IL3-IGH |
| 前体 B-ALL | 亚二倍体/超二倍体（>50 条） | 预后相关 |
| 前体 T-ALL | t(11;14)(p13;q11) | LMO2、TCRα/δ |
| 前体 T-ALL | t(1;14)(p32;q11) | TAL1-TCR |

**FAB 形态学分型**

| 型别 | 特点 |
|---|---|
| **L1** | 原始/幼稚淋巴细胞以小细胞（≤12 μm）为主；核圆、染色质较粗、核仁少而不清；胞浆少，轻中度嗜碱；POX/SBB 阳性细胞一般 ≤3% |
| **L2** | 以大细胞（>12 μm）为主；核形不规则、凹陷/折叠；染色质较疏松、核仁清楚；胞浆较多，轻中度嗜碱 |
| **L3** | 似 Burkitt 型；细胞大小较一致、以大细胞为主；染色质均匀细点状、核仁明显；胞浆较多、深蓝色、空泡明显呈蜂窝状 |

**治疗**

| 治疗 | 内容 |
|---|---|
| 化疗 | **VDLP**：长春新碱（V）、柔红霉素（D）、L-门冬酰胺酶（L）、泼尼松（P）；巩固/维持治疗常用甲氨蝶呤、6-巯基嘌呤等 |
| 靶向治疗 | Ph⁺ ALL 用 TKI（伊马替尼、达沙替尼等）；CD20⁺ 可用利妥昔单抗 |
| 免疫治疗 | **CAR-T**（CD19）；双特异性抗体（贝林妥欧单抗等）【补充】 |
| 造血干细胞移植 | 高危、复发/难治患者 |
| 中枢神经系统预防 | 鞘内注射化疗药物【补充】 |

**药物机制**

- **长春新碱**：结合微管蛋白，抑制有丝分裂纺锤体形成，使有丝分裂阻滞、细胞凋亡。
- **柔红霉素**：嵌入 DNA 碱基对之间，干扰转录，阻止 mRNA 合成。
- **L-门冬酰胺酶**：水解血清门冬酰胺，使肿瘤细胞缺乏门冬酰胺而生长受抑；正常细胞能合成门冬酰胺，受影响较小。
- **泼尼松**：超生理剂量发挥抗炎、抗免疫作用；抑制 IL-2 基因转录，抑制 T 细胞克隆增殖。
- **甲氨蝶呤**：抑制二氢叶酸还原酶，阻断叶酸代谢和 DNA 合成。
- **6-巯基嘌呤**：嘌呤类似物，抑制 DNA 合成。

**CAR-T 与 CRS**

- 将患者 T 细胞在体外导入识别 CD19 的 CAR，扩增后回输；CAR-T 可特异性杀伤 B 细胞肿瘤。
- 2012 年 Emily Whitehead 成为首位接受 CD19 CAR-T 的儿童 ALL 患者；2017 年 FDA 批准。
- 主要不良反应：**细胞因子释放综合征（CRS）**、神经毒性、B 细胞缺乏/低丙种球蛋白血症。
- CAR-NK 正在发展中。

### 5.8 淋巴瘤

**定义**

淋巴瘤是起源于淋巴组织的恶性肿瘤，以**无痛性、进行性淋巴结肿大和局部肿块**为特征性临床表现，全身各组织器官均可受累。按组织病理学分为**霍奇金淋巴瘤（HD）**和**非霍奇金淋巴瘤（NHL）**。

**流行病学**

- 我国男性常见恶性肿瘤中约占第十位。
- 每年发病约 2–4/10 万人口。
- 发病年龄有两个高峰：20–30 岁和 60 岁左右。
- 男女之比约 2.42–3.7:1。
- 我国淋巴瘤发病年龄较年轻，NHL 多于 HD。

**霍奇金淋巴瘤（HD）**

- 经典 HD 起源于**生发中心阶段成熟 B 细胞**的恶性转化。
- 细胞成分复杂：肿瘤细胞 + 各种炎症细胞。
- 具有诊断意义的巨细胞：**Reed-Sternberg（R-S）细胞**，双核、镜影状，是 HD 真正的肿瘤细胞；单个核者称霍奇金细胞。
- 免疫表型：R-S 细胞 **CD15⁺、CD30⁺**，通常 CD45⁻、CD20⁻。
- 组织学分型：
  - 结节性淋巴细胞为主型（NLPHL）；
  - 经典霍奇金淋巴瘤（CHL，约 95%）：结节硬化型、混合细胞型、富淋巴细胞型、淋巴细胞消减型。

**非霍奇金淋巴瘤（NHL）**

- 细胞来源于不同分化阶段的免疫细胞；不同亚型的免疫表型、染色体核型、受累基因和临床表现不同。
- 2008 年 WHO 分类结合形态学、免疫学、遗传学和临床特征，将 NHL 分为 **B 细胞 NHL** 和 **T/NK 细胞 NHL** 两大类。

**Burkitt 淋巴瘤**

- 高度侵袭性；起源于成熟生发中心或生发中心后 B 细胞。
- 首个被确认含有病毒颗粒（EB 病毒）的肿瘤。
- 涉及 **t(8;14)** 的易位，导致 **c-myc** 基因结构性过表达；也可有 t(2;8)、t(8;22)。
- 形态：中等大小 B 细胞，胞浆深蓝、空泡明显；“星空”现象（巨噬细胞吞噬凋亡细胞）【补充】。
- 治疗：强化化疗；MYC 长期被视为“不可成药”，研究中的策略包括抑制 c-Myc 转录、促进 c-Myc 降解、抑制 c-Myc-Max 相互作用、BET 抑制剂（JQ1，抗 BRD4）等。

**弥漫大 B 细胞淋巴瘤（DLBCL）**

- 全球最常见的 NHL，约占全部病例的 30%–40%。
- 弥漫性排列的大 B 细胞肿瘤。
- 根据细胞起源分为 **GCB（生发中心 B 细胞样）** 和 **ABC（活化 B 细胞样）** 亚型，约 10%–15% 无法分类。
- 标准一线治疗 5 年总生存率约 60%–70%。
- **双表达淋巴瘤（DEL）**：BCL-2 和 c-MYC 蛋白高表达；**双打击淋巴瘤（DHL）**：BCL-2 和 c-MYC 基因易位（如 t(14;18) BCL-2 + MYC 易位）。
- 治疗：**R-CHOP**（利妥昔单抗 + 环磷酰胺 + 羟基柔红霉素 + 长春新碱 + 泼尼松）。
- **维奈克拉（Venetoclax，ABT-199）**：BCL-2 抑制剂，用于部分 B 细胞肿瘤。

**利妥昔单抗（rituximab）的作用机制**

1. **抗体依赖性细胞介导的细胞毒作用（ADCC）**：NK 细胞、巨噬细胞通过 FcγR 识别抗体包被的 B 细胞并杀伤。
2. **补体依赖性细胞毒作用（CDC）**：补体级联激活，形成膜攻击复合物。
3. **直接效应与信号干扰**：诱导凋亡、抑制 B 细胞受体信号。

**淋巴瘤的临床表现【补充】**

- 无痛性进行性淋巴结肿大，最常见于颈部、腋下、腹股沟。
- 结外受累：胃、肠、皮肤、骨髓、中枢神经系统等。
- **B 症状**：发热、盗汗、体重下降（6 个月内下降 >10%）。
- 晚期可出现贫血、感染、出血、肝脾大。

### 5.9 多发性骨髓瘤（MM）

- 是**长寿命浆细胞**的恶性肿瘤。
- 骨髓中克隆性浆细胞增生，分泌单克隆免疫球蛋白（M 蛋白）。
- 典型表现：**CRAB**——高钙血症（hyperCalcemia）、肾功能不全（Renal insufficiency）、贫血（Anemia）、骨病（Bone lesions）。
- 诊断：骨髓浆细胞比例、M 蛋白、免疫固定电泳、游离轻链、影像学。
- 治疗【补充】：蛋白酶体抑制剂（硼替佐米）、免疫调节剂（来那度胺）、CD38 单抗（达雷妥尤单抗）、自体干细胞移植。

## 六、血小板

### 6.1 血小板的基本特征

- 平均直径约 **1–2 μm**，体积约 5.8 fL，**无核**。
- 外周血血小板浓度 **150,000–400,000/μL（150–400×10⁹/L）**，成人总量约 1 万亿个。
- 由骨髓（以及肺）产生，约 1/3 储存于脾脏。
- 生存期约 **7–10 天**。
- 产生主要由**促血小板生成素（TPO）**调控；衰老/受损血小板主要由脾脏和肝脏的吞噬系统清除。

> **进化小知识**：无核的血小板仅存在于哺乳动物；其他脊椎动物具有有核的凝血细胞（thrombocytes）。血小板的出现为哺乳动物带来了高效止血的优势，也带来了血栓性疾病的挑战。

### 6.2 血小板的生成与调控

**巨核细胞（megakaryocyte）**

- 巨核细胞是血小板的前体，经历**核内有丝分裂（endomitosis）**：核膜不消失、不形成纺锤体，染色体在核内反复复制，形成多倍体巨核细胞。
- 分化阶段：
  1. 成巨核细胞（megakaryoblast，Ⅰ期）：裂核、嗜碱性胞质；
  2. 嗜碱性巨核细胞（Ⅱ期）：马蹄形核、嗜碱性胞质、嗜天青颗粒围绕中心体；
  3. 颗粒型巨核细胞（Ⅲ期）：大分叶核、嗜酸性胞质、大量嗜天青颗粒；
  4. 成熟巨核细胞（Ⅳ期）：核固缩，胞质充满颗粒，释放血小板。
- 每个巨核细胞可产生 **2000–5000 个血小板**。

**调控**

| 因素 | 作用 |
|---|---|
| **TPO** | 主要由肝脏产生（肾脏、脾等亦有表达）；与巨核细胞/血小板表面 **MPL（c-MPL）**受体结合，促进巨核细胞增殖、分化和血小板生成 |
| 基因调控 | GATA1、RUNX1、FLI1、NFE2 等转录因子；NFE2 缺失小鼠巨核细胞发育异常、血小板减少 |
| 血流剪切力 | 参与血小板生成和释放 |
| 血小板清除 | 衰老/活化血小板被脾、肝巨噬细胞清除；血小板数量减少时 TPO 相对升高，刺激生成 |

- TPO/MPL 轴是血小板生成的核心：TPO 与 MPL 结合 → JAK2/STAT5 等信号 → 巨核细胞增殖、多倍体化、血小板释放。
- 临床药物：
  - **重组人血小板生成素（rhTPO，特比澳）**；
  - **艾曲波帕（eltrombopag）**：小分子非肽类 TPO 受体激动剂；
  - 罗米司亭等【补充】。

### 6.3 血小板的结构

**形态变化**

静息态血小板呈圆盘状；活化后发生**变形（shape change）→ 铺展（spreading）→ 聚集（aggregation）**，并释放颗粒内容物。

**膜结构**

- 血小板膜表面有丰富的糖蛋白和受体，参与黏附、活化、聚集。
- 开放管道系统（open canalicular system，OCS）：增加膜面积，便于颗粒释放和物质交换。
- 致密管道系统（dense tubular system，DTS）：储存 Ca²⁺，参与信号转导。
- 膜磷脂：活化后 PS 外翻，为凝血因子提供催化表面。

**关键膜受体**

| 受体 | 结构/数量 | 配体 | 功能 | 相关药物/疾病 |
|---|---|---|---|---|
| **GPIIb/IIIa（integrin αIIbβ3，CD41/CD61）** | 由 αIIb 和 β3 两个亚基组成；两个基因均位于 17 号染色体；静息血小板约 50,000 个/血小板 | 纤维蛋白原、纤连蛋白、vWF、胶原等含 RGD 基序的分子 | 血小板聚集的最终共同通路；双向信号转导 | 阿昔单抗、替罗非班、依替巴肽；Glanzmann 血小板无力症 |
| **GPIb-IX-V 复合物（CD42）** | GPIbα、GPIbβ、GPIX、GPV 按 2:2:2:1 组成；静息血小板约 25,000 个/血小板 | vWF、α-凝血酶、integrin αMβ2 | 血小板黏附于受损血管内皮下 vWF；介导活化信号 | Bernard-Soulier 综合征；血小板型 vWD |
| **GPVI** | 胶原受体 | 胶原 | 血小板活化、聚集 | 抗 GPVI 药物在研 |
| **GP Ia/IIa（α2β1）** | 胶原受体 | 胶原 | 黏附 | — |
| **P-selectin（CD62P）** | α 颗粒膜蛋白，活化后表达于膜表面 | PSGL-1 | 血小板-白细胞相互作用、炎症 | 活化标志物 |

**GPIIb/IIIa 的双向信号**

1. **由内向外（inside-out）**：血小板激活剂（ADP、肾上腺素、凝血酶等）→ 胞内信号 → 踝蛋白（talin）与 β3 胞内域结合 → 受体“伸展” → 与纤维蛋白原亲和力增加。
2. **由外向内（outside-in）**：配体结合 αIIbβ3 → 一系列磷酸化事件 → 血小板骨架改变、铺展、甚至蛋白翻译 → 稳定聚集和血块回缩。

**GPIb-IX-V 与 vWF**

- vWF 由血管内皮细胞（Weibel-Palade 小体）产生，是分子量可达 >20,000 kDa 的多聚糖蛋白，存在于血浆、血小板和内皮下基质。
- vWF 的 A1 结构域与 GPIbα 结合，介导血小板在高剪切力下的初始黏附。
- GPIbα 的胞内段可介导信号导致血小板活化；其他亚基主要起支撑作用。
- GPIbα 在动脉血栓形成中起关键作用：用 IL-4R 胞外段替换 GPIb 胞外段的小鼠不能形成动脉血栓。

**颗粒**

| 颗粒 | 主要成分 | 功能 |
|---|---|---|
| **α-颗粒** | 纤维蛋白原、vWF、vWF 前体、纤连蛋白、血小板反应蛋白-1、玻连蛋白；凝血因子 V、XI、XIII、蛋白 S、TFPI；PDGF、TGF、EGF、IGF；血管生成因子；PAI-1；P-选择素（CD62P）、CD63；PF4、β-血栓球蛋白、多聚蛋白；趋化因子等 | 黏附、凝血、伤口愈合、血管生成、炎症 |
| **致密颗粒（δ 颗粒）** | ADP、ATP、5-羟色胺、钙离子 | 血小板聚集、血管收缩 |
| **溶酶体** | 酸性水解酶 | 降解吞噬物质 |
| **分泌囊泡** | 膜蛋白、受体等 | 膜修复、黏附 |

### 6.4 血小板的功能

#### （1）止血（primary hemostasis）

血管损伤后的止血过程：

1. **血管收缩**：血小板释放 5-HT、TXA2 等血管收缩物质。
2. **血小板黏附**：vWF-GPIb-IX-V 介导血小板黏附于内皮下胶原；GPVI/α2β1 直接结合胶原。
3. **血小板活化**：凝血酶、ADP、TXA2、胶原、肾上腺素等激动剂 → 形态改变、颗粒释放、GPIIb/IIIa 活化。
4. **血小板聚集**：活化 GPIIb/IIIa 与纤维蛋白原交联，形成血小板血栓。
5. **凝血反应**：血小板膜磷脂（PS 外翻）为凝血因子提供催化表面，促进凝血瀑布，形成纤维蛋白网。
6. **血块回缩与伤口愈合**：血小板收缩蛋白使血块回缩；释放 PDGF、TGF-β 等促进修复。

#### （2）促进凝血

- 血小板活化后 PS 外翻，提供带负电荷的磷脂表面，促进凝血因子（尤其是 Xa、Va、II）组装，放大凝血反应。
- α 颗粒释放凝血因子 V、XI、XIII、纤维蛋白原、vWF 等。
- 血小板也参与血块回缩和伤口愈合。

#### （3）血管稳态维持

- 血小板参与维持内皮完整性；血小板减少时可出现微血管渗漏。
- 出生后血小板参与**动脉导管闭合**；动脉导管未闭占先天性心脏病的 12%–15%。
- 血小板通过 **CLEC-2 受体**与高内皮微静脉（HEV）上的平足蛋白（podoplanin）结合，维持 HEV 完整性，支持淋巴细胞从血液进入淋巴结。

#### （4）免疫炎症与肿瘤

- 血小板释放趋化因子、细胞因子，参与炎症反应和白细胞募集。
- 血小板与肿瘤细胞相互作用，形成“血小板-肿瘤细胞聚集体”，帮助肿瘤细胞逃避免疫攻击、促进转移。
- 血小板也参与淋巴管生成和组织修复。

> **记忆锚点**：血小板的功能不止“止血”，还包括**凝血、血管稳态、免疫炎症、肿瘤转移、伤口愈合**。

### 6.5 血小板功能检测

| 检查 | 内容/意义 |
|---|---|
| 血小板计数、MPV、血涂片 | 数量、大小、形态；排除假性减少 |
| 出血时间（BT） | 反映血小板数量和功能；敏感性和特异性有限，临床少用 |
| 血小板聚集试验（LTA） | 用 ADP、胶原、肾上腺素、花生四烯酸、瑞斯托霉素等诱导，观察聚集曲线；诊断血小板功能缺陷 |
| 流式细胞术 | 检测 CD41/CD61（GPIIb/IIIa）、CD42a/b/d（GPIb-IX-V）、P-选择素（CD62P）、PAC-1 等 |
| PFA-100/200 | 模拟高剪切力下的血小板黏附/聚集，筛选 vWD/血小板功能缺陷 |
| 电子显微镜 | 观察 α/δ 颗粒数量和结构 |
| 基因检测 | 诊断遗传性血小板功能缺陷（GP1BA、GP1BB、ITGA2B、ITGB3、MYH9 等） |

**常见聚集模式**

| 疾病 | ADP/胶原/肾上腺素 | 瑞斯托霉素 | 解释 |
|---|---|---|---|
| Glanzmann 血小板无力症 | 均不聚集 | 正常 | GPIIb/IIIa 缺失 |
| Bernard-Soulier 综合征 | 正常 | 不聚集/明显减弱 | GPIb-IX-V 缺失 |
| 贮存池病 | 第一波正常，第二波减弱/消失 | 正常 | 颗粒释放缺陷 |
| 灰色血小板综合征 | 胶原聚集缺陷 | 正常 | α 颗粒缺失 |
| 血小板型 vWD | 低剂量瑞斯托霉素即可聚集 | 增强 | GPIbα 功能获得 |

### 6.6 血小板减少症

**定义**：血小板计数 <100×10⁹/L【补充】；课件以 ITP 等疾病为主，正常范围为 150–400×10⁹/L。

**病因**

| 机制 | 常见原因 |
|---|---|
| 生成减少 | 骨髓衰竭（AA、MDS、白血病）、化疗/放疗、药物、酒精、B₁₂/叶酸缺乏、病毒感染、先天性巨核细胞生成不良 |
| 破坏增多 | 免疫性（ITP、药物性、输血后紫癜、HIT）、非免疫性（DIC、TTP、HUS、败血症、机械性破坏）、脾功能亢进 |
| 分布异常 | 脾大、脾功能亢进 |
| 稀释 | 大量输血、体外循环 |
| 假性减少 | EDTA 依赖性血小板聚集、血小板卫星现象；血涂片可见血小板聚集，改用枸橼酸抗凝复查 |

**临床表现**

- 皮肤黏膜出血：瘀点、瘀斑、鼻衄、牙龈出血、月经过多。
- 出血程度与血小板计数和功能相关；血小板 <20×10⁹/L 时出血风险明显增加。
- 颅内出血罕见但致命。
- 与凝血因子缺陷不同，血小板减少以**皮肤黏膜出血**为主，深部血肿/关节出血少见。

**免疫性血小板减少性紫癜（ITP）**

- 又称特发性血小板减少性紫癜，是一种获得性自身免疫性出血性疾病。
- 机制：自身抗体（多为 IgG）针对血小板膜糖蛋白 **GPIIb/IIIa、GPIb/IX** → 血小板在脾脏被巨噬细胞吞噬破坏；巨核细胞可代偿性增多。
- 诊断：**排除性诊断**。
  1. 血小板减少，其他血细胞计数正常；
  2. 无临床上明显可能导致血小板减少的疾病；
  3. 骨髓巨核细胞正常或增多（典型）；
  4. 排除假性减少、药物、感染、自身免疫病、淋巴瘤等。
- 临床表现：从仅有瘀点、易瘀伤到严重出血；皮肤黏膜出血为主；颅内出血罕见。
- 治疗：
  - 观察：血小板 >30×10⁹/L 且无出血；
  - 一线：糖皮质激素（泼尼松）、静脉注射免疫球蛋白（IVIG）、抗 D 免疫球蛋白；
  - 二线：利妥昔单抗、TPO 受体激动剂（艾曲波帕、罗米司亭）、脾切除；
  - 血小板输注仅用于危及生命的出血，因输注血小板可能被抗体迅速破坏。

**血栓性血小板减少性紫癜（TTP）**

- 机制：**ADAMTS13** 缺乏（先天性或自身抗体介导）→ vWF 多聚体不能被裂解 → 血小板异常黏附、微血栓形成。
- 五联征：**微血管病性溶血性贫血、血小板减少、神经系统症状、肾脏损害、发热**。
- 外周血：破碎红细胞（schistocytes）、血小板减少、网织红细胞升高、LDH 升高。
- 治疗：**血浆置换**为首选；糖皮质激素、利妥昔单抗、caplacizumab【补充】。
- 注意：除非危及生命，避免血小板输注，以免加重微血栓。

**溶血性尿毒症综合征（HUS）**

- 典型 HUS：Shiga 毒素产生菌（如 E. coli O157:H7）感染，儿童多见，腹泻后出现微血管病性溶血、血小板减少、急性肾衰竭。
- 治疗以支持治疗为主，必要时透析；血浆置换用于非典型 HUS（补体旁路异常）【补充】。

**弥散性血管内凝血（DIC）**

- 全身性凝血激活 → 凝血因子和血小板消耗、继发性纤溶亢进 → 出血、血栓、微循环障碍。
- 常见诱因：感染、创伤、恶性肿瘤、产科并发症、APL。
- 实验室：血小板减少、PT/APTT 延长、纤维蛋白原降低、D-二聚体升高、破碎红细胞。
- 治疗：治疗原发病、支持治疗；肝素用于血栓栓塞为主者【补充】。

**药物性血小板减少**

- 肝素诱导的血小板减少症（HIT）：PF4-肝素抗体 → 血小板活化、血栓形成；典型为血小板下降 >50% 且伴血栓。
- 奎宁、磺胺、万古霉素、GPIIb/IIIa 抑制剂等。
- 处理：停用可疑药物，必要时替代抗凝。

### 6.7 血小板增多症

**定义**

- 血小板计数 >450×10⁹/L 为血小板增多【补充】；课件所述“血小板 >1,000,000/μL（1000×10⁹/L）”为**极端血小板增多**。

**分类**

| 类型 | 机制 | 常见原因 |
|---|---|---|
| **反应性（继发性）血小板增多（RT）** | 无 MPD/MDS；炎症、感染、手术、创伤、缺铁等刺激 | 近期手术、细菌感染、创伤、缺铁性贫血、脾切除后、恶性肿瘤 |
| **克隆性（原发性）血小板增多（AT）** | 骨髓增殖性肿瘤/骨髓增生异常综合征 | 原发性血小板增多症（ET）、CML、原发性骨髓纤维化（PMF）、真性红细胞增多症（PV）、MDS/MPN |

- **原发性血小板增多症（ET）**：极端血小板增多（>1000×10⁹/L），JAK2、CALR、MPL 突变【补充】；血栓和出血风险均增加。
- 治疗：治疗原发病；高危患者用阿司匹林、羟基脲/干扰素等降细胞治疗【补充】。

### 6.8 遗传性血小板功能缺陷

| 疾病 | 缺陷 | 遗传方式 | 血小板计数/形态 | 临床表现 | 诊断要点 | 治疗 |
|---|---|---|---|---|---|---|
| **Glanzmann 血小板无力症** | GPIIb/IIIa（αIIbβ3）缺失或失活 | 常染色体隐性 | 计数和形态正常 | 出生/婴儿期皮肤黏膜出血（鼻衄、牙龈出血）；肌血肿罕见 | 出血时间明显延长；ADP、胶原、肾上腺素、凝血酶均不能诱导聚集；流式 CD41/CD61 缺失/低表达 | 血小板输注（可能因抗体无效）；**重组因子 VIIa（rFVIIa）** |
| **Bernard-Soulier 综合征（BSS）** | GPIb-IX-V 复合物缺乏/功能障碍 | 常染色体隐性 | 中度至重度血小板减少；**巨大血小板**（平均直径 >3.5 μm） | 自发性出血、皮肤黏膜出血 | 出血时间延长；除瑞斯托霉素/博替霉素外，其他激动剂聚集正常；流式 CD42b（GPIb）、CD42a（GPIX）、CD42d（GPV）降低 | 血小板输注 |
| **致密颗粒缺陷（贮存池病）** | δ 颗粒缺乏 | 可为遗传性或获得性 | 计数正常 | 轻中度皮肤黏膜出血 | 第一波聚集正常、第二波减弱/消失；电镜示 δ 颗粒减少 | 血小板输注、抗纤溶药 |
| **灰色血小板综合征** | α 颗粒缺乏 | 常染色体显性/隐性 | 轻度血小板减少；涂片血小板呈灰色、无颗粒 | 轻中度皮肤黏膜出血 | 胶原诱导聚集缺陷；骨髓纤维化；NBEAL2/GFI1B 突变【补充】 | 血小板输注 |
| **MYH9 相关巨血小板综合征** | 非肌肉肌球蛋白重链 IIA（MYH9）突变 | 常染色体显性 | 血小板减少、巨大血小板 | 轻度出血；可伴耳聋、肾病、白内障【补充】 | 血涂片中性粒细胞包涵体；基因检测 | 支持治疗 |
| **血小板型 vWD（pseudo-vWD）** | GPIbα 功能获得突变，增强与 vWF 多聚体结合 | 常染色体显性 | 形态正常，计数降低 | 轻中度出血 | 血浆大分子 vWF 多聚体降低；低剂量瑞斯托霉素即可引起聚集 | 血小板输注、vWF 制剂 |
| **P2Y12 缺陷** | ADP 受体缺陷 | 常染色体隐性 | 计数正常 | 轻中度出血 | ADP 诱导聚集缺失/显著减弱 | 血小板输注 |

**血小板型 vWD 与 2B 型 vWD 的鉴别**

| 项目 | 血小板型 vWD | 2B 型 vWD |
|---|---|---|
| 缺陷 | GPIbα 功能获得 | vWF 功能获得（对 GPIb 亲和力增高） |
| 遗传 | 常染色体显性 | 常染色体显性 |
| 血小板 | 轻度减少，形态正常 | 轻度减少 |
| 大分子 vWF 多聚体 | 降低 | 降低 |
| 低剂量瑞斯托霉素聚集 | 增强 | 增强 |

| 基因 | GP1BA | VWF |

### 6.9 获得性血小板功能异常与抗血小板药物

**获得性原因**

- 药物：阿司匹林、P2Y12 抑制剂、GPIIb/IIIa 抑制剂、NSAIDs、SSRIs 等。
- 尿毒症：血小板功能受损，透析可改善；可用去氨加压素。
- 体外循环、肝病、DIC、骨髓增殖性肿瘤。
- 血液系统疾病：MDS、MPN、异常球蛋白血症。

**抗血小板药物**

| 药物 | 靶点 | 机制 | 特点 |
|---|---|---|---|
| **阿司匹林** | COX-1 | 不可逆乙酰化 COX-1，抑制 TXA2 生成 | 作用持续 7–10 天（血小板无核，不能重新合成 COX） |
| **氯吡格雷/普拉格雷** | P2Y12 | 不可逆抑制 ADP 受体 | 抗血小板；需注意出血、CYP2C19 多态性 |
| **替格瑞洛** | P2Y12 | 可逆抑制 | 起效快，停药后恢复较快 |
| **阿昔单抗、替罗非班、依替巴肽** | GPIIb/IIIa | 阻断纤维蛋白原结合，抑制聚集 | 静脉用药，用于 PCI |
| **沃拉帕沙** | PAR-1 | 阻断凝血酶受体 | 用于动脉粥样硬化血栓事件 |
| **西洛他唑** | PDE3 | 升高 cAMP，抑制血小板 | 用于外周动脉病 |

**适应证**：急性冠脉综合征、PCI、缺血性卒中/短暂性脑缺血发作、外周动脉疾病、某些高危血栓患者。

### 6.10 血小板与凝血因子出血的鉴别

| 项目 | 血小板异常 | 凝血因子异常 |
|---|---|---|
| 出血部位 | **皮肤、黏膜**（鼻出血、牙龈出血、月经过多、胃肠道） | **深部软组织、关节、肌肉** |
| 瘀点 | 有 | 无 |
| 瘀斑 | 小而浅表 | 大而深 |
| 关节积血/肌肉出血 | 非常少见 | 常见 |
| 切割/划痕后出血 | 立即出血，通常较温和 | 延迟 1–2 天，常较严重 |
| 手术/创伤后出血 | 立即，通常温和 | 延迟，常严重 |
| 实验室 | 血小板计数/功能异常；BT 延长；PT/APTT 正常 | 血小板正常；PT/APTT 异常；BT 正常 |

> **临床问答：什么时候输血小板？**
>
> - 预防性输注：血小板 <10×10⁹/L；若伴发热、感染、出血风险，阈值可提高到 <20×10⁹/L。
> - 手术/侵入操作：一般要求血小板 >50×10⁹/L；中枢神经系统/眼科手术要求 >100×10⁹/L。
> - 活动性出血：根据出血程度和血小板计数输注。
> - 免疫性血小板减少（ITP）：仅在危及生命的出血时输注，因输入的血小板会被抗体迅速破坏。
> - 血型匹配：优先 ABO 同型；RhD 阴性育龄女性应尽量输 RhD 阴性血小板，避免抗 D 致敏；紧急情况下 ABO 不相合也可输注。

### 7.5 止血与血栓：一张图理解

```text
血管损伤
  │
  ├─ 血管收缩（内皮素、5-HT、TXA2）
  │
```

### 7.8 易混概念对照

| 易混点 | 区分要点 |
|---|---|
| **HSC vs 造血祖细胞** | HSC 有自我更新；祖细胞无自我更新，只能分化 |
| **网织红细胞 vs 成熟红细胞** | 网织红有残留 RNA/核糖体，体积略大、非双凹；亚甲蓝染色阳性 |
| **MCV vs MCHC** | MCV 对缺铁更敏感（相关性约 70%）；MCHC 约 50% |
| **间接胆红素 vs 直接胆红素** | 间接：脂溶性、与白蛋白结合、溶血时升高；直接：水溶性、肝内结合、胆汁排泄 |
| **G6PD 缺乏 vs PK 缺乏** | G6PD：氧化性药物/蚕豆诱发、Heinz 小体、X 连锁；PK：慢性非球形红细胞溶血、常染色体隐性 |
| **α 地中海贫血 vs β 地中海贫血** | α 链减少 → 过多 β 链形成 HbH（可溶）；β 链减少 → 过多 α 链（不可溶）沉积 |
| **缺铁性贫血 vs 慢性病贫血** | IDA：铁蛋白↓、TIBC↑；ACD：铁蛋白↑、TIBC↓、血清铁↓ |
| **巨幼细胞贫血 vs MDS** | 巨幼：叶酸/B₁₂↓、巨幼变、补充后恢复；MDS：病态造血、克隆性遗传学异常 |
| **AA vs MDS** | AA：骨髓脂肪化、巨核细胞缺如、全血细胞减少；MDS：骨髓增生活跃/病态造血、原始细胞可增多 |
| **类白血病反应 vs CML** | 类白：NAP↑、无 Ph/BCR-ABL、可逆；CML：NAP↓、Ph⁺、BCR-ABL⁺、脾大 |
| **APL vs 其他 AML** | APL：t(15;17) PML-RARα、出血/DIC 突出、ATRA/As₂O₃ 有效 |
| **CML vs CLL** | CML：髓系、Ph⁺、Bcr-Abl、脾大；CLL：成熟 B、CD5⁺CD19⁺CD23⁺ |
| **HD vs NHL** | HD：R-S 细胞、CD15⁺CD30⁺、沿淋巴管扩散；NHL：异质性、跳跃扩散、结外多见 |
| **Burkitt vs DLBCL** | Burkitt：t(8;14) MYC、高度侵袭、星空现象；DLBCL：最常见 NHL、GCB/ABC、R-CHOP |
| **ITP vs TTP** | ITP：单纯血小板减少、免疫破坏、血浆置换无效；TTP：MAHA + 神经/肾损害、ADAMTS13↓、血浆置换有效 |
| **DIC vs TTP** | DIC：凝血因子消耗、PT/APTT 延长、纤维蛋白原↓；TTP：PT/APTT 多正常、ADAMTS13 缺乏 |
| **血小板型 vWD vs 2B 型 vWD** | 前者 GPIbα 获得性功能增强；后者 vWF 功能增强；混合试验可鉴别 |
| **假性粒细胞减少 vs 真性减少** | 假性：边缘池转移，总数不减少；真性：生成/破坏/分布异常导致总池减少 |
| **假性血小板减少** | EDTA 依赖性聚集/血小板卫星现象；血涂片可见聚集，枸橼酸抗凝复查正常 |

## 八、自测与名词表

### 8.1 自测题（附简要答案）

**总论与造血**

1. 血液由哪些成分组成？血浆蛋白各有什么功能？
   - 血浆 55% + 有形成分 45%；白蛋白维持胶体渗透压，球蛋白参与免疫，纤维蛋白原参与凝血。
2. 血液病常见的六大症状/体征是什么？
   - 发热、贫血、出血、血栓、黄疸、肝脾淋巴结肿大。
3. MICM 分型包括哪些内容？
   - 形态学、免疫学、细胞遗传学、分子生物学。
4. HSC 的定义和两大特性是什么？
   - 能自我更新并分化为所有造血细胞；自我更新 + 多向分化。
5. HSC 的免疫表型是什么？
   - Lin⁻ CD34⁺ CD38⁻ CD90⁺ CD45RA⁻。
6. 胚胎期造血的四个阶段及时间？
   - 卵黄囊 2–6 周；肝 6 周–7 个月；脾 3 个月起；骨髓 4 个月起、7 个月后为主。
7. 什么是髓外造血？
   - 骨髓纤维化等病理状态下，肝、脾、淋巴结恢复胎儿期造血功能。
8. niche 由哪些成分组成？
   - 成骨细胞、内皮细胞、神经、网状细胞/基质细胞、细胞外基质等。
9. 归巢和动员有什么区别？
   - 归巢：外周血 → 骨髓 niche；动员：骨髓 niche → 外周血。
10. 骨髓移植分为哪几类？
    - 自体、同基因、异基因；来源可为骨髓、外周血干细胞、脐血。

**红系**

11. 红系发育各阶段的形态特点？
    - 原红→早幼红→中幼红→晚幼红→网织红→成熟红细胞；胞体逐渐变小、核逐渐固缩、Hb 逐渐增多。
12. 网织红细胞的意义？
    - 反映骨髓红系造血活性；溶血/失血升高，AA 降低。
13. EPO 的来源和作用？
    - 肾（少量肝）在缺氧时产生；刺激红系祖细胞增殖分化，1–2 天网织红升高。
14. JAK2 V617F 与什么疾病相关？
    - 真性红细胞增多症（PV）等骨髓增殖性肿瘤。
15. 红细胞膜的主要骨架蛋白有哪些？
    - 血影蛋白、肌动蛋白、锚蛋白、Band 4.1；Band 3 为阴离子交换蛋白。
16. 红细胞的三条主要代谢途径？
    - 糖酵解（EMP）、2,3-DPG 支路、磷酸戊糖途径（HMP）。
17. G6PD 缺乏的诱因和表现？
    - 感染、氧化性药物、蚕豆；Heinz 小体、血管内溶血、新生儿黄疸。
18. 血红蛋白的结构？
    - 2α + 2β 珠蛋白 + 4 个血红素；每个血红素结合 1 个 O₂。
19. 血红素合成的限速酶和辅酶？
    - ALA 合酶；磷酸吡哆醛（维生素 B₆）。
20. 缺铁性贫血的铁代谢特点？
    - 铁蛋白↓、血清铁↓、TIBC↑、转铁蛋白饱和度↓、小细胞低色素。
21. 叶酸/B₁₂ 缺乏为什么导致巨幼细胞贫血？
    - 两者参与 DNA 合成，缺乏导致核质发育不平衡、细胞核发育落后。
22. 贫血的形态学分类？
    - 小细胞低色素、正细胞正色素、大细胞性。

**髓系与白血病**

23. 中性粒细胞颗粒的种类和标志物？
    - 初级（MPO，早幼粒）、次级（乳铁蛋白，中幼粒）、三级（白明胶酶，晚幼粒）、分泌囊泡。
24. 中性粒细胞杀菌的两大机制？
    - 氧化杀菌（呼吸爆发、ROS、MPO）和非氧化杀菌（脱颗粒、防御素、溶菌酶、乳铁蛋白）；NETosis。
25. 中性粒细胞减少的三大机制？
    - 生成减少、破坏增多、分布异常（以及清除加速）。
26. 类白血病反应与 CML 如何鉴别？
    - NAP：类白↑、CML↓；Ph/BCR-ABL：类白阴性、CML 阳性；类白可逆、CML 需 TKI。
27. APL 的染色体易位和融合基因？
    - t(15;17)(q22;q12)，PML-RARα。
28. ATRA 和 As₂O₃ 治疗 APL 的机制？
    - ATRA 诱导分化；As₂O₃ 降解 PML-RARα；两者协同。
29. CML 的分子基础？
    - t(9;22)(q34;q11)，BCR-ABL 融合基因，组成性酪氨酸激酶。
30. 伊马替尼的作用机制？
    - 竞争 Abl 激酶的 ATP 结合位点，抑制 BCR-ABL 及下游信号。

**淋巴系**

31. B 细胞活化的双信号？
    - 第一信号：BCR 结合抗原；第二信号：CD40-CD40L（Tfh）。
32. T 细胞活化的三信号？
    - TCR-pMHC（第一）、CD28-B7（第二）、细胞因子（第三）。
33. CD4 和 CD8 分别识别哪类 MHC？
    - CD4 → MHC II；CD8 → MHC I。
34. Treg 的表型和功能？
    - CD3⁺CD4⁺CD25⁺Foxp3⁺；抑制免疫应答、维持自身耐受。
35. NK 细胞的表型和杀伤特点？
    - CD3⁻CD16⁺CD56⁺；不受 MHC 限制，无需预先致敏；ADCC、missing-self。
36. 淋巴细胞减少/增多的界值？
    - 减少 <1.0×10⁹/L；增多 >4.0×10⁹/L。
37. ALL 的 FAB 分型？
    - L1 小细胞为主；L2 大细胞、核不规则；L3 Burkitt 样、深蓝胞浆、空泡。
38. ALL 常见的染色体易位？
    - t(9;22) BCR-ABL、t(12;21) TEL-AML1、t(1;19) E2A-PBX1、t(4;11) MLL-AF4、t(8;14) MYC-IgH 等。
39. 霍奇金淋巴瘤的特征细胞和免疫表型？
    - R-S 细胞；CD15⁺、CD30⁺、CD45⁻、CD20⁻。
40. 利妥昔单抗的作用机制？
    - ADCC、CDC、直接诱导凋亡/信号干扰。

**血小板**

41. 血小板正常值、寿命？
    - 150–400×10⁹/L；7–10 天。
42. 巨核细胞的核内有丝分裂是什么？
    - 核膜不消失、无纺锤体，染色体在核内反复复制，形成多倍体。
43. GPIIb/IIIa 和 GPIb-IX-V 的配体？
    - GPIIb/IIIa：纤维蛋白原、vWF、纤连蛋白等；GPIb-IX-V：vWF、凝血酶。
44. 血小板 α 颗粒和致密颗粒的主要成分？
    - α：纤维蛋白原、vWF、凝血因子、PDGF、P-选择素等；致密：ADP、ATP、5-HT、Ca²⁺。
45. ITP 的诊断要点？
    - 孤立性血小板减少、无明显继发原因、骨髓巨核细胞正常/增多、排除性诊断。
46. TTP 的五联征？
    - MAHA、血小板减少、神经系统症状、肾损害、发热。
47. Glanzmann 血小板无力症的缺陷和聚集特点？
    - GPIIb/IIIa 缺陷；ADP/胶原/肾上腺素/凝血酶均不聚集，瑞斯托霉素正常。
48. Bernard-Soulier 综合征的缺陷和特点？
    - GPIb-IX-V 缺陷；巨大血小板、血小板减少、瑞斯托霉素不聚集。
49. 血小板型 vWD 与 2B 型 vWD 的区别？
    - 前者 GPIbα 功能获得，后者 vWF 功能获得；混合试验可鉴别。
50. 血小板减少与凝血因子缺陷的出血特点？
    - 血小板：皮肤黏膜、瘀点、立即出血；凝血因子：深部软组织/关节、大瘀斑、延迟出血。

### 8.3 考前最后 10 分钟

1. **造血场所**：卵黄囊 → 肝 → 脾 → 骨髓；出生后骨髓为主，胸腺/脾/淋巴结参与淋巴系。
2. **HSC**：Lin⁻CD34⁺CD38⁻CD90⁺CD45RA⁻；自我更新 + 多向分化；不能靠形态辨认。
3. **红细胞**：双凹、无核、无线粒体；EMP 产 ATP，HMP 产 NADPH，2,3-DPG 调氧亲和力。
4. **贫血三步**：确认贫血 → MCV 分类 → 网织红判断骨髓反应 → 病因检查。
5. **缺铁**：铁蛋白↓、血清铁↓、TIBC↑、小细胞低色素、凹甲；**巨幼**：大细胞、中性粒细胞分叶过多、B₁₂ 神经症状。
6. **粒系颗粒**：早幼粒 MPO、中幼粒乳铁蛋白、晚幼粒白明胶酶。
7. **白血病四联征**：感染/发热、贫血、出血、浸润；诊断看骨髓原始细胞 >20%。
8. **APL**：t(15;17) PML-RARα；ATRA 诱导分化，As₂O₃ 降解融合蛋白；出血/DIC 突出。
9. **CML**：t(9;22) BCR-ABL；伊马替尼竞争 ATP 位点；NAP 低、脾大、嗜碱增多。
10. **淋巴系**：B 细胞 CD19/CD20/CD79a，T 细胞 CD3/CD4/CD8，NK CD16/CD56/CD3⁻；ALL 儿童最常见，HD 看 R-S 细胞，DLBCL 用 R-CHOP。
11. **血小板**：GPIIb/IIIa 聚集（纤维蛋白原），GPIb-IX-V 黏附（vWF）；ITP 是排除性诊断；TTP 看 ADAMTS13 和血浆置换。
12. **出血鉴别**：血小板 → 皮肤黏膜、瘀点、立即出血；凝血因子 → 深部/关节、大瘀斑、延迟出血。
