# 呼吸系统常见症状：知识梳理

> 依据《07呼吸系统常见症状.pptx》整理。授课：李锋，上海交通大学医学院附属胸科医院呼吸与危重症医学科。
> 页码按所提供文件的幻灯片顺序计，共 69 页；下文“P”均指幻灯片页码。整理日期：2026-10-25。
> 用于医学课程复习，重点是症状的描述、机制和鉴别思路。典型联系不能直接替代诊断，课件中的治疗原则不作为个人用药方案。

## 一、知识框架与症状分析方法（P2—6）

**症状**：通常指患者主观感到的异常，如胸痛、呼吸费力。课件还介绍广义“症状”可包含主观症状与客观病态改变。

**体征**：通过体格检查等客观方法发现的异常，如肺部啰音、心脏杂音、血压升高。应区分“患者说什么”和“检查发现什么”。

呼吸系统症状的基础是气道、肺泡、胸膜、肺循环及呼吸调节的改变，但相同主诉也可来自心血管、消化、血液或神经系统。课件先回顾了气道分支和肺泡周围毛细血管，再介绍四组常见症状。

| 主诉 | 首先描述 | 再考虑的机制 | 课件定位 |
| --- | --- | --- | --- |
| 咳嗽、咳痰 | 病程、干湿、时间规律、音色，痰量与性状 | 反射受刺激、分泌物增多、排痰能力变化 | P7—27 |
| 咯血 | 出血来源、量与速度、性状及伴随症状 | 气道或肺出血、肺循环异常、全身出血倾向 | P28—35 |
| 胸痛 | 部位、性质、持续时间、诱因及缓解因素 | 胸壁、胸膜、心血管、食管或牵涉痛 | P36—51 |
| 呼吸困难 | 起病、活动耐量、吸气／呼气、体位与伴随表现 | 通气、换气、循环、携氧或调节异常 | P52—68 |

气体交换回顾：肺泡与血液之间是肺换气，血液承担氧和二氧化碳的运输，血液与组织之间发生组织换气。课件 P3 用“外呼吸”概括肺泡—血液交换；与前面呼吸生理笔记联读时，注意外呼吸通常还涉及肺通气，不要把整个呼吸过程缩减为肺泡换气。

## 二、咳嗽与咳痰：定义及机制（P7—10）

### 2.1 咳嗽反射

**咳嗽**：呼吸道受到刺激后，通过一系列反射使气流快速向外喷出，以清除分泌物和异物的防御动作。刺激可以是机械性的，也可以是化学性的；剧烈、持续咳嗽又可影响生活、传播感染，或增加出血、气胸等风险。

课件 P9 反射图可整理为：**相关部位受到刺激→感觉神经传入→延髓相关咳嗽调节→运动神经传出→声门与呼吸肌协调产生咳嗽**。图中涉及迷走、舌咽、三叉等传入联系，以及喉返、脊神经和膈神经等传出联系。应理解这是分布式反射联系，不要背成“所有刺激都经一根神经”。

### 2.2 痰与咳痰

**痰**：气管、支气管分泌物以及肺泡内渗出液等形成的呼吸道排出物，可含黏液、炎症细胞、坏死组织、尘埃和微生物。痰与口腔唾液不能简单等同。

**咳痰**：借助咳嗽动作将呼吸道内分泌物排至口腔外的过程。炎症时黏膜充血水肿、分泌增多和血管通透性增加，使痰量与性状改变；能否排出还取决于气道通畅和咳嗽力量。

## 三、咳嗽、咳痰的病因与临床分析（P11—27）

### 3.1 五组病因

| 病因组 | 课件举例 | 机制或问诊线索 |
| --- | --- | --- |
| 呼吸道及胸膜疾病 | 咽炎、支气管炎、支扩、哮喘、肺炎、结核、肿瘤、间质病、胸膜病 | 感染、炎症、异物、肿瘤或刺激性气体引起反射；感染是常见原因 |
| 循环系统疾病 | 左心衰竭、肺栓塞 | 左心衰可致肺淤血、水肿，浆液或血性渗出刺激气道 |
| 胃食管反流 | 反流相关慢性咳嗽 | 可伴反酸、烧心、胸骨后不适，平卧时加重；需要时作相应检查 |
| 药物及理化刺激 | ACEI、冷空气等 | 询问用药与起病关系、环境诱因 |
| 神经、精神相关因素 | 课件列脑炎、脑膜炎及焦虑相关咳嗽表现 | 与注意力、情绪和昼夜有关只能提供线索，需排查其他病因 |

**ACEI 相关咳嗽**：服用血管紧张素转换酶抑制剂后出现的咳嗽，课件提示停用相关药物后可缓解；判断时需核对时间关系，并由临床医生评估药物调整，不能仅因咳嗽自行停药。

课件把“白天咳嗽、专注时或夜间消失、伴焦虑”列作功能性线索。这些特点不能单独确诊精神性咳嗽，也不能据此否定器质性疾病。

### 3.2 性质：干性与湿性

**干性咳嗽**：无痰或痰极少，可呈短促、断续、阵发性；课件联系急性喉炎、咳嗽变异性哮喘、胸膜炎和早期肺结核等。无痰不能直接证明没有炎症或严重疾病。

**湿性咳嗽**：咳嗽同时有咳痰，常见于慢性支气管炎、支气管扩张、肺脓肿和肺炎。痰量少也可能与排痰无力有关，不能仅据“咳不出痰”判断分泌物少。

### 3.3 病程：急性、亚急性与慢性

| 成人咳嗽病程 | 课件分组 | 课件重点联系 |
| --- | --- | --- |
| 急性 | ＜3 周 | 普通感冒、急性气管支气管炎，以及 COPD、哮喘、支扩等急性加重 |
| 亚急性 | 3—8 周 | 感染后咳嗽、CVA、EB、UACS 等 |
| 慢性 | ≥8 周 | CVA、UACS、EB、GERC 等 |

边界记忆：为避免表格在第 8 周重叠，复习时将“亚急性 3—8 周”理解为达到 3 周而未达到慢性阈值；本课件的慢性阈值明确写为 ≥8 周。以上是成人教学分组，不直接套用于儿童。

| 缩写 | 名词及含义 |
| --- | --- |
| PIC | 感染后咳嗽：感染后咳嗽持续存在，需结合过程和排除其他原因判断 |
| CVA | 咳嗽变异性哮喘：以咳嗽为主要表现的哮喘类型，不能仅凭“夜间干咳”确诊 |
| EB | 嗜酸细胞性支气管炎：慢性咳嗽的相关病因之一，关注气道嗜酸细胞性炎症证据 |
| UACS | 上气道咳嗽综合征：与上气道相关疾病联系的咳嗽综合征，结合鼻、咽等表现分析 |
| GERC | 胃食管反流性咳嗽：与胃食管反流相关的咳嗽，常需结合反流症状及进一步评估 |

### 3.4 起病、时间规律与音色

| 表现 | 课件提示 | 分析要点 |
| --- | --- | --- |
| 突发咳嗽 | 异物、刺激性气体 | 追问当时活动和吸入史 |
| 发作性咳嗽 | 百日咳、支气管内膜结核、CVA | 明确每次诱因、持续时间和间歇期 |
| 长期咳嗽 | 慢支、CVA、支扩、肺脓肿、结核等 | 不应把“时间长”自动等同某一种慢病 |
| 晨起明显 | 慢性上气道炎症、慢支、支扩 | 联系夜间分泌物积聚及起床排痰 |
| 夜间明显 | 哮喘相关因素、心衰肺淤血等 | 结合体位、喘息、端坐呼吸等 |
| 嘶哑 | 声带炎症、喉返神经受累 | 区分咳声与说话声音改变 |
| 鸡鸣样 | 阵咳后出现高调吸气回声 | 课件以百日咳等为例；并非所有高调声均为百日咳 |
| 金属样 | 气管受压或中央气道病变 | 纵隔肿瘤、主动脉瘤、支气管癌等线索 |
| 低微无力 | 严重肺气肿、声带麻痹、极度衰弱 | 关注气道清除能力，而非只评价声音大小 |

### 3.5 痰的性状、颜色、气味与痰量

| 痰的表现 | 课件典型联系 | 应保留的限制 |
| --- | --- | --- |
| 黏液痰 | 急慢性支气管炎、肺炎初期、哮喘 | 反映分泌改变，不能单独区分感染与非感染 |
| 脓性痰 | 化脓性炎症、肺脓肿、支扩合并感染 | 黄绿颜色不直接等于某一病原，也不是单凭颜色用抗菌药的依据 |
| 血性痰 | 结核、肿瘤等 | 需进入咯血的来源与病因分析 |
| 恶臭痰 | 厌氧菌相关感染、肺脓肿等 | 结合标本质量、影像和病原检查 |
| 粉红色泡沫痰 | 急性肺水肿，尤其左心衰相关 | 与呼吸困难、湿啰音等组合判断 |
| 铁锈色痰 | 典型联系肺炎链球菌肺炎；课件还列肺吸虫病、肺泡出血等 | 非病原特异性 |
| 巧克力色脓痰 | 肺阿米巴病的传统描述 | 需结合流行病学与检查 |
| 灰黑色痰 | 尘埃暴露、尘肺或黑曲霉等课件联系 | 不能仅凭颜色确诊尘肺或真菌感染 |
| 黄绿、翠绿色痰 | 传统联系铜绿假单胞菌 | 颜色仅为提示 |
| 红棕或砖红胶冻样痰 | 传统联系肺炎克雷伯菌 | 不具备独立确诊价值 |
| 大量稀薄浆液痰含膜样物 | 课件描述包虫病“粉皮样物” | 属特定临床线索，不把普通黏液丝等同包虫组织 |

**大量恶臭脓痰**：课件联系支气管扩张、肺脓肿及支气管胸膜瘘；静置后可见上层泡沫、中层浆液或浆液脓性液、下层坏死物质。分层是典型教学现象，不能要求每份标本都出现完整三层。

大量稀薄痰还可见于某些分泌黏液的肺腺癌。课件使用“细支气管肺泡癌（黏液型腺癌）”这一历史表述；旧称覆盖范围与现代分类并非严格一一对应，复习时记住大量分泌与黏液相关腺癌的联系，避免把全部旧称直接替换成单一现代亚型。

**必须注意：白色黏稠拉丝痰不能诊断念珠菌肺炎。**课件 P22 把它与白色念珠菌感染联系，属于特异性不足的描述；即使呼吸道标本检出念珠菌，也常为定植，不能仅凭痰外观或培养结果认定侵袭性感染、决定抗真菌治疗。参见 [IDSA 念珠菌病指南，呼吸道标本相关建议](https://www.idsociety.org/practice-guideline/candidiasis/)。

### 3.6 伴随症状与处理原则的学习边界

| 伴随表现 | 课件提出的主要鉴别方向 |
| --- | --- |
| 发热 | 呼吸道感染、胸膜炎、结核等 |
| 胸痛 | 肺炎、胸膜炎、肺癌、肺栓塞、气胸等 |
| 呼吸困难 | 气道阻塞、哮喘、COPD、重症肺炎、积液、气胸、肺水肿等 |
| 大量脓痰 | 支扩、肺脓肿、支气管胸膜瘘 |
| 咯血 | 结核、支扩、肺脓肿、肺癌、二尖瓣狭窄等 |
| 杵状指 | 支扩、慢性肺脓肿、肺癌、脓胸等 |
| 哮鸣音 | 哮喘、慢性阻塞性气道疾病、异物、肿瘤及心源性哮喘等 |

课件 P27 的核心原则是：咳嗽具有排痰保护作用；过度咳嗽影响睡眠和消耗时才需要权衡抑制咳嗽与排痰。湿性咳嗽应重视分泌物清除。原页“单纯干咳可积极镇咳”不能扩展成所有干咳都应直接用镇咳药；病因评估、排痰能力及药物禁忌仍然重要。

## 四、咯血（P28—35）

### 4.1 咯血的定义与出血部位

**咯血**：课件定义为喉及喉以下呼吸道出血，经口排出。先区分鼻咽、口腔出血和消化道呕血，再讨论呼吸道内的出血部位和病因。

咯血的重要危险是血液或血块阻塞气道导致窒息；同时需考虑失血、氧合和循环影响，不能只记录“多少毫升”。

### 4.2 咯血与呕血的鉴别

以下整合课件 P30 的图像表格。每项为常见特征，混合出血、吞入血液或急速出血时可不典型。

| 鉴别项目 | 咯血 | 呕血 |
| --- | --- | --- |
| 病史背景 | 结核、支扩、肺肿瘤、心肺疾病等 | 消化性溃疡、肝硬化等 |
| 出血前表现 | 喉部痒感、胸闷、咳嗽 | 上腹不适、恶心、呕吐感 |
| 排出方式 | 常随咳嗽咯出 | 常随呕吐排出，可呈喷射状 |
| 常见颜色 | 鲜红 | 棕黑、暗红；急速出血也可鲜红 |
| 混杂物 | 痰、泡沫 | 食物残渣、胃液 |
| 酸碱反应 | 课件列偏碱性 | 课件列偏酸性；不作为单独判别标准 |
| 黑便 | 通常无，吞下较多血液时也可能有 | 常可有，出血停止后仍可持续数天 |
| 后续排出物 | 可继续痰中带血 | 通常不出现持续血痰 |

先问“咳出来还是吐出来”，再结合前驱症状、混合物和病史；不能仅按血色判断来源。

### 4.3 病因与年龄线索

| 病因层面 | 课件举例 |
| --- | --- |
| 支气管 | 支扩、肺癌、支气管结核、慢性支气管炎 |
| 肺实质与肺循环 | 肺结核、肺炎、肺脓肿、肺淤血、肺栓塞 |
| 心血管 | 二尖瓣狭窄、肺动脉高压、相关血管病变等 |
| 全身性或其他原因 | 血液病、风湿免疫病、肺出血肾炎综合征、某些感染、子宫内膜异位症等 |

儿童需结合具体情况考虑特发性肺含铁血黄素沉着症等；青壮年课件强调结核、支扩、二尖瓣狭窄；长期吸烟的中老年患者要警惕肺癌。年龄影响鉴别的优先级，不是排除其他病因的界线。

注意：P31“肺结核是最常见原因”带有地区、人群和年代背景。本笔记保留结核是重要病因这一重点，不将其写成所有环境均成立的排序。

### 4.4 咯血量分级：课件口径与危险性

| 分级 | P32 教学口径 |
| --- | --- |
| 小量 | ＜100 mL／日 |
| 中等量 | 100—500 mL／日 |
| 大量 | ＞500 mL／日，或单次约 100—500 mL |

整理说明：原页中等量写作“＜100—500 mL／日”，存在排版歧义，按小、中、大的教学分组整理为 100—500 mL／日；单次大量的范围照录课件。课件端点并不构成统一临床阈值，答题时注明授课口径。

**危及生命的咯血**：需要关注是否已造成气道阻塞、呼吸衰竭或循环不稳定，而不仅是某个体积阈值。不同文献的“大咯血”数值界限并不一致，少量但快速的出血或肺储备差者也可危险。参见 [胸部影像与介入学会咯血管理共识](https://pmc.ncbi.nlm.nih.gov/articles/PMC10289864/)。

### 4.5 性状与伴随表现

大咯血的课件联系：结核空洞、支扩、慢性肺脓肿。持续或间断痰中带血需考虑肺癌等；剧烈咳嗽也可能伴少量血丝，但不能据“只是血丝”排除重要病因。

| 血痰表现 | 课件典型联系 |
| --- | --- |
| 鲜红 | 结核、支扩、肺脓肿、出血性疾病 |
| 铁锈色 | 肺炎链球菌肺炎、肺吸虫病、肺泡出血 |
| 砖红胶冻样 | 肺炎克雷伯菌肺炎 |
| 暗红 | 二尖瓣狭窄相关肺淤血等 |
| 浆液性粉红泡沫样 | 左心衰相关肺水肿 |
| 黏稠暗红 | 课件列肺栓塞等；同样不具特异性 |

伴发热：感染性病因等；伴胸痛：肺炎、肺栓塞、肿瘤、结核等；伴脓痰：支扩、肺脓肿或空洞；伴皮肤黏膜出血：考虑全身出血倾向及相关感染或免疫疾病。课件还列黄疸等系统表现，用意是提醒不要只在肺内寻找原因。

## 五、胸痛（P36—51）

### 5.1 机制与病因范围

**胸痛**：胸部或其他相关部位病变引起的胸部疼痛主诉。个体痛阈不同，疼痛程度与疾病严重性不完全一致；轻痛不意味着疾病轻，剧痛也不能直接确定病因。

**牵涉痛**：内脏感觉传入与体表感觉在中枢存在联系，使内脏病变被感知为相应体表区域疼痛。胸部感觉涉及肋间神经、交感传入、迷走神经及膈神经等，不能把疼痛位置直接等同病灶位置。

| 病因组 | 课件列举 |
| --- | --- |
| 胸壁 | 皮炎、蜂窝织炎、带状疱疹、肌炎、肋软骨炎、骨折、肋间神经炎等 |
| 心脏、大血管 | 心绞痛、心肌梗死、心包炎、心肌病、瓣膜病、主动脉病变、肺栓塞等 |
| 肺与胸膜 | 胸膜炎、胸膜肿瘤、气胸、血胸、肺炎、肺癌 |
| 纵隔 | 纵隔炎、纵隔气肿、纵隔肿瘤 |
| 其他 | 食管炎、食管裂孔疝、膈下脓肿、肝脓肿、脾梗死、过度通气相关表现等 |

### 5.2 五项核心问诊与典型联系

围绕**部位、性质、持续时间、诱发缓解因素、伴随症状**展开，并补充起病速度、年龄、危险因素和既往史。

| 疼痛模式 | 课件提示方向 | 分析限制 |
| --- | --- | --- |
| 胸骨后、心前区或剑突下压榨感 | 心肌缺血，包括心绞痛、心肌梗死 | 部位可不典型；不能凭位置单独排除 |
| 胸骨后烧灼感、与进食或反流相关 | 食管炎、反流、食管裂孔疝 | 食管和心血管痛可重叠 |
| 胸侧部疼痛，深呼吸或咳嗽加重 | 胸膜炎、肺炎、气胸、肺栓塞等 | “胸膜性疼痛”是模式，不是单一病名 |
| 突发胸背部撕裂样剧痛 | 主动脉夹层等；课件也列食管破裂、肺栓塞 | 急性严重起病需结合生命体征评估 |
| 固定压痛点，按压或动作加重 | 胸壁、肋软骨或肋间神经病变 | 存在压痛不能自动排除并存的其他病因 |
| 沿肋间神经分布的灼痛、刀割痛及疱疹 | 带状疱疹等 | 需结合皮肤检查和病程 |
| 右下胸痛 | 肝胆病变、膈下病变等 | 提醒检查胸外来源 |

持续时间要问清：一次疼多久、持续还是反复、是否逐渐加重、是否与活动、呼吸、体位或进食同步。课件没有给出一套适用于全部病因的时长界限，不宜自行加成机械诊断标准。

### 5.3 硝酸甘油反应与危险伴随表现

**必须注意：硝酸甘油缓解胸痛不能用来确诊心绞痛，也不能用未缓解排除或确诊心肌梗死。**课件 P48、P50 将心绞痛和心梗放在同组讨论影响因素，复习时应拆开理解；诊断需要综合病史、心电图及相应检查。[NICE CG95 建议](https://www.nice.org.uk/guidance/CG95/chapter/recommendations)明确反对单凭硝酸甘油反应作诊断。

| 伴随表现 | 课件鉴别重点 |
| --- | --- |
| 咳嗽、咳痰 | 气管、支气管、肺病变 |
| 呼吸困难 | 肺炎、气胸、胸膜炎、肺栓塞；也需结合心血管情况 |
| 咯血 | 肺栓塞、肺癌等 |
| 休克或明显循环不稳定 | 心肌梗死、主动脉夹层、大面积肺栓塞等 |
| 吞咽困难 | 食管病变等 |

这一组的学习重点是先识别可能严重的心肺血管病，再作胸壁、食管等鉴别；“胸痛不重”“年轻”或“按得痛”均不是独立排除标准。

## 六、呼吸困难（P52—68）

### 6.1 定义与五类病因

**呼吸困难**：患者主观感到空气不足或呼吸费力，可伴呼吸频率、深度、节律和呼吸肌用力的变化。主观感觉和客观检查要分别记录，不能把呼吸困难直接等同低氧血症或呼吸衰竭。

课件分为：**肺源性、心源性、中毒或代谢相关、神经精神性、血液性**。同一个人可以有多个机制并存，例如 COPD 同时合并心衰或贫血。

### 6.2 肺源性：吸气性、呼气性、混合性

**吸气性呼吸困难**：以吸气费力为主，课件联系喉、气管及较大气道的狭窄或阻塞，严重时有三凹征，可伴吸气性喉鸣、干咳。气道阻力增大，吸气努力造成胸腔负压明显增加。

**呼气性呼吸困难**：以呼气费力、呼气时间延长为主，常伴呼气性哮鸣音；机制为小气道狭窄和／或肺弹性回缩减弱，课件联系支气管哮喘、COPD 等。

**混合性呼吸困难**：吸气和呼气均感费力，课件联系重症肺炎、重症结核、肺栓塞、间质性肺病、大量积液和气胸等，涉及有效换气面积减少、肺胸膜力学及气体交换异常等机制。

| 类型 | 最突出的呼吸相 | 典型声音或外观 | 主要定位思路 |
| --- | --- | --- | --- |
| 吸气性 | 吸气 | 三凹征、吸气性喉鸣 | 较大气道狭窄或阻塞 |
| 呼气性 | 呼气 | 呼气延长、呼气性哮鸣 | 小气道阻力或弹性回缩异常 |
| 混合性 | 两相 | 两相费力，可合并多种肺部体征 | 肺实质、胸膜及较广泛气体交换障碍等 |

注意：真实患者表现可以混合，不能把所有肺源性呼吸困难都归成“吸气低氧、呼气高碳酸”这样的固定对应。

### 6.3 心源性呼吸困难

左心衰机制主线：**左心功能不全→肺循环压力增高→肺淤血／肺水肿→肺顺应性和气体交换受影响→呼吸费力**。课件将相关过程分述为肺淤血、弥散下降、肺活量下降及反射性呼吸调节改变。

**端坐呼吸**：平卧时呼吸困难加重，坐起或采取端坐位后减轻的体位性表现，是课件左心衰相关呼吸困难的重要线索，需结合基础心脏病和其他体征。

**心源性哮喘**：心功能不全、肺淤血或肺水肿相关的喘息表现，可伴呼吸困难和哮鸣音；并非支气管哮喘的另一名称。课件还强调夜间发作、两肺底或全肺湿啰音等联系。

右心衰部分强调体循环淤血背景，可见于慢性肺源性心脏病、某些先天性心脏病或左心衰进展。右心衰相关呼吸困难需结合原发病及循环状态解释，不能将其机制直接写成“右心衰一律造成肺水肿”。

课件列治疗后好转为临床线索；治疗反应不能代替诊断，也不将“强心、利尿、扩血管”照抄为所有呼吸困难者的处理方案。

### 6.4 代谢、药物和化学毒物相关呼吸困难

**Kussmaul 呼吸**：代谢性酸中毒引起的深大、较规则的代偿性呼吸，课件举尿毒症、糖尿病酮症酸中毒和肾小管性酸中毒等。关键是酸负荷与通气加深的联系，“伴鼾声”不是定义所必需。

课件 P63 的“颈动脉窦化学感受器”应区分为**颈动脉体**化学感受器；颈动脉窦主要与压力感受有关。此为术语辨析，联读呼吸生理笔记中的外周化学感受器部分。

| 因素 | 主要机制 | 课件表现与辨析 |
| --- | --- | --- |
| 阿片类、巴比妥类等药物过量 | 可抑制呼吸中枢 | 呼吸变慢、变浅，严重时节律异常、通气衰竭；并非必须先出现潮式或间停呼吸 |
| 有机磷中毒 | 可同时涉及分泌物增多、气道及神经肌肉等机制 | 原课件与中枢抑制并列，复习时不能将其所有呼吸表现简化成单一中枢抑制 |
| CO 中毒 | 形成碳氧血红蛋白，影响携氧和供氧 | 课件列樱桃红色，不能把该体色当作必须存在的诊断条件 |
| 亚硝酸盐、苯胺类 | 形成高铁血红蛋白，损害正常携氧功能 | 联系血液性缺氧 |
| 氰化物 | 抑制细胞色素氧化酶，妨碍细胞利用氧 | 联系组织性缺氧；P65“血细胞色素氧化酶”按术语更正为细胞色素氧化酶 |

“中毒性”是课件的教学分组，其中包含代谢性酸中毒等情形，并非每项都意味着外源毒物暴露。

### 6.5 神经精神性与血液性呼吸困难

神经系统病变可影响呼吸中枢调节，课件描述深慢呼吸、双吸气、呼吸中断等节律变化。精神心理相关状态可表现为浅快、叹息样呼吸，过度通气时可伴手足搐搦。上述表现不能单独证明心理性病因，仍须结合心肺、代谢、药物和神经系统评估。

**血液性呼吸困难**：红细胞数量或血红蛋白功能异常，使有效携氧能力和血氧含量下降而出现呼吸不适，课件列重度贫血、高铁血红蛋白血症、硫化血红蛋白血症。血氧含量与氧分压不是同一个指标，携氧障碍时 PaO₂ 不一定降低。

### 6.6 伴随症状帮助定位

| 伴随表现 | 课件重点方向 | 不能忽略的限制 |
| --- | --- | --- |
| 哮鸣音 | 哮喘等气道狭窄 | 也可有心源性、肿瘤或其他原因 |
| 明显吸气费力、喉鸣 | 喉水肿、气道异物等 | 提示较大气道问题 |
| 发热、咳嗽、咳痰 | 气道或肺部感染 | 结合病程和检查 |
| 突发剧烈胸痛 | 肺栓塞、气胸等 | 同时考虑心血管等胸痛病因 |
| 大量泡沫样痰 | 急性左心衰、有机磷中毒等 | 结合暴露史和循环、肺部体征 |
| 意识障碍 | 课件列颅脑病变 | 还应结合缺氧、高碳酸、药物或代谢等可能，不能只定位于脑部 |

## 七、四组症状的组合分析与问诊模板

| 症状组合 | 优先展开的鉴别 | 下一步需要补足的信息 |
| --- | --- | --- |
| 慢性咳嗽、痰量多、反复脓痰，伴咯血 | 支扩、肺脓肿及其他慢性感染或气道病变 | 病程、体位排痰、感染发作、影像、出血风险 |
| 呼吸困难、粉红泡沫痰、湿啰音、平卧加重 | 肺水肿，特别是心源性因素 | 基础心脏病、体位关系、循环与氧合情况 |
| 突发胸痛与呼吸困难，伴或不伴咯血 | 肺栓塞、气胸，也需鉴别急性心血管病 | 起病速度、危险因素、生命体征及针对性检查 |
| 干咳、夜间明显或诱因明确 | CVA、反流、UACS、药物等 | 用药、鼻咽症状、反流表现、气道相关检查 |

这些组合用于建立问题清单，不能把“症状三联征”当成充分诊断条件。

问诊时可顺序记录：

1. **起病与病程**：突然还是逐渐？首次还是反复？持续多久？
2. **主症特征**：咳嗽干湿，痰量色味，出血方式和速度，疼痛部位性质，呼吸困难与活动、体位的关系。
3. **伴随表现**：发热、胸痛、喘息、咯血、体重变化、其他部位出血或意识变化。
4. **危险因素与背景**：吸烟、结核接触、过敏或哮喘、心肺病史、药物、职业或毒物暴露等。
5. **与体征对照**：把主诉与视触叩听所见、氧合和循环指标一起解释。

## 八、易混点、自测与答题要点

### 8.1 易混点

1. 咳嗽是一种保护性反射，干咳不等于应立即镇咳；湿咳还要考虑排痰能力。
2. 慢性咳嗽不只有慢性支气管炎，需掌握 CVA、UACS、EB、GERC。
3. 痰色是线索；绿色痰、铁锈痰、胶冻痰均不能直接指定病原。
4. 白黏拉丝痰不证明念珠菌感染，呼吸道培养阳性也常仅为定植。
5. 咯血先分来源，再评估危险；吞血后可出现黑便，呕血也可能鲜红。
6. 咯血量教学分级与临床危险程度不完全一致；少量快速出血也可造成气道危险。
7. 胸痛程度与疾病严重性不成固定比例；硝酸甘油反应不作诊断依据。
8. 吸气性、呼气性与混合性呼吸困难按临床模式区分，不与特定血气类型机械绑定。
9. 心源性哮喘与支气管哮喘不是同一个概念。
10. 呼吸困难、低氧血症、血氧含量下降和呼吸衰竭之间有联系，但不能互相直接替代。

### 8.2 自测题

1. 看到“夜间干咳 10 周”，应列出哪些常见慢性咳嗽病因？还需问什么？
2. 痰培养出现念珠菌，能否据此确定肺部真菌感染？
3. 从哪六个方面区分咯血与呕血？
4. 为什么仅凭 24 小时咯血量不足以判断危险？
5. 胸痛被硝酸甘油缓解，能否确定心绞痛？
6. 三类肺源性呼吸困难分别突出在哪个呼吸相？机制是什么？
7. 怎样把左心衰、肺淤血、肺顺应性下降与端坐呼吸联系起来？
8. 严重贫血造成呼吸困难时，为什么 PaO₂ 不一定降低？

### 8.3 答题要点

1. 成人 ≥8 周属于慢性教学分组，考虑 CVA、UACS、EB、GERC、药物及其他气道肺病；继续问鼻咽、反流、诱因、用药、吸烟、危险症状并结合检查。
2. 不能；常为定植，需临床、影像和必要的进一步证据，不能凭单次培养或痰色决定抗真菌治疗。
3. 背景病史、出血前症状、排出方式、颜色及混合物、黑便、出血后是否继续血痰；每项都有例外。
4. 气道阻塞、出血速度、肺储备和呼吸循环影响都重要；不同资料阈值不同。
5. 不能；病史、心电图及相应检查才构成综合评估。
6. 吸气性：大气道阻力增大；呼气性：小气道狭窄或弹性回缩减弱；混合性：两相均费力，结合肺实质、胸膜及气体交换障碍。
7. 左心功能下降使肺循环压力上升，肺淤血水肿影响力学和交换，平卧可加重，坐起可减轻；结合基础病和肺部体征判断。
8. PaO₂ 主要反映血浆中溶解氧的分压，贫血主要降低血红蛋白所携带的氧和血氧含量，两者不是同一个量。
