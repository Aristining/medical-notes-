## 一、 绪论与概述

### 1. 基本概念与功能

- **内分泌系统组成**：内分泌腺（垂体、甲状腺、甲状旁腺、肾上腺、性腺、松果体等） + 散在的内分泌细胞（胃肠道、心脏、肾脏、肝脏等）。

- **激素（Hormone）定义**：由内分泌腺或散在的内分泌细胞所分泌、以**体液为媒介**、在细胞与细胞之间传递信息的**高效能生物活性物质**。

- **四大生理功能**：① 维持机体稳态（Homeostasis）；② 调节新陈代谢（Metabolism）；③ 促进生长发育（Growth and development）；④ 调节生殖过程（Reproduction）。

- **历史里程碑**：1902年，William Bayliss 和 Ernest Starling 发现了第一个激素——**促胰液素（Secretin）**（将盐酸加入离体小肠研磨提取液注入血液，引起胰液分泌增加）。

### 2. 激素的五种递送方式

1.  **远距分泌（Telecrine）**：激素经血液循环远距离运送至靶细胞（最常见）。

2.  **神经内分泌（Neuroendocrine）**：神经内分泌细胞合成激素，沿轴突运送或释放入血作用于靶细胞（如下丘脑神经元）。

3.  **旁分泌（Paracrine）**：激素进入细胞外液/局部循环，作用于邻近靶细胞。

4.  **自分泌（Autocrine）**：内分泌细胞分泌的激素通过局部扩散又反过来作用于自身细胞。

5.  **胞内分泌（Intracrine）**：激素在细胞内合成后直接作用于细胞内的受体。

### 3. 激素作用的一般特征（★高频简答/选择）

1.  **相对特异性（Relative Specificity）**

    - 取决于靶细胞上特异性的**受体**（有的分布非常局限，有的范围广泛）。

    - **受体特征**：相对特异性、饱和性、竞争性、可逆性；受体数量受调控，存在**上调（Up-regulation）**和**下调（Down-regulation）**。

2.  **信使作用（Messenger Role）**

    - 将内外环境变化的信息传递给靶细胞。

    - **只调节靶细胞固有的内在生理生化反应**（启动、加速或减慢），**既不添加新功能，也不提供额外能量**。

3.  **高效作用（High Efficiency / 生物放大效应）**

    - 激素水平极低（$\text{nmol/L}$ 甚至 $\text{pmol/L}$ 级），但作用极强，构成酶促放大级联反应。

    - *例1（第二信使放大）*：$1\text{ mol}$ 胰高血糖素 $\rightarrow 3 \times 10^6\text{ mol}$ 葡萄糖。

    - *例2（轴系调节逐级放大）*：$0.1\ \mu\text{g CRH} \rightarrow 1\ \mu\text{g ACTH} \rightarrow 40\ \mu\text{g}$ 糖皮质激素 $\rightarrow 6000\ \mu\text{g}$ 糖原储备。

4.  **相互作用（Interactions）**

    - **协同作用（Synergism）**：多种激素联合作用时，总效应**明显大于**各激素单独效应之和（如：肾上腺素 + 胰高血糖素 + 皮质醇 联合升血糖效应远超单一叠加）。

    - **拮抗作用（Antagonism）**：两种激素效应相反，相互抑制（如：胰岛素降血糖 vs 胰高血糖素/GH/GC/肾上腺素升血糖），对维持稳态至关重要。

    - **竞争作用（Competition）**：化学结构相似的激素竞争结合同一受体位点。

      - *经典例子*：**盐皮质激素（醛固酮）**与盐皮质激素受体（MR）**亲和力高**，低浓度即可生效；**孕激素**对该受体**亲和力低**，但当孕激素浓度极高时（如妊娠期），可竞争性结合MR，从而减弱醛固酮的保钠排钾作用。

    - **★允许作用（Permissive Action）【必考名解】**：

      - **定义**：某些激素本身并不能直接引起某种生物效应，但它的存在却是另一种激素发挥该效应的**必备基础**（即一种激素对其他激素的支持性作用）。

      - **经典例子**：糖皮质激素（GC）本身不直接收缩血管，但唯有在它存在时，儿茶酚胺（NE/E）才能正常发挥缩血管和维持血压的作用；此外，雌激素对催产素（OT）刺激子宫收缩也具有允许作用。

      - **可能机制**：调节靶细胞上另一激素受体的表达（增加受体数量/亲和力），或调节受体后信号转导通路。

### 4. 激素分泌的节律与调控

- **生物节律性分泌**（受生物钟控制，中枢位于**下丘脑视交叉上核 SCN**）：

  - **昼夜节律（日节律）**：以分、时为周期呈**脉冲式分泌**（如生长激素GH入睡后1h达高峰；皮质醇、ACTH晨起7-8点最高，午夜最低；褪黑素夜间高）。

  - **月周期节律**：女性性激素（FSH、LH、雌激素Es、孕激素在排卵期与月经周期的波动）。

  - **季节性周期节律**：甲状腺激素（冬季分泌增多）。

- **三大调控方式**：

  1.  **下丘脑-腺垂体-靶腺轴（体液调节）**：高位腺体促进低位靶腺，低位靶腺负反馈抑制高位腺体。

      - **① 长反馈**：靶腺激素（如 $\text{T}_3/\text{T}_4$、GC）反馈调节下丘脑或腺垂体。

      - **② 短反馈**：腺垂体促激素（如 TSH、ACTH）反馈抑制下丘脑释放激素。

      - **③ 超短反馈**：下丘脑肽能神经元受其自身分泌的调节肽的负反馈调节。

  2.  **代谢产物调节（体液调节）**：血液中化学成分直接调节内分泌腺（如：高血糖 $\rightarrow$ 胰岛素 $\uparrow$；低血钙 $\rightarrow \text{PTH} \uparrow$）。

  3.  **神经调节**：自主神经直接支配（如：应急状态交感神经兴奋 $\rightarrow$ 肾上腺髓质分泌儿茶酚胺；睡眠时迷走神经兴奋 $\rightarrow$ 胰岛B细胞分泌胰岛素）。

## 二、 下丘脑-垂体内分泌生理

### 1. 下丘脑与垂体的功能联系（★核心解剖与生理通路）

下丘脑的**肽能神经元**具有“**换能作用**”（将神经活动的电信号转变为化学信号/分泌激素），分为两类，构成下丘脑与垂体之间的两条独立通路：

|  |  |  |
|----|----|----|
| 比较维度 | 下丘脑-腺垂体系统（前叶） | 下丘脑-神经垂体系统（后叶） |
| **起源神经元** | **小细胞肽能神经元**（位于下丘脑“促垂体区”核团，如弓状核等） | **大细胞肽能神经元**（位于下丘脑**视上核 SON、室旁核 PVN**） |
| **结构与通路** | **结节漏斗束** $\rightarrow$ **垂体门脉系统**（垂体上动脉 $\rightarrow$ 初级毛细血管丛 $\rightarrow$ 门微静脉 $\rightarrow$ 次级毛细血管丛） | **下丘脑-垂体束**（神经轴突直接穿过正中隆起抵达神经垂体） |
| **联系性质** | **神经-体液联系**（血液通路） | **直接神经联系**（轴浆运输） |
| **分泌/释放物质** | 下丘脑分泌 **下丘脑调节肽（HRP）**，调节腺垂体合成并分泌7种激素 | 下丘脑合成 **血管升压素（ADH/VP）** 和 **缩宫素（OT）**，神经垂体**无合成功能，仅负责贮存和释放**入血 |

#### 附：下丘脑调节肽（HRP）的种类与作用

*(注：1968年Guillemin分离出TRH，1971年Schally分离出GnRH，二人获1977年诺贝尔奖)*

|  |  |  |
|----|----|----|
| 中文名称 | 英文缩写 | 主要生理作用 |
| 促甲状腺激素释放激素 | **TRH** | 促进 **TSH** 分泌；**促进催乳素（PRL）分泌** |
| 促性腺激素释放激素 | **GnRH** | 促进 **LH** 和 **FSH** 分泌 |
| 促肾上腺皮质激素释放激素 | **CRH** | 促进 **ACTH** 分泌 |
| 生长激素释放激素 | **GHRH** | 促进 **GH** 分泌 |
| 生长抑素 | **GHIH (SS)** | **抑制 GH** 分泌；也抑制 TSH、PRL、胰岛素等分泌 |
| 催乳素释放因子 | **PRF** | 促进 **PRL** 分泌 |
| 催乳素释放抑制激素 / **多巴胺** | **PIF (DA)** | **抑制 PRL** 分泌（生理状态下以多巴胺的经常性抑制为主） |

#### 腺垂体分泌的激素分类：

- **促激素（有靶腺）**：促甲状腺激素（TSH）、促肾上腺皮质激素（ACTH）、促卵泡激素（FSH）、黄体生成素（LH）。

- **直接作用于靶组织的激素**：生长激素（GH）、催乳素（PRL）、促黑激素（MSH）。

### 2. 生长激素（Human Growth Hormone, hGH）

- **概述**：腺垂体中**含量最多**的激素；191个氨基酸的蛋白质激素，**化学结构与催乳素（PRL）相似，故作用有交叉**。

- **分泌特点**：脉冲式释放；**入睡后1小时（慢波睡眠期）出现分泌高峰**；青春期分泌量最大，20岁以后随年龄增长逐年下降。

- **生理作用**：

  1.  **促进生长（核心作用）**：促进细胞体积增大和数目增多，全面促进骨骼、肌肉和内脏生长（**对脑的生长发育无影响！**）。

      - **直接作用**：刺激骨骺生长板（软骨板）的**前软骨细胞（生发层细胞）分化为幼稚软骨细胞**，并使其表达 IGF-1 受体及局部产生 IGF-1。

      - **间接作用（主效应，通过生长介素/胰岛素样生长因子 IGF-1）**：GH 诱导**肝脏**等外周靶细胞产生 **IGF-1（Somatomedin）**，IGF-1 促进软骨组织摄取营养物质，加速 DNA、RNA、蛋白质、胶原及硫酸软骨素合成，促进幼稚软骨细胞增殖并骨化成为骨细胞，使长骨加长。

      - **★分泌异常疾病**：

        - **幼年分泌不足** $\rightarrow$ **侏儒症（Dwarfism）**：身材矮小，但**智力完全正常**（区别于呆小症）。

        - **幼年分泌过多** $\rightarrow$ **巨人症（Gigantism）**。

        - **成年分泌过多** $\rightarrow$ **肢端肥大症（Acromegaly）**：骨骺已闭合，长骨不再加长，但肢端短骨、颅骨、面骨及软组织增生肥大（结缔组织中透明质酸和硫酸软骨素聚集）。

  2.  **调节代谢（生酮、升糖、促蛋白合成）**：

      - **蛋白质代谢**：促进氨基酸进入细胞，加速肝外组织（特别是骨骼肌）蛋白质合成，减少氨基酸分解（正氮平衡，增加非脂肪体重）。

      - **脂肪代谢**：促进脂肪分解，增强脂肪酸氧化供能，减少脂肪堆积。**使机体能量来源由“糖供能”向“脂肪供能”转移**。

      - **糖代谢**：**升高血糖**（抑制外周组织摄取和利用葡萄糖，降低外周组织对胰岛素的敏感性，即具有抗胰岛素效应）。

- **分泌调节**：

  - **下丘脑双重调节**：$\text{GHRH (+)}$ 与 $\text{GHIH/SS (-)}$。

  - **负反馈调节**：血中 GH $\uparrow \rightarrow$ 刺激下丘脑分泌 SS；外周产生的 **IGF-1** 负反馈抑制腺垂体分泌 GH，并抑制下丘脑 GHRH、刺激 SS 分泌。

  - **其他促进因素**：**慢波睡眠**、**低血糖**（最强的代谢刺激之一）、血中氨基酸增多、游离脂肪酸减少、运动、应激刺激、甲状腺激素、雌激素与睾酮。

### 3. 催乳素（Prolactin, PRL）

- **生理作用**：

  1.  **调节乳腺活动**：

      - **妊娠期**：在雌激素、孕激素的基础上，PRL 协同促进乳腺腺泡发育。*注：妊娠期虽 PRL 很高，但因高水平雌、孕激素拮抗其泌乳作用，故妊娠期不泌乳；分娩后雌、孕激素骤降，PRL 才启动泌乳。*

      - **哺乳期**：促进乳汁合成与分泌，**启动和维持泌乳**。

  2.  **调节性腺功能（剂量依赖性双向作用）**：

      - **小剂量（生理水平）**：促进卵巢雌、孕激素合成。

      - **大剂量（高PRL血症/哺乳期）**：反馈性**抑制下丘脑 GnRH 及腺垂体 FSH、LH 分泌**，从而抑制排卵和雌激素合成（临床表现为闭经-溢乳综合征，也是哺乳期生理性避孕的机制）。

  3.  **参与应激反应与免疫调节**：是三大应激激素之一（ACTH、GH、PRL）。

- **分泌调节**：

  - **抑制因素（占主导）**：下丘脑分泌的 **多巴胺（Dopamine, 即 PIF）**、生长抑素（SS）。（若切断垂体柄，其他腺垂体激素均减少，唯独 **PRL 分泌增加**）。

  - **促进因素**：**TRH**、妊娠、婴儿吸吮乳头（神经内分泌反射：吸吮乳头机械感受器 $\rightarrow$ 脊髓上行至下丘脑 $\rightarrow$ 抑制 PIH/多巴胺神经元并刺激 PRF $\rightarrow \text{PRL} \uparrow$）、睡眠、应激。

  - **反馈调节**：PRL 通过短反馈促进下丘脑释放多巴胺（PIF），实现自身负反馈。

### 4. 神经垂体激素：缩宫素（OT）与抗利尿激素（ADH）

1.  **催产素 / 缩宫素（Oxytocin, OT）**（主要由**室旁核**合成）

    - **生理功能**：

      - **射乳反射（促进乳汁排放）**：婴儿吸吮乳头或听到婴儿哭声 $\rightarrow$ 下丘脑室旁核/视上核兴奋 $\rightarrow$ 神经垂体释放 OT $\rightarrow$ 刺激乳腺腺泡周围的**肌上皮细胞收缩**，使乳汁排出。（*注意区分：PRL 管“产奶”，OT 管“排奶”*）。

      - **刺激子宫收缩（分娩正反馈）**：作用强弱与子宫功能状态及性激素水平有关（非孕期弱，妊娠末期极强）。**雌激素具有允许作用**（提高子宫对 OT 的敏感性，促进 OT 受体表达），而孕激素抑制其作用。

    - **分泌调控**：

      - **促进**：分娩时胎儿压迫扩张宫颈和阴道（**Fergusson 反射，典型正反馈**）、吸吮乳头、雌激素允许作用。

      - **抑制**：内源性阿片肽、NO、GABA、急性疼痛/恐惧。

2.  **抗利尿激素 / 血管升压素（ADH / VP）**（主要由**视上核**合成）

    - **生理功能**：① 作用于肾远曲小管和集合管主细胞（$\text{V}_2$受体-cAMP-PKA途径），促进水通道蛋白（AQP-2）嵌入管腔膜，增加水的重吸收，发挥**抗利尿作用**（维持血浆晶体渗透压）；② 大剂量（如失血性休克时）作用于血管平滑肌（$\text{V}_1$受体），引起**血管收缩、血压升高**。

3.  **促黑激素（MSH，了解）**：促进黑色素细胞合成黑色素，使皮肤色素沉着（ACTH 因含与 MSH 相同的氨基酸序列，故高 ACTH 时也会导致皮肤色素沉着）。

## 三、 甲状腺的内分泌功能

- **解剖基础**：人体**最大**的内分泌腺。**滤泡上皮细胞**合成并分泌甲状腺激素（TH，主要是 $\text{T}_4$ 占90%以上，以及生物活性更强的 $\text{T}_3$），以胶质形式（甲状腺球蛋白 TG）**大量贮存于腺泡腔内**（体内唯一细胞外大量贮存的激素）。滤泡旁细胞（C细胞）分泌降钙素（CT）。

### 1. 甲状腺激素（TH）的生理作用（★必考大题）

#### （1）对代谢的影响

1.  **产热效应（显著提高基础代谢率 BMR）**

    - **靶组织**：加速体内物质氧化，使绝大多数组织耗氧量和产热增加（以**心、肝、骨骼肌、肾**最为显著；但**脑、脾、性腺、肺、睾丸、视网膜等除外**，它们的耗氧率不受 TH 影响！）。

    - **★三大产热机制**：

      1.  增强细胞膜 $\text{Na}^+\text{-K}^+\text{-ATP}$ 酶（钠泵）的活性和表达，消耗 ATP 产热。

      2.  促进线粒体解偶联蛋白（UCP）的激活，使氧化磷酸化解偶联，化学能不储存于 ATP 而直接转化为热能。

      3.  增加**线粒体的数量和体积**，增强脂肪酸氧化酶系活性。

2.  **对三大营养物质代谢的影响（★双向调控特征）**

|  |  |  |  |
|----|----|----|----|
| 代谢类型 | 生理水平 / 正常作用 | 分泌过多（甲亢） | 分泌不足（甲减） |
| **蛋白质代谢** | 促进蛋白质及酶合成，呈**正氮平衡**，利于生长发育 | **分解** $>$ **合成**，呈**负氮平衡**，尿氮/尿酸排出增加；骨骼肌蛋白分解导致**肌无力**（肌醇降低）；骨基质蛋白分解导致**骨质疏松、血钙升高** | 蛋白质合成减少；但组织间隙中**粘蛋白（透明质酸、硫酸软骨素等）增多**，结合大量正离子和水分子，引起**非凹陷性粘液性水肿（Myxedema）** |
| **糖代谢** | 双向：既升糖（促小肠吸收糖、促肝糖原分解、促糖异生、增强儿茶酚胺等升糖激素作用），又降糖（加速外周组织利用糖） | **升糖效应略强于降糖**。表现为餐后血糖迅速升高（甚至出现一过性糖尿），但因外周利用也快，随后血糖又快速下降 | 肠道吸收糖慢，外周组织利用糖也慢，血糖曲线平坦 |
| **脂类代谢** | 双向：既促进脂肪酸氧化分解（提高激素敏感性脂肪酶活性，协同儿茶酚胺），又促进胆固醇合成与降解清除 | **促分解** $>$ **促合成**。体脂大量消耗（消瘦）；对胆固醇而言，**清除降解速度** $>$ **合成速度**，故**甲亢患者血清胆固醇水平降低（**$\downarrow$**）！** | 脂肪合成与堆积增加，胆固醇降解过慢，导致**高胆固醇血症**，易发动脉粥样硬化 |

#### （2）促进生长发育（★与GH的对比）

- **经典实验**：1912年 Gudernatsch 给蝌蚪喂食马甲状腺组织，蝌蚪提前变态成为“微型蛙”；若切除蝌蚪甲状腺，则长成巨型蝌蚪而不能变态为蛙。

- **a. 促进脑发育的关键激素（胎儿期 — 出生后头2年）**：促进神经元增殖、分化、胞体长大、突起（树突/轴突）分支和突触形成；促进神经胶质细胞生长及神经纤维**髓鞘形成**。

- **b. 调控骨骼生长发育（新生儿/幼年期）**：刺激骨化中心发育，加速软骨骨化，促进长骨和牙齿生长；**与 GH 协同作用**（促进 GH 分泌，并提高外周组织对 IGF-1 的敏感性）。

- **★重要临床特点**：

  1.  胎儿期 **11周前**自身甲状腺尚未合成 TH，脑发育所需 TH **完全由母体提供** $\rightarrow$ **孕妇必须及时补碘**。

  2.  TH 在**胎儿期主要作用于大脑，但不作用于骨骼生长**（故先天性甲减患儿出生时身高、体重可完全正常！但出生后数周至3~4个月即显现症状） $\rightarrow$ **新生儿必须常规进行甲低（TSH/**$\text{T}_4$**）筛查**。

  3.  **呆小症（克汀病，Cretinism）**：胎儿或婴幼儿期 TH 缺乏，表现为**身材矮小 + 智力低下** + 牙齿发育不全。

#### （3）影响器官系统的功能

1.  **神经系统**：兴奋已发育成熟的中枢神经系统，易化儿茶酚胺作用，提高交感神经兴奋性。（甲亢时：烦躁不安、多愁善感、喜怒无常、失眠多梦、注意力不集中、**双手细颤**；甲减时：表情淡漠、反应迟钝、嗜睡、记忆力减退）。

2.  **心血管系统**：

    - 直接作用于心肌（增加肌浆网 $\text{Ca}^{2+}$ 释放，促进肌球蛋白重链 $\alpha$-MHC 表达） + 间接**上调心肌细胞膜** $\beta$ **肾上腺素能受体的数量和亲和力**（对儿茶酚胺的允许/易化作用）。

    - 效应：心率加快、心肌收缩力增强、心输出量增加、心脏做功增加；外周组织产热多导致外周血管舒张（外周阻力下降），故甲亢表现为**收缩压升高、舒张压略降、脉压增大**，严重时引起甲亢性心脏病、心肌肥大甚至心力衰竭。

### 2. 甲状腺激素的分泌调控（五大机制）

1.  **下丘脑-腺垂体-甲状腺轴（HPT轴，主要调节途径）**：

    - **TRH**（下丘脑） $\xrightarrow{+}$ **TSH**（腺垂体） $\xrightarrow{+}$ $\text{T}_3, \text{T}_4$（甲状腺）。

    - **TSH 的双重作用**：① 全面促进 TH 合成（聚碘、碘活化、碘化、偶联）与释放；② **营养作用**：刺激甲状腺滤泡上皮细胞增生、腺体肥大（如缺碘导致地方性甲状腺肿“大脖子病”，是因为 $\text{T}_3/\text{T}_4$ 合成不足 $\rightarrow$ 对垂体负反馈减弱 $\rightarrow \text{TSH}$ 持续极高 $\rightarrow$ 刺激腺泡代偿性增生肿大）。

    - **外界因素**：**寒冷**（通过去甲肾上腺素 NE 神经元）刺激下丘脑释放 TRH $\rightarrow \text{TSH} \uparrow \rightarrow \text{TH} \uparrow$；**应激**（糖皮质激素 $\uparrow$、生长抑素 GHIH $\uparrow$）则抑制 TRH 和 TSH 分泌。

2.  **负反馈调节**：血中游离 $\text{T}_3, \text{T}_4$ 升高，主要直接反馈抑制腺垂体（最主要部位）合成和释放 TSH（诱导抑制性蛋白合成，并下调腺垂体上的 TRH 受体，降低垂体对 TRH 的敏感性），同时也负反馈抑制下丘脑释放 TRH。

3.  **★自身调节（Autoregulation / 血碘水平的调节）**：

    - 指不依赖 TSH，甲状腺根据血碘浓度自我调节碘摄取与合成的能力。

    - 适量补碘 $\rightarrow$ 碘活化与 TH 合成增加。

    - **★过量碘** $\rightarrow$ **碘阻滞效应（Wolff-Chaikoff 效应）**：血碘浓度过高时，甲状腺聚碘作用受抑，过氧化物酶活性受抑，导致 **TH 合成锐减**（临床用于甲亢术前准备服用复方碘溶液）。

    - **★碘阻滞脱逸现象（Escape Phenomenon）**：若持续给予过量外源碘，正常甲状腺钠-碘同向转运体（NIS）表达下调，胞内碘浓度回落，碘阻滞效应消失，$\text{T}_4/\text{T}_3$ **合成再次恢复正常水平**，从而避免发生甲减。

4.  **自主神经调节**：

    - 交感-肾上腺素能纤维兴奋（NE 作用于 $\alpha, \beta$ 受体） $\rightarrow$ 促进 $\text{T}_3, \text{T}_4$ 合成与释放。

    - 副交感-胆碱能纤维兴奋（ACh 作用于 M 受体） $\rightarrow$ 抑制 $\text{T}_3, \text{T}_4$ 分泌。

5.  **免疫调节（异常病理状态）**：

    - B淋巴细胞产生针对 TSH 受体的自身抗体（TRAb）：

      - **TSH 受体刺激性抗体（TSAb）**：模拟 TSH 作用且不受负反馈抑制 $\rightarrow$ **毒性弥漫性甲状腺肿（Graves 病 / 自身免疫性甲亢）**。

      - **TSH 受体阻断性抗体（TBAb）**：阻断 TSH 与受体结合 $\rightarrow$ **萎缩性甲状腺炎（甲减）**。

## 四、 调节钙磷代谢的激素

人体正常血钙稳态维持在 $9.0 \sim 10.3\text{ mg/dL}$**（**$2.25 \sim 2.75\text{ mmol/L}$**）**。主要由三大钙调节激素通过作用于**骨骼、肾脏、小肠**共同维持：

### 1. 甲状旁腺激素（Parathyroid Hormone, PTH）

- **分泌细胞**：甲状旁腺主细胞。

- **核心效应**：**升血钙、降血磷**。

- **靶器官与作用机制**：

  1.  **对肾脏的作用**：

      - 促进**远曲小管和集合管**重吸收 $\text{Ca}^{2+} \rightarrow$ 尿钙排泄减少，血钙 $\uparrow$。

      - **抑制近端小管（为主）和远端小管**重吸收磷酸盐 $\rightarrow$ 促进尿磷排泄，**血磷** $\downarrow$。

      - **激活肾小管上皮细胞线粒体内的** $1\alpha$**-羟化酶**，促进 $25\text{-OH-D}_3$ 转化为有活性的 $1,25\text{-(OH)}_2\text{-D}_3$，从而**间接促进小肠对钙、磷的吸收**。

  2.  **对骨的作用（动员骨钙入血）**：

      - **快速效应（数分钟内）**：刺激骨细胞和成骨细胞膜上的钙泵，将骨液中的 $\text{Ca}^{2+}$ 迅速转运入血（不破坏骨基质）。

      - **延缓效应（12~14h出现，数日/数周达高峰）**：加强**破骨细胞**的数量和溶骨活动，分泌酸性物质（$\text{H}^+$）和溶酶体酶溶解骨基质与羟磷灰石，使钙、磷大量释放入血。

      - **★重要机制考点（PTH 的双重剂量效应）**：

        - *注：破骨细胞膜上其实没有 PTH 受体！PTH 的受体位于**成骨细胞**上。*

        - **大剂量、持续性 PTH**：作用于成骨细胞，使其释放 **M-CSF（巨噬细胞集落刺激因子）和 RANKL** $\rightarrow$ 诱导前破骨细胞分化为成熟的**破骨细胞** $\rightarrow$ **骨吸收增强、骨钙释放**。

        - **小剂量、间歇性 PTH**：作用于成骨细胞，使其释放 **IGF-1** 等生长因子 $\rightarrow$ 诱导前成骨细胞分化为成熟的**成骨细胞** $\rightarrow$ **促进骨形成、骨钙沉积**（临床用于治疗骨质疏松症的药理机制！）。

- **分泌调控**：主要受**血浆游离** $\text{Ca}^{2+}$ **浓度**直接负反馈调节（血钙 $\downarrow \rightarrow \text{PTH} \uparrow$，长期低血钙致甲状旁腺增生；血钙 $\uparrow \rightarrow \text{PTH} \downarrow$）。此外，血磷 $\uparrow$（通过降低血钙）、儿茶酚胺、$\text{PGE}_2$ 可促进 PTH 分泌。

### 2. 1,25-二羟维生素 D₃（钙三醇）

- **合成与两次羟化活化过程（★必记路线）**：

  $$\text{皮肤 } 7\text{-脱氢胆固醇} \xrightarrow{\text{紫外线}} \text{维生素 D}_3 \text{（或食物摄取）} \xrightarrow{\text{肝脏 } 25\text{-羟化酶}} 25\text{-OH-D}_3 \xrightarrow[\text{（受 PTH}\uparrow, \text{低血钙, 低血磷 激活）}]{\text{肾脏近端小管 } \mathbf{1\alpha\text{-羟化酶}}} \mathbf{1,25\text{-(OH)}_2\text{-D}_3\text{（最高活性）}}$$

- **核心效应**：**升血钙、升血磷**。

- **生理作用**：

  1.  **对小肠（最主要靶器官）**：进入小肠黏膜上皮细胞，结合核受体，**诱导合成钙结合蛋白（Calbindin）**，并增加刷状缘钙通道（TRPV6）和基底膜钙泵表达，强力**促进小肠对钙和磷的吸收**。

  2.  **对骨（双向调节，助骨矿化）**：一方面直接刺激成骨细胞释放因子活化破骨细胞，促进旧骨溶解、骨钙释放，并**对 PTH 在骨的作用起允许/协同作用**（若缺乏 $\text{VD}_3$，PTH 对骨的作用显著减弱）；另一方面由于大幅提高了血钙和血磷水平，为骨钙沉积提供原料，间接促进成骨和骨钙化（缺乏时：儿童患**佝偻病**，成人患**骨软化症**）。

  3.  **对肾脏**：促进肾小管对钙、磷的重吸收（作用较弱）。

- **分泌调控**：低血钙（通过 PTH $\uparrow$ 激活 $1\alpha$-羟化酶）、低血磷（直接激活 $1\alpha$-羟化酶）、PRL、GH 促进其生成；**糖皮质激素（GC）抑制其生成并拮抗其肠钙吸收作用**。

### 3. 降钙素（Calcitonin, CT）

- **分泌细胞**：甲状腺**滤泡旁细胞（C细胞）**。

- **核心效应**：**降血钙、降血磷**。

- **生理作用**：

  1.  **对骨**：直接**抑制破骨细胞**的活动和生成，减少骨溶解与骨钙释放；同时促进成骨细胞活动，加速钙、磷在骨中沉积。

  2.  **对肾**：**抑制**肾小管对钙、磷、钠、氯的重吸收，增加尿钙、尿磷排泄。

  - *特点*：作用迅速而短暂；在**儿童期（骨骼更新快）对血钙调节非常重要**，而在成年人作用较弱（很快会被 PTH 的升钙作用所抵消）。

- **分泌调控**：**血钙升高**刺激 CT 分泌；进食后胃肠激素（**胃泌素 Gastrin**、促胰液素、缩胆囊素等）也可提前刺激 CT 分泌，防止餐后高血钙。

|----|----|----|----|----|----|----|

## 五、 胰岛的内分泌功能

胰岛占胰腺体积的 $1\%\sim 2\%$，由 $1\sim 2 \times 10^6$ 个胰岛散在分布组成：

- **A 细胞（**$\alpha$ **细胞，约20%）**：分泌**胰高血糖素（Glucagon）**。

- **B 细胞（**$\beta$ **细胞，约75%）**：分泌**胰岛素（Insulin）**。

- **D 细胞（**$\delta$ **细胞，约5%）**：分泌**生长抑素（Somatostatin, SS）**（通过旁分泌抑制 A、B 细胞分泌）。

- **PP 细胞（F 细胞）**：分泌胰多肽。

### 1. 胰岛素（Insulin）—— 体内唯一的降血糖激素、促合成激素

#### （1）★胰岛素的分泌机制（高频简答题！）

当血糖浓度升高时，胰岛 B 细胞通过以下“代谢-电偶联”过程释放胰岛素：

1.  **摄取与磷酸化**：血液中的高浓度葡萄糖通过 B 细胞膜上的 **GLUT-2（葡萄糖转运体2，非胰岛素依赖型）** 顺浓度梯度易化扩散进入 B 细胞，随即被胞内的 **葡萄糖激酶（Glucokinase，B细胞的葡萄糖感受器）** 催化生成 $6$-磷酸-葡萄糖（G-6-P）。

2.  **ATP 生成增加**：G-6-P 经糖酵解和三羧酸循环氧化代谢，使细胞内 $\text{ATP}$ **生成增多，**$\text{ATP/ADP}$ **比值升高**。

3.  $\text{K}_{\text{ATP}}$ **通道关闭与去极化**：高浓度 ATP 结合并**关闭细胞膜上的 ATP 敏感性钾通道（**$\text{K}_{\text{ATP}}$**）**，阻碍 $\text{K}^+$ 外流，导致细胞膜发生**去极化**。

4.  $\text{Ca}^{2+}$ **内流与胞吐**：膜去极化激活膜上的电压门控型 $\text{Ca}^{2+}$ 通道（L型）**开放，细胞外** $\text{Ca}^{2+}$ **顺电化学梯度内流，胞内** $[\text{Ca}^{2+}]_{\text{i}}$ **升高，触发含有胰岛素的分泌囊泡向细胞膜移动并通过**出胞作用（胞吐）释放胰岛素入血。（*临床联系：磺脲类降糖药如格列本脲正是通过直接阻断* $\text{K}_{\text{ATP}}$ *通道来促胰岛素分泌的*）。

#### （2）胰岛素受体与信号转导机制

- **受体结构**：跨膜糖蛋白四聚体（$2\alpha + 2\beta$，由二硫键连接），属于**酪氨酸蛋白激酶型受体（RTK）**。

- **转导过程**：胰岛素与胞外 $\alpha$ **亚单位**结合 $\rightarrow$ 变构激活胞内段 $\beta$ **亚单位的酪氨酸蛋白激酶**活性，使其自身酪氨酸残基磷酸化 $\rightarrow$ 进而磷酸化胞内的 **胰岛素受体底物（IRS）** $\rightarrow$ 激活下游两条主通路：

  1.  **PI3-K（磷酸肌醇3激酶）通路**：主要介导代谢效应（促 GLUT-4 转位、促糖原/脂肪/蛋白质合成）。

  2.  **MAPK（丝裂原激活蛋白激酶）通路**：主要介导促细胞生长、增殖及基因表达效应。

#### （3）胰岛素的生理作用（全面促进三大营养物质合成与贮存）

1.  **糖代谢（降低血糖：三促两抑）**：

    - **促进组织细胞摄取和利用葡萄糖**：

      - *机制1（对骨骼肌和脂肪细胞）*：通过信号转导促使胞质囊泡中的 **GLUT-4（胰岛素依赖型转运体）** 通过胞吐募集并嵌入细胞膜，大幅加速葡萄糖跨膜转运入细胞。

      - *机制2（对肝细胞）*：肝细胞膜上是 GLUT-2（不受胰岛素调节），但胰岛素能**诱导并激活肝细胞内的葡萄糖激酶**，加速葡萄糖磷酸化为 G-6-P，降低肝细胞内游离葡萄糖浓度，从而维持细胞内外葡萄糖浓度梯度，促进肝细胞持续摄取葡萄糖。

    - **促进肝糖原和肌糖原合成**（激活糖原合酶，抑制糖原磷酸化酶）。

    - **促进葡萄糖转变为脂肪酸**并贮存于脂肪组织。

    - **抑制糖原分解**、**抑制糖异生**。

2.  **脂肪代谢**：

    - 促进脂肪酸和甘油三酯合成并贮存；同时**强烈抑制脂肪细胞内激素敏感性脂肪酶（HSL）的活性**，减少脂肪分解和游离脂肪酸释放。

    - *病理联系（糖尿病酮症酸中毒 DKA）*：胰岛素严重缺乏时 $\rightarrow$ 脂肪大量分解，游离脂肪酸（FFA）涌入肝脏 $\rightarrow$ 在肝内 $\beta$-氧化生成大量乙酰CoA，超出三羧酸循环处理能力而缩合生成大量**酮体（乙酰乙酸、**$\beta$**-羟丁酸、丙酮）** $\rightarrow$ 引起**酮血症、酮尿症及代谢性酸中毒**。

3.  **蛋白质代谢**：促进氨基酸主动转运入细胞，加速 DNA/RNA 转录与核糖体翻译，促进蛋白质合成；抑制蛋白质分解（缺乏时出现负氮平衡、消瘦乏力）。

4.  **★电解质代谢（促进** $\text{K}^+$ **内流）**：激活细胞膜 $\text{Na}^+\text{-K}^+\text{-ATP}$ 酶，**促进细胞外** $\text{K}^+$ **进入细胞内**，降低血钾。（*临床应用：静脉滴注“胰岛素 + 葡萄糖”极化液可用于抢救重度高钾血症；反之，糖尿病酮症酸中毒缺乏胰岛素时易伴发高钾血症*）。

5.  **促进生长**：与生长激素（GH）具有明显的协同作用（只有在胰岛素保障氨基酸摄取和能源供应的前提下，GH 才能发挥正常的促生长效应）。

#### （4）胰岛素的分泌调控

1.  **血糖水平（最核心的调节因素）**：高血糖对胰岛素分泌呈**三相反应**：

    - **急性期（5 min 内）**：胰岛素分泌迅速增加10倍（释放B细胞内预先贮存的囊泡池），随即回落。

    - **延迟期（15 min 后再次上升，2~3 h 达高峰）**：激活胰岛素合成酶系，新合成的胰岛素释放。

    - **慢性期（持续高血糖 1 周以上）**：刺激胰岛 B 细胞增殖肥大，分泌进一步持续增加。

2.  **氨基酸和脂肪酸**：血中氨基酸（特别是**精氨酸和赖氨酸**）增多、游离脂肪酸和酮体增多均可促进胰岛素分泌（氨基酸与葡萄糖联合作用具有强协同效应）。

3.  **激素调节**：

    - **胃肠激素（肠促胰岛素效应 Incretin effect）**：**抑胃肽（GIP，又称依赖葡萄糖的促胰岛素多肽）**、**胰高血糖素样多肽-1（GLP-1）**、胃泌素、促胰液素等在进食后（血糖尚未升高前）即可前馈刺激胰岛素分泌（故**口服葡萄糖比静脉注射等量葡萄糖引起的胰岛素分泌量多得多！**）。

    - **升糖激素**：GH、皮质醇、TH、**胰高血糖素**（直接旁分泌刺激B细胞，并通过升血糖间接刺激）均促进胰岛素分泌。

    - **抑制性激素**：胰岛 D 细胞分泌的**生长抑素（SS）**、肾上腺素（作用于 $\alpha_2$ 受体）。

4.  **神经调节**：

    - **迷走神经兴奋**（释放 ACh 作用于 $\text{M}_3$ 受体，或通过胃肠激素） $\rightarrow$ **促进**胰岛素分泌。

    - **交感神经兴奋**（释放 NE 作用于 $\alpha_2$ 受体） $\rightarrow$ **抑制**胰岛素分泌（注：虽激动 $\beta_2$ 受体促分泌，但生理状态下以 $\alpha_2$ 抑制效应占绝对优势）。

### 2. 胰高血糖素（Glucagon）—— 强效促进分解代谢的升糖激素

- **生理作用（主要靶器官是肝脏，对骨骼肌无糖原分解作用）**：

  1.  **迅速升高血糖**：激活肝细胞膜受体-cAMP-PKA系统，强力**促进肝糖原分解**，并**促进肝内糖异生**（加速氨基酸转化为葡萄糖）。

  2.  **促进脂肪分解与生酮**：激活脂肪酶，促进脂肪分解，加速游离脂肪酸进入肝脏氧化生成**酮体**。

  3.  **促进蛋白质分解**：抑制肝内蛋白质合成，加速氨基酸入肝异生为糖。

  4.  大剂量可增强心肌收缩力、促进胰岛素和胰岛生长抑素分泌。

- **分泌调控**：

  - **血糖降低（饥饿状态）** $\rightarrow$ 胰高血糖素分泌 $\uparrow$（对维持饥饿时血糖稳态、保障大脑能量供应至关重要）；高血糖则抑制其分泌。

  - **★血中氨基酸增多** $\rightarrow$ **促进胰高血糖素分泌！**

    - *生理意义（必考思考题）*：**为什么进食纯蛋白餐（氨基酸增多）既刺激胰岛素分泌，又同时刺激胰高血糖素分泌？**

    - *解答*：进食纯蛋白质不含糖，氨基酸入血后刺激胰岛素分泌以促进氨基酸摄取合成蛋白质；但胰岛素同时会降低血糖，若无胰高血糖素同步升高来促进肝糖原分解和糖异生以维持血糖，纯蛋白餐后就会发生**低血糖**！因此两者同升是为了在利用氨基酸合成蛋白质的同时**防止低血糖的发生**。

  - **神经与旁分泌**：交感神经兴奋（$\beta$ 受体）促进其分泌，迷走神经抑制其分泌；**胰岛素（通过旁分泌）和生长抑素（SS）抑制 A 细胞分泌胰高血糖素**。

### 2. 糖皮质激素（Glucocorticoid, GC，以皮质醇为主）

#### （1）生理作用与药理作用（★高频大题，结合库欣综合征记忆）

1.  **调节三大营养物质代谢**：

    - **糖代谢（升血糖，抗胰岛素）**：强力**促进肝内糖异生**（诱导糖异生关键酶合成，并提供氨基酸底物），增加肝糖原贮存；同时抑制外周组织摄取和利用葡萄糖（对抗胰岛素）。分泌过多可引起类固醇性高血糖及继发性糖尿。

    - **蛋白质代谢**：促进**肝外组织（特别是骨骼肌、皮肤、骨基质、淋巴组织）蛋白质分解**，抑制其合成，产生的氨基酸入血运至肝脏，促进**肝内蛋白质和血浆蛋白合成**。

      - *过多表现（库欣综合征 Cushing's syndrome）*：肌肉萎缩消瘦（四肢纤细）、**骨质疏松**、皮肤菲薄、皮下胶原纤维断裂形成**紫纹**、血管壁变薄易致**皮肤瘀斑**、伤口愈合不良、淋巴组织萎缩。

    - **脂肪代谢（脂肪重新分布）**：促进四肢皮下脂肪分解动员（增强儿茶酚胺、GH等的脂解作用），使血中脂肪酸升高氧化供能；但同时（部分由于高血糖刺激胰岛素分泌）促进**面部、颈背部、躯干和腹部脂肪合成与沉积**。

      - *过多表现*：**“向心性肥胖”**——**满月脸、水牛背、悬垂腹**，而四肢消瘦。

2.  **影响水盐代谢**：

    - **弱的盐皮质激素样作用（轻微保钠排钾）**：因结构与醛固酮相似，高浓度时可结合盐皮质激素受体（导致水钠潴留、高血压、低血钾）。

    - **★排水作用（维持正常尿量）**：GC 能**舒张肾入球小动脉**（降低血管阻力），增加肾血浆流量和肾小球滤过率（GFR），并且**抑制抗利尿激素（ADH）的分泌与作用**，从而促进水排泄。

      - *临床考点*：**肾上腺皮质功能不全（如 Addison 病）患者**，由于严重缺乏糖皮质激素，GFR 下降且 ADH 分泌增多，若在短时间内摄入大量水分，极易发生“水中毒”（Water intoxication），必须补充 GC 才能治愈（补醛固酮无效！）。

3.  **★对血液系统的影响（“三多两少”）**：

    - **增加（**$\uparrow$**）**：**红细胞（RBC）**、**血小板（PLT）**、**中性粒细胞**（促进骨髓造血及释放入血，并阻碍中性粒细胞附壁与游出血管；同时多血质导致“多血质面容”）。

    - **减少（**$\downarrow$**）**：**淋巴细胞**（抑制胸腺和淋巴组织有丝分裂，促进淋巴细胞凋亡）、**嗜酸性粒细胞**（促进其在脾和肺中破坏滞留）。

4.  **对循环系统的影响（维持正常血压所必需）**：

    - **★对儿茶酚胺的允许作用**：上调心肌和血管平滑肌细胞膜上肾上腺素能受体的表达和亲和力，增强血管对儿茶酚胺（NE/E）的缩血管敏感性，维持正常血管张力和血压。

    - 抑制前列腺素合成，**降低毛细血管壁通透性**，减少血浆渗出，有利于维持有效循环血容量。

    - 对离体心脏有加强收缩力的作用。

5.  **其他各系统作用**：

    - **呼吸系统**：**促进胎儿肺表面活性物质（二棕榈酰卵磷脂 DPPC）的合成**（由肺泡Ⅱ型细胞分泌），加速胎儿肺成熟（临床上对有早产风险的孕妇注射地塞米松以预防新生儿呼吸窘迫综合征 NRDS）。

    - **消化系统**：增进食欲，促进胃酸和胃蛋白酶原分泌，抑制胃黏液合成，减弱胃黏膜屏障（长期大剂量应用易诱发或加重**消化性溃疡**）。

    - **骨骼系统**：抑制成骨细胞活力，抑制肠钙吸收，促进PTH溶骨（长期使用致骨质疏松）。

6.  **参与应激反应（Stress Reaction）**：机体遭受各种伤害性刺激（创伤、失血、感染、寒冷、饥饿、中毒、剧烈情绪波动等）时，血中 ACTH 和 GC 急剧升高，以**提高机体对伤害性刺激的耐受（抵抗）能力**。

7.  **抑制炎症反应和免疫反应（药理剂量）**：

    - **抗炎**：稳定溶酶体膜，降低毛细血管通透性，抑制水肿、渗出和炎细胞浸润，抑制花生四烯酸代谢（减少前列腺素和白三烯生成）。

    - **免疫抑制**：抑制 T 淋巴细胞分化增殖，减少白介素等细胞因子合成，抑制巨噬细胞吞噬与抗原呈递。

#### （2）糖皮质激素的分泌调控

1.  **HPA轴调节**：下丘脑 **CRH** $\xrightarrow{+}$ 腺垂体 **ACTH** $\xrightarrow{+}$ 肾上腺皮质束状带分泌 **GC**。

    - **ACTH 的作用**：不仅刺激 GC 分泌，还**刺激肾上腺皮质束状带和网状带细胞的生长发育**（对球状带仅起允许作用）。

2.  **基础昼夜节律**：受视交叉上核控制呈脉冲式及日节律波动——入睡后分泌减少，**午夜（0:00）最低**，凌晨开始上升，**起床前（早晨 7:00~8:00）达到分泌高峰**，白天维持较低水平。

3.  **应激分泌**：痛觉通路（创伤）、孤束核（内脏传入）、边缘系统（情绪）将伤害性信息传至下丘脑，强力激活 CRH-ACTH-GC 系统。

4.  **负反馈调节与临床停药原则**：

    - 包含长反馈（GC 抑制垂体 ACTH 为主，也抑制下丘脑 CRH）、短反馈（ACTH 抑制 CRH）、超短反馈。

    - **★注意**：在**急性应激状态**下，GC 对下丘脑和腺垂体的**负反馈抑制作用暂时减弱甚至消失**，从而保证血中 ACTH 和 GC 维持极高水平以应对危机。

    - **★临床指导意义**：临床长期大剂量使用外源性糖皮质激素类药物时，会通过长反馈强烈抑制患者自身的 CRH 和 **ACTH** 分泌，导致患者自身的**肾上腺皮质束状带发生废用性萎缩**。此时若**突然停药**，外源激素消失而萎缩的肾上腺皮质来不及恢复分泌，将引发急性肾上腺皮质功能不全危象甚至死亡！因此停药时必须**缓慢逐级减量**，必要时补充 ACTH。

### 3. 醛固酮（Aldosterone）与肾上腺髓质激素

1.  **醛固酮（盐皮质激素代表）**：

    - **生理作用**：作用于肾远曲小管和集合管上皮细胞，诱导醛固酮诱导蛋白（AIP）合成，强力**保** $\text{Na}^+$**、保水、排** $\text{K}^+$**、排** $\text{H}^+$，维持细胞外液容量和血压。（分泌过多即原发性醛固酮增多症：导致水钠潴留、高血压、低血钾、代谢性碱中毒）。

    - **分泌调节**：**几乎不受 ACTH 直接控制**（ACTH 仅起允许作用），主要受两大因素调节：

      1.  **肾素-血管紧张素-醛固酮系统（RAAS）**：循环血量减少、肾灌注压下降、致密斑感受 $\text{NaCl}$ 负荷降低或交感神经兴奋 $\rightarrow$ 肾球旁细胞分泌**肾素（Renin）** $\rightarrow$ 血管紧张素原转化为血管紧张素Ⅰ $\xrightarrow{\text{ACE}}$ **血管紧张素Ⅱ/Ⅲ** $\rightarrow$ 强力刺激肾上腺皮质球状带分泌醛固酮。

      2.  **血** $\text{K}^+$ **和血** $\text{Na}^+$ **浓度**：**血** $\text{K}^+$ **升高**（最敏感的直接刺激）或**血** $\text{Na}^+$ **降低**直接刺激球状带分泌醛固酮。

2.  **肾上腺髓质激素（肾上腺素 E 与 去甲肾上腺素 NE）**：

    - **生理作用**：提高中枢神经系统兴奋性（警觉反应）；作用于心血管和呼吸系统（心率 $\uparrow$、心肌收缩力 $\uparrow$、心输出量 $\uparrow$、血压 $\uparrow$、支气管平滑肌舒张促通气、骨骼肌和冠脉血管舒张而皮肤内脏血管收缩实现**血液重新分配**）；促进肝糖原和肌糖原分解及脂肪分解，迅速升高血糖和血中游离脂肪酸，增加能量供应。

    - **分泌调节**：

      1.  **神经调节（主导）**：交感神经节前纤维兴奋，末梢释放 **ACh** 作用于嗜铬细胞膜上的 $\text{N}_1$ **型胆碱能受体**，促进 E 和 NE 释放。

      2.  **体液调节（皮质对髓质的调节）**：肾上腺皮质束状带的血液经血窦直接流入髓质，高浓度的糖皮质激素（GC）能激活髓质内苯乙醇胺氮甲基转移酶（PNMT）等酶的活性，促进去甲肾上腺素（NE）甲基化转变为肾上腺素（E）。

      3.  **自身负反馈调节**：细胞内合成的儿茶酚胺过多时，可负反馈抑制酪氨酸羟化酶（限速酶）的活性。

## 七、 ★压轴必考题：应激反应与应急反应的比较

在面对各种有害刺激（如创伤、失血、缺氧、感染、剧痛、寒冷、恐惧等）时，机体同时启动**应激反应**和**应急反应**，两者相辅相成，共同维持生命：

|  |  |  |
|----|----|----|
| 比较维度 | 应激反应（Stress Reaction） | 应急反应（Emergency Reaction） |
| **提出学者** | Selye（塞里） | Cannon（坎农，“战或逃”反应 Fight or Flight） |
| **核心反应系统** | **下丘脑 - 腺垂体 - 肾上腺皮质轴（HPA轴）** | **交感 - 肾上腺髓质系统（SAM系统）** |
| **主要调节方式** | 神经-体液调节（CRH $\rightarrow$ ACTH $\rightarrow$ 皮质） | 神经调节为主（交感节前纤维释放 ACh $\rightarrow$ 髓质） |
| **核心效应激素** | **促肾上腺皮质激素（ACTH）** 与 **糖皮质激素（GC，皮质醇）**（另有 GH、PRL、ADH、醛固酮、胰高血糖素参与） | **儿茶酚胺：肾上腺素（E）与去甲肾上腺素（NE）** |
| **启动速度与持续时间** | 启动相对较慢，但效应持久 | 启动极其迅速（数秒内），持续时间较短 |
| **主要生理表现** | ① 促进糖异生与蛋白质、脂肪分解，保证持久供能； ② 对儿茶酚胺发挥**允许作用**，维持血管张力和血压； ③ 降低毛细血管通透性维持血容量； ④ 抗炎、抗过敏、抗休克、稳定溶酶体膜。 | ① 中枢兴奋，警觉性提高； ② 心率加快、心输出量增加、血压升高； ③ 血液重新分配（保证心、脑、骨骼肌供血）； ④ 支气管舒张，肺通气增加； ⑤ 肝糖原与脂肪迅速分解，血糖升高，快速供能。 |
| **核心生理意义** | **提高机体对伤害性刺激的“耐受能力”（抵抗力）** | **提高机体对伤害性刺激的“应变能力”（克服困难或逃避环境）** |
| **两者相互关系** | 两者在实际伤害刺激下往往**同时发生、紧密配合**： ① 交感-肾上腺髓质兴奋可刺激下丘脑 CRH-ACTH 释放； ② 糖皮质激素（GC）对儿茶酚胺的心血管效应起**允许作用**，且能激活 PNMT 酶促进髓质合成肾上腺素。若切除肾上腺皮质，动物在应激下极易发生循环衰竭死亡；若切除肾上腺髓质，动物仍可存活但应变能力下降。 |  |

## 八、 跨章节横向综合对比速记表（考前冲刺必背）

### 1. 升血糖激素 vs 降血糖激素汇总

- **唯一降血糖激素**：**胰岛素**（促摄取利用、促糖原合成、促转变为脂肪、抑糖原分解、抑糖异生）。

- **五大升血糖激素（具有强大的协同升糖效应）**：

  1.  **胰高血糖素**：强力促肝糖原分解 + 促糖异生（飢饿时主力）。

  2.  **肾上腺素（E）**：强力促肝糖原和肌糖原分解（应急时主力）。

  3.  **糖皮质激素（GC）**：强力促糖异生 + 拮抗胰岛素（抑制外周组织用糖） + 对胰高血糖素和肾上腺素的升糖及脂解作用起**允许作用**。

  4.  **生长激素（GH）**：抑制外周组织摄取利用糖，降低胰岛素敏感性（引发垂体性糖尿病）。

  5.  **甲状腺激素（TH）**：促进小肠吸收糖、促糖原分解及糖异生、增强儿茶酚胺作用（双向调节，甲亢时升糖占优）。

### 2. 三大幼年发育障碍疾病鉴别（★选择题必考！）

|  |  |  |  |  |
|----|----|----|----|----|
| 疾病名称 | 病因（缺乏的激素） | 身材表现 | 智力水平 | 特殊体征与治疗 |
| **侏儒症（Dwarfism）** | 幼年缺乏 **生长激素（GH）**（或 IGF-1 受体缺陷 Laron 侏儒） | 矮小（身体比例匀称） | **完全正常** | 生殖器官发育可能受影响，但无神经系统损害；青春期骨骺闭合前注射重组人 **hGH** 有效 |
| **呆小症 / 克汀病（Cretinism）** | 胎儿期或婴幼儿期缺乏 **甲状腺激素（TH）**（或严重缺碘） | 矮小（比例不匀称，上身长下身短） | **严重低下（白痴）** | 骨化中心发育延迟、牙齿发育不全、表情呆滞、聋哑；**必须在出生后3个月内尽早补充甲状腺素（**$\text{T}_4$**）**，否则智力损伤不可逆 |
