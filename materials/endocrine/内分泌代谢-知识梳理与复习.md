## 一、全章主线与学习地图

 **激素代谢的核心，是解释一条化学信号如何产生、到达靶细胞、发挥作用并最终终止。** 

```text
原料与前体
   ↓ 合成酶 / 翻译后加工
内分泌细胞内的激素
   ↓ 储存与刺激分泌
血液运输：游离型 ⇌ 蛋白结合型
   ↓ 与相应受体结合
靶细胞：信号转导 / 基因表达改变
   ↓
代谢、生长、水盐平衡与钙磷稳态
   ↓ 灭活、排泄与反馈
信号终止，并调节下一轮分泌
```

学习每类激素时，固定回答七个问题： **谁分泌？属于哪类？用什么原料？关键酶是什么？怎样运输？主要效应是什么？如何反馈与灭活？**

## 二、激素分类：化学性质决定代谢方式

### 1. 按来源分类

课件第 3–6 页列出下丘脑、垂体、甲状腺、甲状旁腺、肾上腺、胰岛和性腺，也提示肝、肾等器官参与内分泌功能。

-  **下丘脑** ：释放激素、释放抑制因子，以及 ADH 和催产素的合成。
-  **腺垂体** ：GH、PRL、TSH、ACTH、FSH、LH 等。
-  **甲状腺** ：滤泡上皮合成 T₃、T₄；滤泡旁 C 细胞分泌降钙素。
-  **甲状旁腺** ：主细胞分泌 PTH。
-  **肾上腺** ：皮质分泌类固醇激素，髓质分泌儿茶酚胺。
-  **胰岛** ：胰岛素、胰高血糖素、生长抑素和胰多肽。
-  **肝、肾** ：肝参与 IGF-1 生成和维生素 D 的 25-羟化；肾完成活性维生素 D 生成的关键 1α-羟化。

### 2. 按化学本质分类

| 类别 | 代表激素 | 生化记忆重点 |
| --- | --- | --- |
| 肽类、蛋白质与糖蛋白 | 下丘脑调节肽、垂体激素、胰岛素、PTH、降钙素 | 基因编码；常需前体切割；通过胞吐释放 |
| 氨基酸衍生物 | 甲状腺激素、儿茶酚胺、松果体激素 | 同属氨基酸衍生物，但物理性质与作用机制不同 |
| 类固醇及相关衍生物 | 皮质醇、醛固酮、性激素、活性维生素 D | 胆固醇相关来源；维生素 D 属开环类固醇衍生物 |
| 脂肪酸衍生物 | 前列腺素等 | 常参与局部信号调节 |

 **辨析：甲状腺激素与儿茶酚胺虽然都来自酪氨酸，但不能据此把两者的储存、运输及受体机制混为一谈。** 

## 三、下丘脑—垂体：先区分合成部位和释放部位

### 1. 两条联系通路

| 通路 | 过程 | 代表 |
| --- | --- | --- |
| 下丘脑—腺垂体 | 下丘脑调节因子经垂体门脉系统调节腺垂体细胞 | CRH → ACTH；TRH → TSH；GnRH → FSH/LH |
| 下丘脑—神经垂体 | 下丘脑神经元合成，沿轴突运输至神经垂体储存和释放 | ADH、催产素 |

 **神经垂体释放 ADH 和催产素，但主要合成部位在下丘脑。**  课件第 11 页用“视上核—ADH、室旁核—催产素”突出主要分工；不要理解为两核只有一种激素表达。

### 2. ADH 与催产素

 **抗利尿激素（ADH/AVP）** ：又称精氨酸血管升压素，是由下丘脑合成、经神经垂体释放的九肽，主要作用是促进水的保留。

 **催产素（OT）** ：是由下丘脑合成、经神经垂体释放的九肽，促进分娩时子宫收缩及乳汁射出。

两者共同结构特点： **9 个氨基酸、Cys¹—Cys⁶ 二硫键成环、C 端酰胺化** ；主要区别在第 3、8 位。

| 激素 | 氨基酸顺序 | 第 3 位 | 第 8 位 |
| --- | --- | --- | --- |
| ADH/AVP | Cys–Tyr–Phe–Gln–Asn–Cys–Pro–Arg–Gly–NH₂ | Phe | Arg |
| 催产素 | Cys–Tyr–Ile–Gln–Asn–Cys–Pro–Leu–Gly–NH₂ | Ile | Leu |

课件第 12 页中文名称写成“天冬氨酸”，而同页英文为  **Asn** 。此处应为 **天冬酰胺** ；两条序列以英文缩写为准。可核对 [GPCRdb：人血管升压素序列](https://ww.gpcrdb.org/ligand/8624/info/)与[催产素/血管升压素家族序列表](https://www.tandfonline.com/doi/pdf/10.4161/worm.24246)。

### 3. 下丘脑调节因子和腺垂体激素

| 下丘脑调节因子 | 主要作用对象 | 下游结果 |
| --- | --- | --- |
| CRH | ACTH | 促进肾上腺皮质激素分泌 |
| TRH | TSH | 促进甲状腺激素生成和释放 |
| GnRH（旧称 LRH） | FSH、LH | 调节性腺功能 |
| GHRH | GH | 促进 GH 分泌 |
| 生长抑素（SST/GHRIH） | GH 等 | 抑制相关激素分泌 |
| 多巴胺（主要 PRL 抑制因子） | PRL | 对 PRL 形成持续性抑制 |

 **补充辨析** ：课件第 5、13、17 页采用 PRH/PRIH、MRH/MRIH 的传统分类框架。复习人体 PRL 调节时，应重点掌握 **多巴胺的持续抑制作用** ，不宜把“9 种调节激素”理解为 9 种地位完全相同、均已明确的独立人体激素。[Endotext：PRL 分泌调节](https://www.ncbi.nlm.nih.gov/books/NBK278984/)

| 腺垂体激素 | 化学本质 | 主要功能 |
| --- | --- | --- |
| ACTH | 多肽 | 促进肾上腺皮质生长与分泌 |
| TSH | 糖蛋白 | 促进甲状腺生长与分泌 |
| FSH | 糖蛋白 | 女性促进卵泡发育，男性支持精子生成 |
| LH | 糖蛋白 | 女性促进排卵及黄体形成，男性促进睾酮分泌 |
| GH | 蛋白质 | 促进生长并调节代谢 |
| PRL | 蛋白质 | 促进和维持乳汁生成 |
| MSH | 多肽 | 促进黑色素合成；注意 POMC 的组织特异性加工 |

### 4. GH、PRL 与 POMC

 **补充：GH 的生长作用**  既有直接作用，也通过诱导 IGF-1 产生而实现；GHRH 促进、SST 抑制 GH 分泌，IGF-1 对下丘脑和垂体形成负反馈。GH 呈脉冲分泌，受睡眠、营养、运动等影响。[Endotext：GH 正常生理](https://www.ncbi.nlm.nih.gov/books/NBK279056/)

 **PRL 与 OT 的区别** ：PRL 负责“产乳”，OT 负责“射乳”。课件第 14 页“OT 引起泌乳”应按乳汁射出理解。

 **阿片促黑皮质素原（POMC）** ：是可经组织特异性蛋白水解产生 ACTH、MSH、LPH、内啡肽等活性肽的共同前体。重点是“一种前体可产生多种信号肽”，不是所有组织都生成同样的产物组合。（课件第 15–16 页）

### 5. 三条经典内分泌轴

```text
下丘脑 CRH → 腺垂体 ACTH → 肾上腺皮质 → 皮质醇
下丘脑 TRH → 腺垂体 TSH  → 甲状腺     → T₄ / T₃
下丘脑 GnRH → 腺垂体 LH / FSH → 性腺 → 性激素等

外周激素反馈到垂体和下丘脑，调节上游分泌。
```

## 四、甲状腺激素：在 Tg 上合成，也在 Tg 上储存

### 1. 结构和原料

 **甲状腺激素（TH）** ：主要为 T₄ 和 T₃，是由甲状腺球蛋白上的酪氨酸残基与碘形成的含碘氨基酸衍生物。

| 名称 | 缩写 | 结构与意义 |
| --- | --- | --- |
| 一碘酪氨酸 | MIT | 酪氨酸上有 1 个碘，是合成中间体 |
| 二碘酪氨酸 | DIT | 酪氨酸上有 2 个碘，是合成中间体 |
| 甲状腺素/四碘甲腺原氨酸 | T₄ | 3,5,3′,5′ 位碘化，甲状腺分泌的主要形式 |
| 三碘甲腺原氨酸 | T₃ | 3,5,3′ 位碘化，是主要高活性形式 |
| 反三碘甲腺原氨酸 | rT₃ | 3,3′,5′ 位碘化，缺乏显著的经典甲状腺激素活性 |

 **T₃ 与 rT₃ 的碘数相同，位置不同，生物活性不同。**  MIT、DIT 也不能与成熟 T₃、T₄ 混淆。（课件第 20–23 页）

### 2. 合成四步：聚碘—氧化—碘化—偶联

| 步骤 | 部位与过程 | 关键要点 |
| --- | --- | --- |
| 聚碘 | 血液 I⁻ 经滤泡上皮基底外侧膜进入细胞，再转向滤泡腔 | NIS 利用 Na⁺ 梯度；Na⁺/K⁺-ATP 酶间接供能 |
| 氧化 | 顶端膜与滤泡腔交界处，I⁻ 被活化 | TPO 与 H₂O₂ 参与 |
| 碘化/有机化 | Tg 的 Tyr 残基被碘化 | 生成 MIT、DIT；TPO 催化 |
| 偶联 | Tg 上碘化酪氨酸残基发生氧化偶联 | DIT＋DIT → T₄；MIT＋DIT → T₃ |

课件第 28 页以“I₂”示意活性碘，记忆重点是  **TPO 催化的氧化与有机化过程** 。聚碘是由 Na⁺ 梯度驱动的继发性主动转运，不能简单说成 NIS 本身直接水解 ATP。[Endotext：甲状腺激素合成与分泌](https://www.ncbi.nlm.nih.gov/sites/books/NBK285550/)

 **甲状腺球蛋白（Tg）** ：是提供 Tyr 残基、承载甲状腺激素合成并在滤泡腔储存激素的大分子蛋白。

 **甲状腺过氧化物酶（TPO）** ：催化碘的氧化、Tg 上 Tyr 残基的碘化及碘化残基的偶联；不是聚碘载体，也不负责 Tg 的溶酶体水解。

### 3. 储存、释放与碘回收

课件第 33–35 页的主线：

```text
滤泡腔中：含 T₃/T₄ 的 Tg 胶质
       ↓ TSH 刺激，胞饮/内吞
滤泡细胞内：与溶酶体结合
       ↓ 蛋白酶水解
游离 T₃/T₄ → 进入血液（以 T₄ 为主）

未偶联 MIT/DIT → 脱碘 → I⁻ 与 Tyr 回收利用
```

- 甲状腺激素是 **以 Tg 结合形式在细胞外滤泡腔大量储存**  的特殊例子。
- 课件给出的储存量可供利用约  **50–120 天** ，属于教学估计范围。
- 不要把“释放 T₃/T₄ 的蛋白水解”与“MIT/DIT 脱碘回收”写成同一步反应。

### 4. 血液运输与外周代谢

 **甲状腺素结合球蛋白（TBG）** ：是甲状腺激素在血浆中的主要结合蛋白；另有转甲状腺素蛋白（旧称 TBPA）和白蛋白参与运输。

多数 T₃、T₄ 与蛋白结合，少数以游离形式存在；结合与游离之间可相互转换。（课件第 36 页）

| 比较项 | T₄ | T₃ |
| --- | --- | --- |
| 甲状腺直接分泌 | 主要形式 | 少量 |
| 外周来源 | 可转化为 T₃ 或 rT₃ | 相当部分来自外周 T₄ 转化 |
| 作用特点 | 主要前激素与循环储备 | 主要高活性形式 |
| 课件半衰期 | 约 6.7 天 | 约 1.5 天 |

课件第 37 页强调脱碘是主要代谢方式，另有脱氨、脱羧和葡萄糖醛酸结合等途径。 **T₄ → T₃ 属活化转化，T₄ → rT₃ 属失活方向，不能把所有脱碘都等同于失活。** [Endotext：甲状腺激素代谢](https://ncbi.nlm.nih.gov/books/NBK285545/)

### 5. 调节与碘的双重作用

-  **TSH** ：促进甲状腺激素合成及释放；TH 对 TRH、TSH 形成负反馈。
-  **适量碘** ：是合成原料；缺碘可引起激素合成不足及代偿性甲状腺肿。
-  **短期大量碘** ：可急性抑制有机化、合成及释放；课件以此联系甲状腺术前准备。该效应不是“大量碘永久抑制甲状腺”。[Endotext：碘与合成调节](https://www.ncbi.nlm.nih.gov/sites/books/NBK285550/)
- 课件第 25 页“甲亢吸碘率↑、甲减↓”是简化趋势；吸碘率还受碘负荷和病因影响，不能凭此概括所有甲状腺毒症。

 **数值辨析** ：课件第 27 页写“成人碘需要量 50 μg/天”，不宜作为现行通用推荐量。NIH/FNB 的成人 RDA 为  **150 μg/天** ；不同国家和人群的推荐值可能不同。[NIH：碘营养参考](https://ods.od.nih.gov/factsheets/Iodine-HealthProfessional/)

## 五、肾上腺皮质：同一起点，靠酶分出三条路线

### 1. 三带、三类激素

| 由外到内 | 主要激素 | 代谢作用方向 |
| --- | --- | --- |
| 球状带 | 醛固酮等盐皮质激素 | 水盐平衡 |
| 束状带 | 皮质醇等糖皮质激素 | 糖、脂、蛋白质代谢及应激 |
| 网状带 | DHEA 等肾上腺雄激素 | 雄激素及其前体作用 |

 **记忆：球—束—网，盐—糖—性。** （课件第 40–41 页）

### 2. 化学结构

课件第 42–44 页的重点是糖皮质激素和盐皮质激素的  **21 碳骨架** 。DHEA 属  **19 碳**  雄激素，不能把“肾上腺皮质激素”一概写成 21 碳。

- 常见皮质类固醇结构：C₃ 酮基、C₂₀ 酮基、C₄=C₅ 双键及 C₂₁ 羟基等。
- 皮质醇含 17α-OH、11β-OH。
-  **可的松/皮质素** ：相应 C₁₁ 位为酮基，与皮质醇的活性及相互转化有关。
- 醛固酮的 C₁₈ 醛基是重要识别点；不含 17α-OH。
-  **辨析** ：课件第 44 页列出的“皮质酮”不能仅因缺少 17α-OH 就归作主要盐皮质激素；它也是糖皮质激素的一员，在人体的主要性低于皮质醇。[Endotext：肾上腺皮质分区与激素](https://www.ncbi.nlm.nih.gov/sites/books/NBK278945/)

### 3. 合成起点与三条支路

 **共同原料是胆固醇；首个共同产物是孕烯醇酮。**  课件第 45–48 页用羟化及侧链裂解解释分流。

```text
胆固醇（27C）
   ↓ StAR 介导供料；CYP11A1/P450scc 催化侧链裂解
孕烯醇酮（21C）
   ├─ 经孕酮、DOC、皮质酮等 → 醛固酮（球状带）
   ├─ 经 17α-羟化中间体、11-脱氧皮质醇 → 皮质醇（束状带）
   └─ 经 17α-羟孕烯醇酮、17,20-裂解 → DHEA（网状带）
```

 **补充与酶名校订** ：现代命名中，胆固醇转成孕烯醇酮的首步酶为  **CYP11A1（胆固醇侧链裂解酶）** ；StAR 介导的胆固醇线粒体转运对急性合成调节很重要。课件写“20α-羟化酶为整个反应关键限速酶”，不能原样等同于现代酶学表述。[Endotext：类固醇生成通路](https://www.ncbi.nlm.nih.gov/sites/books/NBK278953/)

| 酶/调节蛋白 | 主要任务 | 应掌握的区分 |
| --- | --- | --- |
| StAR | 促进胆固醇进入线粒体内膜供料 | 是调节蛋白，不是羟化酶 |
| CYP11A1/P450scc | 胆固醇侧链裂解，生成孕烯醇酮 | 共同起始酶 |
| 3β-HSD | 孕烯醇酮等转为相应 Δ⁴-3-酮类中间体 | 包含脱氢及异构化 |
| CYP17A1 | 17α-羟化和 17,20-裂解 | 支持糖皮质激素及雄激素路径 |
| CYP21A2 | 21-羟化 | 参与皮质醇和醛固酮前体形成 |
| CYP11B1 | 11β-羟化等 | 皮质醇合成末端的重要酶 |
| CYP11B2 | 醛固酮合酶，含连续氧化活性 | 球状带醛固酮生成的关键特征 |

课件第 48 页“17α-羟化酶只存在于束状带”需修正为： **CYP17A1 见于束状带和网状带，球状带缺乏该酶。**  这也解释了网状带能够产生 DHEA。[Endotext：肾上腺雄激素](https://ncbi.nlm.nih.gov/sites/books/NBK278929/)

### 4. 皮质醇：运输、节律和降解

 **皮质醇（cortisol）** ：是人体主要糖皮质激素，储存量少，分泌呈昼夜节律，多数在血浆中与蛋白结合。

- 课件第 49 页：约 75%–80% 与 CBG 结合，约 15% 与白蛋白结合，约 5%–10% 游离，作为教学近似比例记忆。
- 正常作息下通常清晨较高、夜间较低；解读时应结合采血时间和睡眠节律。
- 第 50–52 页：主要在肝脏代谢，形成还原产物及结合物，再经尿排泄。
-  **17-羟皮质类固醇（17-OH-CS）** ：反映保留相应 C₁₇ 侧链结构的一组代谢物。
-  **17-酮类固醇（17-KS）** ：C₁₇ 有酮基的一组类固醇，重要来源为雄激素代谢；不宜作为皮质醇的特异性指标。

### 5. 补充：皮质醇、醛固酮及应激

 **皮质醇作用概括** ：促进肝糖异生、增加可用能量，促进外周蛋白分解并改变脂代谢；对血管反应有允许作用，也参与炎症和免疫调节。其分泌受 CRH—ACTH—皮质醇轴及负反馈调节。[皮质醇生理与代谢](https://www.ncbi.nlm.nih.gov/books/NBK538239/?report=printable)

 **醛固酮（aldosterone）** ：是球状带分泌的主要盐皮质激素，作用于远端肾单位，促进 Na⁺ 重吸收和 K⁺ 排泄，并促进 H⁺ 分泌；其主要调节因素是 **血管紧张素Ⅱ和血 K⁺** ，ACTH 不是日常调节的主导因素。[Endotext：醛固酮分泌调节](https://www.ncbi.nlm.nih.gov/books/NBK279079/)

| 比较项 | 应激反应中的 HPA 轴 | 应急反应中的交感—肾上腺髓质系统 |
| --- | --- | --- |
| 主要信号 | CRH → ACTH → 皮质醇 | 交感神经活动、儿茶酚胺 |
| 主要任务 | 动员和维持应对负荷的代谢能力 | 快速改变心血管及能量供应 |
| 复习提示 | 常突出持续的内分泌适应 | 常突出快速反应 |

两套系统可在同一事件中协同激活；“应激/应急”是教学侧重点的区分，不是完全互斥的两种状态。

## 六、肾上腺髓质：酪氨酸到儿茶酚胺

### 1. 来源和结构

 **儿茶酚胺** ：含邻苯二酚结构和胺侧链的一类物质，主要包括多巴胺（DA）、去甲肾上腺素（NE/NA）和肾上腺素（E/A）。（课件第 54–55 页）

- 肾上腺素：主要由肾上腺髓质嗜铬细胞生成并作为激素释放。
- 去甲肾上腺素：可由髓质释放，也可作为多数交感节后神经纤维的递质。
- 多巴胺：是儿茶酚胺合成中间体，也是重要神经递质。

### 2. 合成四步

```text
酪氨酸 Tyr
  ↓ 酪氨酸羟化酶 TH（关键限速酶）
多巴 DOPA
  ↓ 芳香族 L-氨基酸脱羧酶
多巴胺 DA
  ↓ 多巴胺 β-羟化酶
去甲肾上腺素 NE
  ↓ 苯乙醇胺 N-甲基转移酶 PNMT；SAM 提供甲基
肾上腺素 E
```

 **酪氨酸羟化酶** ：催化 Tyr → DOPA，是儿茶酚胺生物合成的关键限速酶。注意它与甲状腺激素合成中的  **TPO**  不是同一种酶。（课件第 55–56 页）

### 3. 灭活：MAO 与 COMT；HVA 与 VMA

| 项目 | 名称或结果 |
| --- | --- |
| MAO | 单胺氧化酶，参与氧化脱氨 |
| COMT | 儿茶酚-O-甲基转移酶，参与甲基化 |
| DA 的重要终末代谢产物 | 高香草酸 HVA |
| NE/E 的重要终末代谢产物 | 香草扁桃酸 VMA |

 **HVA（高香草酸）与 VMA（香草扁桃酸）是两种不同物质** 。课件第 57 页“高香草酸（香草扁桃酸）”不应当作同义词背诵。[儿茶酚胺代谢通路及代谢物图](https://www.ncbi.nlm.nih.gov/books/NBK543227/pdf/Bookshelf_NBK543227.pdf)

课件第 58 页以嗜铬细胞瘤联系髓质激素；掌握“分泌来源—代谢产物—生化检测”的联系即可，单一代谢物不能脱离背景直接确诊。

## 七、胰岛激素：前体加工与血糖方向

### 1. 胰岛细胞与产物

| 细胞 | 主要激素 | 作用方向 |
| --- | --- | --- |
| α/A 细胞 | 胰高血糖素 | 动员肝葡萄糖输出，维持空腹血糖 |
| β/B 细胞 | 胰岛素 | 促进营养储存和利用，降低血糖 |
| δ/D 细胞 | 生长抑素 | 对胰岛分泌起抑制性旁分泌调节 |
| PP 细胞 | 胰多肽 | 参与胰腺及消化功能调节 |

细胞名称与激素对应见课件第 61 页；功能方向为补充串联。

### 2. 胰岛素的结构与合成

 **胰岛素（insulin）** ：由胰岛 β 细胞生成的肽类激素，成熟分子共  **51 个氨基酸** ，由 A 链 21 aa、B 链 30 aa 组成，有  **3 对二硫键** ：2 对链间，1 对 A 链内。

```text
人前胰岛素原 preproinsulin（110 aa）
       ↓ 切去 24 aa 信号肽
胰岛素原 proinsulin（86 aa）
       ↓ 折叠、二硫键形成，分泌颗粒内蛋白水解加工
成熟胰岛素（A 链＋B 链，共 51 aa）＋C 肽（31 aa）
       ＋切割过程中移除的连接位点碱性残基
```

 **C 肽** ：是胰岛素原加工时释放的连接肽，与成熟胰岛素按等摩尔生成和分泌，可作为理解内源性胰岛分泌的线索；两者在外周血中浓度不必相等，因为清除不同。

 **勘误** ：课件第 62–63 页前胰岛素原写 109 aa；标准人前体为  **110 aa** 。不能用 86−51=35 就把 C 肽背成 35 aa，因为还需计入被去除的碱性连接残基。[UniProt：人胰岛素前体](https://www.uniprot.org/uniprotkb/P01308-1)、[Endotext：胰岛素生物合成与结构](https://www.ncbi.nlm.nih.gov/books/NBK279029/)

### 3. 补充：胰岛素分泌与作用机制

葡萄糖代谢增加 → β 细胞 ATP/ADP 比升高 → ATP 敏感性 K⁺ 通道关闭 → 去极化 → 电压依赖性 Ca²⁺ 通道开放 → Ca²⁺ 内流 → 分泌颗粒胞吐。[Endotext：胰岛素分泌](https://www.ncbi.nlm.nih.gov/books/NBK279029/)

 **胰岛素受体** ：具有内在酪氨酸激酶活性的膜受体；受体激活后通过 IRS—PI3K—Akt 等信号通路发挥代谢作用。

| 靶组织 | 主要结果 |
| --- | --- |
| 骨骼肌和脂肪组织 | 促进 GLUT4 向细胞膜转位，增加葡萄糖摄取 |
| 肝脏 | 促进糖原储存，抑制葡萄糖输出 |
| 多种代谢组织 | 促进合成代谢，抑制过度分解代谢 |

 **辨析** ：不能把“GLUT4 转位”写成所有组织都共同采用的胰岛素作用机制。[Endotext：胰岛素受体及信号网络](https://www.ncbi.nlm.nih.gov/books/NBK378978/)

### 4. 胰高血糖素：长度和前体要分清

 **胰高血糖素（glucagon）** ：由胰岛 α 细胞分泌的  **29 aa 单链多肽** ，来自较长的前体经蛋白水解加工。

 **勘误** ：课件第 65 页写“胰高血糖素原 37 aa”。对于标准人前体，应区分：前胰高血糖素原约  **180 aa**  → 去信号肽后胰高血糖素原  **160 aa**  → 成熟胰高血糖素  **29 aa** 。37 aa 对应另一前体衍生肽  **oxyntomodulin（胃泌酸调节素）** ，不能作为人胰高血糖素原的标准长度。[APS：前胰高血糖素来源肽及加工](https://journals.physiology.org/doi/10.1152/physrev.00057.2024)

 **补充：胰高血糖素作用与调节** ：主要作用于肝，通过 G 蛋白偶联受体及 cAMP—PKA 等信号促进葡萄糖输出；低血糖、禁食和氨基酸可促进分泌，高血糖、胰岛素及生长抑素可抑制分泌。不要把其主要升糖机制写成直接促进骨骼肌糖原分解。[Endotext：胰高血糖素生理](https://www.ncbi.nlm.nih.gov/sites/books/NBK279127/)

| 比较项 | 胰岛素 | 胰高血糖素 |
| --- | --- | --- |
| 来源 | β 细胞 | α 细胞 |
| 成熟结构 | 51 aa，A/B 双链 | 29 aa，单链 |
| 主要受体 | 受体酪氨酸激酶 | G 蛋白偶联受体 |
| 对血糖的主方向 | 降低 | 升高 |
| 代谢理解 | 储存与利用营养 | 动员肝葡萄糖输出 |

### 5. 课件中的科学史

课件第 64 页介绍：1965 年 9 月 17 日，我国首次人工合成结晶牛胰岛素，由中国科学院有关研究所和北京大学协作完成。此处作为课件中的科学史线索；不应把“牛胰岛素”与上述“标准人前体长度”混用。

## 八、钙磷基础：离子钙与总钙不是同一指标

### 1. 分布、吸收与生理功能

课件第 68 页：体钙绝大多数在骨，体磷也主要储存在骨组织中。第 69–74 页突出以下关系：

-  **钙吸收** ：经肠道主动和被动途径完成，活性维生素 D 是重要调节因素。
-  **磷吸收** ：主要在小肠；肾脏排泄对磷稳态很重要。
-  **钙功能** ：骨与牙结构、凝血、神经肌肉活动，以及细胞内第二信使。
-  **磷功能** ：骨与牙结构、核酸、磷脂、高能磷酸化合物及蛋白磷酸化；无机磷酸盐也参与缓冲。

第 69、73 页的每日需要量与粪尿排泄百分比为课件教学口径，会受年龄、摄入量及生理状态影响，不作为所有人的固定常数；第 70 页的 Ca:P 比例也不应外推成个人补充剂配方。

### 2. 血钙、血磷与酸碱状态

 **离子钙（游离 Ca²⁺）** ：是血钙中直接参与多数生理活动并受到严密调节的部分。

- 血钙包括游离离子钙、蛋白结合钙及小分子阴离子复合钙。
- 课件第 76 页概括约一半为离子钙；“非游离钙”不能全部等同于不可扩散的蛋白结合钙。
- 白蛋白变化可改变总钙，未必意味着离子钙同幅度变化。
- 碱血症时蛋白结合钙倾向增加，离子钙可降低，神经肌肉兴奋性增高；酸血症趋势相反。

 **参考范围辨析** ：课件第 76 页“2.25–2.9 mmol/L（9–11 mg/dL）”换算并不完全一致。成人总钙常见参考范围约  **2.1–2.6 mmol/L（8.5–10.5 mg/dL）** ，离子钙约  **1.25 mmol/L** ，具体按检测实验室及人群解释。[Endotext：钙磷稳态与参考范围](https://ncbi.nlm.nih.gov/books/NBK279023/?report=printable)

课件第 77 页的血磷  **0.96–1.44 mmol/L**  和钙磷乘积  **35–40（以 mg/dL 数值相乘）** ，作为课件数值定位保留。钙磷乘积依赖单位、总钙/离子钙及磷报告口径，不能机械当作人人必须维持的定值。

## 九、三类钙磷调节激素：围绕骨—肾—肠理解

### 1. 甲状旁腺激素（PTH）

 **甲状旁腺激素（PTH）** ：由甲状旁腺主细胞分泌的  **84 aa 多肽** ，经前体加工而来，主要功能是提高细胞外液 Ca²⁺ 水平。

课件第 79–84 页：

| 靶器官 | 作用链条 | 结果 |
| --- | --- | --- |
| 肾 | 增加远端肾单位 Ca²⁺ 重吸收 | 对钙有保留作用 |
| 肾 | 抑制磷酸盐重吸收，以近端小管为主 | 尿磷排出增加 |
| 肾—小肠 | 促进肾 1α-羟化酶，增加活性维生素 D | 间接增加肠道钙、磷吸收 |
| 骨 | 促进骨吸收的信号与骨钙动员 | Ca、P 可由骨释放 |

 **关键结论：PTH 升血钙、降血磷。**  虽然骨吸收同时释放 Ca 和 P，但促排磷的肾作用使血磷净趋势下降。

 **补充辨析** ：PTH 促骨吸收主要通过成骨细胞谱系/骨细胞的信号（如 RANKL）间接调节破骨细胞；不能把持续高 PTH 的促骨吸收与间歇低剂量 PTH 的促骨形成混为一谈。[Endotext：PTH 与骨代谢](https://www.ncbi.nlm.nih.gov/books/NBK279023/)

 **调节** ：血离子 Ca²⁺ 降低 → PTH 增多；活性维生素 D 对 PTH 有负反馈。课件第 82 页把“小肠作用”和“激活 1α-羟化酶”写在一起，应明确： **羟化酶被促进的关键部位是肾，肠道效应是间接的。** 

### 2. 降钙素（CT）

 **降钙素（CT）** ：由甲状腺滤泡旁 C 细胞分泌的  **32 aa 多肽** ，主要抑制破骨细胞介导的骨吸收。（课件第 85–88 页）

- 血 Ca²⁺ 升高可促进 CT 分泌。
- 课件主线：抑制溶骨，并促进肾排出 Ca 和 P，净趋势是血 Ca、P 降低。
-  **补充** ：在成人日常钙稳态中的作用小于 PTH 和维生素 D；不宜把三者简单看成同等强度的调节者。课件关于 CT 肠道剂量效应的展开不作为本章主线。[Endotext：降钙素](https://www.ncbi.nlm.nih.gov/books/NBK279023/)

### 3. 活性维生素 D：皮肤—肝—肾两次羟化

 **骨化三醇（calcitriol）** ：即  **1,25-(OH)₂-D₃** ，是维生素 D₃ 的主要高活性激素形式。

```text
皮肤 7-脱氢胆固醇
       ↓ UVB，先形成前维生素 D₃，再异构化
维生素 D₃ ← 食物来源也可补充
       ↓ 肝 25-羟化酶
25-(OH)-D₃（骨化二醇）
       ↓ 肾 1α-羟化酶 CYP27B1
1,25-(OH)₂-D₃（骨化三醇）

24-羟化及后续反应 → 分解、灭活方向
```

课件第 89–96 页突出肝的 25-羟化、肾的 1α-羟化及 24-羟化分流。 **25-(OH)-D 与 1,25-(OH)₂-D 是不同分子，不能用名称相近来替代。** 

 **作用** ：

- 小肠：增加钙转运相关蛋白表达，促进 Ca 与 P 吸收。
- 肾：参与钙重吸收调节，与其他激素共同维持稳态。
- 骨：支持正常矿化和骨更新；作用取决于矿物供应及激素环境，不能只背“促进溶骨”或只背“促进成骨”。
- 作用机制串联：维生素 D 结合蛋白（DBP）参与运输，细胞内 VDR 与 RXR 等调节靶基因表达。（课件第 92 页）

 **调节** ：低钙通过 PTH 促进肾 1α-羟化；活性维生素 D 对自身生成及 PTH 形成负反馈。补充理解：FGF23 也是重要的磷调节激素，促进肾排磷并抑制活性维生素 D 生成，但不属于本课件展开主线。[Endotext：钙磷激素网络](https://www.ncbi.nlm.nih.gov/books/NBK279023/)

### 4. 钙磷激素总对照

| 激素 | 来源/活化部位 | 主要作用机制 | 血钙净趋势 | 血磷净趋势 |
| --- | --- | --- | --- | --- |
| PTH | 甲状旁腺主细胞 | 保钙、排磷，促进活性 D 形成及骨钙动员 | ↑ | ↓ |
| CT | 甲状腺 C 细胞 | 抑制骨吸收，促进肾排钙磷 | ↓ | ↓ |
| 1,25-(OH)₂-D₃ | 肾完成关键活化 | 尤其促进肠吸收 Ca、P，支持骨更新和矿化 | ↑ | ↑ |

 **尿液箭头的边界** ：课件第 83、87、95、97 页以“PTH：尿 Ca↓/P↑；CT：尿 Ca↑/P↑；活性 D：尿 Ca↓/P↓”概括肾小管效应。真实尿排出量还取决于血浓度、滤过负荷、摄入量和肾功能； **PTH 增强钙重吸收，并不保证任何高 PTH 状态的 24 小时尿钙都低** 。维生素 D 增加肠钙吸收后也可增加尿钙，不能直接用课件箭头判断个体尿检。

### 5. 低钙反馈链

```text
血离子 Ca²⁺ ↓
      ↓
PTH ↑
 ├─ 肾保钙 ↑，排磷 ↑
 ├─ 肾 1α-羟化酶 ↑ → 活性维生素 D ↑ → 肠吸收 Ca/P ↑
 └─ 促进骨钙动员
      ↓
血 Ca²⁺ 回升 → 抑制 PTH 分泌
```

| 胰岛素 | 人前体 110 aa | 信号肽切除、折叠、C 肽加工 | 成熟 51 aa、3 对二硫键 |
| 胰高血糖素 | 较长的 proglucagon | 组织特异性蛋白水解 | 成熟 29 aa |
| PTH | 前体多肽 | 蛋白水解加工 | 成熟 84 aa |
| CT | 前体多肽 | 蛋白水解加工 | 成熟 32 aa |
| 活性维生素 D₃ | 皮肤/食物 D₃ 来源 | 肝 25-羟化＋肾 1α-羟化 | 皮—肝—肾 |

### 2. 最容易混淆的成对概念

| 成对概念 | 一句话区分 |
| --- | --- |
| 腺垂体 / 神经垂体 | 前者自身合成相应激素；后者主要储存并释放下丘脑来源的 ADH/OT |
| PRL / OT | 产乳 / 射乳 |
| Tg / TPO / TBG | 合成与储存载体 / 合成催化酶 / 血浆运输蛋白 |
| MIT、DIT / T₃、T₄ | 单个碘化酪氨酸残基 / 偶联形成的甲腺原氨酸 |
| T₃ / rT₃ | 同为三碘，但碘位置和活性不同 |
| T₄ 脱碘 / MIT、DIT 脱碘 | 可活化或失活 / 碘回收 |
| TH / TPO | 儿茶酚胺合成中的酪氨酸羟化酶 / 甲状腺过氧化物酶；TH 也可按上下文指甲状腺激素 |
| 皮质醇 / 可的松 | C₁₁ 位为羟基 / 酮基 |
| 皮质醇 / 醛固酮 | 糖皮质激素、HPA 轴 / 盐皮质激素、RAAS 与 K⁺ 调节 |
| HVA / VMA | 高香草酸、多巴胺代谢 / 香草扁桃酸、NE/E 代谢 |
| 胰岛素原 / 胰岛素 | 单链前体 / 成熟 A、B 链结构 |
| 总钙 / 离子钙 | 包含多种存在形式 / 直接参与生理活动的游离部分 |
| PTH / 活性 D | 都可升血钙，但血磷净趋势相反 |
| 25-(OH)-D / 1,25-(OH)₂-D | 肝羟化产物 / 肾进一步活化后的激素形式 |

## 十二、自测题与参考答案

### 自测题

1. ADH 和催产素由何处合成、何处释放？两者第 3、8 位分别是什么？
2. PRL 和催产素在哺乳中的分工是什么？
3. CRH—ACTH—皮质醇轴如何形成负反馈？
4. Tg、TPO、TBG 分别负责什么？
5. 甲状腺激素合成的四步是什么？哪些由 TPO 催化？
6. 为什么 T₄ 脱碘不一定代表激素失活？
7. 球状带、束状带、网状带的主要产物是什么？
8. 为什么球状带不走典型的 17α-羟化支路？
9. 儿茶酚胺合成限速酶是什么？PNMT 使用什么供甲基？
10. HVA 和 VMA 分别主要联系哪些儿茶酚胺？
11. 人胰岛素的 110、86、51、31 分别代表什么？
12. 胰岛素受体与胰高血糖素受体有什么不同？
13. 为什么 PTH 同时促进骨 Ca/P 释放，却使血磷下降？
14. PTH 促进钙重吸收，是否意味着所有高 PTH 患者尿钙都低？
15. 维生素 D 活化依次在哪些器官进行？哪个肾酶是关键调节点？
16. 三类钙磷激素分别如何影响血钙、血磷？

### 参考答案

1. 下丘脑合成，神经垂体释放；ADH 为 Phe³/Arg⁸，OT 为 Ile³/Leu⁸。
2. PRL 促产乳，OT 促射乳。
3. 皮质醇对垂体 ACTH 及下丘脑 CRH 形成负反馈。
4. Tg：合成支架和储存；TPO：氧化、碘化、偶联；TBG：血液运输。
5. 聚碘—氧化—碘化—偶联；后三步由 TPO 参与催化。
6. 转为 T₃ 是活化方向，转为 rT₃ 是失活方向。
7. 醛固酮—皮质醇—DHEA 等雄激素。
8. 球状带缺乏 CYP17A1；束状带和网状带具有相应酶活性。
9. 酪氨酸羟化酶；SAM。
10. HVA 联系多巴胺，VMA 联系 NE/E。
11. 人前胰岛素原—胰岛素原—成熟胰岛素—C 肽的 aa 数。
12. 胰岛素受体有内在酪氨酸激酶活性；胰高血糖素受体为 GPCR。
13. 肾促排磷作用使血磷净趋势下降。
14. 否；还取决于高钙导致的滤过负荷及其他条件。
15. 皮肤生成/食物摄入 → 肝 25-羟化 → 肾 1α-羟化；关键肾酶 CYP27B1。
16. PTH：Ca↑/P↓；CT：Ca↓/P↓；活性 D：Ca↑/P↑，均为主趋势。
