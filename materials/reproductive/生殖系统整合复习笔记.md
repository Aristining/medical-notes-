## 一、男性生殖系统

**课件定位：01A，第2～44页；复习题在第45页。**

### 1.1 组成、功能与精子运输路线

| 组成 | 器官 | 主要功能 |
| --- | --- | --- |
| 生殖腺 | 睾丸 | 产生精子、分泌雄激素 |
| 生殖管道 | 附睾、输精管、射精管等 | 精子成熟、贮存、运输 |
| 附属腺 | 精囊腺、前列腺、尿道球腺 | 分泌精浆，与精子共同构成精液 |
| 外生殖器 | 阴囊、阴茎 | 为睾丸提供适宜环境，完成交配等功能 |

**运输顺序必须会默写：**

生精小管 → 直精小管 → 睾丸网 → 输出小管 → 附睾管 → 输精管 → 射精管 → 尿道。

注意：精子在**生精小管产生**，在**附睾进一步成熟、贮存**。精子发生与附睾成熟是不同环节。

### 1.2 睾丸的一般结构

- **被膜**：由外向内可见鞘膜脏层、白膜、血管膜。白膜为致密结缔组织，向内形成睾丸纵隔与睾丸小隔。
- **实质**：包括生精小管、直精小管、睾丸网。
- **间质**：小管之间的疏松结缔组织，含血管及睾丸间质细胞。
- **生精小管管壁**：生精上皮＋界膜。生精上皮由**生精细胞和支持细胞**构成；界膜包括基膜、肌样细胞和成纤维细胞等。

**结构与功能联系**：生精小管内负责配子发生，管间间质负责雄激素分泌。

### 1.3 生精细胞的层次与染色体变化【重点】

从基膜向管腔，基本顺序为：

**精原细胞 → 初级精母细胞 → 次级精母细胞 → 精子细胞 → 精子。**

> **统一记法**：`n`表示染色体组数，`C`表示DNA含量。课件把DNA含量也写成n，容易混淆；本笔记统一改用C。染色体数按着丝粒计数，DNA复制后染色体数仍为46条。

| 细胞 | 位置与识别点 | 染色体数/组数 | DNA含量 | 后续变化 |
| --- | --- | --- | --- | --- |
| 精原细胞，复制前 | 紧贴基膜；圆形或椭圆形，约12 μm；A型、B型 | 46条，2n | 2C | 有丝分裂、自我更新或分化；分化后经历DNA复制 |
| 初级精母细胞，复制后 | 位于精原细胞近腔侧；体积较大，约18 μm；染色质常呈粗线状 | 46条，2n | 4C | 完成第一次减数分裂 |
| 次级精母细胞 | 比初级小，约12 μm；存续时间短，切片中少见 | 23条，1n；含X或Y | 2C | 完成第二次减数分裂 |
| 精子细胞 | 近腔面；较小，约8 μm | 23条，1n | 1C | 经形态改建成为精子 |
| 精子 | 头部浓染，尾伸入管腔 | 23条，1n | 1C | 释放并进入后续管道 |

**一条主线：**

`2n、2C → DNA复制 → 2n、4C → 减Ⅰ → 1n、2C → 减Ⅱ → 1n、1C`。

- 第一次减数分裂分离同源染色体，染色体组数减半。
- 第二次减数分裂分离姐妹染色单体。
- 一个初级精母细胞一般形成**4个精子细胞**。
- 次级精母细胞很快进入减Ⅱ，因此比初级精母细胞难在切片中见到。

### 1.4 精子发生与精子形成【重点】

**精子发生（spermatogenesis）**：从精原细胞增殖、分化到精子产生的全过程。课件记约**64天**。

**精子形成（spermiogenesis）**：精子细胞经过形态改建成为精子的过程，**不再发生细胞分裂，染色体数和DNA含量不变**。

精子形成的五个变化：

1. **核浓缩**：染色质高度凝集，核蛋白由组蛋白逐步转为鱼精蛋白为主。
2. **顶体形成**：高尔基复合体形成顶体，覆盖头部前方，含顶体酶。
3. **尾形成**：中心体移至顶体对侧，参与鞭毛形成。
4. **线粒体集中**：聚集于尾部中段，形成线粒体鞘，为运动供能。
5. **多余胞质脱落**：形成残余体，由支持细胞吞噬。

| 精子部分 | 主要结构 | 功能联系 |
| --- | --- | --- |
| 头部 | 浓缩的核、顶体、细胞膜 | 携带遗传信息，参与受精 |
| 颈部 | 中心粒等连接结构 | 连接头与尾 |
| 中段 | 轴丝、线粒体鞘等 | 供能与运动 |
| 主段、末段 | 以轴丝等鞭毛结构为主 | 推动精子运动 |

**精子发生的两个特点：**

- **同源细胞群**：由同一精原细胞产生的各级生精细胞，经胞质桥相连，发育具有同步性。
- **生精上皮周期/分期**：不同发育阶段细胞形成特定组合；课件记人有6个期。

### 1.5 支持细胞与睾丸间质细胞【重点对比】

| 项目 | 支持细胞 Sertoli cell | 间质细胞 Leydig cell |
| --- | --- | --- |
| 位置 | 生精上皮内，基底部至近腔面 | 生精小管之间的间质 |
| 光镜 | 轮廓不清；核不规则、浅染，核仁明显 | 细胞较大而圆，胞质嗜酸性 |
| 电镜 | 侧面和腔面有凹陷，可容纳生精细胞；含细胞器、微丝和微管；相邻细胞间有紧密连接 | 具有分泌类固醇激素细胞特征，如丰富滑面内质网及管状嵴线粒体 |
| 主要激素调节 | FSH | LH |
| 分泌 | 抑制素、雄激素结合蛋白ABP等 | 雄激素，以睾酮为代表 |
| 核心任务 | 支持生精、建立屏障、调节局部微环境 | 提供雄激素 |

**支持细胞功能的答题清单：**

- 支持、营养生精细胞。
- 吞噬、消化残余体。
- 促进精子释放与输送。
- 分泌ABP，使局部维持较高雄激素水平。
- 分泌抑制素，对FSH形成负反馈。
- 以细胞间紧密连接构成血睾屏障的关键部分。

### 1.6 血睾屏障【名词解释＋简答重点】

**定义**：血液与生精小管近腔侧生精细胞之间的一组屏障结构，其中**相邻支持细胞之间的紧密连接是核心**。

课件列出的相关结构，由外向内为：

毛细血管内皮及其基膜 → 间质结缔组织 → 生精小管界膜 → 支持细胞间紧密连接。

- 紧密连接将生精上皮分为**基底室与近腔室**。
- 精原细胞和早期初级精母细胞位于基底侧，后续发育阶段在近腔侧完成。
- **意义一**：维持精子发生所需的稳定微环境。
- **意义二**：限制生精细胞抗原与免疫系统接触，减少自身免疫反应。

**答题提醒**：若问“最主要的结构基础”，应直接写“支持细胞之间的紧密连接”。

### 1.7 下丘脑－垂体－睾丸轴

下丘脑分泌**GnRH**，促进垂体分泌FSH和LH。

| 轴线 | 靶细胞 | 作用及反馈 |
| --- | --- | --- |
| LH → 间质细胞 | Leydig细胞 | 促进睾酮产生；睾酮对下丘脑和垂体产生负反馈 |
| FSH → 支持细胞 | Sertoli细胞 | 促进支持生精及ABP等合成；抑制素主要抑制FSH分泌 |

**记忆联系**：LH管“间质和睾酮”，FSH管“支持和生精”，两者协同维持精子发生。

### 1.8 生殖管道的组织学鉴别

| 管道 | 上皮及管腔 | 肌层/其他 | 功能或识别点 |
| --- | --- | --- | --- |
| 直精小管 | 起始段以单层支持细胞为主，无生精细胞 | 管径细 | 生精小管与睾丸网之间的通道 |
| 睾丸网 | 单层立方或低柱状上皮；管腔较大、不规则 | 位于睾丸纵隔 | 汇集精子 |
| 输出小管 | 有纤毛细胞与无纤毛吸收细胞相间，细胞高低不一，腔缘呈波浪/锯齿状；课件称假复层纤毛柱状上皮 | 管周有平滑肌 | 重吸收液体，纤毛帮助运输 |
| 附睾管 | 假复层柱状上皮，主细胞顶端有**静纤毛**；管腔较规则，常见精子 | 以主细胞、基细胞为主，外有平滑肌 | 精子成熟、贮存；分泌肉毒碱、甘油磷酸胆碱、唾液酸等 |
| 输精管 | 假复层柱状上皮，黏膜皱襞明显 | 肌层很厚，**内纵、中环、外纵** | 强力收缩运输精子 |

**静纤毛本质是长微绒毛**，与能够摆动的运动纤毛不同。附睾管不要背成依靠运动纤毛摆动运输。

### 1.9 前列腺与精液

**正常前列腺：**

- 课件按腺体分布列出尿道周带黏膜腺、内带黏膜下腺、外带主腺。
- 上皮可呈单层立方、单层柱状或假复层。
- 腺腔有皱襞，可见**凝固小体**。
- 间质内平滑肌丰富。
- 临床病理复习还需记住：**前列腺增生多在移行区，癌多在外周区**，不要把课件的旧式三组腺体分法与现代分区强行一一对应。

**精液＝精子＋生殖管道及附属腺分泌物。**课件中的精液量和精子浓度属于教学示例；“低于400万/mL即不育”等说法不能当作现行诊断界值。精液指标与生育能力不能用单一数字直接画等号，见[核对说明](#corrections)。

## 二、女性生殖系统

**课件定位：01B，第2～42页；第43页另附阴茎结构。**

### 2.1 组成与卵巢结构

| 器官 | 主要功能 |
| --- | --- |
| 卵巢 | 形成卵细胞，分泌性激素 |
| 输卵管 | 营养、输送生殖细胞；壶腹部是常见受精部位 |
| 子宫 | 内膜发生月经周期变化，容纳胚胎和胎儿 |
| 乳腺 | 产生和排出乳汁 |
| 阴道及外生殖器 | 生殖通道等 |

女性生殖系统具有**年龄性变化**和**周期性变化**。

**卵巢的四个定位点：**

- 表面上皮：单层立方或单层扁平，其下为白膜。
- 皮质：含不同阶段卵泡、黄体、白体等。
- 髓质：疏松结缔组织，血管丰富。
- 卵巢门：可见门细胞，分泌雄激素。

### 2.2 卵泡的发育分期【重点】

本课程分期：**原始卵泡 → 初级卵泡 → 次级卵泡 → 成熟卵泡**。不同教材对“次级卵泡”的命名可能不同，答本课程题时结合“是否有卵泡腔”等形态判断。

| 阶段 | 卵母细胞 | 卵泡细胞及周围结构 | 最有用的识别点 |
| --- | --- | --- | --- |
| 原始卵泡 | 初级卵母细胞，核大、浅染，核仁明显；停于减Ⅰ前期 | 周围一层扁平卵泡细胞 | **一卵＋一层扁平细胞** |
| 初级卵泡 | 初级卵母细胞增大 | 卵泡细胞由立方/柱状变为多层；透明带出现；周围形成卵泡膜 | **细胞变高、增层，但无明显卵泡腔** |
| 次级卵泡 | 大部分生长阶段仍为初级卵母细胞 | 出现并扩大卵泡腔；形成卵丘、放射冠；颗粒层与卵泡膜内外层清楚 | **有卵泡腔和卵丘** |
| 成熟卵泡 | 临近排卵时完成减Ⅰ，形成次级卵母细胞和第一极体；次级卵母细胞停于减Ⅱ中期 | 卵泡腔巨大，向卵巢表面突出 | **大卵泡腔、偏位卵丘、准备排卵** |

**三个名词：**

- **卵丘**：卵母细胞及其周围卵泡细胞形成、突入卵泡腔的细胞团。
- **放射冠**：紧贴透明带外侧、呈放射状排列的一层卵泡细胞。
- **颗粒层**：卵泡内围绕卵泡腔等部位的多层卵泡细胞。

### 2.3 透明带与卵泡膜

**透明带（zona pellucida）：**

- 位于卵母细胞与卵泡细胞之间。
- 课件记由卵母细胞和卵泡细胞共同参与形成。
- 为均质、折光、嗜酸性、PAS阳性的糖蛋白层。
- 参与精卵识别、特异性结合与受精过程。
- 卵母细胞与周围卵泡细胞通过穿越透明带的细胞突起相接，并形成缝隙连接。**透明带本身不是细胞，也不是“缝隙连接”结构。**

| 卵泡膜 | 组成与作用 |
| --- | --- |
| 内层 | 毛细血管丰富，含膜细胞，参与类固醇激素合成 |
| 外层 | 胶原纤维、平滑肌纤维等，承担支持作用 |

### 2.4 雌激素合成：两细胞、两促性腺激素【重点】

1. **LH作用于卵泡膜内层细胞**，促进雄激素合成。
2. 雄激素进入颗粒细胞。
3. **FSH作用于颗粒细胞**，促进芳香化酶等作用，将雄激素转化为雌激素。

**记忆句：膜细胞先造雄激素，颗粒细胞再转雌激素。**不能把两类细胞的作用和FSH/LH的靶点颠倒。

### 2.5 排卵、黄体与白体【重点】

**排卵：**

- 在典型28天周期模型中约为第14天；实际周期中日期可变。
- 直接激素触发因素是**LH高峰**。
- 卵泡小斑处酶活性增强、卵丘与壁分离、卵泡膜外层平滑肌收缩，促使卵泡破裂。
- 排出的是**次级卵母细胞＋透明带＋放射冠**，经腹腔被输卵管伞端拾取。
- **排卵时通常尚未完成第二次减数分裂。**

**黄体（corpus luteum）**：排卵后卵泡壁塌陷，血管和结缔组织侵入，在LH作用下，卵泡壁细胞肥大并分化为内分泌细胞团。

| 项目 | 粒黄体细胞 | 膜黄体细胞 |
| --- | --- | --- |
| 来源 | 颗粒细胞 | 卵泡膜内层细胞 |
| 光镜特点 | **大、浅、多** | **小、深、少** |
| 电镜 | 均有分泌类固醇激素细胞特征 | 同左 |
| 课件功能重点 | 主要分泌孕激素，并参与雌激素合成 | 与粒黄体细胞协同产生雌激素 |

- **月经黄体**：未妊娠时约维持2周，随后退化。
- **妊娠黄体**：妊娠后维持较久；课件记约6个月。此数值不等于“整个时期妊娠激素都只由黄体供应”。
- **白体（corpus albicans）**：黄体退化后形成的结缔组织瘢痕。
- 卵巢还可分泌雄激素、松弛素等；课件将雄激素联系于门细胞，将松弛素联系于妊娠黄体粒黄体细胞。

### 2.6 优势卵泡与闭锁卵泡

**优势卵泡的选择：**

同批卵泡对FSH的敏感性不同 → FSH受体表达较多、反应较强者生长较快 → 雌激素及抑制素B增加 → FSH受负反馈而下降 → 优势卵泡继续生长，较小卵泡退化。

**闭锁卵泡（atretic follicle）**：在发育不同阶段未能成熟而发生退化的卵泡。闭锁从胎儿期开始，并持续到更年期。

- 早期生长卵泡闭锁：卵母细胞及卵泡细胞退化，透明带可呈波浪状。
- 晚期生长卵泡闭锁：膜细胞可肥大，形成间质腺。
- 卵泡总数总体减少；每月只有少数进入后续生长，通常一个成为优势卵泡。不能把一个月经周期误当成原始卵泡至成熟卵泡的全部耗时。

### 2.7 卵细胞发生及两次停滞【重点】

| 阶段 | 染色体及DNA | 时间/停滞位置 |
| --- | --- | --- |
| 卵原细胞，复制前 | 46条，2n、2C | 胎儿期有丝分裂增殖 |
| 初级卵母细胞，复制后 | 46条，2n、4C | 胎儿期进入减Ⅰ，长期停于**减Ⅰ前期** |
| 次级卵母细胞 | 23条，1n、2C | 临近排卵完成减Ⅰ后形成，停于**减Ⅱ中期** |
| 卵细胞及第二极体 | 各23条，1n、1C | 通常在受精后完成减Ⅱ |

**与精子发生比较：**

| 项目 | 精子发生 | 卵细胞发生 |
| --- | --- | --- |
| 增殖与发生特点 | 青春期后持续进行，精原细胞保留更新能力 | 卵原细胞增殖主要在胎儿期；卵母细胞储备有限 |
| 胞质分配 | 相对均等 | 明显不等，多数胞质留给卵细胞 |
| 一个初级细胞的主要结果 | 4个精子细胞 | 1个大卵细胞，其余为极体 |
| 长期停滞 | 无对应的两次长期停滞 | 减Ⅰ前期、减Ⅱ中期 |
| 形态改建 | 精子细胞需经历精子形成 | 无精子式的头尾改建过程 |

### 2.8 子宫壁、内膜分层与血供

**子宫壁三层：**内膜、肌层、外膜。

- 内膜表面为单层柱状上皮，包括分泌细胞和纤毛细胞。
- 固有层含基质细胞、子宫腺、血管和纤维。
- 肌层很厚，由平滑肌组成，课件分三层。
- 外膜在子宫底和体大部为浆膜，部分为纤维膜。

| 内膜分层 | 血供 | 对卵巢激素反应及功能 |
| --- | --- | --- |
| **功能层** | 主要由螺旋动脉供应 | 敏感，发生周期性变化并在月经期剥脱；也是胚泡植入相关部位 |
| **基底层** | 基底/直动脉供应 | 相对稳定，月经后修复、再生功能层 |

血供主线：子宫动脉 → 弓状动脉 → 放射状小动脉 → 基底动脉及螺旋动脉。

### 2.9 子宫内膜周期【重点对比表】

以下按**28天周期模型，出血第1天为周期第1天**。

| 项目 | 月经期 | 增生期，对应卵巢卵泡期的一部分 | 分泌期，对应黄体期 |
| --- | --- | --- | --- |
| 课件日期 | 第1～4天 | 第5～14天 | 第15～28天 |
| 激素背景 | 雌、孕激素下降 | 雌激素作用为主 | 孕激素作用突出，伴雌激素 |
| 功能层 | 缺血、坏死、剥脱、出血 | 修复和增厚 | 进一步增厚并为植入作准备 |
| 子宫腺 | 随功能层破坏 | 早期短直，晚期稍弯曲 | **高度弯曲、腔扩大、含糖原分泌物** |
| 基质 | 组织脱落、出血 | 基质细胞增生 | 水肿、血管充血 |
| 螺旋动脉 | 收缩引起缺血，后续损伤出血 | 伸长、弯曲 | 更长、更弯曲 |
| 课件内膜厚度示例 | 功能层脱落 | 约2～4 mm | 约5～7 mm |

**月经形成的机制链：**

黄体退化 → 雌、孕激素下降 → 螺旋动脉收缩、功能层缺血坏死 → 血管损伤与出血 → 功能层组织和血液排出。

**注意**：卵巢卵泡期包含月经期和内膜增生期，不能把“卵泡期”机械地只等同于第5～14天。

### 2.10 女性生殖轴与周期综合题

下丘脑GnRH → 垂体FSH、LH → 卵巢结构和激素变化 → 子宫内膜变化。

- FSH促进卵泡生长及颗粒细胞功能。
- 卵泡期雌激素促进内膜增生。
- 排卵前，持续高水平雌激素产生正反馈，促成LH高峰。
- LH高峰触发排卵和黄体化。
- 黄体分泌孕激素和雌激素，使内膜转为分泌期，并产生负反馈。
- 未妊娠时黄体退化，性激素下降，出现月经，下一轮卵泡开始生长。

**课件第34页思考题：**

| 周期时间 | 卵巢主要结构 | 激素重点 | 内膜表现 |
| --- | --- | --- | --- |
| 第12天 | 发育中的优势卵泡，接近成熟 | FSH/LH作用下雌激素升高 | 增生期，腺体较直或稍弯，基质增生 |
| 第22天 | 功能活跃的黄体 | LH维持黄体，孕激素作用明显 | 分泌期，腺体迂曲扩张、含分泌物，基质水肿 |

### 2.11 输卵管、宫颈、阴道与乳腺

| 部位 | 组织结构 | 识别/功能联系 |
| --- | --- | --- |
| 输卵管 | 黏膜、肌层、浆膜；单层柱状上皮，含纤毛细胞和分泌细胞；肌层内环外纵 | 壶腹部黏膜皱襞发达，参与受精及运输 |
| 宫颈管 | 高大、分支的黏膜皱襞和腺性隐窝；单层柱状上皮，含分泌细胞等 | 外宫颈表面为复层鳞状上皮；鳞柱交界及转化区与宫颈病变有关 |
| 阴道 | 黏膜、肌层、外膜；黏膜为复层扁平非角化上皮 | 与单层柱状上皮的子宫内膜区别 |
| 乳腺 | 小叶内含腺泡与导管；腺泡多为单层立方或柱状上皮；间有结缔组织和脂肪 | 静止期与活动期比较是识图要点 |

**乳腺活动状态：**

| 状态 | 腺体 | 结缔组织和脂肪 |
| --- | --- | --- |
| 静止期 | 腺泡不发达，导管相对突出 | 相对丰富 |
| 妊娠、哺乳等活动期 | 导管和腺泡增生，腺泡及腔扩大，分泌活跃 | 相对减少 |

乳腺导管上皮随管径变化，不能把整条输乳管系统都概括成同一种上皮。

**课件附录：阴茎**由两条阴茎海绵体、一条尿道海绵体及白膜、皮肤等构成，尿道位于尿道海绵体中。

## 三、生殖系统的发生与发育异常

**课件定位：02，第2～27页为发生，第29～48页为异常，第50页为病例讨论。**

### 3.1 总体来源：先有共同原基，再分化

- 泌尿、生殖系统的许多主要结构与**间介中胚层**有关。
- 间介中胚层形成纵行的生肾索；尿生殖嵴分为外侧的中肾嵴与内侧的生殖腺嵴。
- 生殖系统发育需分别分析：**性腺、生殖管道、外生殖器**。三者并非由同一种激素直接决定。
- 课件以“性别未分化期”和“分化期”组织内容。

**相关背景流程：**排卵 → 输卵管壶腹部受精 → 卵裂并向子宫运行 → 桑椹胚入宫腔 → 胚泡脱离透明带 → 植入子宫内膜。

**尿囊背景**：课件还介绍尿囊与膀胱早期发育的联系；其残迹形成脐尿管，正常闭锁后成为脐中韧带。此处用于理解泌尿与生殖系统发育的位置关系。

### 3.2 原始生殖细胞、性索和两套管道

**原始生殖细胞（PGC）：**

1. 与上胚层来源有关。
2. 早期暂位于近尿囊的卵黄囊壁区域。
3. 沿后肠及背系膜迁移到生殖腺嵴。
4. 进入性腺原基后，参与形成将来的生殖细胞。

**易错点**：卵黄囊壁是PGC早期所在及迁移相关位置，不应直接等同于PGC最终的胚层起源。课件第10页已给出上胚层来源提示。

**初级性索**：生殖腺表面体腔上皮增生并向深部形成的细胞索。

**未分化期的两套生殖管道：**

| 管道 | 英文/别名 | 来源与后续意义 |
| --- | --- | --- |
| 中肾管 | Wolffian duct，Wolff管 | 已形成的中肾排泄管道；在睾酮作用下形成主要男性内生殖管道 |
| 中肾旁管 | Müllerian duct，Müller管 | 中肾外侧体腔上皮内陷形成；未受AMH抑制时形成主要女性内生殖管道 |

### 3.3 课件时间轴

以下“周”按课件胚胎发育时间理解，不与临床按末次月经计算的孕周混用。

| 时间 | 主要事件 |
| --- | --- |
| 胚第4周左右 | 间介中胚层形成生肾索等结构 |
| 胚第5周左右 | 尿生殖嵴及初级性索形成 |
| 第6周前后 | 性腺尚处未分化阶段；PGC已迁入或正在迁入性腺原基 |
| 第7周左右 | 睾丸分化开始明显 |
| 第9周前 | 外生殖器外形通常尚难分辨男女 |
| 第10周左右 | 卵巢分化逐渐明显 |
| 第16周左右 | 课件示卵巢皮质索细胞团进一步形成原始卵泡 |

### 3.4 性腺分化与三个关键激素【重点】

通常情况下：Y染色体短臂**SRY基因**启动睾丸分化调控网络，促使未分化性腺向睾丸发育。卵巢形成也有主动的基因调控，不能只理解成“什么信号都没有”。

| 信号 | 主要来源/生成 | 核心作用 | 缺陷后推理 |
| --- | --- | --- | --- |
| **AMH，抗米勒管激素** | 胎儿睾丸支持细胞 | 使中肾旁管退化 | 缺乏时可保留子宫、输卵管等中肾旁管衍生结构 |
| **睾酮T** | 胎儿睾丸间质细胞 | 维持中肾管，形成男性内生殖管道 | 缺乏或受体不能反应时，中肾管不能正常男性化 |
| **DHT，双氢睾酮/二氢睾酮** | 睾酮经5α还原酶转化 | 促进男性外生殖器、前列腺等发育 | 缺乏时外生殖器男性化不足，男性内管道仍可存在 |

**病例分析三问：**

1. 有没有正常分化的睾丸？决定能否提供AMH和睾酮。
2. 有没有AMH作用？用于判断子宫、输卵管是否保留。
3. 有没有雄激素及其受体作用？分别判断中肾管和外生殖器。

### 3.5 睾丸与卵巢的发生

| 项目 | 睾丸发生 | 卵巢发生 |
| --- | --- | --- |
| 性索主要变化 | 初级性索向深部增殖，形成睾丸索 | 初级性索多退化；表面上皮再形成次级性索，即皮质索 |
| 生殖细胞 | PGC → 精原细胞 | PGC → 卵原细胞 → 初级卵母细胞 |
| 支持细胞 | 性索相关细胞形成支持细胞 | 皮质索细胞团外周形成卵泡细胞 |
| 间质细胞 | 间充质细胞形成睾丸间质细胞 | 形成卵巢间质等支持结构 |
| 后续结构 | 睾丸索在青春期前后管腔化并形成生精小管等 | 初级卵母细胞与外围卵泡细胞构成原始卵泡 |

**核心区别**：男性主要保留、发展深部睾丸索；女性主要发展皮质索和卵泡结构。

### 3.6 生殖管道的来源【重点默写表】

| 胚胎结构 | 男性主要结局 | 女性主要结局 |
| --- | --- | --- |
| 中肾小管 | **输出小管** | 大部退化 |
| 中肾管 | **附睾管、输精管、射精管、精囊腺** | 大部退化，可留残迹 |
| 中肾旁管未融合的头侧部分 | AMH作用下退化 | **输卵管** |
| 中肾旁管融合的尾侧部分 | 退化 | **子宫、宫颈及阴道上部相关结构** |
| 尿生殖窦相关结构 | 尿道及前列腺等腺体的上皮来源 | 参与阴道板形成、阴道下部及前庭等发育 |

**两个特别容易混淆的来源：**

- 输出小管来自**中肾小管**，附睾管来自**中肾管**。
- 前列腺不属于中肾管衍生物，精囊腺属于中肾管衍生物。

**阴道来源的课程理解**：课件第24～25页强调尿生殖窦、窦结节与阴道板，第40、45页又采用“上1/3与下2/3”的传统分段描述。复习应抓住**中肾旁管与尿生殖窦共同参与**，避免只背“整条阴道都来自某一处”。固定比例属于教材传统模型。

### 3.7 外生殖器共同原基与对应结构

泄殖腔被尿直肠隔分为腹侧尿生殖窦与背侧肛直肠管。外生殖器的共同原基包括生殖结节、尿生殖褶、阴唇阴囊隆起等。

| 未分化原基 | 男性 | 女性 |
| --- | --- | --- |
| **生殖结节** | 伸长形成阴茎相关结构 | 阴蒂 |
| **尿生殖褶** | 向中线融合，参与阴茎尿道腹侧的形成 | 不融合，形成小阴唇 |
| **阴唇阴囊隆起** | 向中线融合形成阴囊 | 大阴唇 |
| 尿生殖沟/窦相关区域 | 伴随尿道闭合与延长 | 阴道前庭相关区域 |

**记忆配对**：阴茎－阴蒂，阴囊－大阴唇，尿生殖褶－小阴唇。

### 3.8 常见结构畸形

| 异常 | 发生机制 | 表现及复习联系 |
| --- | --- | --- |
| **隐睾** | 睾丸未沿正常下降途径进入阴囊；机制并非单一DHT不足 | 可停在腹腔或腹股沟；温度环境影响生精，双侧可致不育；生殖细胞肿瘤风险增加 |
| **先天性腹股沟斜疝** | 腹膜鞘突未闭，腹腔与腹股沟/阴囊存在交通 | 肠管等可经通道疝入 |
| **鞘膜积液/鞘突囊肿** | 鞘突不同部位闭合不全，液体积聚 | 与“疝内容物为肠管”区别；鞘膜腔正常可有少量液体 |
| **尿道下裂** | 尿生殖褶融合不全、阴茎尿道形成异常 | 尿道开口位于阴茎腹侧，可在龟头、阴茎、阴囊或会阴等部位 |
| **尿道上裂** | 尿道背侧发育异常 | 开口在背侧，可伴膀胱外翻 |
| 阴茎/阴蒂缺如 | 生殖结节发育缺陷 | 与共同原基联系 |
| 小阴茎 | 雄激素不足或反应异常等 | 与激素作用联系 |
| **双子宫** | 两侧中肾旁管尾侧未融合 | 可伴双阴道或单阴道 |
| **双角子宫** | 中肾旁管融合不全 | 宫底形成双角 |
| **中隔子宫** | 已融合的结构内部中隔吸收不全 | 与“双角＝融合不全”区别 |
| 阴道闭锁/处女膜不通 | 阴道板形成、管腔化或开口贯通过程异常 | 可导致经血排出障碍；具体层次需区分 |
| 子宫缺如 | 中肾旁管发育障碍 | 性腺及外生殖器可与子宫发育状态不一致 |

课件“隐睾1/3癌变”等数字不作普遍风险结论，详见[核对说明](#corrections)。

### 3.9 性发育差异/异常：分类与核型

课件用**DSD（disorders of sex development）**表示性染色体、性腺或性激素/作用异常导致的先天性性发育差异。学习时分别描述核型、性腺、内生殖器、外生殖器和激素，避免用单一特征代替完整判断。

| 情况 | 典型核型 | 主要问题 | 复习关键词 |
| --- | --- | --- | --- |
| **Klinefelter综合征，克氏综合征** | 47,XXY，可有嵌合等 | 睾丸发育与功能不全 | 小睾丸、生精障碍、不育，身材较高，可有男性乳房发育 |
| **Turner综合征** | 45,X及其他X染色体异常/嵌合 | 卵巢发育不全 | 条索状性腺、身材矮小、颈蹼、肘外翻、原发闭经、第二性征不足 |
| X三体 | 47,XXX | 表现差异较大 | 可有身材高、语言或学习困难风险增加，多数可有正常女性性征和生育能力 |
| 47,XYY综合征 | 47,XYY | 表现差异较大 | 可身材高，部分存在学习、语言或神经发育方面困难；多数性发育正常 |

**表述校正**：不把“47,XXX必然智力低下、乳房和外生殖器发育差”作为通则；克氏综合征也不等于普遍智力障碍。参见[MedlinePlus：X三体](https://medlineplus.gov/genetics/condition/trisomy-x/)与[NICHD：克氏综合征表现](https://www.nichd.nih.gov/health/topics/klinefelter/conditioninfo/symptoms)。

### 3.10 性腺发育异常

| 情况 | 性腺及分泌 | 内生殖器与外观 | 鉴别要点 |
| --- | --- | --- | --- |
| **46,XY完全性腺发育不全，Swyer综合征** | 条索状性腺，缺乏正常睾丸分泌 | 无足够AMH，因此可有子宫、输卵管；无正常睾酮作用，外生殖器通常呈女性型；青春期性征不足、原发闭经 | **46,XY＋有子宫＋睾酮低/性腺功能不全** |
| 46,XX单纯性腺发育不全 | 卵巢发育不全，性激素不足 | 有女性内生殖器，青春期发育不足、原发闭经 | 核型XX；肿瘤风险不能简单照搬含Y材料者 |
| **卵睾性DSD** | 同一个体存在卵巢组织和睾丸组织 | 表现取决于组织分布及功能，核型可多样 | 课件旧称“真两性畸形”；不能只凭外观判断是否有两种性腺组织 |
| 46,XX睾丸性DSD | 有睾丸组织，可与SRY易位或其他睾丸分化基因改变有关 | 外观可男性化，常有小睾丸和生精障碍 | **XX也可能形成睾丸组织** |

关于Swyer综合征的“条索状性腺、有女性内生殖结构”可核对[MedlinePlus](https://medlineplus.gov/genetics/condition/swyer-syndrome/)。课件“46,XY女性＝卵巢”的概括不宜推广，必须确认具体性腺类型。

### 3.11 雄激素作用异常：最重要的病例鉴别表【重点】

| 情况 | 核型、性腺 | 主要缺陷 | 子宫/输卵管 | 男性内管道 | 外生殖器、青春期表现 |
| --- | --- | --- | --- | --- | --- |
| **完全型雄激素不敏感，CAIS** | 46,XY，有睾丸 | **AR雄激素受体**功能异常；T和DHT可正常/升高 | 通常缺如，因为AMH仍有效 | 缺如或发育不全 | 女性型外生殖器、短盲端阴道；乳房可发育，阴毛/腋毛稀少，原发闭经 |
| **5α还原酶2缺乏** | 46,XY，有睾丸 | **SRD5A2**异常，T转为DHT受阻 | 通常缺如，AMH正常 | 可存在，因为T作用保留 | 外生殖器男性化不足，程度可变；青春期T增加后可进一步男性化 |
| **46,XY性腺发育不全** | 46,XY，条索状性腺 | 睾丸分化失败，T及AMH均不足 | 可存在 | 不正常发育 | 女性型外观，乳房等第二性征通常发育不足 |
| **17α羟化酶/17,20裂解酶缺乏，46,XY** | 46,XY，有睾丸 | 性激素合成不足，AMH可保留 | 通常缺如 | 发育不足 | 外生殖器可女性型或男性化不足；青春期性征不足，并可有高血压、低钾 |

**一定要会解释：**

- CAIS“没有子宫”由**AMH仍起作用**解释，不能归因于“雄激素太高”。
- CAIS“外观女性型”由**雄激素受体失效**解释，不能说一定缺乏睾酮。
- 5α还原酶缺乏“有男性内管道、外观男性化不足”，说明**睾酮与DHT的作用不同**。
- Swyer“有子宫”，提示AMH也不足，区别于CAIS。

上述差别可核对[GeneReviews：AIS](https://www.ncbi.nlm.nih.gov/books/NBK1429/)及[MedlinePlus：5α还原酶缺乏](https://medlineplus.gov/genetics/condition/5-alpha-reductase-deficiency/)。AIS是一个谱系，表中详细表现指完全型，不能全部套用于部分型或轻型。

### 3.12 先天性肾上腺皮质增生：21与17比较【重点】

两者均可为常染色体隐性遗传，但阻断位置不同，雄激素方向相反。

| 项目 | **21羟化酶缺乏** | **17α羟化酶/17,20裂解酶缺乏** |
| --- | --- | --- |
| 相关基因 | CYP21A2 | CYP17A1 |
| 基本机制 | 皮质醇合成减少，ACTH反馈性升高；前体转向雄激素合成 | 皮质醇和性激素合成受阻；具有盐皮质激素作用的前体增加 |
| 雄激素 | **增多** | **减少** |
| 46,XX表现 | 经典型可有外生殖器男性化；无胎儿睾丸AMH，子宫等仍可存在 | 胎儿期女性外生殖器可正常，青春期性征发育不足、原发闭经 |
| 46,XY表现 | 可有过早男性化，课件称男性假性性早熟 | 外生殖器男性化不足；有睾丸AMH，通常无子宫；青春期性征不足 |
| 血压/电解质补充 | 失盐型可有低血压、低钠、高钾；并非所有亚型均失盐 | 典型为**高血压、低血钾** |

**记忆**：21缺乏先抓“雄激素多”；17缺乏先抓“性激素少＋高压低钾”。机制核对：[21羟化酶缺乏](https://medlineplus.gov/genetics/condition/21-hydroxylase-deficiency/)、[17α羟化酶缺乏](https://medlineplus.gov/genetics/condition/17-alpha-hydroxylase-17-20-lyase-deficiency/)。

### 3.13 课件病例：17岁、女性外观、原发闭经、46,XY

**题干补充条件**：LH升高、FSH正常、睾酮在正常男性范围，雌激素略高于成年男性。

**优先考虑的机制**：完全型雄激素不敏感综合征。题干支持这一可能性，但不能仅据这些资料作最终诊断。

**答题链：**

1. 46,XY且睾酮达到男性范围，提示可能存在分泌功能的睾丸。
2. 雄激素受体不能正常反应，使外生殖器未正常男性化；负反馈减弱可解释LH升高。
3. 睾丸支持细胞分泌AMH，中肾旁管退化，因此通常无子宫、输卵管。
4. 睾丸可在腹腔或腹股沟等位置；阴道可短且呈盲端。
5. 部分雄激素可经芳香化转为雌激素，解释乳房发育等女性型第二性征。
6. 需结合内生殖器影像、性腺定位和AR等检查进一步确认。

**关于参赛讨论**：核型、外观、激素水平、性别认同与赛事资格是不同问题。仅凭本题资料不能直接作出参赛资格结论，应结合具体项目和届时适用规则，并尊重当事人隐私与知情权。

## 四、生殖系统与乳腺病理

**课件重点页明确列出：子宫颈疾病、子宫体疾病、妊娠滋养细胞疾病、乳腺癌。卵巢肿瘤和前列腺疾病也在课件范围内。**

病理题统一按“**病因/来源 → 肉眼 → 镜下 → 临床联系 → 鉴别**”组织答案。判断恶性不能只看细胞层数或肿块大小，应重视组织结构、异型性及浸润。

<a id="cervix"></a>
### 4.1 子宫颈疾病【重点】

**课件定位：03，第3～22页。**

#### 4.1.1 慢性子宫颈炎

- 病因：感染、机械损伤、阴道内环境变化等。
- 症状：可轻微或无明显症状，部分白带增多、偶带血。
- 基本病理：**非特异性慢性炎，伴增生性改变**。
- 镜下：黏膜充血、水肿；间质内淋巴细胞、浆细胞和单核细胞浸润；可有腺上皮增生和鳞状上皮化生。

| 课件列举类型/相关改变 | 机制 | 识别点 |
| --- | --- | --- |
| 宫颈息肉 | 黏膜上皮、腺体及间质局限性增生 | 向外突出的息肉样病变 |
| 纳氏囊肿，Nabothian cyst | 增生或化生的鳞状上皮覆盖、阻塞腺口，黏液潴留 | 扩张的腺体形成囊肿 |
| 所谓“宫颈糜烂” | 很多实际上是宫颈柱状上皮异位/外翻，外观呈红色；少数为真正上皮缺损 | 不能仅凭“红”判定炎症、癌前病变或癌 |

**校正**：柱状上皮异位可为正常生理现象，不应统一归为慢性炎症，更不能直接等同癌前病变。[NHS：宫颈柱状上皮异位](https://www.nth.nhs.uk/resources/cervical-ectropion/)

#### 4.1.2 高危HPV与宫颈癌发生

- 典型相关高危型：**16、18**，课件还列31、33、58等。
- 核心病因链：**持续高危型HPV感染 → 部分患者形成高级别癌前病变 → 进一步发生浸润癌**。
- 好发部位：宫颈鳞柱交界附近的**转化区/移行带**。
- 免疫抑制等因素可增加感染持续及进展风险。

| 病毒蛋白 | 主要作用 | 记忆联系 |
| --- | --- | --- |
| E2 | 参与病毒复制调控，抑制E6/E7转录等 | E2调控丧失可使E6/E7表达失控 |
| **E6** | 促进p53降解，削弱细胞周期检查与凋亡 | **E6－p53** |
| **E7** | 使pRb失活，释放细胞周期限制，促进入S期 | **E7－Rb；可伴p16过表达** |
| p16、Ki-67 | 属于宿主标记物，不是HPV病毒蛋白 | p16与异常Rb通路相关，Ki-67反映增殖活动 |

**不要背成必然链**：“慢性宫颈炎一定发展为异型增生再癌变”。持续高危HPV感染才是这里应抓住的主要机制，短暂感染也不等于癌。[NCI：宫颈癌病因及预防](https://www.cancer.gov/types/cervical/causes-risk-prevention)

#### 4.1.3 SIL与CIN对应【必须掌握】

- **SIL**：鳞状上皮内病变，分低级别LSIL、高级别HSIL。
- **CIN**：宫颈上皮内瘤变，传统按异型增生程度分Ⅰ、Ⅱ、Ⅲ级。
- 两套体系的核心区别在分组方式；表中为课程常用对应。

| 传统CIN | 异型细胞累及上皮厚度 | SIL对应 | 基膜 |
| --- | --- | --- | --- |
| CINⅠ，轻度异型增生 | 主要限于下1/3 | **LSIL** | 完整 |
| CINⅡ，中度异型增生 | 达下2/3左右 | **HSIL** | 完整 |
| CINⅢ，重度异型增生及原位癌 | 超过2/3，可达全层 | **HSIL** | 完整 |
| 浸润性鳞癌 | 突破上皮或腺体基膜，进入间质 | 已超出“上皮内”病变范围 | **被突破** |

**识图要点**：随级别升高，细胞成熟、分层及极性逐渐丧失，核异型和异常增殖范围扩大。

**三个容易丢分的点：**

1. HSIL对应CINⅡ和CINⅢ，不能只对应CINⅢ。
2. **原位癌可累及宫颈腺体，但只要相关基膜完整，仍未形成间质浸润。**“累腺”不自动等于“浸润癌”。
3. LSIL常体现HPV感染相关低级别改变，不能理解成必然向癌进展；HSIL的癌前意义更突出。

**挖空细胞（koilocyte）**：核增大、深染、核膜不规则，核周有清亮空晕。提示HPV相关细胞病变，不能单凭它认定已经癌变。

#### 4.1.4 宫颈浸润癌

| 项目 | 复习要点 |
| --- | --- |
| 组织学类型 | 以鳞癌为主，课件约80%；腺癌约15%，另有其他类型 |
| 肉眼 | 糜烂样型、外生菜花型、内生浸润型、溃疡型 |
| 鳞癌镜下 | 异型鳞状上皮细胞突破基膜，在间质中形成浸润性癌巢等；分化好者可见角化及细胞间桥 |
| 临床联系 | 接触性出血、不规则阴道流血 |
| 筛查联系 | HPV检测寻找高危感染，TCT等细胞学寻找异常细胞；确诊与浸润判断需要组织学等依据 |

**扩散路径：**

- **直接蔓延**：向下累及阴道，向两侧累及宫旁及盆壁，可压迫/侵犯输尿管导致肾积水；向前累及膀胱，向后累及直肠。
- **淋巴道转移常见**：宫旁、闭孔、髂内外、髂总等区域淋巴结，进一步扩散至其他站点。
- **血道转移**：晚期可至肺、骨、肝等。

**课件旧标准**：早期浸润癌写为深度≤5 mm且宽度≤7 mm。现行FIGO框架已不以横向7 mm作为IA期分组限制，复习时区分课程旧口径与新版分期。[NCI：宫颈癌分期定义](https://www.cancer.gov/types/cervical/hp/cervical-treatment-pdq)

**预防思考题答题点**：HPV疫苗、规范筛查、异常结果的进一步评估和癌前病变处理。接种疫苗后仍需按适用方案筛查；不在此记忆具体年龄和间隔。[WHO：宫颈癌](https://www.who.int/news-room/fact-sheets/detail/cervical-cancer)

<a id="uterus"></a>
### 4.2 子宫体疾病【重点】

**课件定位：03，第23～39页。**

#### 4.2.1 子宫内膜异位症与子宫腺肌病

共同的病理识别基础是发现**子宫内膜腺体和间质**，关键区别为位置。

| 项目 | 子宫内膜异位症 | 子宫腺肌病 |
| --- | --- | --- |
| 位置 | 子宫内膜及肌层以外的异位部位，典型为卵巢等盆腔部位 | **子宫肌层内**散在内膜腺体和间质 |
| 典型大体 | 卵巢病变可形成巧克力囊肿 | 子宫肌层增厚、子宫增大，肌壁内散在病灶 |
| 机制 | 异位内膜反复出血，陈旧出血积聚 | 肌层内内膜组织周期性变化及周围肌组织反应 |
| 关键词 | **卵巢＋咖啡色黏稠液体** | **肌层＋腺体和间质** |

**巧克力囊肿**：异位子宫内膜反复出血形成囊腔，内含黏稠咖啡色陈旧出血物。

**组织学与周期联系**：病灶也可受性激素影响，因此不能只记囊肿颜色而忽略来源。

#### 4.2.2 子宫内膜增生症

- 主要背景：内源性或外源性雌激素持续作用，尤其缺乏足够孕激素拮抗时。
- 可见于育龄期和围绝经期，以异常子宫出血为临床联系。
- 核心形态：**腺体相对间质增多，腺体拥挤程度增加**。

| 类型 | 腺体/间质关系 | 细胞异型 | 意义 |
| --- | --- | --- | --- |
| 增生不伴非典型性 | 腺体增多，腺间仍有间质 | 无明显非典型性 | 与非典型增生区别 |
| **非典型增生/EIN** | 腺体更拥挤，腺体与间质比例明显升高 | **存在细胞异型** | 是子宫内膜样癌的重要癌前病变 |

**不要把“内膜厚度>10 mm”当作普遍诊断标准。**课件给出的是形态描述，厚度受年龄、周期和检测方式等影响，分类与确诊重在组织学。

#### 4.2.3 子宫内膜癌：课件Ⅰ型与Ⅱ型比较

| 项目 | **Ⅰ型，激素相关型** | **Ⅱ型，非典型雌激素相关型** |
| --- | --- | --- |
| 常见组织类型 | **子宫内膜样癌** | **浆液性癌**；课件另列透明细胞癌 |
| 背景 | 长期雌激素作用、内膜增生/EIN；肥胖、糖尿病等相关 | 常发生于非活动性或萎缩内膜背景 |
| 课件年龄 | 55～65岁较多 | 65～75岁较多 |
| 典型分子联系 | **PTEN失活**等 | 浆液性癌常有**TP53异常** |
| 受体典型趋势 | ER、PR常阳性 | ER、PR常阴性或表达较少，存在变异 |
| p53理解 | 典型低级别内膜样癌多为野生型表达模式 | 浆液性癌常为异常表达模式 |
| 生物学行为 | 常相对较缓和，仍取决于分级和分期 | 浆液性癌较侵袭，易有腹膜扩散和淋巴结转移 |

**内膜样癌的大体与镜下：**

- 弥漫型：内膜弥漫增厚，伴出血、坏死，可浸润肌层。
- 局限型：宫底或宫角等部位形成息肉样、乳头状肿物。
- 镜下：恶性腺体增生、拥挤和结构复杂，伴间质/肌层浸润等恶性证据。
- 课件“腺棘癌”是腺癌伴良性样鳞状分化的传统用语。
- 共同临床联系：**阴道不规则流血，尤其绝经后出血的病例线索**。

**扩散**：直接累及宫颈、输卵管、卵巢或穿过肌层、浆膜至邻近组织；淋巴转移至盆腔及腹主动脉旁等淋巴结；晚期可血行转移至肺、肝、骨。

**校正/补充**：Ⅰ/Ⅱ型是有助复习的传统框架，现代分类还重视POLEmut、MMRd、p53abn、NSMP四类分子特征。p53不宜简单用“阳性＝突变、阴性＝正常”判断，异常也可表现为完全缺失。见[NCI：子宫内膜癌](https://www.cancer.gov/types/uterine/hp/endometrial-treatment-pdq)和[CAP妇科肿瘤标记物规范](https://www.cap.org/wp-content/uploads/protocols/Gynecologic.Bmk_1.3.0.0.REL_CAPCP.pdf?download=true)。

#### 4.2.4 平滑肌瘤与平滑肌肉瘤【重点对比】

| 项目 | **子宫平滑肌瘤** | **子宫平滑肌肉瘤** |
| --- | --- | --- |
| 性质 | 常见良性肿瘤，与性激素等因素有关 | 恶性，多为原发，不是大多数肌瘤的自然结局 |
| 部位 | 黏膜下、肌壁间、浆膜下；可单发或多发 | 子宫肌层等 |
| 大体 | 表面光滑、边界清楚，无真包膜；灰白、质韧，切面**编织状/漩涡状**；可变性、钙化 | 可有出血、坏死，形态常不如良性病变均一 |
| 镜下 | 梭形细胞成束、旋涡状排列，核长杆状、两端钝圆；异型不明显，核分裂少 | **细胞异型、核分裂活跃、肿瘤细胞凝固性坏死**是核心评估项 |
| 临床联系 | 黏膜下或影响宫腔者可引起月经过多、贫血，影响生育 | 局部侵袭及转移风险 |

课件记“≥10个核分裂象/10个高倍视野”等诊断线索，应与异型性、肿瘤细胞坏死等综合判断，不能把单个数字当作所有平滑肌肿瘤的唯一诊断条件。

<a id="gtd"></a>
### 4.3 妊娠滋养细胞疾病【重点】

**课件定位：03，第40～48页。**

#### 4.3.1 总体框架与hCG

- 葡萄胎：包括完全性与部分性，均与异常受精及绒毛改变有关。
- 妊娠滋养细胞肿瘤性疾病（GTN）包括侵袭性葡萄胎、绒毛膜癌等。
- **hCG**是重要线索：与滋养细胞活性有关，可用于病变评估及随访观察。
- 葡萄胎清除后hCG持续异常，提示应考虑持续性病变；不是只观察“子宫是否变小”。

#### 4.3.2 完全性与部分性葡萄胎【补足课件图示】

| 项目 | **完全性葡萄胎** | **部分性葡萄胎** |
| --- | --- | --- |
| 典型受精机制 | 无母系核遗传物质的卵，与精子结合后复制，或与两精子结合 | 正常含母系核遗传物质的卵，获得两套父系遗传物质 |
| 典型核型 | 二倍体，常46,XX，也可46,XY | 三倍体，常69,XXY，也可其他组合 |
| 核基因组来源 | 通常均为父系 | 通常父系2套、母系1套 |
| 绒毛水肿 | 广泛、明显 | 部分绒毛水肿，与相对正常绒毛混杂 |
| 滋养细胞增生 | 较弥漫、可呈环周性 | 较局灶、通常较轻 |
| 胎儿组织 | 通常无 | 可有胎儿/胚胎组织 |
| hCG趋势 | 一般升高更显著 | 常较完全性低，不能仅凭数值分型 |
| **p57** | 绒毛间质及细胞滋养细胞通常**不表达** | 通常**表达** |
| 后续持续性病变风险 | 较高 | 较低，但并非为零 |

**p57原理**：p57是与母系表达有关的细胞周期调节蛋白。典型完全性葡萄胎缺乏母系基因组，因此相关绒毛细胞p57阴性。**p57阳性不能单独区分部分性葡萄胎与普通流产产物。**遗传机制与分类可核对[NCI：妊娠滋养细胞疾病](https://www.cancer.gov/types/gestational-trophoblastic/hp/gtd-treatment-pdq)，p57鉴别意义参见[FIGO滋养细胞疾病报告](https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.13877)。

**普通葡萄胎形态：**

- 大体：胎盘绒毛高度水肿，形成透明/半透明薄壁水泡，成串似葡萄；局限于宫腔，未侵入肌层。
- 镜下：绒毛增大、间质水肿；绒毛血管减少、缺失或功能不良；滋养细胞不同程度增生。
- 典型完全性病例可表现为子宫大于相应妊娠时间、hCG显著增高、无胎儿；**不能把“均无胎儿”推广到部分性葡萄胎**。

#### 4.3.3 葡萄胎、侵袭性葡萄胎、绒毛膜癌【最重要鉴别表】

| 项目 | 葡萄胎 | **侵袭性葡萄胎** | **绒毛膜癌** |
| --- | --- | --- | --- |
| 基本病变 | 水肿绒毛及滋养细胞增生 | 葡萄胎样绒毛侵入肌层/血管 | 高度恶性的滋养细胞肿瘤 |
| 绒毛结构 | **有** | **有，哪怕已变性坏死** | **无** |
| 子宫肌层 | 未侵入 | **侵入** | 可深部侵入 |
| 出血坏死 | 可有 | 常明显 | **极明显** |
| 细胞异型 | 程度可变 | 增生和异型更显著 | 明显，常见细胞滋养细胞及合体滋养细胞混合 |
| 血行播散 | 普通葡萄胎不以播散为特征 | 可累及血管并出现远处病灶 | **早期血行转移突出**，肺等常受累 |
| 妊娠背景 | 异常妊娠 | 常继发于葡萄胎 | 可继发葡萄胎、流产、足月分娩、异位妊娠等 |
| hCG | 常升高 | 清除葡萄胎后仍持续异常 | 常持续或显著升高 |

**回答“最本质区别”时先写：侵袭性葡萄胎保留绒毛，绒毛膜癌不形成绒毛。**二者都可有明显出血坏死，不能仅据出血鉴别。

**绒毛膜癌镜下标准描述：**两种主要滋养细胞成巢状混合增生，异型明显，缺乏绒毛结构，常缺乏自身支持性间质，侵袭血管并伴广泛出血、坏死。

**绒毛膜癌临床联系**：妊娠结束后持续不规则阴道流血、hCG持续异常，也可能以肺或其他器官血行转移表现首先就诊。恶性程度高，但妊娠性绒癌通常对化疗敏感，不能由“高度恶性”直接推导“现代治疗后必然预后差”。

**分类校正**：课件将侵袭性葡萄胎称为“交界性肿瘤”，并把部分远处病灶描述为“非转移”。复习其形态鉴别时保留“有绒毛、侵肌层”，现代分类则将其列入GTN，不能笼统认为不存在转移能力。[NCI：GTD分类](https://www.cancer.gov/types/gestational-trophoblastic/hp/gtd-treatment-pdq)

### 4.4 卵巢肿瘤

**课件定位：03，第49～57页。**

#### 4.4.1 按组织发生分类

| 类别 | 课件近似比例 | 代表肿瘤 | 记忆方向 |
| --- | --- | --- | --- |
| **上皮性肿瘤** | >60% | 浆液性、黏液性肿瘤等 | 囊液、内衬上皮、乳头与浸润 |
| **生殖细胞肿瘤** | 约20% | 畸胎瘤、无性细胞瘤、卵黄囊瘤、胚胎性癌 | 年龄、胚层组织、特征性标记 |
| **性索间质肿瘤** | 约5% | 粒层细胞瘤、卵泡膜细胞瘤、支持－间质细胞瘤 | 激素分泌和性征变化 |

这些比例用于认识常见程度，不是同一研究人群的精确构成比。

#### 4.4.2 浆液性与黏液性肿瘤

| 项目 | **浆液性肿瘤** | **黏液性肿瘤** |
| --- | --- | --- |
| 大体 | 单房或多房囊性肿物，内含清液 | 常较大、多房，含富糖蛋白的黏稠液体 |
| 良性 | 内壁光滑，单层立方/柱状上皮，无明显异型 | 囊壁光滑，单层高柱状黏液上皮 |
| 交界性 | 乳头增多、上皮增生及轻中度异型，缺乏明确破坏性间质浸润 | 上皮增生、乳头和复杂腺体，可有异型，但缺乏明确破坏性浸润 |
| 恶性 | 囊实性、乳头复杂分支，可有出血坏死、明显异型和浸润；可见砂粒体 | 囊实性，复杂腺体、实性癌巢等，伴浸润 |
| 课件分子联系 | 低级别浆液性癌联系KRAS等通路，高级别浆液性癌联系TP53异常 | KRAS改变较常见 |

**交界与恶性的核心区别**：是否存在相应的破坏性间质浸润等恶性结构。课件“2～3层、>3层”的描述是简化形态示例，不能把数上皮层数当作通用诊断规则。

**砂粒体**：层状钙化结构，是浆液性肿瘤的提示性形态之一，不等于单凭它就能确定良恶性。

#### 4.4.3 生殖细胞肿瘤

| 肿瘤 | 形态/性质 | 复习关键词 |
| --- | --- | --- |
| **成熟性畸胎瘤** | 由成熟组织组成，卵巢常见囊性类型，通常良性；可见皮脂、毛发、牙齿，组织来自不同胚层 | **成熟组织＋皮脂毛发牙齿** |
| **不成熟性畸胎瘤** | 含未成熟组织，课件强调原始神经管等；常见于较年轻患者，具有恶性潜能 | **未成熟神经组织** |
| 卵巢甲状腺肿 | 以甲状腺组织为主的单胚层/特化畸胎瘤 | **卵巢内甲状腺组织** |
| **无性细胞瘤** | 原始生殖细胞来源的恶性肿瘤；相当于睾丸精原细胞瘤 | **胎盘碱性磷酸酶PLAP阳性** |
| 胚胎性癌 | 高度恶性，青年患者可见 | 未分化、胚胎性恶性肿瘤 |
| **卵黄囊瘤，内胚窦瘤** | 恶性，年轻患者常见 | 卵黄囊分化；补充联想AFP |

**名称校正**：卵巢“皮样囊肿”通常指**成熟囊性畸胎瘤**，不能因为皮肤和附件突出，就把所有皮样囊肿都归为单胚层畸胎瘤。[NCI：皮样囊肿定义](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/dermoid-cyst)

#### 4.4.4 性索间质肿瘤

| 肿瘤 | 主要激素联系 | 课件性质 | 病理生理联系 |
| --- | --- | --- | --- |
| **粒层细胞瘤** | 雌激素 | 课件称低度恶性 | 雌激素过多可影响子宫内膜，联系内膜增生/癌 |
| **卵泡膜细胞瘤** | 雌激素 | 多为良性 | 也可有雌激素相关表现 |
| **支持－间质细胞瘤** | 雄激素 | 潜在恶性，行为与分化等有关 | 可有男性化表现 |

**跨章节联系**：正常膜细胞、颗粒细胞参与激素合成，因此相应肿瘤可表现为激素过多；看见卵巢肿物伴异常性征，要想到性索间质肿瘤。

### 4.5 前列腺疾病

**课件定位：03，第58～63页；正常组织见01A第43～44页。**

#### 4.5.1 前列腺增生与前列腺癌

| 项目 | **良性前列腺增生BPH** | **前列腺癌** |
| --- | --- | --- |
| 常见部位 | 尿道周围、移行区 | **外周区，后部常见** |
| 机制/来源 | DHT参与腺上皮和间质增生 | 多为腺癌 |
| 大体 | 结节性增大，可明显压迫尿道 | 灰白、质硬，边界不清，切面可有沙粒感 |
| 镜下 | 腺体、平滑肌及纤维组织不同程度增生；腺体可扩张并有皱襞 | 异型小腺体浸润性生长；高分化者细胞异型可不突出，需重视浸润证据 |
| 临床线索 | 排尿困难、尿潴留 | 早期可无典型梗阻；进展后可局部侵犯或转移 |
| 重要提示 | 不是前列腺癌的同义词，也不能把增生必然视作癌前阶段 | **周围神经浸润**等支持恶性；骨转移尤其脊椎是重要线索 |
| PSA | 可因良性等原因升高 | 可升高，但**不能单独凭PSA确诊癌** |

**DHT机制**：睾酮经5α还原酶转化为DHT，后者通过雄激素受体参与前列腺生长。不要把DHT写成“某种基因的表达量”。

**课件BPH五类，按增生成分区分：**

| 类型 | 腺体 | 平滑肌 | 纤维组织 |
| --- | --- | --- | --- |
| 纤维型 | 不突出 | 不突出 | 增多 |
| 纤维肌型 | 不突出 | 增多 | 增多 |
| 平滑肌型 | 不突出 | 增多 | 不突出 |
| 纤维腺瘤型 | 增多 | 不突出 | 增多 |
| **纤维肌腺瘤型，课件最常见** | 增多 | 增多 | 增多 |

#### 4.5.2 Gleason评分：补足课件图

- Gleason关注癌的**组织结构/腺体分化模式**。
- 常用基本理解：主要模式＋第二模式，写成`3＋4＝7`等。实际报告取值需按标本类型及规范执行。
- 分数相同也不一定行为相同：`3＋4＝7`以模式3为主，`4＋3＝7`以模式4为主，后者分级组更高。

| 分级组 Grade Group | 常用Gleason对应 |
| --- | --- |
| 1 | ≤6，常见3＋3＝6 |
| 2 | 3＋4＝7 |
| 3 | 4＋3＝7 |

该表用于理解课件评分示意，来源：[NCI/SEER：前列腺癌分级](https://training.seer.cancer.gov/prostate/cancer-evaluation/grade.html)。不要把“6分”直接理解为一般考试中的“中等水平”。

### 4.6 乳腺癌【重点】

**课件定位：03，第64～75页；正常乳腺见01B第39～41页。**

#### 4.6.1 概况与分类框架

- 课件强调40～60岁多见、外上象限常见、单侧发病较多；这些是典型分布，不能用于排除其他年龄和部位的病例。
- 相关因素：激素暴露、遗传易感等。
- **BRCA1/2参与DNA双链断裂的同源重组修复**。课件另列PALB2、PTEN、TP53等相关基因；注意将遗传易感与肿瘤中的HER2扩增/过表达区分。
- 首先区分**原位病变**与**浸润癌**，再看组织类型、分级、受体与分子相关指标。

| 类别 | 代表类型 | 判断核心 |
| --- | --- | --- |
| 原位病变 | 导管原位癌DCIS、小叶原位癌LCIS | 肿瘤细胞局限于原有导管/小叶系统内，基膜完整 |
| 浸润性癌 | 浸润性癌非特殊型，课件称浸润性导管癌；浸润性小叶癌；其他特殊类型 | 癌细胞突破原有结构基膜，浸润间质 |
| 乳头表皮特殊病变 | 乳腺Paget病 | 乳头、乳晕表皮内出现Paget细胞，常与深部乳腺癌相关 |

#### 4.6.2 DCIS、LCIS与Paget病

| 病变 | 主要部位/镜下 | 关键词 |
| --- | --- | --- |
| **导管原位癌DCIS** | 癌细胞充满导管，基膜未破坏；可有不同结构模式 | **导管内＋基膜完整** |
| **粉刺型DCIS** | 常为高级别；扩张导管内中央癌组织坏死，可有钙化；大体挤压可见黄色软膏样物 | **中央坏死＋粉刺样内容物** |
| **小叶原位癌LCIS** | 小叶末梢导管与腺泡扩张，内充满较小、温和一致的肿瘤细胞；基膜完整 | **小叶腺泡充满均一小细胞** |
| **乳腺Paget病** | 乳头/乳晕表皮内有大而异型、胞质较透明的癌细胞 | **乳头湿疹样改变＋表皮内Paget细胞** |

**微小浸润**：癌细胞已越过基膜，最大单个浸润灶不超过**1 mm**，已不能算纯原位癌。课件写“小于1 mm”，规范常用“≤1 mm”。[NCI/SEER：乳腺微小浸润定义](https://staging.seer.cancer.gov/cs/input/02.05.50/breast/size/)

#### 4.6.3 浸润性癌非特殊型与浸润性小叶癌【对比重点】

| 项目 | **浸润性癌非特殊型，课件称浸润性导管癌** | **浸润性小叶癌** |
| --- | --- | --- |
| 大体 | 无包膜、边界不清、浸润性生长，灰白、质硬，可有沙粒感 | 灰白、橡皮样或柔韧，与周围分界不清 |
| 高分化形态 | 腺样结构明显，细胞较一致，核分裂较少 | 常为小而较一致的细胞 |
| 低分化形态 | 癌细胞成巢、团、索，异型明显，核分裂较多 | 典型为**单行串珠状/列兵式**浸润，也可环绕既有结构 |
| 特征线索 | 腺管或癌巢浸润，伴间质反应 | 细胞黏附差，可见印戒样细胞、胞质黏液空泡 |

**乳腺癌肉眼改变与机制：**

| 表现 | 机制 |
| --- | --- |
| **橘皮样外观** | 淋巴管受阻导致皮肤水肿，毛囊等固定处相对下陷 |
| **乳头回缩/下陷** | 癌相关纤维组织增生、收缩及牵拉 |
| 卫星结节 | 主癌周围浸润性病灶 |
| 皮肤溃疡 | 癌侵犯皮肤，继发坏死、脱落 |

不要把橘皮样外观和乳头回缩都笼统写成“癌细胞堵塞导管”。

#### 4.6.4 扩散与预后因素

- **直接蔓延**：沿导管或组织间隙扩散，可侵犯脂肪、胸大肌及胸壁等。
- **淋巴转移常见**：同侧腋窝淋巴结最重要，也可至锁骨下、锁骨上、乳内等淋巴结。
- **血道转移**：可至肺、肝、骨、脑等。

主要预后信息：肿瘤大小、淋巴结状态、远处转移、组织学类型与分级，以及ER、PR、HER2等生物学特征。HER2相关预后也受靶向治疗等因素影响，不能脱离治疗条件笼统判断。

#### 4.6.5 ER、PR、HER2与Ki-67【重点】

| 指标 | 意义 | 复习联系 |
| --- | --- | --- |
| **ER** | 雌激素受体 | 阳性提示可能存在激素依赖，联系内分泌治疗 |
| **PR** | 孕激素受体 | 与激素通路、分组和预后判断有关 |
| **HER2** | 受体酪氨酸激酶相关蛋白/基因 | 过表达或扩增可提供抗HER2治疗靶点 |
| **Ki-67** | 细胞增殖指标 | 表达较高提示增殖活跃，不能孤立决定全部治疗 |

**课件常用免疫表型分组：**

| 分组 | 课件典型表型 | 课程记忆的治疗关联 |
| --- | --- | --- |
| **腔面A型** | ER＋、PR＋、HER2－，Ki-67较低；课件≤20% | 内分泌治疗相关 |
| **腔面B型，HER2阴性** | ER＋，课件PR＋、HER2－、Ki-67较高；课件>20% | 内分泌治疗，部分病例结合化疗 |
| **腔面B型，HER2阳性** | 激素受体阳性、HER2＋ | 内分泌治疗和抗HER2治疗相关，结合其他治疗 |
| **HER2过表达型，课件分组** | ER－、PR－、HER2＋ | 抗HER2治疗相关 |
| **三阴性** | ER－、PR－、HER2－ | 缺少上述三种常规靶点；课件以化疗为主要关联 |

**理解边界：**

- 上表保留课堂记忆框架，免疫组化替代分组不等同于完整基因表达分型。
- 腔面B型PR可低表达或阴性，不能把“PR一定阳性”作为必要条件。
- **Ki-67的20%是本课件采用的切分方式，不是适用于所有实验室和病例的统一界值。**
- 三阴性并非“现代治疗只能用化疗”；部分病例可有免疫或其他靶向治疗机会。本节只复习标记物与治疗靶点的联系，不列具体方案。[NCI：乳腺癌生物标志物](https://www.cancer.gov/types/breast/diagnosis/breast-cancer-biomarker-tests)

**课件药物关联补记**：HER2可联系曲妥珠单抗（Herceptin）；BRCA1/2相关同源重组修复缺陷可联系PARP抑制剂。这里只记机制与靶点关联，具体适用人群不能仅凭这两个关键词决定。

**精准病理诊断的答题框架**：组织学类型 → 浸润与否 → 组织学分级 → 肿瘤范围和切缘 → 淋巴结状态 → ER/PR/HER2等 → 必要时遗传及其他分子检测。不要只回答“做免疫组化”。

### 5.2 最容易混淆的概念

| 一组概念 | 区分句 |
| --- | --- |
| 精子发生 / 精子形成 | 前者是全过程，后者是精子细胞形态改建；后者不再减数分裂 |
| 精子细胞 / 精子 | 染色体数和DNA相同，形态与功能成熟程度不同 |
| 透明带 / 放射冠 | 透明带是糖蛋白层，放射冠是细胞层 |

### 7.2 简答与综合题

#### 题1：试述精子发生过程

**答题顺序**：地点 → 细胞顺序 → 分裂类型和遗传物质变化 → 精子形成 → 支持细胞配合。

参考要点：发生于生精小管；精原细胞有丝分裂增殖、分化，复制DNA后形成初级精母细胞；减Ⅰ形成次级精母细胞，减Ⅱ形成精子细胞；后者经核浓缩、顶体和尾形成、线粒体重排及胞质脱落而变为精子。一个初级精母细胞一般产生4个精子细胞；支持细胞提供营养、屏障和局部调节。

#### 题2：试述支持细胞的结构和功能

**结构先定位**：生精上皮内，轮廓不清，浅染不规则核、核仁明显；细胞侧面和腔面有凹陷，细胞间紧密连接。

**功能分点**：支持营养、吞噬残余体、精子释放输送、分泌ABP、分泌抑制素、构成血睾屏障。把“结构上的紧密连接”与“屏障功能”对应起来。

#### 题3：结合卵巢变化解释月经周期

**必须把三条线写在一起**：卵泡/黄体 → 雌孕激素 → 内膜。

参考要点：卵泡发育时雌激素增加，内膜修复增生；排卵前持续高雌激素正反馈产生LH高峰，触发排卵；排卵后黄体形成，孕激素作用使内膜进入分泌期；未妊娠时黄体退化，雌孕激素下降，螺旋动脉收缩及组织损伤导致功能层剥脱、月经来潮。

#### 题4：比较CAIS、5α还原酶缺乏和Swyer综合征

**先看子宫，再看睾酮和雄激素作用**：

- CAIS：有睾丸，AMH有效，通常无子宫；T可正常或高，但AR异常，外生殖器女性型，乳房可发育。
- 5α还原酶缺乏：有睾丸，AMH有效；T维持男性内管道，DHT不足使外生殖器男性化不足，青春期可进一步男性化。
- Swyer：性腺为条索状，AMH和T均不足，因此可有子宫，且青春期第二性征通常不足。

#### 题5：SIL、CIN、原位癌与浸润癌是什么关系？

参考要点：LSIL常对应CINⅠ；HSIL对应CINⅡ、Ⅲ；随级别增高，异型细胞占据上皮厚度增加。原位癌可累及全层及腺体，但相关基膜仍完整；一旦突破基膜进入间质，才构成浸润癌。宫颈鳞癌多与高级别上皮内病变相关。

#### 题6：比较葡萄胎、侵袭性葡萄胎和绒癌

按“**绒毛 → 浸润 → 出血坏死 → hCG → 播散**”回答：

- 葡萄胎有水肿绒毛及滋养细胞增生，未侵肌层。
- 侵袭性葡萄胎保留绒毛，但侵入肌层或血管，常伴出血坏死。
- 绒癌无绒毛，由异型滋养细胞组成，出血坏死明显，易血行转移。
- hCG有助病变活动及随访判断，但不能仅凭其数值完成三者的形态学鉴别。

#### 题7：试述浸润性乳腺癌的形态及临床病理联系

参考要点：肉眼灰白、质硬、边界不清、无包膜、浸润性生长；镜下癌细胞成腺管、巢、团或索浸润间质，异型及核分裂随分化程度而变。阻塞淋巴管形成橘皮样水肿，纤维反应牵拉造成乳头回缩，侵犯皮肤可溃疡；常见同侧腋窝淋巴结转移，晚期可血行转移。小叶癌还应写单行串珠状浸润。

#### 题8：乳腺癌病理报告为何要测ER、PR、HER2、Ki-67？

参考要点：形态学提供肿瘤类型、浸润与分级信息；ER/PR评价激素通路，HER2提示相应靶点，Ki-67反映增殖活动。应与分期、淋巴结、切缘及必要的遗传/分子信息结合，完成更完整的预后与治疗相关评估。不能只测标记物而忽略形态与分期。
