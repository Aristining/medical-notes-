一、核心脉络：滤过、回收、调水、调酸

肾单位
├─ 肾小球
│  ├─ 滤过了多少：GFR、清除率、血肌酐、胱抑素C等
│  └─ 漏出了什么：白蛋白及其他较大分子蛋白
├─ 近端肾小管
│  ├─ 回收小分子蛋白、葡萄糖、氨基酸、电解质等
│  └─ 受损：尿α₁-MG、β₂-MG、RBP等增加，尿酶升高
└─ 髓袢、远端小管与集合管
   ├─ 浓缩/稀释：尿比重、尿渗量、自由水清除率
   └─ 酸碱调节：泌H⁺、处理HCO₃⁻，联系肾小管性酸中毒

最重要的区分：滤过率下降与滤过屏障漏蛋白是两类问题；肾功能评估需要同时看功能和损伤证据。

二、肾小球基础：滤过屏障与GFR

对应第 5～13 页。

2.1 滤过屏障

课件从内皮、基膜、足细胞裂隙等结构解释滤过，并强调：

  • 机械屏障与分子大小、形态有关。
  • 电荷相关的选择性影响白蛋白等物质的滤过。
  • 血细胞和大部分血浆蛋白通常不会大量进入原尿。
  • 小分子蛋白可以滤过，其尿中最终排出量还受肾小管回收影响。

2.2 GFR的概念

肾小球滤过率GFR：单位时间内两侧肾脏生成的滤液量。

课件典型值约125 mL/min，约相当于180 L/日的原尿。GFR不是每分钟最终排出的尿量，因为绝大部分原尿会被重吸收。

三、清除率：用尿中排出量反推滤过功能

对应第 14～21 页。

3.1 清除率通式

C = U × V / P

C：清除率，mL/min
U：尿中该物质浓度
P：血浆中该物质浓度，须与U使用相同浓度单位
V：每分钟尿量，mL/min

含义：肾脏每分钟排出的该物质量，相当于多少毫升血浆所含的量。

需要按标准体表面积校正时：

校正清除率 = (U × V / P) × (1.73 / 实际体表面积[m²])

校正后可表示为mL/min/1.73 m²。不要混用校正后的数值和未校正的绝对清除率。

计算最常见错误： 忘记把24小时尿量除以1440换成每分钟尿量；血、尿浓度单位不同；定时尿收集遗漏。

3.2 菊粉清除率

理想滤过标志物需满足：自由通过肾小球，不被肾小管重吸收或分泌，不在体内被明显分解、结合或破坏。

菊粉符合这些特点，因此菊粉清除率可反映GFR，是课件所述的经典参考方法。

课件参考值2.0～2.3 mL/s，换算为120～138 mL/min。基本公式仍是U × V / P，若存在稀释、冲洗等操作，须明确各变量对应的真实体积与浓度。

3.3 内生肌酐清除率Ccr

Ccr = 尿肌酐浓度 × 每分钟尿量 / 血浆肌酐浓度

课件参考范围：80～120 mL/min/1.73 m²。

优点与意义：

  • 无需外源性输入菊粉，可用于评估滤过功能。
  • 在血肌酐尚未明显升高时，滤过功能可能已下降。
  • 帮助评价功能损害、随访变化及部分药物相关决策。

纠正课件的简化： 肌酐除肾小球滤过外还存在肾小管分泌，因此Ccr并不严格等于真实GFR；定时尿收集误差也会影响结果。KDIGO 2024 CKD指南

3.4 课件旧分组，作为课程资料识别

第20页列出的Ccr教学分组：

Ccr 原课件表述
<80 mL/min 肾功能损害
50～80 mL/min 肾功能不全代偿期
25～50 mL/min 失代偿期
<25 mL/min 肾功能衰竭期
<10 mL/min 尿毒症终末期

这些是旧教学分组，不能直接替代现代CKD分期，也不能与AKI分期混用。

第21页“Ccr达到某一值即限蛋白/透析”等表述不作为独立决策规则。现代评估结合eGFR、尿白蛋白和病程；透析启动须综合症状、体征、实验室异常及患者情况。KDIGO：CKD评估与透析时机

四、血中滤过标志物：升高能说明什么

对应第 22～29 页。

指标 来源与肾脏处理 课件参考范围 主要限制
尿素 Urea 蛋白质/氨基酸代谢相关，经肾排泄，受重吸收等影响 1.78～7.14 mmol/L 饮食、分解代谢、肾灌注等影响较多
肌酐 Cr 与肌肉肌酸代谢有关，以滤过排泄为主，另有小管分泌 44～133 μmol/L 肌肉量、饮食、药物等影响；早期损伤可仍在参考范围
尿酸 UA 嘌呤代谢终产物，肾滤过后有复杂转运 课件未统一列范围 生成增加和排泄减少都可升高，并非专一滤过指标
胱抑素C Cys C 多种有核细胞产生，自由滤过后在近端小管摄取分解 0.51～1.09 mg/L 也存在非GFR影响因素，不能认为完全无干扰

4.1 血肌酐正常为什么不一定代表肾功能正常

课件第19页曲线说明血肌酐与GFR并非简单线性关系。早期GFR下降时，血肌酐的绝对变化可能较小；明显升高时，滤过功能往往已受到较明显影响。

应结合基础值、变化速度、尿量和其他检查，而非只看“是否超出参考范围”。

4.2 尿素和肌酐的比较

  • 尿素容易受肾前性因素等影响，因此特异性较差。
  • 两者均不能单独承担早期肾损伤筛查。
  • 课件第25页的“SU/Cr≤10或≥10”没有交代统一单位和换算，不作为可直接计算的通用阈值。
  • 尿素与尿素氮BUN不是同一报告量，不能把尿素/肌酐比与BUN/Cr比任意互换。

4.3 胱抑素C：课程重点与现代解释

课件第38页选择题给出的答案是血清胱抑素C测定，体现本课件对其早期滤过功能评价价值的强调。

补充理解：现代成人CKD评估通常先计算肌酐相关eGFR；条件允许时，肌酐与胱抑素C联合估算可提高准确性。胱抑素C仍会受甲状腺状态、糖皮质激素等因素影响。KDIGO 2024：GFR评估

五、蛋白尿定位：肾小球“漏”还是肾小管“收不回”

对应第 30～47 页。

5.1 肾小球性蛋白尿

滤过屏障受损，使本来不易通过的中、高分子蛋白增加进入尿液。

重点蛋白：白蛋白Alb、转铁蛋白TRF、IgG、IgA、IgM等。

尿中变化 主要理解
尿白蛋白增加 肾小球损伤的重要线索，可用于糖尿病、高血压相关肾损伤等评估
较大分子免疫球蛋白排出增加 提示屏障选择性进一步受损
尿常规蛋白阴性、低水平白蛋白已增多 常规方法的检出限不足以排除早期异常

“微量白蛋白”是尿中白蛋白排出量较小的概念，并不是一种分子量更小的新白蛋白。

5.2 选择性蛋白尿与SPI

  • 选择性较高：主要排出较小的蛋白，大分子IgG相对少。
  • 选择性较差/非选择性：大分子蛋白也明显漏出。
SPI = IgG清除率 / TRF清除率
    = (尿IgG / 血IgG) / (尿TRF / 血TRF)
SPI 课件判读
<0.1 高选择性
0.1～0.2 中度选择性
>0.2 低选择性或非选择性

SPI越高，选择性越差。 它反映通透性异常，但也受小管处理和蛋白电荷等影响，不能单靠SPI区分孔径改变与电荷相关障碍。

5.3 肾病综合征的生化联系

肾小球屏障受损
    ↓
大量蛋白尿
    ↓
低白蛋白血症及相关液体分布变化 → 水肿

伴随肝脏脂蛋白合成及脂代谢改变 → 高脂血症
抗凝相关蛋白丢失等改变 → 高凝状态

记忆主干：大量蛋白尿、低蛋白血症、水肿、高脂血症，并注意血栓风险相关的高凝改变。

5.4 肾小管性蛋白尿

近端小管重吸收障碍，使原本已经滤过的小分子蛋白不能被有效回收，尿中排出增加。

标志物 主要特点 解读重点
尿β₂-微球蛋白 β₂-MG 小分子蛋白，正常滤过后几乎被近端小管回收 升高提示重吸收障碍，但需考虑血中生成量和滤过负荷
尿α₁-微球蛋白 α₁-MG 尿pH对检测稳定性的影响较小 课件强调其早期小管损伤价值
视黄醇结合蛋白 RBP 正常滤过后被近端小管处理 小管重吸收功能线索
尿溶菌酶等 同属低分子蛋白观察对象 需结合全身性生成增多等因素

课件数值：尿β₂-MG<0.3 mg/L或<0.2 mg/g肌酐；尿α₁-MG列<10 mg/g肌酐或10～30 mg/L。浓度与肌酐比是不同表达方式，不能不经换算当作等价数值。

5.5 同一指标在血和尿中的意义可能不同

以β₂-MG为例：

  • 血β₂-MG升高：可来自滤过下降，也可来自生成增加。
  • 尿β₂-MG升高：可来自小管回收受损，也可来自血浓度过高造成滤过负荷增加。
  • 课件提出需同时看血β₂-MG，不能只看尿结果就定位小管损伤。

肾小球性与肾小管性蛋白尿的总对照：

特征 肾小球性 肾小管性
主要机制 屏障通透性异常，漏出增加 小分子蛋白回收减少
主要尿蛋白 Alb、TRF、免疫球蛋白等 α₁-MG、β₂-MG、RBP等
关键问题 “不该大量滤过的漏下来了” “已经滤过的没有收回去”

六、尿酶和其他小管指标

对应第 48～53 页。

指标 主要来源/机制 课件用途
NAG 近端小管细胞溶酶体酶，分子较大，正常不经肾小球大量滤过 早期小管损伤、药物肾毒性、上尿路感染、移植相关损伤辅助监测

组织蛋白酶B 近端小管溶酶体水解酶 课件列为早期损伤的辅助指标

七、浓缩稀释功能：尿比重与尿渗量

对应第 54～60 页。

7.1 基础逻辑

髓质渗透梯度、小管及集合管对水和溶质的处理，共同决定尿液能否浓缩或稀释。受损时可出现夜尿增多、低比重尿，或比重相对固定。

7.2 课件中的尿比重试验

检查 课件重点
3小时尿比重试验 24小时分次留尿，观察尿量分布及比重波动
昼夜尿比重试验/莫氏试验 课件正常24小时尿量1000～2000 mL，昼夜尿量比3～4∶1，12小时夜尿≤750 mL
莫氏试验比重 最高比重>1.020，最高与最低差≥0.009

第57页3小时试验另列“一次>1.025，一次<1.003”的课件要求，与莫氏试验指标分开记忆。

现象 思考方向
少尿伴较高比重 肾脏保水能力仍存在，可联系肾前性因素
夜尿增多、低比重、多尿 浓缩能力下降等
比重长期相对固定约1.010 等渗尿倾向，提示浓缩稀释功能受损

7.3 尿渗量Uosm

尿渗量反映每千克水中渗透活性颗粒的数量，主要取决于颗粒数。 相比尿比重，它较少受单个大分子质量的影响。

课件列禁饮条件下尿渗量600～1000 mOsm/kg H₂O，肾脏可调节范围约40～1400 mOsm/kg H₂O。数值必须结合取样条件解释。

比较 含义
Uosm > Posm 高渗尿，尿已浓缩
Uosm < Posm 低渗尿，尿已稀释
Uosm ≈ Posm 等渗尿

课件尿渗量≈(尿比重−1)×40000为粗略估算，不能替代直接测量。

8.2 自由水清除率CH₂O

CH₂O = V − Cosm
      = V × (1 − Uosm/Posm)
CH₂O 尿液状态 解释
>0 Uosm<Posm，稀释尿 排出的尿可看作“等渗尿量＋额外纯水”
<0 Uosm>Posm，浓缩尿 相对于等渗排泄，肾脏保留了水
=0 Uosm=Posm，等渗尿 尿渗量与血浆相等

计算示例： V＝2 mL/min，Uosm＝150，Posm＝300 mOsm/kg，则Cosm＝1 mL/min，CH₂O＝＋1 mL/min，表示排出自由水，尿液处于稀释状态。

一次CH₂O为0不等于已确诊肾衰竭；应关注在需要调节时是否持续缺乏变化。

九、肾小管性酸中毒RTA

对应第 63～68 页。

主线：泌H⁺障碍或HCO₃⁻重吸收障碍，导致肾脏维持酸碱平衡的能力受损。

类型 课件定位/特点 理解抓手
Ⅰ型 远端泌H⁺障碍 有酸负荷时尿液不能充分酸化
Ⅱ型 近端HCO₃⁻重吸收障碍 碳酸氢盐从尿中丢失
Ⅲ型 近、远端混合障碍的课件分类 作为本课件分类理解
Ⅳ型 代谢性酸中毒伴高钾 突出血钾升高

课件的功能试验原理：

  • 氯化铵负荷试验：考察酸负荷后尿液能否充分酸化，帮助评价远端泌酸能力。
  • 碳酸氢盐重吸收/排泄试验：考察近端对HCO₃⁻的回收能力。

辨析： Ⅱ型RTA并不意味着任何时点尿液都呈碱性，尿pH与当时血HCO₃⁻及滤过负荷有关。复习重点是病变环节及试验原理。

10.1 按临床问题选项目

问题 主要检查方向
是否有肾脏损伤线索 尿常规、沉渣、尿蛋白及白蛋白相关检测
滤过功能如何 血肌酐、Cys C、eGFR，必要时相应清除率/测定GFR

是否为近端小管损伤 低分子蛋白、尿酶，联系尿糖/氨基酸等
浓缩稀释能力如何 尿比重、尿/血渗量、Cosm、CH₂O
是否有酸碱调节障碍 血气、电解质、尿液相关检查，必要时功能试验
肾血流评估 课件列PAH清除试验，与GFR不是同一问题

10.2 14岁男孩病例：如何建立检查思路

课件信息：咽部不适后出现眼睑和下肢水肿、红色尿、持续少尿，每日尿量约130～150 mL。

  1. 水肿、血尿、少尿共同提示应重点评估肾脏，尤其肾小球疾病及急性肾功能受损。
  2. 尿常规和沉渣：确认红细胞、蛋白、管型等，判断红色尿的性质及肾源性线索。
  3. 血肌酐、尿素、电解质、酸碱状态：评价功能受损与并发异常。
  4. 血清蛋白、尿蛋白定量/相应比值：评价蛋白丢失和水肿背景。
  5. 若考虑感染相关肾炎，结合病史选择补体、链球菌感染相关证据等进一步检查。

课件未提供实际实验室结果，不能虚构结果后直接确诊链球菌感染后肾炎。

十一、复习提纲

11.1 建议优先记住

  • GFR：两肾每分钟形成多少滤液，不能与终尿量混淆。
  • 清除率：C＝UV/P，先统一单位再计算。
  • 菊粉：理想滤过标志物的经典例子。
  • 肌酐：正常不排除早期异常，Ccr也不严格等于GFR。
  • 尿白蛋白、TRF、较大分子Ig：联系肾小球屏障。
  • 尿α₁-MG、β₂-MG、RBP：联系近端小管回收。
  • 尿NAG：联系小管细胞损伤。
  • SPI高：选择性差。
  • 尿渗量看浓缩稀释；CH₂O正为排自由水、负为保水。
  • RTA：Ⅰ型远端泌酸，Ⅱ型近端丢碱，Ⅳ型突出高钾。
