本章为上海交通大学医学院《呼吸系统》整合课程病理生理学部分的"缺氧"章（课件章名为第五章），授课教师黄莺；笔记依据课件《04 缺氧.pdf》（共 66 页，正文 P2–P63）整理，文中页码均标注为"课件 Pxx"。缺氧是贯穿呼吸、循环、血液、中毒等多章节的核心病理过程，主线为"供氧不足或用氧障碍 → 血氧指标改变 → 四型缺氧 → 代偿与损伤 → 氧疗"。

一、本章知识框架

  • 缺氧概念与常用血氧指标
    • 缺氧：组织供氧不足或用氧障碍引起的病理过程
    • 六项指标：PO2、CO2max、CO2、SO2、P50、动-静脉血氧含量差（A-VdO2）
  • 缺氧的类型、原因和机制（四种单纯性缺氧）
    • 低张性缺氧：吸入气 PO2↓／外呼吸功能障碍／静脉血分流入动脉
    • 血液性缺氧：贫血／CO 中毒／高铁血红蛋白血症／Hb 与 O2 亲和力↑
    • 循环性缺氧：缺血性／淤血性（休克、心衰、血栓）
    • 组织性缺氧：呼吸链抑制／呼吸酶合成↓／线粒体损伤／组织水肿
    • 四型血氧变化总表、多种缺氧并存、hypoxia 与 hypoxemia 之辨
  • 缺氧时细胞的反应
    • 代偿：用氧能力↑、肌红蛋白↑、糖酵解↑、低代谢状态；HIF-1 氧感受机制
    • 损伤：细胞膜离子紊乱、线粒体损伤、溶酶体破裂
  • 缺氧时器官系统的功能代谢变化
    • 代偿：低氧通气反应／心输出量↑、血液重分布、肺血管收缩／RBC↑、2,3-DPG↑
    • 失代偿：呼吸衰竭、急性肺水肿／肺动脉高压、心力衰竭／微循环障碍／意识障碍
  • 机体对缺氧的耐受性与氧疗
    • 去除病因、氧疗（低张性最有效）、防止氧中毒

二、分节知识点

第一节 缺氧概念与常用血氧指标

1. 缺氧的概念：因组织供氧不足或用氧障碍，导致机体代谢、功能和形态结构异常变化的病理过程称为缺氧（hypoxia）；也存在于高原、高空、坑道等特殊环境；严重缺氧可危及生命。核心环节：O2 delivery 减少或 O2 utilization 障碍 → 细胞 ATP 生成改变 → 代谢、功能、结构变化（课件 P5）。临床分析线索：病史（分析病因）、症状体征、血气指标；血气分析与指脉氧检测仪为常用检测手段（课件 P6–P7）。

2. 常用血氧指标汇总（课件 P8–P9）：

指标 英文 定义 正常值 主要影响因素
血氧分压（PO2） partial pressure of oxygen 物理溶解于血液中的氧所产生的张力 动脉血 100 mmHg；静脉血 40 mmHg 动脉血：吸入气氧分压、外呼吸功能；静脉血：内呼吸状态
血氧容量（CO2max） oxygen binding capacity 100 ml 血液中血红蛋白完全氧合后的最大带氧量 20 ml/dl Hb 的量、Hb 与氧的结合能力
血氧含量（CO2） oxygen content 100 ml 血液中实际含有的氧量 动脉血 19 ml/dl；静脉血 14 ml/dl 血氧分压、血氧容量
血氧饱和度（SO2） oxygen saturation Hb 结合氧的百分数，约等于血氧含量/血氧容量 动脉血 93%–98%；静脉血 70%–75% 主要取决于 PO2；也与 pH、温度、CO2 分压、2,3-DPG 有关
P50 P50 血氧饱和度为 50% 时的血氧分压 26–27 mmHg Hb 的质；pH、温度、CO2 分压、2,3-DPG
动-静脉血氧含量差（A-VdO2） arteriovenous blood oxygen difference CaO2 − CvO2，反映组织摄氧与用氧 约 5 ml/dl（19 − 14） 组织代谢率、血流速度、HbO2 释氧能力（见下临床意义）

3. 指标间关系（课件 P10）：PaO2 决定 SO2（二者≈平行变化）；CO2 由 CO2max 与 SO2 共同决定（CO2 ≈ CO2max × SO2 加物理溶解氧）。

4. 各指标变化的临床意义（课件 P11）：

  • PaO2 降低：吸入气氧分压过低；肺通气（换气）障碍致肺功能明显降低；可引起 SaO2、CaO2 降低。PaO2 升高：吸入纯氧或高压氧治疗。
  • PvO2 降低：组织部位血流明显减慢；PvO2 升高：组织细胞用氧障碍、或组织部位血液释放 O2 减少。
  • CO2max 降低：严重贫血、Hb 变性（可引起 CaO2 降低而 SaO2 正常）；CO2max 升高：红细胞增多症、血液浓缩。
  • SaO2 降低：各种原因引起 PaO2 明显降低时；可引起 CaO2 降低。
  • CaO2 降低：即低氧血症（hypoxemia），见于 PaO2 和（或）CO2max 明显降低。
  • A-VdO2 减小：主要见于组织性缺氧（组织利用 O2 障碍致 CvO2 明显增加）；也见于低张性或血液性缺氧中 HbO2 释放 O2 能力降低时。A-VdO2 增大：见于循环性缺氧（血流明显减慢，组织从单位容量血液中摄 O2 增多，CvO2 减少）。
  • P50 变小：遗传性 Hb 分子异常或严重碱中毒，氧离曲线左移，肺摄 O2 增多而组织释放 O2 明显减少；P50 增大：严重高碳酸血症和代谢性酸中毒，氧离曲线右移。

5. 组织供氧与耗氧（课件 P12）：组织供氧量 = 动脉血氧含量 × 组织血流量；组织耗氧量 =（动脉血氧含量 − 静脉血氧含量）× 组织血流量。决定组织供氧的三个关键因素：①组织血液灌流量；②血液 Hb 的含量与性质；③PaO2。

第二节 缺氧的类型、原因和机制

分类依据（课件 P14、P41–P42）：按氧供应链四个环节分类——大气氧→①吸入肺泡、弥散入血液障碍→低张性缺氧；②与血红蛋白结合障碍→血液性缺氧；③气体在血液中运输（血液循环）障碍→循环性缺氧；④组织细胞摄取、利用障碍→组织性缺氧。前三型属"供氧不足"，组织性缺氧属"用氧障碍"（课件 P42）。

（一）低张性缺氧（hypotonic hypoxia / hypoxic hypoxia，乏氧性缺氧）

概念（课件 P15）：以动脉血氧分压（PaO2）降低、血氧含量（CaO2）减少为基本特征，对组织供氧不足的缺氧，称低张性缺氧或乏氧性缺氧。

病因与发生机制（课件 P16–P19）：

  1. 吸入气氧分压过低：大气性缺氧（atmospheric hypoxia）、高原性缺氧（high altitude hypoxia）。海拔越高，大气压、PiO2、PAO2、SaO2 依次下降（课件 P17）：

  1. 外呼吸功能障碍：肺通气、换气功能障碍→呼吸性缺氧（respiratory hypoxia）。
  2. 静脉血分流入动脉：右向左分流，如法洛氏四联症（Tetralogy of Fallot），临床表现为发绀、呼吸困难、缺氧性发作、蹲踞。

缺氧机制：PaO2 与 CaO2 过低→氧弥散速度减慢→细胞缺氧。

皮肤黏膜颜色（课件 P21–P22）：发绀（cyanosis）——毛细血管血液中脱氧 Hb（HHb）平均浓度达到或超过 5 g/dL（正常≤2.6 g/dL）时，皮肤黏膜呈青紫色。慢性缺氧可见杵状指（clubbing digits）。

临床举例：高原反应/大气性缺氧、慢性肺疾病外呼吸功能障碍、法洛氏四联症。

临床联系： 高原反应——快速进入海拔 3000 m 以上时 PiO2、PAO2 下降，SaO2 降至约 90%（3000 m）、75%（5000 m），发生低张性缺氧，机体以低氧通气反应、红细胞增多等代偿（课件 P17、P58）；法洛氏四联症因静脉血右向左分流入动脉， PaO2、SaO2 降低并出现发绀、蹲踞等（课件 P19）。

（二）血液性缺氧（hemic hypoxia / isotonic hypoxia，等张性缺氧）

概念（课件 P24）：由于 Hb 含量减少或性质改变，导致血液携带氧的能力降低或氧合血红蛋白不易释出结合的氧，引起组织供氧不足；因物理溶解氧不变、PaO2 正常，又称等张性缺氧。

病因与发生机制（课件 P25–P28）：

  1. 贫血：贫血性缺氧（anemic hypoxia），Hb 量↓→CO2max↓。
  2. 一氧化碳中毒：生成碳氧血红蛋白（HbCO）。机制：①CO 与 Hb 亲和力高；②HbCO 失去携带氧气的能力；③增加其余 Hb 与 O2 的亲和力（释氧困难）；④抑制 2,3-DPG 的产生（氧离曲线左移）。HbCO 增至 10%–20% 出现头痛、乏力、眩晕、恶心呕吐；增至 50% 迅速出现痉挛、呼吸困难、昏迷甚至死亡。
  3. 高铁血红蛋白血症（HbFe3+OH，methemoglobin）：①Fe3+ 与羟基牢固结合，失去携氧能力；②剩余 Fe2+ 与 O2 亲和力增强，氧离曲线左移。遗传性者如 HbM（Boston）α58 组氨酸→酪氨酸。肠源性紫绀（enterogenous cyanosis）：食用含大量硝酸盐的腌菜等→肠道细菌作用下生成亚硝酸盐→吸收入血→HbFe3+OH 达到 1.5 g/dL→发绀和明显缺氧症状。
  4. 血红蛋白与氧的亲和力异常增强：血红蛋白病，如 Hb Bristol（β67 缬→天冬氨酸）；Hb 不易释放氧。

血氧变化特点（课件 P29、P43）：

PaO2 SaO2 CO2max CaO2 A-VdO2 CvO2
N N（严重贫血）或 N/↓（HbCO、HbFe3+OH） ↓（贫血、HbCO、MetHb）；亲和力↑型 N ↓（亲和力↑型 N） ↓ HbCO、MetHb 相对↑；亲和力↑型↑

注意：Hb 与氧亲和力增强时，CO2max 和 CaO2 都正常。组织缺氧机制：Hb 携 O2 量减少、供 O2 能力减弱；或 Hb 与 O2 亲和力异常增高、不易释放氧。

皮肤黏膜颜色（课件 P30）：贫血——皮肤黏膜较苍白；HbCO——樱桃红色；HbFe3+OH——棕褐色（咖啡色、深棕色），明显紫绀；Hb 与 O2 亲和力增高——鲜红色。

临床举例：各种严重贫血、CO 中毒、亚硝酸盐（腌菜）中毒、血红蛋白病。

临床联系： CO 中毒见于火灾、燃气泄漏，皮肤樱桃红色为其特征，HbCO 50% 可致死；亚硝酸盐中毒即肠源性紫绀，腌菜腌制不当硝酸盐被还原为亚硝酸盐，HbFe3+OH 达 1.5 g/dL 即出现发绀（课件 P26、P28）。

（三）循环性缺氧（circulatory hypoxia / hypokinetic hypoxia，低动力性缺氧）

概念（课件 P32）：由于组织血流量减少使组织供氧减少所引起的缺氧；可分为缺血性缺氧（ischemic hypoxia）和淤血性缺氧（congestive hypoxia）。

病因与发生机制（课件 P33）：全身性循环性缺氧：休克、心衰（酸中毒）；局部性循环性缺氧：动脉硬化、血管炎、血栓等。

血氧变化特点（课件 P34、P43）：

PaO2 SaO2 CO2max CaO2 A-VdO2 CvO2
N N N N ↑（淤血性）；N（缺血性） ↓（淤血性）

注意：左心衰竭（肺水肿）、休克（ARDS）时可合并 PaO2↓、SaO2↓、CaO2↓。组织缺氧机制：淤血造成血流减慢，单位时间内流经组织细胞的血流量减少，同时单位容积血液弥散给组织的氧量相对较多。

皮肤黏膜颜色（课件 P35）：动脉缺血——皮肤苍白；静脉淤血——容易引起紫绀。

临床举例：休克、心力衰竭（全身性）；动脉硬化、血管炎、血栓致局部缺血。

临床联系： 休克是循环性缺氧的典型，且失血性休克可同时并存四型缺氧：失血 Hb↓→血液性；循环障碍→循环性；肺淤血、水肿→低张性；内毒素血症→组织性（课件 P44）。

（四）组织性缺氧（histogenous hypoxia / dysoxidative hypoxia，氧利用障碍性缺氧）

概念（课件 P37）：在组织供氧正常的情况下，因组织、细胞利用氧的能力减弱所引起的缺氧；又称氧利用障碍性缺氧；其中毒物抑制呼吸链者称组织中毒性缺氧（histotoxic hypoxia）。

病因与发生机制（课件 P38，呼吸链及氧化磷酸化抑制剂作用环节）：

  1. 药物、毒物抑制线粒体氧化磷酸化：
    • NADH→FMN 环节：鱼藤酮、巴比妥、胍乙啶；
    • CoQ→cyt b→cyt c1→cyt c 环节：抗霉素 A、苯乙双胍（ phenformin 类）、8-氢-羟基喹啉、萘醌；
    • cyt aa3→O2 环节：氰化物、一氧化碳、硫化氢、叠氮化合物；CN- 与 Cytaa3 的 Fe3+ 结合生成 Cytaa3Fe3+-CN-，中断呼吸链。
  2. 呼吸酶合成减少：维生素 B1、B2、PP 等缺乏。
  3. 线粒体损伤：放射线、细菌毒素、尿毒症。
  4. 组织水肿：增加氧弥散距离。

血氧变化特点（课件 P39、P43）：

PaO2 SaO2 CO2max CaO2 A-VdO2 CvO2
N N N N ↓（↓↓） ↑↑

组织缺氧机制：组织细胞利用氧障碍，静脉血中氧剩余增多。

皮肤黏膜颜色（课件 P40）：皮肤黏膜色泽较红润（鲜红色）；死于氰化物中毒者面容如入睡者相仿。

临床举例：氰化物中毒、硫化氢中毒、维生素缺乏、尿毒症线粒体损伤。

临床联系： 氰化物中毒时氧供完全正常但细胞"用氧不能"，CvO2↑↑、A-VdO2↓↓、皮肤鲜红；治疗关键是解除呼吸链酶的抑制（课件 P38–P40、P61）。

多种缺氧类型并存与概念辨析（课件 P44–P46）

  • 失血性休克四型并存：失血 Hb↓→血液性缺氧；循环障碍→循环性缺氧；肺淤血、水肿→低张性缺氧；内毒素血症→组织性缺氧。
  • hypoxia 与 hypoxemia（课件 P46）：hypoxemia 指动脉血氧含量低于正常；hypoxia 指组织供氧不足。低氧血症可以是组织缺氧的原因，但二者不一定共存（课件设问 Q2）。
  • "快乐缺氧"（happy hypoxia，Science 2020 年 5 月）：COVID-19 患者血氧饱和度明显降低却无呼吸困难主诉的现象（课件 P45）。

第三节 缺氧时细胞的反应

1. 代偿性变化（课件 P48）：

  • 细胞对氧利用能力增强：线粒体数目增多、呼吸酶活性增强；
  • 肌红蛋白增加：与氧的亲和力高（肌红蛋白氧解离曲线位于血红蛋白左侧，低 PO2 下仍能结合氧）；
  • 糖酵解增强；
  • 低代谢状态：合成代谢减少、离子泵功能抑制（减少耗氧）。

2. 代偿的分子机制：HIF-1 氧感受（课件 P49–P50）：

  • 正常氧：脯氨酰-4-羟化酶（prolyl-4-hydroxylase，需 Fe2+ 和 O2）使 HIF-1α 的 Pro564/402 羟化→VHL 蛋白（Von Hippel-Lindau 产物，E3 泛素连接酶）识别并加泛素信号→蛋白酶体（proteasome）降解；天冬酰胺羟化酶（Asn803）同时抑制 HIF-1 转录活性。
  • 低氧：羟化酶受抑制→HIF-1α 不被羟化而稳定→入核与 ARNT 结合成活性转录因子→激活靶基因：无氧糖酵解酶类、促红细胞生成素合成、血管生成（VEGF）等。
  • HIF-1 调控的缺氧代偿反应（课件 P50）：代谢酶类→糖酵解增强；血管内皮→毛细血管增生；肺血管→肺血管收缩；特定氧感受细胞→红细胞增多；颈动脉体→肺通气增加、循环代偿。
  • 2019 年诺贝尔生理学或医学奖授予 Kaelin、Ratcliffe、Semenza，表彰其发现细胞如何感受和适应氧 availability（课件 P51）；HIF-1 发现里程碑及 HIF 通路药物（如罗沙司他）为自学内容（课件 P52）。

3. 损伤性变化（课件 P53–P55）：

  • 细胞膜变化：缺氧致 ATP 减少、膜对离子通透性增高。Na+ 内流（钠泵功能障碍）→细胞水肿、线粒体肿胀、溶酶体肿胀；K+ 外流→合成代谢障碍、各种酶代谢障碍、加重能量代谢障碍；Ca2+ 内流→进入线粒体使其功能障碍、与钙调蛋白激活磷脂酶使膜磷脂分解、自由基生成增加。
  • 线粒体变化：轻度缺氧线粒体功能增强；严重缺氧线粒体损伤、ATP 减少。损伤机制：氧化应激（ROS 生成、膜脂质过氧化、膜结构破坏）；供氧障碍；线粒体用氧障碍（呼吸链中断）；钙稳态紊乱（钙超载抑制氧化磷酸化）。
  • 溶酶体变化：溶酶体肿胀、破裂、释出大量溶酶体酶→细胞及其周围组织溶解、坏死。

第四节 缺氧时器官系统的功能代谢变化

总规律与耐受性（课件 P57）：缺氧对机体的影响主要取决于缺氧发生的速度、程度、部位、持续时间以及机体本身的功能代谢状况；急性严重缺氧以损伤为主；慢性轻度缺氧以代偿性变化为主（提高组织细胞供氧量和利用氧能力）。耐受性影响因素：代谢耗氧率和中枢神经系统功能、年龄、机体健康状况、锻炼适应状况等。

各系统代偿与失代偿（课件 P58）：

呼吸系统 低氧通气反应、呼吸运动增强、回心血量↑ 呼吸抑制、呼吸衰竭、急性肺水肿

缺氧时红细胞 2,3-DPG 增多的机制（自学）（课件 P59）：糖酵解中 1,3-二磷酸甘油酸经 DPGM（二磷酸甘油酸变位酶）生成 2,3-DPG；2,3-DPG 经 DPGP（2,3-DPG 磷酸酶）分解为 3-磷酸甘油酸/2-磷酸甘油酸；缺氧时糖酵解增强、pH 增高激活磷酸果糖激酶，使 2,3-DPG 生成增多。2,3-DPG↑使 Hb 与 O2 亲和力下降、氧离曲线右移（P50↑），利于 HbO2 向组织释氧（串联课件 P8、P11）。

第五节 缺氧治疗的病理生理学基础

治疗原则（课件 P61）：

  • 去除病因；
  • 氧疗：低张性缺氧最有效；血液性和循环性缺氧主要靠提高血液物理溶解的氧；组织性缺氧治疗关键是解除呼吸链酶的抑制；
  • 防止氧中毒。

氧中毒（课件 P62）：吸入气氧分压过高或长时间吸入高浓度氧，可引起细胞损害、器官功能障碍。基本机制：产生大量氧自由基和活性氧，导致组织细胞损伤。类型：脑型氧中毒、肺型氧中毒、新生儿吸入高浓度氧导致视网膜损害。

五、高频考点与记忆口诀

  • ★课件标星考点：四种单纯性缺氧的血气指标原发性变化（课件 P43）——低张性看 PaO2↓、SaO2↓；血液性看 CO2max↓（或 CvO2 相对↑）；循环性淤血看 CvO2↓、A-VdO2↑；组织性看 CvO2↑↑、A-VdO2↓↓。
  • 发绀≠缺氧：发绀条件（脱氧 Hb≥5 g/dL）与三类"缺氧不发绀"例外（贫血、CO 中毒、组织性缺氧）。
  • A-VdO2 增大只见于循环性（淤血）；减小见于组织性缺氧及 HbO2 释氧能力降低时。
  • CO 中毒四机制与樱桃红色；亚硝酸盐→肠源性紫绀（咖啡色）；氰化物→鲜红色、面容如入睡。
  • P50 与氧离曲线：↑=右移（酸中毒、高碳酸血症、2,3-DPG↑）；↓=左移（碱中毒、HbCO、MetHb、Hb 亲和力↑）。
  • HIF-1 氧感受通路：常氧"羟化-泛素化-蛋白酶体降解"，低氧"稳定-入核-转录"（糖酵解酶、EPO、VEGF）；2019 年诺贝尔奖。
  • 慢性缺氧四系统代偿/失代偿（课件 P58 表）与肺动脉高压因果链：肺血管持续收缩＋RBC↑↑→血粘度↑↑→阻力↑↑→肺动脉高压→心衰。
  • 呼吸链抑制剂作用部位：头（鱼藤酮、巴比妥、胍乙啶）、中（抗霉素 A、苯乙双胍、8-氢-羟基喹啉、萘醌）、尾（氰化物、CO、硫化氢、叠氮化合物）。
  • 氧疗原则：低张性最有效；血液性、循环性靠物理溶解氧；组织性关键在解除呼吸链酶抑制；警惕氧中毒。
  • hypoxia 与 hypoxemia 不一定共存；"快乐缺氧"现象（Science 2020）。
  • 口诀（自编口诀）："低张压饱含都降，容量正常动静小；血液压正常容量低，亲和增高容量保；循环四指标皆正常，唯见淤血动静高；组织静含升升动静降，皮肤红润睡容貌。"（四型缺氧血氧特点）
  • 口诀（自编口诀）："脱氧五克发绀现，贫血一氧化碳难见绀；增多发绀未必缺氧，绀与缺氧细分辨。"（发绀与缺氧关系）
  • 口诀（自编口诀）："一氧化碳四招凶：抢位亲和高、携氧落空、锁氧不放、DPG 被抑释氧难；皮肤樱桃红。"（CO 中毒机制）
  • 口诀（自编口诀）："常氧羟化 VHL 接，泛素体里送它走；低氧羟酶全歇业，HIF 入核救急筹。"（HIF-1 氧感受）
  • 口诀（自编口诀）："鱼藤巴比妥堵头，抗霉素醌堵中游，氰硫叠氮堵尾口，细胞色素氧化酶休。"（呼吸链抑制剂部位）

六、自测题

  1. 写出 P50 与动-静脉血氧含量差的定义和正常值；P50 增大伴氧离曲线右移见于哪些情况？ 答：P50 为血氧饱和度 50% 时的血氧分压，正常 26–27 mmHg；A-VdO2 = CaO2 − CvO2，约 5 ml/dl。P50 增大、曲线右移见于严重高碳酸血症和代谢性酸中毒（2,3-DPG 增多时亦右移），Hb 与 O2 亲和力下降、利于组织释氧。（课件 P8、P11）

  2. 氧疗对哪型缺氧最有效？为什么组织性缺氧氧疗效果有限？ 答：低张性缺氧最有效（可提高 PaO2、SaO2）；血液性和循环性缺氧氧疗主要提高血液物理溶解的氧；组织性缺氧是用氧障碍，治疗关键是解除呼吸链酶的抑制，单纯提高氧供不能解决利用障碍。（课件 P61）

  3. 病例：男性，慢性咳喘 10 年。血气：PaO2 62 mmHg↓、SaO2 90%↓、CO2max 正常、CaO2↓、A-VdO2 正常偏低。判断缺氧类型并说明依据。 答：低张性缺氧。原发性变化为 PaO2↓、SaO2↓、CaO2↓而 CO2max 正常，符合外呼吸功能障碍所致乏氧性缺氧的特点。（课件 P20、P43）

  4. 病例：女性，月经过多致贫血，Hb 60 g/L。PaO2 98 mmHg 正常、SaO2 正常、CO2max↓、CaO2↓、A-VdO2↓。判断类型；为何其皮肤苍白而多无发绀？ 答：血液性缺氧（贫血性）。PaO2、SaO2 正常而 CO2max↓为其特点。严重贫血 Hb 总量少，毛细血管脱氧 Hb 难以达到 5 g/dL，故一般不出现发绀而表现为苍白。（课件 P21、P29、P43）

  5. 病例：某患者进食大量腌制不当的腌菜后口唇青紫。查：PaO2 正常、SaO2 N/↓、CO2max↓、CaO2↓、A-VdO2↓，血液呈棕褐色（咖啡色）。判断类型并述机制。 答：血液性缺氧之高铁血红蛋白血症（肠源性紫绀）。硝酸盐经肠道细菌还原为亚硝酸盐吸收入血，使 HbFe2+ 氧化为 Fe3+；HbFe3+OH 失去携氧能力且剩余 Fe2+ 与 O2 亲和力增强、氧离曲线左移；HbFe3+OH 达 1.5 g/dL 即出现发绀。（课件 P25、P27、P28）

  6. 病例：感染性休克患者四肢湿冷、尿少。PaO2、SaO2、CO2max、CaO2 均正常，A-VdO2↑、CvO2↓。判断类型并解释 A-VdO2 增大的机制。 答：循环性缺氧（全身性、淤血/缺血兼有）。血流减慢使单位时间流经组织的血量减少，组织从单位容积血液中摄取的 O2 相对增多，故 CvO2↓、A-VdO2↑。（课件 P33、P34、P43）

  7. 病例：某工人吸入含氰化物气体后昏迷，皮肤鲜红。PaO2、SaO2、CO2max、CaO2 均正常，A-VdO2↓↓、CvO2↑↑。判断类型并述机制与治疗关键。 答：组织性缺氧（组织中毒性）。CN- 与细胞色素氧化酶（Cytaa3）的 Fe3+ 结合生成 Cytaa3Fe3+-CN-，呼吸链中断，细胞用氧障碍，静脉血氧剩余增多故 CvO2↑↑、A-VdO2↓↓、皮肤鲜红；治疗关键是解除呼吸链酶的抑制。（课件 P38–P40、P61）

  8. 为什么"缺氧≠紫绀"？举出缺氧而无发绀的两种情况；发绀是否一定有缺氧？ 答：发绀取决于毛细血管脱氧 Hb≥5 g/dL。严重贫血 Hb 总量少、CO 中毒 HbCO 呈樱桃红、组织性缺氧 HbO2 偏高，均可缺氧而不发绀；反之红细胞增多症 Hb 总量多、脱氧 Hb 易≥5 g/dL，可发绀而缺氧不明显。故二者不能等同。（课件 P11、P21、P30）

  9. 列出 CO 中毒引起缺氧的四个机制，并指出其特征性肤色。 答：①CO 与 Hb 亲和力高；②HbCO 失去携带氧气的能力；③增加其余 Hb 与 O2 的亲和力、释氧困难；④抑制 2,3-DPG 的产生（氧离曲线左移）。特征性肤色为樱桃红色。（课件 P26、P30）

  10. 简述常氧与低氧时 HIF-1α 的不同命运及其主要靶基因产物。 答：常氧：脯氨酰-4-羟化酶（需 Fe2+、O2）羟化 HIF-1α 的 Pro564/402→VHL（E3 泛素连接酶）识别加泛素→蛋白酶体降解，且天冬酰胺羟化酶（Asn803）抑制其转录；低氧：羟化受抑→HIF-1α 稳定入核，与 ARNT 形成活性转录因子→激活无氧糖酵解酶类、促红细胞生成素、VEGF（血管生成）等基因。（课件 P49）

  11. 比较慢性缺氧时呼吸、循环、血液、神经系统的代偿与失代偿变化，并写出慢性缺氧性肺动脉高压的因果链。 答：代偿：呼吸——低氧通气反应、呼吸运动增强、回心血量↑；循环——心输出量↑、血液重分布、肺血管收缩；血液——RBC↑、Hb↑、2,3-DPG↑；神经对缺氧极为敏感。失代偿：呼吸抑制、呼吸衰竭、急性肺水肿；心律失常、心动过缓、肺动脉高压、心力衰竭；RBC↑↑、血粘度↑↑、血流阻力↑↑、微循环障碍；功能紊乱直至意识障碍、惊厥、昏迷。因果链：慢性缺氧→肺血管持续收缩＋RBC↑↑→血液粘度↑↑→血流阻力↑↑→肺动脉高压→心力衰竭。（课件 P58）

  12. 慢性缺氧引起红细胞生成增多，对机体有何利弊？ 答：利：RBC、Hb 增多使 CO2max 增大、携氧供氧增加，属血液代偿；弊：RBC 过多使血液粘度↑↑、血流阻力↑↑，引起微循环障碍、加重心脏负荷并参与肺动脉高压形成。（课件 P58）

  13. 举例说明 hypoxia 与 hypoxemia 不一定共存。 答：hypoxemia 指动脉血氧含量低于正常。组织性缺氧与单纯循环性缺氧时 CaO2 正常，无低氧血症却存在组织缺氧；反之轻度低氧血症若代偿充分，也可暂无明显组织缺氧。（课件 P46）

  14. 氧中毒的基本机制与类型有哪些？ 答：机制：吸入气氧分压过高或长时间吸高浓度氧→产生大量氧自由基和活性氧→组织细胞损伤。类型：脑型氧中毒、肺型氧中毒、新生儿吸入高浓度氧致视网膜损害。（课件 P62）

  15. 课件思考题：由平原快速抵达高原（海拔超过 3000 m）时，机体会出现哪些代偿反应？为什么？ 答：呼吸系统低氧通气反应、呼吸运动增强（颈动脉体感受低氧）；循环系统心输出量↑、血液重分布、肺血管收缩；血液系统 RBC、Hb 及 2,3-DPG 增多（HIF-1 激活 EPO 等基因）；细胞层面糖酵解增强、肌红蛋白增多。目的为增加氧的摄取、运输、携带与释放，对抗 PiO2、PAO2、SaO2 下降所致的低张性缺氧。（课件 P17、P48–P50、P58）
