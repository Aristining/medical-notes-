第一部分 凝血与抗凝（生理基础）

1.1 生理性止血（hemostasis）

定义：正常情况下，小血管受损后在几分钟内自行停止流血的过程。

三个阶段（顺序常考）：

  1. 血管收缩
  2. 血小板血栓形成
  3. 血液凝固

凝血（coagulation）定义：血液由液体流态转变成凝胶固态的过程（可溶性纤维蛋白原 → 不可溶性纤维蛋白）。

机体意义：凝血激活与止血栓形成是出血时防止血液过度流失的主要机制；通过凝血与抗凝血（含纤溶）之间的平衡，使止血反应限制在损伤局部，其他部位无血栓形成，保持全身血液的流体状态。

1.2 凝血级联反应（coagulation cascade）

凝血因子特点：多为丝氨酸蛋白酶（以酶原/Proenzyme 形式存在，激活后成为酶）；另有辅因子（co-factors）；反应需要 Ca²⁺ 和磷脂。

两条启动途径 + 共同途径

途径 别名 启动因素 涉及因子
内源性途径 接触激活途径 Contact activation pathway 接触负电界面（玻璃等）、细胞外 DNA/NETs、异常蛋白聚集物（体外和病理条件下重要）；胶原暴露 Ⅻ → Ⅻa；PK/KK/HK 正反馈促进 Ⅻ 活化；Ⅻa → Ⅺ → Ⅺa → Ⅸ → Ⅸa
外源性途径 组织因子途径 Tissue factor pathway 组织因子（TF/Ⅲ）入血 Ⅶ/Ⅶa–TF–Ca²⁺ → 激活 Ⅹ 和 Ⅸ
共同途径 — — Ⅹa + Ⅴa + Ca²⁺（凝血酶原酶复合物 Prothrombinase）→ Ⅱ（凝血酶原）→ Ⅱa（凝血酶）→ Ⅰ（纤维蛋白原）→ FM → 纤维蛋白；ⅩⅢ → ⅩⅢa 交联稳定
  • Tenase 复合物 = Ⅸa + Ⅷa + Ca²⁺（激活 Ⅹ）。
  • 关键考点（课件特别强调）：因子 Ⅷ/Ⅸ（tenase）对内源和外源两条途径都必不可少——外源途径产生的 Ⅶa-TF 也依赖 Ⅸa/Ⅷa 放大信号。因此血友病 A/B 只影响 APTT 而不影响 PT，但出血严重。
  • 内源 vs 外源的区别（课件注释）：内源性所有凝血成分来自血液；外源性需要促凝因子 TF 入血。
  • 内源启动的正循环：PK（前激肽释放酶）/KK（激肽释放酶）/HK（高分子量激肽原）共同促进 Ⅻ 活化。

凝血检查：PT 与 aPTT（必考）

课件用"Y 形图"表示两条检测覆盖范围：

  • PT（凝血酶原时间，Prothrombin time）：试剂为完全 thromboplastin（磷脂 + 钙 + TF）；覆盖 FⅦ + 共同途径（Ⅹ、Ⅴ、Ⅱ、纤维蛋白原），即反映外源途径。
  • aPTT（活化部分凝血活酶时间）：试剂为部分 thromboplastin（磷脂 + 钙，无 TF）；覆盖 接触因子（HMWK、PK、Ⅻ、Ⅺ）+ Ⅸ、Ⅷ + 共同途径，即反映内源途径。
  • INR（国际标准化比值）：INR 高 → 出血风险；INR 低 → 血栓风险。

药物-检测对应关系（课件注释，易考）：

药物/状态 敏感指标 原因
华法林 / VitK 缺乏 PT 延长最明显 FⅦ 半衰期最短、下降最快
普通肝素 APTT 更敏感 体外 PT 试剂 TF 浓度高，ATⅢ 灭活效果在 PT 中不明显
低分子肝素 PT、APTT 均不敏感 主要抗 Ⅹa

记忆：具体效果由体外反应条件决定（PT 高剂量 TF；APTT 由 Ⅷ/Ⅸ/Ⅹ/Ⅱ 共同决定）。

1.3 抗凝系统（anti-coagulation system）

两大体系：

  • 细胞抗凝体系：血管内皮细胞（VEC）、单核-巨噬细胞、肝细胞。
  • 体液抗凝体系：血浆抗凝因子（AT、TFPI 等）、蛋白 C 系统、纤维蛋白溶解系统。

（1）组织因子途径抑制物 TFPI

主要由内皮细胞合成（肺、肝、肾、胎盘等组织广泛存在；巨核细胞和某些肿瘤细胞也可合成）。机制（两步，需 Ca²⁺）：

  1. TFPI 可逆地结合并抑制 Ⅹa；
  2. 与 Ca²⁺、Ⅹa 结合的 TFPI 再与 TF-Ⅶa 结合，抑制 Ⅶa 活性。

（2）抗凝血酶 Ⅲ（AT-Ⅲ）

  • 属丝氨酸蛋白酶抑制剂家族（Serpins）（同族：heparin cofactor Ⅱ、protein C inhibitor）。
  • 与 Ⅹa 或凝血酶形成复合物并灭活；也抑制 Ⅸa、Ⅻa、纤溶酶、胰蛋白酶、激肽释放酶。
  • 肝素及肝素类物质（硫酸乙酰肝素 HS）可大大加强 AT-Ⅲ 活性。
  • 血液中对凝血酶灭活作用的 60%–70% 由 AT-Ⅲ–肝素完成（数字常考）。

（3）活化蛋白 C（APC）系统 —— 凝血过程的负反馈调节

  • 凝血酶（Ⅱa）与内皮表面**血栓调节蛋白（TM）**结合后激活蛋白 C（PC）→ APC。
  • PC 同为丝氨酸蛋白酶家族，依赖维生素 K。
  • APC（在蛋白 S 辅助下）灭活 Ⅴa、Ⅷa。
  • APC 还能抑制 PAI-1 → 促进纤溶。

（4）血管内皮细胞的六大抗凝机制（简答题高频）

  1. 不表达 TF，表达 TFPI，防止局部凝血扩大化；
  2. 表达血栓调节蛋白（TM），与 PC 联合抗凝；
  3. 表达肝素样物质，与 AT-Ⅲ 结合抗凝；
  4. 产生 t-PA、u-PA 促进纤溶；
  5. 产生 PGI₂、NO 与 ADP 酶，扩张血管、抑制血小板活化聚集；
  6. **α₂-巨球蛋白（α₂M）**等其他抗凝机制（α₂M 抑制凝血酶和纤溶）。

（5）单核-巨噬细胞与肝细胞

  • 单核/巨噬细胞系统：吞噬清除 TF、免疫复合物、内毒素等促凝物质；清除活化凝血因子、纤溶酶等与抑制物形成的复合物。
  • 肝细胞：产生凝血因子和抗凝因子（AT-Ⅲ、PC、PS）；摄取并灭活已活化的凝血因子。

1.4 纤维蛋白溶解系统（纤溶，fibrinolysis）

两个阶段：① 纤溶酶原（PLG）激活生成纤溶酶（PLN）；② 纤维蛋白（Fibrin）降解产生 FDP。

组成成分表（课件原表）

类别 成员
酶原与酶 纤溶酶原（PLG）/ 纤溶酶（PLN）
纤溶激活物 组织型 t-PA；尿激酶型 u-PA（尿激酶 UK）
纤溶抑制物 纤溶酶抑制物：α₂-抗纤溶酶（α₂-AP/α₂-PI）、α₂-巨球蛋白（α₂M/α₂-MG）；纤溶酶原激活物抑制物：PAI-1、PAI-2；凝血酶活化的纤溶抑制物 TAFI
相关受体 膜联蛋白 2（annexin 2）、αMβ2 整合素、尿激酶受体（uPAR）

来源：t-PA 来自内皮细胞；u-PA 来自肾脏上皮细胞、单核巨噬细胞、内皮细胞。

纤溶酶生成的两种机制

  1. 纤维蛋白依赖的激活（主要机制）：t-PA 与 PLG 结合于纤维蛋白上的赖氨酸（Lys, K）残基；TAFI（肝细胞合成，60 kD 单链糖蛋白；被凝血酶活化为 TAFIa 后具羧肽酶活性）切除纤维蛋白羧基端赖氨酸残基 → 抑制纤溶。
  2. 受体依赖的激活：t-PA 与 PLG 结合内皮细胞表面 annexin 2；u-PA 结合白细胞表面 整合素 αMβ2 或 uPAR。

纤溶的三条激活途径

  • 外激活途径：t-PA、u-PA（内皮细胞源、分泌细胞源如尿/胆汁/乳汁唾液泪、组织源如肺前列腺子宫、血细胞源）。
  • 内激活途径：凝血系统激活产物（Ⅻa、Ⅺa、KK、凝血酶）激活 PLG。
  • 外源激活途径：溶栓药物——链激酶（SK）、尿激酶（UK）、重组 t-PA（rt-PA）。

课件注释：正常血管内纤溶主要由纤维蛋白依赖性的 t-PA 激活机制完成；HRG（富含组氨酸糖蛋白）与纤溶酶竞争结合纤维蛋白位点。

FDP 的抗凝机制（4 条，简答高频）

  1. X、Y 片段与 FM 结合，阻止 FM 聚合成可溶性纤维蛋白；
  2. Y、E 片段有抗凝血酶作用；
  3. D 片段对 FM 交联聚集有抑制作用；
  4. FDP 能抑制血小板黏附与聚集。

1.5 实验室抗凝剂（采血管考点）

  • 钙螯合剂：EDTA、枸橼酸钠、草酸钠（凝血需 Ca²⁺，螯合即抗凝）。
  • 肝素及衍生物：普通肝素（UFH）、低分子肝素（LMWH）。
  • 肝素特点对比：UFH 起效快、半衰期短、个体差异大；LMWH 更稳定、更安全。

1.6 平衡失调的三种结局

  • 凝血↑ 和/或 抗凝↓ → 血栓形成（Thrombosis）
  • 凝血↓ 和/或 抗凝↑ → 出血（Haemorrhage）
  • 凝血↑引起血管内广泛凝血，在一定条件下转变为止凝血功能障碍 → DIC

第二部分 血栓性疾病

2.1 基本概念（名词解释高频）

名词 定义
血栓形成 Thrombosis 血液成分在活体的心脏或血管内发生粘集、凝固形成病理性固体凝块，造成血管部分或完全堵塞、相应部位血供障碍的过程
血栓栓塞 Thromboembolism 血栓由形成部位脱落，随血流移动部分或全部堵塞某些血管，引起相应组织/器官缺血、缺氧、坏死（动脉血栓）及淤血、水肿（静脉血栓）
高凝状态 Hypercoagulable states 由遗传性或获得性因素引起的易发血栓的病理状态
易栓症 Thrombophilia 存在易发生血栓的遗传性或获得性缺陷，也称血栓形成倾向
静脉血栓栓塞症 VTE 血液在静脉内不正常凝结、使血管完全或不完全阻塞的静脉回流障碍性疾病；包括 深静脉血栓形成（DVT） 与 肺血栓栓塞症（PTE）

2.2 Virchow 三要素（维柯氏三要素，必考）

1856 年 Rudolf Virchow 提出（"Virchow's triad" 一词至 1950 年代才出现）。

  1. 静脉淤滞（Venous stasis）：长时间手术、长期不动（长途飞机/汽车、住院卧床）、静脉曲张。
  2. 内皮损伤（Endothelial injury）：血管穿刺、剪切应力或高血压所致损伤；接触促凝表面（细菌、异物碎片、活化血小板与白细胞膜）。
  3. 高凝状态（Hypercoagulability）：血液成分改变导致过度易凝。

案例：经济舱综合征（economy class syndrome）——长途飞行中或飞行后 48 小时内 DVT/PTE 高发，乘客与机组均可发生。

2.3 内皮损伤促血栓（机制题高频）

损伤因素：感染、自身免疫、机械性损伤、化学物质与代谢物。

正常 VEC → 抗凝；受损 VEC → 促凝，具体变化：

  1. VEC 脱落 → 血小板黏附于内皮下组织（胶原、层粘连蛋白、微纤维、vWF）并相互聚集——血栓形成的最早期反应之一；
  2. 受损 VEC 表达 TF 增多，并能结合 Ⅸa、Ⅹa，局部促凝增强；
  3. 局部 TFPI、AT-Ⅲ、TM、t-PA 减少，PAI-1 增多 → 抗凝与纤溶活性降低；
  4. 缩血管物质（内皮素 ET、TXA₂、PAF）增多，扩血管物质（PGI₂、NO）减少 → 血管强烈收缩痉挛；聚集血小板释放的 AA 代谢产物 PGG₂、PGH₂、TXA₂ 也缩血管。血管强烈收缩与痉挛是血栓形成、血管闭塞、组织缺血或梗死的重要原因。

概括式：TF↑、vWF↑、PAI > t-PA、TXA₂ > PGI₂、ET↑ → 凝血活化 + 血小板活化 + 黏附聚集 → 纤维蛋白形成。

感染时白细胞-内皮相互作用：LPS/TNF/IL-1/PAF/LTB₄/C5a 等使内皮表达 ICAM-1/ELAM-1，白细胞（CD11/CD18）黏附，释放 TF、活性氧等。

2.4 高凝状态的三类分子基础

（1）凝血因子异常

  • 遗传性：多态性，如凝血酶原 G20210A（位于凝血酶原基因 3' 非翻译区 20210 位 G→A）。
  • 获得性增多：
    • 糖尿病、肥胖、高脂血症 → 纤维蛋白原（FBG）增多（炎症及代谢异常促进凝血酶与 Fbg 生成，同时 PAI-1 升高抑制纤溶 → 促凝、低纤溶）；
    • 恶性肿瘤、吸烟酗酒 → Ⅲ（TF）增高；
    • 肾病综合征 → Ⅱ、Ⅴ、Ⅶ、Ⅷ 增高（尿中丢失 AT-Ⅲ、纤溶酶原，代偿性合成凝血因子；炎症激活凝血）。
  • 共同原因：内皮损伤、慢性炎症、血小板活化、TF 增加、纤溶抑制。

（2）抗凝因子异常

  • 数量减少或功能降低：遗传性 AT-Ⅲ 缺乏症；遗传性 PC 或 PS 缺乏/缺陷；获得性 AT-Ⅲ、HCⅡ、PC 或 PS 缺乏。
  • APC 抵抗：因子 Ⅴ Leiden 突变（R506Q）。
  • 干扰抗凝的异常物质：抗磷脂抗体（APS）、高同型半胱氨酸血症。

APC 抵抗机制：APC 正常情况下在蛋白 S 辅助下切割 Ⅴa 的 Arg506–Gly507 肽键使其失活。R506Q 突变后，突变 Ⅴa 保持促凝活性，但 APC 对其降解效率大大降低 → 高凝状态。

  • 发现史：Dalbäck 首先发现 APCR；1994 年荷兰 Leiden 大学 Bertina 发现 Ⅴ 因子 R506Q。
  • 危险度：杂合子血栓危险增加 5～10 倍，纯合子 50～100 倍——迄今发现的血栓最高危因素（数字必考）。

抗磷脂综合征（APS）：抗磷脂抗体包括狼疮抗凝物（LA，功能性实验室现象，非单一抗体）、抗心磷脂抗体（aCL）、抗 β₂ 糖蛋白 Ⅰ 抗体等。

  • 矛盾现象（考点）：抗磷脂抗体体外延长磷脂依赖性凝血时间，体内却促进血栓形成（炎症激活、促凝物质生成）。

（3）纤溶功能降低

  • 遗传性：PAI 高表达（血栓及心肌梗死）；先天性纤溶酶原异常症。
  • 获得性：VEC 损伤引起 PA 分泌减少 / PAI-1 过多；高脂血症；缺血性中风；血栓前状态。
  • 炎症的四重打击：白细胞与内皮活化/损伤；TF 等促凝物质增加；血小板活化；抗凝纤溶功能下降。

2.5 血细胞与血栓

血小板（黏附—激活—聚集三步）

  1. 黏附：GPⅠb--Ⅴ 通过受损内皮释放的 vWF 结合内皮下胶原；GPⅥ 与 GPⅠa/Ⅱa 直接结合胶原。
  2. 激活：α 颗粒与致密体释放 → ADP 释放、TXA₂ 合成、GPⅡb/Ⅲa 活化、膜磷脂（PS）暴露。
  3. 聚集：GPⅡb/Ⅲa 结合 vWF 与纤维蛋白原 → 血小板聚集。
  4. 另有免疫调节功能。

血小板促栓的三种情形：① 特殊流场下易活化（如冠心病：血管狭窄、斑块破裂）；② 生物活性物质、药物、化学物质、免疫复合物激活（如肾炎、SLE）；③ 数量增多（如原发性血小板增多症）。

TXA₂ / PGI₂ 平衡与阿司匹林（剂量考点）

磷脂 →（磷脂酶 A₂）→ 花生四烯酸 →（COX）→ PGG₂/PGH₂：

  • 经血栓素合成酶 → TXA₂：促血小板聚集、强缩血管、促血管平滑肌增殖、促动脉粥样硬化（胶原、ADP、凝血酶可刺激其生成）。
  • 经前列环素合成酶 → PGI₂：抑制血小板聚集、扩血管、抑制平滑肌增殖、抗动脉粥样硬化、保护胃黏膜、调节肾血流。
  • 小剂量阿司匹林抑制 COX-1（血小板 TXA₂）；大剂量阿司匹林同时抑制 COX-2（内皮 PGI₂）——故抗栓用小剂量。

白细胞与免疫血栓（immunothrombosis）

  • IL-1β 分泌促进血小板活化、炎症与补体激活；
  • 内皮释放含 vWF 与 P-选择素的 Weibel-Palade 小体（WPB） → 天然免疫细胞与血小板在内皮表面聚集；
  • 中性粒细胞释放 NETs（主要由 PAD4 酶调控） → 自身免疫病（狼疮、小血管炎）、血管损伤、血液凝固与血栓形成；
  • 单核细胞释放 TF 激活外源凝血级联。

白细胞促栓五机制：① VEC-白细胞相互作用使 TF 大量表达；② 释放溶酶体酶使血管通透性增高、激活凝血和补体；③ AA 代谢产物使小血管收缩、通透性增强、趋化白细胞；④ 产生超氧阴离子和羟自由基，损伤细胞、破坏 PGI₂-TXA₂ 平衡；⑤ 可塑性降低、通过毛细血管时间延长。

研究亮点：中性粒细胞 NET 形成能力受肠道菌群调控，抗生素处理可缓解脓毒症中 DIC 的发生（Zhang D, Nature 2015）。

红细胞与凝血（5 条）

  1. 心肌梗死、恶性肿瘤等循环中出现大量红细胞聚集体，影响微循环灌流；
  2. 红细胞增多、变形能力降低 → 血黏度增加 → 促进血小板黏附聚集释放；
  3. 高切变应力下红细胞释放 ADP 诱导血小板聚集；释放的血红蛋白形成自由基诱导聚集；
  4. 红细胞破坏（溶血）可激活凝血系统；
  5. 真性红细胞增多症约 1/3 患者发生血栓。

第三部分 凝血障碍与出血（出血性疾病）

3.1 定义与特征

出血性疾病（hemorrhagic/bleeding disorders）：在先天性或获得性因素作用下，机体止、凝血功能降低和（或）抗凝功能异常增强，表现为皮肤、黏膜和内脏自发性出血或轻微损伤后出血不止的疾病。

四大特征：

  1. 原因未明、反复的自发性出血或轻微损伤后过度出血/出血不止的病史；
  2. 出血程度、频度与局部损伤程度不相符合；
  3. 一般止血治疗效果差，对因治疗后疗效明显；
  4. 基本发病环节为血管和（或）血小板异常、凝血功能障碍、循环中抗凝物质增多；先天性/遗传性因素引起者多见。

三大病理生理环节：血管壁受损或结构异常；血小板量和质的异常；血浆中凝血和抗凝因子的异常。

3.2 血管壁缺陷与出血

遗传性

  • 遗传性出血性毛细血管扩张症（HHT，Rendu-Osler-Weber 综合征）：
    • 常染色体显性遗传；与 **TGFβ1/BMP9 通路（Endoglin 基因）**相关；
    • 血管先天性弹性纤维和平滑肌缺乏，小动静脉壁仅由一层 VEC 构成 → 血流冲击下扩张扭曲形成小血管瘤；
    • 口唇、鼻黏膜、头面、躯干、手背足底毛细血管扩张；
    • 轻者鼻出血/齿龈出血，重者胃肠道出血、继发性贫血。
    • 课件病例：58 岁女性，直肠间歇性排鲜血、乏力、进行性呼吸困难；自幼反复鼻出血，母亲类似；唇黏膜毛细血管扩张、甲襞病变；Hb 8.1 g/dl、MCV 72 fl；内镜见动静脉畸形与结肠毛细血管扩张；基因检测 Endoglin 突变。
  • 艾-唐综合征（Ehlers-Danlos syndrome, EDS）：10 余种类型，Ⅳ 型为血管型/出血型；先天性 Ⅲ 型胶原合成障碍 → 血管脆性和通透性增加 → 大片瘀斑/血肿，严重可致命性大动脉破裂、胃肠道穿孔。（Type 1/2 经典型，Type 3 过度活动型，Type 4 血管型。）

获得性

  • 血管壁免疫性损伤：过敏性紫癜；
  • 代谢性因素：VitC 缺乏、长期应用肾上腺皮质激素；
  • 感染性血管性紫癜；异常蛋白血症性血管性紫癜。

IgA 血管炎（2012 年改名；旧称 Henoch-Schönlein purpura / 过敏性紫癜）：

  • 侵犯皮肤和其他器官细小动脉与毛细血管的过敏性血管炎；
  • 病因：感染、药物、过敏等形成 IgA 类循环免疫复合物沉积于真皮上层毛细血管（IgA 沉积、补体活化、中性粒细胞介导的血管炎；注意"过敏"指 IgE 介导的 Ⅰ 型超敏反应背景）；
  • 四联表现：紫癜、腹痛、关节痛、肾损害，但血小板不减少（与血小板减少性紫癜鉴别的关键！）；
  • 儿童期最常见血管炎，好发 7～14 岁。

3.3 血小板缺陷

数量减少

  • 遗传性：先天性巨核细胞生成不良。
  • 获得性：生成减少（自身抗体、电离辐射、药物抑制）；破坏过多（SLE 等）；特发性血小板减少性紫癜（ITP）；微血管血栓-出血综合征（TTP、HUS）；其他（脾功能亢进）。

ITP（特发性血小板减少性紫癜）：致病因素使血小板免疫原性改变或异常表达内部抗原 → 自身免疫反应 → 血小板大量破坏；感染、药物或全身性疾病免疫反应可致继发性血小板减少。

TTP（血栓性血小板减少性紫癜）：遗传或获得性（自身免疫）因素使 vWF 裂解酶 ADAMTS13 活性下降 → vWF 多聚体形成 → 病理性血小板聚集、血栓形成 → 消耗性血小板减少及血管损伤。

  • 三联症：血小板减少、微血管病性溶血性贫血（MAHA）、中枢神经症状；
  • 五联症：+ 肾损伤 + 发热。

HUS（溶血性尿毒症综合征）：以微血管病性溶血、急性肾衰竭、血小板减少为特征，是小儿急性肾衰竭常见病因之一；1/3 以上患儿有神经系统受累。

  • 常由感染性腹泻后细菌毒素引起（志贺毒素 Shiga toxin）；
  • 血管内皮损伤是始动环节：内皮损伤 → 基底膜暴露 → 血小板激活、局部血栓 → 红细胞/血小板机械性损伤（MAHA + 血小板减少）+ 肾内微血管血栓栓塞 → GFR 急剧下降；重症肾皮质坏死 → 急性肾衰竭。

TMA（血栓性微血管病）= TTP + HUS + DIC。机制：微血管内皮损伤、微血栓形成或结构异常 → 管腔狭窄、纤维蛋白丝沉积、局部剪切力增加 → 红细胞机械性破碎 → 裂红细胞（schistocytes）+ 血管内溶血（MAHA）。

功能缺陷（数量可正常，出血特点与血小板减少相似：皮肤瘀斑、黏膜出血、术后过量出血）

功能环节 遗传性缺陷
黏附功能 遗传性巨大血小板综合征（Bernard-Soulier syndrome）；遗传性假血友病（vWF）
聚集功能 先天性血小板膜 GPⅡb/Ⅲa 缺乏或结构异常
释放功能 遗传性贮存池病、灰色血小板综合征
花生四烯酸代谢 环氧化酶或 TXA₂ 合成酶缺失
促凝功能 PF3（PS）先天性缺乏或减少

获得性血小板功能缺陷：慢性肾疾患、慢性肝病、DIC、慢性骨髓增生性疾病、异常蛋白血症等。

  • 慢性肾衰/尿毒症：代谢产物胍琥珀酸酚抑制血小板黏附、聚集、释放，TF 也减少；
  • 骨髓增生性疾病：血小板对 ADP 反应性下降，TF 减少；
  • 长期大剂量阿司匹林、吲哚美辛等 NSAIDs：抑制血小板环氧化酶 → 聚集性降低。

3.4 凝血因子缺陷

类型 疾病
遗传性 血友病 A：Ⅷ 缺乏；血友病 B：Ⅸ 缺乏；血管性假血友病（vWD）：vWF 缺乏；纤维蛋白原（Fbg）缺乏

血友病（hemophilia）要点

  • 性联隐性遗传，基因位于 X 染色体（FⅧ 基因位于 Xq28，长 186 kb）；女性传递、男性发病；发病率 1/5000～1/10000；
  • 正常男性 × 传递者女性 → 子女中男性半数患者、女性半数传递者；
  • 约 30% 无家族史（基因突变所致）；
  • FⅧ 基因突变类型：大片段缺失占半数以上；错义突变在轻-中型占 86%；倒转在重型占 50%；遗传稳定、可产前诊断；
  • FⅧ:C 活性与临床表现相关，是血友病 A 分型依据。

血友病 A 分型表：

程度 FⅧ:C 活性 主要临床表现

临床表现：

  • 出血与生俱来、伴随终身；常为软组织或深部肌肉内血肿；
  • 致残性：负重关节反复出血（血友病关节）——急性关节积血"红肿热痛"；慢性血友病关节炎可致无法站立；关节残疾发生率高达 77.7%；
  • 血肿压迫：周围神经（疼痛、麻木、肌肉萎缩）；血管（缺血坏死或淤血水肿）；输尿管（排尿障碍）；腹膜后（麻痹性肠梗阻）；口腔底/喉/颈部（呼吸困难甚至窒息）。

关节病变进程：急性出血 → 滑膜内/关节内出血 → 慢性滑膜炎（滑膜增厚、变脆呈绒毛状、炎症增生）→ 更易频繁出血 → 进展性关节病变（表面侵蚀、骨囊肿、关节腔狭窄 → 关节腔完全消失）。

诊断与治疗：

  • 中国注册患者 11,108 名，远低于实际患病人数（漏诊、诊断资源不足、登记不完整）；接受预防治疗者不足 10%；人均 FⅧ 用量全球较低。
  • 预防治疗：规律输入凝血因子，使血浆因子长期维持一定水平，减少反复出血与致残。
    • 初级预防：确诊后、第 2 次关节出血前、年龄 <3 岁、无关节病变证据时开始；
    • 次级预防：≥2 次关节出血后、体检和影像学未发现关节病变前开始；
    • 三级预防：关节病变已形成后开始。
    • 早期预防治疗可明显减少每年关节出血 87%。
  • 治疗进展：
    1. FⅧ 补充：终身用药、费用与注射负担高、约 30% 病人产生中和抗体；
    2. FⅧ 类似物：FⅧ-Fc 融合蛋白、翻译后修饰优化；
    3. 抑制抗凝途径：TFPI 抑制剂；
    4. FⅨ-FⅩ 双特异性抗体：艾美赛珠单抗（emicizumab，first-in-class）——2026 年 Lasker 奖（研发者 Takehisa Kitazawa，2023 Ernest Beutler 奖）。

课件病例 1（轻型血友病 A 漏诊）：男，26 岁，拔阻生牙后压迫 30 分钟回家，创口活动性渗血 3 天；幼时腿部外伤出血不止；APTT 58 秒明显延长；因子 Ⅷ 促凝成分缺乏 → 血友病 A（轻型）；予冷沉淀每日两次后伤口愈合。（提示：APTT 单独延长 + 出血史 → 想内源途径因子缺乏。）

课件病例 2（维生素 K 依赖性凝血因子缺乏症 VKCFD）：女，12 岁，长期腹泻史，鼻出血不止 21 天；APTT、PT、CT 均延长，Ⅱ、Ⅶ、Ⅸ、Ⅹ 因子均减少，FⅨ 基因正常、无自身抗体（APTT 82.7 s、PT 120 s、CT 75 h）。→ 腹泻致脂溶性 VitK 吸收障碍 → 四种 VitK 依赖因子同时减少（机制：VitK 参与维生素 K 环氧化物还原酶循环）。

第四部分 弥散性血管内凝血（DIC）

4.1 定义与概述

DIC 是一种复杂的全身性血栓-出血性疾病（thrombo-hemorrhagic disorder）：血管内纤维蛋白生成、促凝物质与血小板消耗、继发性纤溶亢进；临床以血管内凝血与出血为特征。

动态过程：

促凝物质入血 → 凝血↑ / 纤溶↓ → 广泛性血栓形成（高凝状态）
        → 凝血因子与血小板消耗 → 凝血↓ / 纤溶↑（低凝状态）
        → 继发性纤溶亢进（FDP 形成）→ 全身性出血综合征

4.3 发病机制

（一）广泛微血栓形成的机制

1. 凝血系统的异常激活

  • 组织损伤：广泛组织损伤、妊娠并发症、肿瘤 → TF 表达、入血 → 外源性凝血途径异常激活 → 微血栓形成。
    • 组织 TF 活性（μ/mg）：肝 10、肌肉 20、脑 50、肺 50、胎盘蜕膜 2000（解释产科并发症为何极易致 DIC）。
  • 血管内皮损伤：感染、内毒素、缺氧、酸中毒 → VEC 损伤 → TF 表达 + 内皮下胶原暴露 → 血小板黏附聚集释放 + 单核/巨噬/中性粒细胞激活（细胞因子、补体、活性氧）→ 微血栓形成。
  • 血细胞受损：血小板激活（黏附、激活、聚集、促凝）；白细胞激活（细胞因子、溶酶体酶、NETs）；红细胞溶血（ADP 等）。
  • 其他促凝物质：肿瘤（癌促凝物）、出血性胰腺炎（胰蛋白酶）、毒蛇咬伤（外源毒素）、羊水栓塞。

2. 抗凝功能减弱：血浆 AT-Ⅲ 水平明显下降；PC 系统显著受抑；TFPI 的负调控受抑制（内皮细胞失去正常抗凝调控功能）。

3. 纤溶功能失调（降低）：VEC 损伤 → 促进 PC 活化能力降低 → 对 PAI-1 的抑制减弱；t-PA 分泌减少、PAI-1 增多 → 局部纤溶活性明显降低；凝血增强、Fbn 生成过多使纤溶相对降低。

微血栓形成链条：炎症介质/细胞因子 → VEC 与白细胞活化 → TF 表达↑、抗凝减弱、PAI-1 抑制纤溶 → 血管内纤维蛋白（Fn）形成 + Fn 清除不足 → Fn 沉积、血栓形成。

（二）止凝血障碍的机制

1. 凝血物质大量消耗（凝血因子 + 血小板）。

2. 继发性纤溶功能增强（三条途径）：

  1. 凝血系统激活产物（Ⅱa、Ⅺa、KK、Ⅻa）增多 → 激活 PLG → PLN → 降解 Fbg、Fbn 及 Ⅱ、Ⅷ、Ⅹ、Ⅺ → 继发性低凝状态；
  2. VEC 释放 t-PA；PK 与 VEC 膜上 HMW-K 结合 → KK → 单链 u-PA（tcu-PA）→ 激活 PLG；
  3. 凝血酶与 VEC 表面 TM 结合 → APC 系统活化。

4.4 诱发（促进）因素（5 条）

  1. 单核巨噬细胞功能受损：其清除促凝物质、活化凝血因子复合物、Fbn/FM/FDP 复合物、补体及细胞碎片的能力下降（长期大量糖皮质激素、反复感染、严重肝病）；
  2. 严重肝功能障碍：急性肝坏死释放 TF 和溶酶体酶；肝硬化晚期内毒素入循环；合成凝血/抗凝因子能力降低，凝血-抗凝平衡处于很低水平（rebalanced hemostasis 再平衡止血状态），一旦促凝物质入血或血管损伤极易血栓或出血；灭活 Ⅺa、Ⅸa、Ⅹa 能力下降；
  3. 血液高凝状态：原发性（遗传性 AT-Ⅲ/PC/PS 缺乏、APC 抵抗）；继发性（肾病综合征、恶性肿瘤尤其转移时、白血病、妊娠中毒症）；生理性（高龄、妊娠后期：凝血因子增加、抗凝下降、纤溶抑制、静脉淤滞——雌激素促 Fbg 合成、胎盘促 PAI-2 合成、PS 下降）；酸中毒使 VEC 受损、肝素抗凝活性减弱、凝血活性和血小板聚集性增高（严重缺氧时高凝的重要原因）；
  4. 微循环障碍（休克）：血流缓慢、血黏度增高、淤滞；VEC 受损；活化凝血因子局部积聚不易清除；肝肾功能降低无法清除活化因子与纤溶产物；血管舒缩障碍利于 Fbn 沉着（呼应 Virchow 三要素）；
  5. 机体纤溶系统功能状态：纤溶功能降低利于 DIC（高龄、吸烟、妊娠后期、糖尿病；不恰当使用 **EACA（氨基己酸）或 PAMBA（对羧基苄胺）**过度抑制纤溶）。

4.5 主要临床特征（四大表征 + 发生率）

临床表现 发生率 特征
出血 84–96% 出血突然发生
微循环衰竭（休克） 30–80% 突然、早期即出现
多器官功能衰竭（MODS） 50% 2 个及以上器官衰竭

（1）出血机制（4 条）

  1. 广泛微血栓形成使凝血因子大量消耗、血小板明显减少；
  2. 继发性纤溶增强产生大量纤溶酶，既降解 Fbn/Fbg，又水解各种凝血因子；
  3. FDP 具有强大抗凝作用；
  4. 多种因素使微血管壁受损。

（约 80–90% 患者以出血为初发症状：紫癜、血泡、皮下血肿、采血部位出血、创面出血等。）

（2）休克机制（5 条）

  1. 微血栓形成 → 回心血量减少；
  2. 严重出血 → 血容量降低；
  3. 激肽和补体系统激活 → 激肽、组胺降低外周阻力、血压下降；
  4. FDP 小片段 A、B、C 增强激肽和组胺的扩血管、增高通透性作用；
  5. 心内微血栓及肺内广泛微血栓阻塞 → 肺动脉高压、心肌损伤、心脏负担加重 → 心功能降低（心源性休克）。

（3）MODS 机制

器官内广泛微血栓 → 缺血、缺氧、代谢功能障碍 → 缺血坏死与脏器衰竭；另有器官系统间相互影响及原发病本身的变化。

器官 临床表现
肺 肺泡损伤、ARDS
肾 皮质坏死、肾功能衰竭
消化道 恶心、呕吐、腹泻、出血
肝 黄疸、肝功能衰竭
心 收缩力降低、肺动脉高压
神经 神志不清、嗜睡、昏迷

（4）微血管病性溶血性贫血（MAHA）

慢性/亚急性 DIC 时微血管内先形成 Fbn 细丝而血流未完全阻断；红细胞通过 Fbn 细丝或 VEC 裂隙时受血流冲击挤压 → 机械性损伤 → 裂体细胞（schistocyte）；碎片脆性高、易破裂溶血 → 贫血。 注意：裂红细胞并非仅见于 DIC（TTP、HUS 亦可见）。

三期文字要点（课件原文整理）：

  1. 高凝期：可有严重程度不同的微血栓形成；部分患者无明显临床症状（急性 DIC 该期短、不易发现）。实验检查：凝血和复钙时间缩短、血小板粘附性增高。
  2. 消耗性低凝期：大量凝血因子消耗和血小板减少；有严重程度不等的出血，可有休克或某脏器功能障碍。实验检查：凝血和复钙时间明显延长、血小板明显减少、血浆 Fbg 含量减少；部分病人纤溶指标异常。
  3. 继发性纤溶亢进期：纤溶系统激活、纤溶亢进；多有严重出血，严重者休克及 MODS。实验检查：除前期指标外，主要有纤溶活性增强的证据：
    • ① FDP 增多，血浆中出现 D-二聚体；
    • ② 凝血块或优球蛋白溶解时间缩短；
    • ③ 凝血酶时间延长（反映 FDP 的抗凝作用）；
    • ④ 3P 试验阳性；纤溶过强时 3P 反可转阴。

两个关键实验室指标

D-二聚体试验：

  • 目的：判断微血栓的存在及纤溶活性增强；
  • D-二聚体 = 纤溶酶分解稳定（交联）纤维蛋白的产物；是微血栓形成的标志性指标、反映继发性纤溶亢进的重要指标；
  • 原理对照：纤溶酶分解 Fbg → 产物不含 D-二聚体；分解可溶性 FM → 不含 D-二聚体；分解交联的纤维蛋白（微血栓） → 产生 D-二聚体。

血浆鱼精蛋白副凝试验（3P 试验）：

  • 凝血反应产生 FM；继发性纤溶激活产生 FDP 的 X 片段；二者结合成可溶性纤维蛋白单体复合物（SFMC）；
  • 加入硫酸鱼精蛋白后 FM 与 X 片段分离，FM 自行聚合出现沉淀物 → 3P 阳性；
  • 意义：标志凝血与纤溶同时发生；早、晚期都可能阴性（早期纤溶未启动、晚期纤溶过强 FM 被降解）。

4.7 DIC 分型

  1. 按发生快慢：急性 DIC、亚急性 DIC、慢性 DIC；
  2. 按代偿情况：失代偿型、代偿型、过度代偿型（不常见）。

4.8 DIC 治疗（6 条）

  1. 早期治疗；
  2. 积极防治原发病；
  3. 抗凝治疗：肿瘤相关慢性 DIC 使用 AT-Ⅲ、肝素或其他新型抗凝剂阻断凝血恶性循环——DIC 主要治疗手段之一；
  4. 脏器功能的维持和保护；
  5. 补充凝血物质：产科并发症导致的 DIC 通常需补充纤维蛋白原；
  6. 抗纤溶治疗：不能常规使用抗纤溶药物；仅当有明显纤溶亢进和出血倾向时考虑。

附二 课件思考题与病例分析

课件思考题（slide 127）：

  1. 分析 DIC 时出血的原因和机制，并说明与 DIC 发展过程中所出现的某些病理变化之间的关系。
  2. 论述内毒素如何通过对血管内皮细胞损伤导致 DIC 发生。
  3. 试论述 DIC 时凝血功能亢进与继发性纤溶功能增强之间的转化关系。
  4. 影响 DIC 发展的因素。

答题要点提示：第 1 题用"4.5(1) 出血机制 4 条"；第 2 题用"2.3 内皮损伤 + 4.3 凝血激活(2)"，串联 LPS→单核/内皮活化→TF 表达、细胞因子/补体/活性氧、胶原暴露→血小板活化；第 3 题用"4.1 动态过程 + 4.3(二)2 继发纤溶三途径"，强调凝血酶既是促凝核心又是纤溶/APC 激活的开关；第 4 题用"4.4 诱发因素 5 条"。

课件病例（slide 126）示范分析：女，29 岁，妊娠 8 个多月，胎盘早期剥离急诊入院；昏迷、牙关紧闭、手足强直；结膜出血斑、多处瘀点瘀斑、消化道出血、血尿；BP 80/50 mmHg、脉搏细数、尿少。化验：Hb 70 g/L、RBC 2.7×10¹²/L、外周血见裂体细胞；血小板 85×10⁹/L（4 h 后 75×10⁹/L）；纤维蛋白原 1.78 g/L（后 1.6 g/L）；PT 20.9 s 延长；3P 阳性；尿蛋白+++、RBC++。诊断：胎盘早剥、DIC、休克。

  • DIC 证据：多部位自发出血 + 休克；血小板进行性下降；Fbg 进行性下降；PT 延长；3P 阳性；裂体细胞（MAHA）。
  • 发病机制：胎盘早剥 → 富含 TF 的胎盘蜕膜组织损伤、TF 大量入血 → 外源凝血途径异常激活 → 广泛微血栓；休克/缺氧/酸中毒 → VEC 损伤进一步促凝；消耗 + 继发纤溶 → 低凝与出血。
  • 诱发因素：妊娠后期生理性高凝（凝血因子↑、抗凝↓、纤溶抑制、静脉淤滞）；休克致微循环障碍；单核巨噬清除功能相对不足。
  • 分期：已进入消耗性低凝期并向继发性纤溶亢进期过渡（Fbg 与血小板明显消耗、PT 延长、3P 阳性、广泛出血）。

附三 历史故事线（帮助记忆的"钩子"）

  • 发霉的甜苜蓿（sweet clover disease）：1920 年代牛群出血病 → Frank Schofield 发现霉变草木樨致病 → Karl Link（威斯康星大学）分离出双香豆素（Dicoumarol）→ 改造为华法林：先作鼠药，1955 年用于心肌梗死后的艾森豪威尔总统，从此"从鼠药到抗凝药"，并被 WHO 列为基本药物。机制：抑制维生素 K 环氧化物还原酶 → Ⅱ、Ⅶ、Ⅸ、Ⅹ 减少（1943 年 Dam 与 Doisy 因维生素 K 研究获诺奖）。
  • 肝素的发现：1916 年霍普金斯医学院 Howell 布置学生 McLean 寻找促凝物质，结果肝提取物反而抗凝；1918 年 Howell 从犬肝分离出该物质，因源自肝脏（希腊文 hepar）命名 heparin；今主要原料为猪小肠黏膜；本质为硫酸酯化的糖胺聚糖/粘多糖。
  • "皇家病"血友病：维多利亚女王家族通过联姻把血友病带入德、俄、西等王室；沙皇尼古拉二世之子阿列克谢患血友病，"妖僧"拉斯普京因"治愈"表象获宠干政，间接加速罗曼诺夫王朝覆灭（1918 年全家被杀）——"血友病和近代史的终章"。
  • APCR 的发现：瑞典 Dalbäck 发现家系性"对 APC 抗凝反应差"；1994 年 Leiden 大学 Bertina 定位 FⅤ R506Q。
  • 艾美赛珠单抗：从"一万种行不通的方法"中诞生的 FⅨ-FⅩ 双特异性抗体，获 2026 年 Lasker 奖。
