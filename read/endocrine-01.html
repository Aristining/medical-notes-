一、内分泌系统总论

1.1 内分泌腺的组成

内分泌系统由两部分组成：

  • 内分泌腺：如垂体、甲状腺、甲状旁腺、肾上腺、松果体等，为独立的器官。
  • 散在内分泌细胞：分散分布于其他器官中，如胃肠道内分泌细胞、胰岛细胞等。

1.2 内分泌腺的共同特征

  • 腺细胞排列成索状、网状、团块状或滤泡状
  • 无导管
  • 分泌物为激素（hormone）
  • 具有丰富的毛细血管（血窦）

1.3 腺细胞分类

类型 超微结构特征 分泌激素类型
分泌含氮激素细胞 发达的高尔基体、粗面内质网（RER）、膜被颗粒 含氮激素（蛋白质类、胺类）
分泌类固醇激素细胞 丰富的滑面内质网（SER）、管状嵴线粒体、脂滴 类固醇激素

线粒体嵴的区分：分泌含氮激素细胞的线粒体为板状嵴；分泌类固醇激素细胞的线粒体为管状嵴。

二、垂体（Pituitary / Hypophysis）

2.1 垂体的概述

垂体位于颅底蝶鞍的垂体窝中，分为两大部分：

腺垂体（Adenohypophysis）：

  • 远侧部（Pars distalis）—— 前叶的主要部分
  • 结节部（Pars tuberalis）
  • 中间部（Pars intermedia）

神经垂体（Neurohypophysis）：

  • 神经部（Pars nervosa）—— 后叶的主要部分
  • 漏斗柄（Infundibular stalk）
  • 正中隆起（Median eminence）

漏斗柄 + 正中隆起 = 漏斗（Infundibulum）

解剖学上分为前叶（腺垂体远侧部 + 中间部 + 结节部）和后叶（神经垂体）。组织学上更常按腺垂体和神经垂体分类。

2.2 腺垂体的结构

2.2.1 远侧部（Pars distalis）

远侧部是腺垂体的主要部分，HE染色后颜色最深。腺细胞集合成团索状。

根据HE染色后胞质着色特征，远侧部细胞分为三类：

细胞类型 占比 胞质特征 细分
嫌色细胞（Chromophobe） ~50% 体积小，胞质着色浅 —
嗜酸性细胞（Acidophil） ~40% 体积较大，胞质嗜酸性（红色） 生长激素细胞（STH）、催乳激素细胞（PRL）
嗜碱性细胞（Basophil） ~10% 体积最大，胞质嗜碱性（蓝色） 促甲状腺激素细胞（TSH）、促性腺激素细胞（FSH/LH）、促肾上腺皮质激素细胞（ACTH/LPH）

嫌色细胞的本质：电镜下观察，嫌色细胞胞质中膜被颗粒极少，有观点认为嫌色细胞是嗜色细胞脱颗粒后的状态。

嗜色细胞是嗜酸性细胞和嗜碱性细胞的总称。

免疫组化可通过激素特异性抗体区分不同的内分泌细胞。

2.2.2 中间部（Pars intermedia）

位于腺垂体远侧部和神经垂体神经部之间的狭窄区域。

  • 主要细胞：嫌色细胞
  • 含大小不等的滤泡
  • 少量嗜碱性细胞为黑素细胞刺激素细胞，分泌黑素细胞刺激素（MSH）

2.2.3 结节部（Pars tuberalis）

包绕在神经垂体漏斗外侧。

  • 细胞组成与远侧部相似：嗜酸性细胞、嗜碱性细胞、嫌色细胞
  • 有观点认为结节部细胞具有内分泌功能，是对远侧部功能的补充

2.3 神经垂体的结构

神经垂体由大量的无髓神经纤维和神经胶质细胞组成，含丰富的毛细血管。

神经部的三种主要结构：

结构 说明
垂体细胞（Pituicyte） 神经胶质细胞，细胞核清晰但轮廓不清
无髓神经纤维（Unmyelinated axons） 神经元的突起，与下丘脑神经元胞体相连
赫令体（Herring body） 光镜下粉红色均质团块，为无髓神经纤维末端膨大，内含膜被颗粒（ADH和OT）

赫令体的数量变化：ADH和OT的释放是脉冲式的。激素已释放时，赫令体数量减少、体积变小；激素储存时，赫令体数量增多、体积增大。

2.4 垂体的发生

腺垂体和神经垂体的胚胎起源不同，这是两者在结构和功能上差异巨大的根本原因。

部分 胚胎起源 发生过程
腺垂体 原始口腔（口凹）顶部外胚层 人胚4周 → 原始口腔顶部外胚层向背侧隆起形成拉特克囊（Rathke's pouch） → 囊细胞增生、囊腔消失、与口腔连接退化 → 形成腺垂体
神经垂体 神经管头端（间脑底部/第3脑室底部） 间脑底部向腹侧突出呈漏斗状 → 形成神经部原基 → 与拉特克囊后壁相连 → 形成神经部、正中隆起和漏斗柄

2.5 垂体门脉系统（Hypothalamohypophyseal Portal System）

垂体门脉系统是连接下丘脑与垂体的特殊血管系统。

门静脉的定义：两端均连有毛细血管的小静脉。

组成（血流方向）：

垂体上动脉 → 初级毛细血管网（漏斗部）→ 垂体门微静脉 → 次级毛细血管网（远侧部）→ 垂体静脉
  • 初级毛细血管网：位于神经垂体漏斗部
  • 垂体门微静脉：连接初级和次级毛细血管网
  • 次级毛细血管网：位于腺垂体远侧部

垂体门脉系统的功能：将下丘脑弓状核产生的释放激素（RH）和释放抑制激素（RIH）运输至腺垂体远侧部，调节远侧部内分泌细胞的功能。

2.6 下丘脑与垂体的关系

2.6.1 下丘脑概述

  • 属于间脑，位于丘脑腹下方
  • 构成第3脑室侧壁和底部
  • 重要核团：弓状核、视上核、室旁核
  • 神经元分为神经分泌型和非神经分泌型

2.6.2 下丘脑与腺垂体的关系（功能联系）

弓状核（小神经内分泌细胞）分泌两类激素：

类别 激素 缩写
释放激素（RH） 生长激素释放激素 SRH
催乳激素释放激素 PRH
促甲状腺激素释放激素 TRH
促性腺激素释放激素 GnRH
促肾上腺皮质激素释放激素 CRH
黑素细胞刺激素释放激素 MSRH
释放抑制激素（RIH） 生长抑素 SOM
催乳激素抑制激素 PIH
黑素细胞刺激素抑制激素 MSIH

运输路径：弓状核 → 释放激素/抑制激素 → 漏斗部初级毛细血管网 → 垂体门微静脉 → 远侧部次级毛细血管网 → 作用于远侧部相应的嗜酸性/嗜碱性细胞。

关键结论：下丘脑与腺垂体在结构上没有直接联系，两者之间的关系体现在功能上——下丘脑通过垂体门脉系统对腺垂体的内分泌活动进行调节。

2.6.3 下丘脑与神经垂体的关系（结构+功能联系）

视上核和室旁核（大神经内分泌细胞）：

  • 合成抗利尿激素（ADH）和催产素（OT）
  • 均为含氮类激素

运输路径：视上核/室旁核神经元 → 轴突（即神经垂体内的无髓神经纤维）→ 轴突运输 → 神经纤维末端膨大（赫令体）→ 释放ADH和OT → 入血。

关键结论：下丘脑与神经垂体在结构上直接相连（神经元突起构成神经垂体的无髓神经纤维），在功能上也密切相关（下丘脑合成的激素直接运输到神经垂体释放入血）。

三、甲状腺（Thyroid）

3.1 甲状腺的结构概述

甲状腺位于颈前部，由左右两叶和中间的峡部组成，为实质性器官。

  • 被膜：结缔组织
  • 实质：由数百万个甲状腺滤泡和滤泡间结缔组织组成

甲状腺滤泡的结构：

  • 滤泡壁：由滤泡上皮细胞围成，其间有少量滤泡旁细胞
  • 滤泡腔：含嗜酸性胶状物质，主要成分为碘化的甲状腺球蛋白（甲状腺激素的储存形式/前体）

3.2 滤泡上皮细胞（Follicular Epithelial Cell）

特征 描述
光镜 细胞核圆，位于细胞正中；胞质弱嗜碱性
电镜 微绒毛（游离面）、发达的粗面内质网、高尔基体、膜被颗粒、紧密连接
功能 合成并分泌甲状腺激素（T3、T4）

细胞形态与功能状态的关系：

  • 功能活跃时 → 细胞增高呈柱状，滤泡腔内空泡增多（碘化甲状腺球蛋白被大量吸收）
  • 功能低下时 → 细胞呈矮立方或扁平状
  • 正常情况下 → 细胞呈立方形

临床联系——甲亢：甲亢患者滤泡上皮细胞呈高柱状，滤泡腔内大量空泡，提示合成功能亢进。

3.3 滤泡旁细胞（Parafollicular Cell / C细胞）

特征 描述
光镜 体积大而圆，染色浅；位于滤泡壁上或滤泡间结缔组织内
银染 胞质内含嗜银颗粒（银盐染色呈黑色）
电镜 发达的粗面内质网、高尔基体、膜被颗粒 → 属于分泌含氮激素细胞

4.2 主细胞（Parathyroid Chief Cell）

特征 描述
光镜 体积较小，多边形，细胞核圆
电镜 线粒体、粗面内质网、高尔基体、分泌颗粒丰富 → 属于分泌含氮激素细胞
功能 合成甲状旁腺激素（PTH）

PTH的功能：

  • 激活破骨细胞的破骨功能 → 骨质溶解 → 升高血钙
  • 刺激小肠对Ca²⁺的吸收
  • 刺激肾小管对Ca²⁺的吸收

临床意义：甲状腺切除手术时需尽量保留甲状旁腺，否则缺乏PTH可能导致血钙浓度不稳定，严重时威胁生命。

4.3 嗜酸性细胞（Oxyphil）

特征 描述
光镜 体积较大，胞质含嗜酸性颗粒
出现时间 青春期之后才出现，随年龄增加数量增多
功能 不详

注意区分：甲状旁腺的嗜酸性细胞（Oxyphil）与腺垂体的嗜酸性细胞（Acidophil）名称不同、结构不同、功能完全不同，切勿混淆。

五、甲状腺和甲状旁腺的发生

5.1 甲状腺的发生

  • 起源：与第1对咽囊平齐的原始咽腹侧正中间内胚层
  • 过程：原始咽底正中内胚层 → 向腹侧突出 → 以甲状舌管与原始咽相连 → 沿颈部正中向尾侧生长 → 甲状舌管退化消失 → 人胚10-12周甲状腺滤泡出现并开始分泌甲状腺激素

5.2 甲状旁腺的发生

咽囊 腹侧 背侧
第3对咽囊 胸腺原基 下甲状旁腺
第4对咽囊 退化 上甲状旁腺
第5对咽囊 — 滤泡旁细胞？（有争议，另一观点认为来源于神经嵴）

常见畸形：第3对咽囊背侧形成的下甲状旁腺与腹侧形成的胸腺一起迁移，可能导致甲状旁腺位于胸腔内。

5.3 胚胎起源总结

  • 甲状腺滤泡上皮细胞 → 内胚层（原始咽）
  • 甲状旁腺细胞 → 内胚层（第3、4对咽囊）
  • 滤泡旁细胞 → 内胚层（第5对咽囊？）或外胚层（神经嵴？）

6.2 肾上腺皮质（Adrenal Cortex）

肾上腺皮质分为三条带，均合成类固醇激素：

带名 占比 细胞特征 分泌激素
球状带（Zona glomerulosa） 10-15% 细胞较小，排列成团块状 盐皮质激素（醛固酮）→ 促进肾小管保钠排钾
束状带（Zona fasciculata） ~78% 细胞较大，着色浅（脂滴丰富），排列成细胞束 糖皮质激素（皮质醇、皮质酮）→ 促进糖异生
网状带（Zona reticularis） 7-10% 细胞较小，着色较深，排列成网格状 雄激素

束状带着色浅的原因：类固醇激素的合成原料为脂滴中的胆固醇。束状带细胞内含大量脂滴，HE染色过程中脂滴被溶解，故胞质着色浅。

临床联系：儿童性早熟或女性出现男性第二性征时，需考虑肾上腺皮质网状带增生的可能。

肾上腺皮质细胞的超微结构（分泌类固醇激素细胞的典型特征）：

  • 管状嵴线粒体
  • 丰富的滑面内质网（SER）
  • 大量脂滴

6.3 肾上腺髓质（Adrenal Medulla）

髓质内有三种重要结构：

（1）嗜铬细胞（Chromaffin Cells）

即髓质细胞，为肾上腺髓质的主要功能细胞。

特征 描述
光镜 多边形，胞质嗜碱性；铬盐染色后可见嗜铬颗粒（黄褐色）
电镜 膜被颗粒 → 属于分泌含氮激素细胞
功能 合成肾上腺素（大部分细胞）和去甲肾上腺素（少部分细胞）

膜被颗粒的形态差异：

  • 含肾上腺素的颗粒：电子密度低（颜色浅）、体积小
  • 含去甲肾上腺素的颗粒：电子密度高（颜色深）、体积大

（2）交感神经节细胞

  • 位于髓质内的神经节中
  • 多个神经元聚集构成神经节
  • 神经元特征：核大、染色浅、核仁明显、胞质染色深（含尼氏体）
  • 周围有卫星细胞（被囊细胞），起保护、营养、支持和绝缘作用
  • 功能：释放乙酰胆碱 → 作用于嗜铬细胞 → 调节肾上腺素和去甲肾上腺素的合成

（3）中央静脉（Central Vein）

  • 位于肾上腺髓质
  • 管壁含纵行平滑肌
  • 髓质血窦汇总至中央静脉 → 肾上腺静脉

6.4 肾上腺的血供

肾上腺的血液供应非常丰富，形成两套路径：

肾上腺动脉 → 被膜小动脉
  ├─ 大部分 → 皮质血窦 → 髓质血窦 → 中央静脉 → 肾上腺静脉
  └─ 少数 → 越过皮质 → 直接到达髓质血窦 → 中央静脉 → 肾上腺静脉

皮质与髓质的功能联系：大部分血液先经过皮质再到达髓质，因此髓质中富含皮质激素。例如，束状带产生的糖皮质激素可激活髓质细胞内的N-甲基转移酶，使去甲肾上腺素转变为肾上腺素——这是髓质中肾上腺素多于去甲肾上腺素的原因。

6.5 肾上腺的发生

部分 胚胎起源 发生时间
皮质 中胚层（生殖腺嵴附近） 人胚第6周开始；先形成原发性皮质（后退化），第15周形成继发性皮质
髓质 外胚层（神经嵴细胞） 人胚第6周开始；神经嵴细胞经背肠系膜迁移至皮质中央并内陷

皮质发育时间线：

  • 出生时：已出现球状带和束状带
  • 3岁时：网状带出现，三条带几乎发育完全

髓质发育：神经嵴细胞 → 迁移至皮质内侧 → 形成髓质（发生时间晚于皮质）
